# AI 场景道具叙事（Prop Storytelling — Objects as Meaning-Carriers）

> 本页为 AI 场景道具叙事：道具作为意义载体（揭示角色/推进剧情/象征主题）、道具母题（Motif）设计、麦高芬（MacGuffin）、生产设计整合（色彩/质感/位置强化氛围）。知识本体来自 2026 道具叙事指南（Fiveable/FasterCapital/Cinevisionary/Beverlyboy）。AI 应用面向 DirectorX：场景设计（衔接 165 环境、169 服装、203 时代、208 关系、209 对应）。
> 来源：Fiveable「Prop Significance」、Cinevisionary「Storytelling Through Objects」、FasterCapital「Prop Design: Crafting Objects that Tell a Story」、Beverlyboy「How Do Props Carry Story」。

## 概述

**核心断言**：道具 = **意义载体**——揭示角色（身份/过往/状态）、推进剧情（驱动/转折）、象征主题（钥匙/戒指/护符）。**道具母题（Motif）跨场景复现**是叙事强化器（衔接 203：道具的年代锚；169：道具一致性）。

## 核心概念

### 道具三功能

```
① 角色延伸：揭示性格/地位/背景
② 叙事功能：驱动/转折剧情（麦高芬）
③ 象征主题：承载主题（母题复现）
```

### 道具母题设计（Motif）

关键道具**跨场景复现**（同一物件不同状态）→ 主题强化（衔接 203：道具状态记录兼叙事；169：状态表）。

## 技巧与示例

### 道具叙事工作流（AI 映射）

```text
叙事分析（道具承担什么功能）→ 道具设计
  → 母题规划（跨场景复现/状态变化）
  → 生成（道具一致性锁定 169）
  → 检查（状态/位置/象征是否到位）
```

### 道具状态叙事

同一道具状态变化 = 叙事进程：完好的照片 → 破损的照片（关系破裂）——**道具状态是关系弧的物证**（衔接 208 空间关系弧）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 道具纯装饰 | 叙事浪费 | 功能设计 |
| 母题不复现 | 主题弱 | 跨场景复现 |
| 状态不记录 | 矛盾 | 状态表（169） |
| 时代错物 | 出戏 | 年代锚（203） |
| 道具与角色脱节 | 无延伸 | 角色延伸 |

## 工作流应用（AI 映射）

场景设计（衔接 165/169/203/208）：

```text
叙事分析 → 道具功能设计 → 母题规划
  → 生成（一致性 169）→ 状态检查
  → 与关系弧联动（208）→ 交付
```

**DirectorX 纪律**：道具是意义载体非装饰；母题跨场景复现；状态变化即叙事；年代锚防出戏。
