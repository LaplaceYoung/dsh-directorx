# 色彩心理学与品牌视觉（Color Psychology & Brand Visuals）

> 本页是 DirectorX 色彩心理学手册：色彩=创作信号而非固定含义、品牌色情绪表、三分调色板工作流、字幕可读性规则、分格式用色（口播/产品/教学/广告）、色彩节奏与转化。与 36 调色 / 45 风格统一 / 43 竖屏可读性衔接。
> 来源：CapCut 视频色彩心理学指南、Jasmine Directory 2026 数字广告、Build Grow Scale 数据 vs 神话、Kelpi Meta 广告用色。

## 概述

**色彩应帮助观众更快理解视频**：感受什么、看哪里、哪个动作重要。在短视频里，最强的色彩选择=**情绪、可读性、品牌一致、字幕无障碍**四者的平衡。

**核心断言**：
1. 色彩心理学不是给每种颜色分配固定含义——而是**把色彩当创作信号**：15 秒产品演示里亮红价格标签制造紧迫；教程里冷静的蓝/绿背景让指令更容易跟；
2. 每个色彩选择都应该**有一份工作**（引导视线/制造层次/承载品牌）——不是所有视频都需要响亮颜色；
3. **数据 vs 神话**（Build Grow Scale）：没有"转化率最高的颜色"——颜色效果依赖语境、品类、受众；"红色按钮增加 21% 转化"是营销神话，可复用的是**对比与层次**原理。

## 常见颜色情绪信号（上下文决定，非铁律）

| 颜色 | 常见信号 | 典型用途 |
|---|---|---|
| 红 Red | 紧迫、能量、危险、激情 | 限时价签、CTA、警告 |
| 橙/黄 Orange/Yellow | 速度、乐观、注意力 | 促销、年轻品牌、强调 |
| 蓝 Blue | 信任、冷静、专业 | 金融、科技、教学 |
| 绿 Green | 健康、自然、安心/隐秘 | 食品、环保、医疗、教程 |
| 紫/粉 Purple/Pink | 创意、奢华、柔美 | 美妆、时尚、创作者 |
| 青 Teal | 现代、清新、高级 | 科技、生活方式 |
| 黑白灰 Mono | 高级、极简、戏剧 | 时尚、高端、口播 |

**纪律**：把最强的颜色**保留给决策点**——演示画面保持中性，用鲜亮强调色标"Today only / 新到 / 加入购物车"；如果每个标签都是亮红，就没有哪个重要。

## 用颜色引导视线（分离结构）

在短视频里，观众第一秒决定是否继续看——用颜色创造清晰焦点，分离：
- 说话人 vs 背景；
- 标题 vs 辅助文字；
- 产品 vs 周围道具；
- CTA vs 画面其余部分；
- 字幕 vs 动态画面。

例：开场"毁掉产品图的 3 个错误"——标题不要放在杂乱的货架上用相似色；放深色半透明块上、高对比文字、背景干净。

## 三分调色板工作流（可靠的小调色板）

```
Base 基础色：背景/主导场景色调
Text 文字色：字幕、钩子、标签
Accent 强调色：高亮、按钮、箭头、关键词
```

**三步工作流**：
1. **定义视频任务**：一句话"看完后观众应该感觉什么、做什么？"（自信尝试/注意产品质感/理解错误并收藏/感到限时紧迫）——决定调色板情绪；
2. **选三分调色板**：营销片=炭黑底+白字+黄强调；健康教程=柔绿底+近黑字+哑金强调；产品演示=**基础色不得扭曲产品本色**；
3. **全片统一角色**：强调色=重要，就只给重要项用；黄色=步骤号，就别同时用于警告、价格、装饰。

## 字幕与叠加可读性（色彩心理学失效点）

- **基础系统**：白色无衬线字 + 黑色半透明底 + 一致字号与位置 + 不快速变色 + 按语速断行（约 180 词/分钟以下）；
- 开口字幕在亮暗素材上都测过再发；
- **重要文字避开下三分之一**（字幕常驻区）——放上三分之二（→ 43 安全区）；
- **不要只用颜色传达含义**："点绿色按钮"→ 色盲/低对比感观众可能看不到——说"右下角的绿色 Start 按钮"+ 箭头/形状/标签；
- 图内关键文字在正文/描述中重复。

## 分格式用色优先级

| 格式 | 目标 | 用色 |
|---|---|---|
| 口播 Talking-Head | 脸清晰+字幕可读 | 背景不与肤色/发色/服装融合；复杂背景柔化或加半透明块 |
| 产品演示 Product Demo | 产品视觉优先 | 中性表面+一致灯光+克制强调；**调色不得改变商品真实外观**（买家收货不意外） |
| 教学 Educational | 信息组织 | 一色="做"、一色="避免"、一色="示例"；系列内保持一致（观众学会你的视觉语言） |
| 广告/发布 Launch | 钩子+CTA 高对比 | 首帧无声音也说明主题；尾帧下一步动作视觉化 |

## 色彩节奏（短视频留存）

- **色彩节奏（Color Pacing）**：按段落切换/推进色板，与叙事节拍同步——单调色板=节奏疲惫，随机变色=混乱；
- 情绪段落对应色板（钩子高饱和 → 中段中性 → CTA 强调色回归）——与 45 文档"情绪→色值映射"同构；
- 电商广告研究（Hanspub）：视听符号的情感传播——颜色多样性诉求受**产品类型**调节（享乐品适合多彩、实用品适合克制）。

## 常见错误

1. 追求"万能转化色"：神话——可复用的是对比与层次原理。
2. 每像素都用品牌色：品牌色是系统不是规则——背景/字幕让位可读性。
3. 全屏高饱和：画面吵闹，没有焦点。
4. 每个标签都亮红：没有哪个重要。
5. 字幕白字无底：亮背景上消失。
6. 只用颜色传达信息：色盲/低对比观众漏掉。
7. 调色扭曲产品本色：电商信任崩坏。
