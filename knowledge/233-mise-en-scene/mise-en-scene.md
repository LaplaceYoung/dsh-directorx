# 电影场面调度全要素（Mise-en-Scène — Setting, Costume, Lighting & Staging）

> 本页为电影场面调度（Mise-en-Scène）全要素：四大领域（场景/服装化妆/灯光/调度构图）、道具/色板/美术设计补充、场面调度的叙事功能（时空/情绪/性格/强调）。知识本体来自 2026 场面调度理论（CSUN Film Art/OKState/OpenALG/Wikipedia）。AI 应用面向 DirectorX：视觉世界（衔接 222 美术、218 色彩、225 布光、227 调度、233 对应）。
> 来源：CSUN「Mise-en-Scène (Film Art)」、OKState「Mise-en-Scène Intro」、Wikipedia「Mise-en-scène」、Filmmakers Academy「Mise en Scène Glossary」。

## 概述

**核心断言**：场面调度 = **画面里一切可控制元素的整体设计**——场景（时空）、服装化妆（角色）、灯光（情绪）、调度构图（关系）。**四大领域统一叙事**：建立时空、营造情绪、揭示性格、强调重点（衔接 222：美术设计的理论总纲）。

## 核心概念

### 四大领域（CSUN）

```
① 场景 Setting：时空/氛围
② 服装化妆 Costume & Make-up：角色/性格
③ 灯光 Lighting：情绪/维度（225）
④ 调度构图 Staging：关系/重点（227）
```

### 补充要素

道具（209）/色板（218）/美术设计（222）——强化整体"look"。

### 叙事功能

| 功能 | 说明 |
|---|---|
| 时空 | 建立时代/地点（203） |
| 情绪 | 氛围营造（181） |
| 性格 | 角色外化（169/226） |
| 强调 | 引导注意（216） |

## 技巧与示例

### 场面调度设计工作流（AI 映射）

```text
剧本 → 场面调度分析（四领域逐项）
  → 场景设计（228）→ 服装（169）
  → 灯光（225）→ 调度（227）
  → 统一性检查（222）→ 生成
```

### 综合示例（一场戏）

"1940s 雨夜办公室：暗色木饰场景（203 时代）+ 风衣角色（169）+ 低调单侧光（225）+ 前景台灯主导构图（227）"——四领域协同。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只盯单要素 | 整体失衡 | 四领域协同 |
| 要素互斥 | 时代/情绪乱 | 统一叙事 |
| 无强调设计 | 重点模糊 | 构图强调 |
| 服装与场景脱节 | 角色出戏 | 统一色板（218） |
| 忽视道具 | 场景空 | 道具补充（209） |

## 工作流应用（AI 映射）

视觉世界（衔接 218/222/225/227）：

```text
剧本 → 四领域分析 → 逐项设计
  → 统一性检查（222）→ 生成
  → 叙事功能校验
```

**DirectorX 纪律**：四领域协同；统一叙事目标；要素不互斥；强调设计明确。
