# 广告与宣传片制作（Commercial & Corporate Video）

> 本页是 DirectorX 广告/宣传片知识库：广告片时长与字数规范、脚本结构模板、广告类型、企业宣传片 10 大类型、产品/电商视频打法与 AI 生成应用。
> 来源：ScreenWeaver 广告脚本时长规范、What a Story 企业视频制作指南 2026、行业广告脚本模板常识。

## 概述

广告（Commercial/Ad）与宣传片（Corporate/Brand Video）的共同本质：**为目标服务**——不是"讲完一个故事"，而是"让目标受众采取一个行动"（购买、信任、注册、投递简历）。区别：
- **广告**：付费投放、时长极短（15/30/60 秒）、转化导向、强钩子强 CTA。
- **宣传片**：自有渠道（官网/主页/招聘页）、时长 60 秒-5 分钟、信任与认知导向、弱 CTA（好奇驱动）。

2026 关键背景（What a Story）：AI 生成视频淹没了"看起来还行但没有意义"的内容——**真正为特定受众、绑定可衡量结果、创造真实理解**的视频更有价值。宣传片不是"内容填充"，而是"沟通基础设施"。

## 广告片时长与字数规范（ScreenWeaver）

广告按"字数+节拍"计时，不按页数。自然语速约 **2.5 词/秒**：

| 片长 | 口播字数（英文） | 中文口播字数参考 | 结构容量 |
|---|---|---|---|
| 15 秒 | 30-38 词 | 40-55 字 | 视觉为主，一句钩子 + 品牌 |
| 30 秒 | 60-75 词 | 80-110 字 | 铺垫 + 一个转折 + 标语 |
| 60 秒 | 130-150 词 | 170-220 字 | 可加第二个节拍/客户证言 |
| 90 秒 | 195-225 词 | 260-330 字 | 品牌内容/前贴片 |

**两个修正因素**：
1. **静默与画面也占时间**：产品镜头、logo 停留、反应节拍可能占 1/3 时长——按全字数上限写必然超时。
2. **语速不是固定值**：奢侈品/药品广告慢读（~2 词/秒，字数减 20%）；零售/年轻向广告快读（>3 词/秒）。**定稿前必须按实际语速朗读计时**。

## 广告脚本结构（AV 双栏格式）

```
【视频】（画面/动作）          【音频】（口播/音效/音乐）
---------------------------------------------
1. 特写：痛点物件            VO: 你还在为 X 烦恼吗？
2. 中景：主角皱眉            音效：烦恼音
3. 产品特写入场              VO: 现在，Y 来解决
4. 产品演示（关键功能）       VO: 只要 3 步……
5. 使用前后对比               VO: 效果立竿见影
6. 品牌 logo + 标语          VO: Z，让生活更简单
```

### 经典广告结构模板
1. **问题-方案（Problem-Solution）**：痛点 → 产品即解药 → 使用演示 → 结果 → CTA（DTC 品牌主力）。
2. **证言式（Testimonial）**：客户现身说法 → 具体问题 → 具体结果（数字）→ 品牌。
3. **生活方式（Lifestyle）**：不卖功能卖场景/身份 → 情绪画面 + 音乐 → 品牌收尾（奢侈品、汽车）。
4. **对比式（Comparison）**：竞品弱点（不点名）→ 我们的优势 → 直接 CTA。
5. **悬念式（Suspense）**：先抛谜题/反转 → 揭晓产品（科技、新品发布）。
6. **示范式（Demo）**：纯产品演示 + 极限测试（防水/承重/速度）→ 数据说话。
7. **品牌宣言（Manifesto）**：价值观宣言 + 大场面 + 无硬 CTA（品牌形象片）。

### 30 秒广告的节拍分配（推荐）
```
0-3s    钩子（痛点/悬念/利益，1-2 句）
3-15s   展开（产品登场 + 一个核心卖点演示）
15-25s  强化（对比/证言/使用场景）
25-30s  品牌收尾（logo + 标语 + 行动提示）
```

## 广告类型速查

| 类型 | 时长 | 目标 | 关键元素 |
|---|---|---|---|
| 电视/前贴片广告 | 15/30/60s | 品牌认知+转化 | 强钩子、标语 |
| 信息流广告（Feed） | 15-30s | 转化 | 原生感、首帧即钩子 |
| 电商短视频（带货） | 15-60s | 直接下单 | 痛点→演示→价格→逼单 |
| 开屏广告 | 5-15s | 冲击 | 首帧视觉、品牌名 |
| 品牌形象片 | 60-120s | 认知/情感 | 视觉语言、音乐、无硬 CTA |
| 病毒视频 | 任意 | 传播 | 反转、幽默、共鸣 |

## 企业宣传片 10 大类型（What a Story 2026）

| 类型 | 目标 | 最佳位置 | 理想时长 | 常见错误 |
|---|---|---|---|---|
| 公司形象片 Company Profile | 建立可信度 | 首页/关于页/路演 | 2-5 分钟 | 讲完整个公司史（应制造好奇） |
| 产品解释/演示 Explainer/Demo | 认知→理解 | 首页 hero/产品页 | 60-90s（首页）；2-8 分钟（深度演示） | 讲功能不讲结果 |
| 品牌介绍片 Brand Intro | 情感连接 | 首页/社媒/活动 | 60-90s | 与形象片混淆 |
| 客户证言 Testimonial | 信任背书 | 落地页/销售材料 | 60-120s | 空泛好评无数据 |
| 案例研究 Case Study | 决策期信任 | 提案/跟进邮件 | 2-4 分钟 | 一个故事讲太多 |
| 企业文化/招聘 Culture | 吸引人才 | 招聘页/LinkedIn | 90s-3 分钟 | 千篇一律的"欢乐办公" |
| 培训/入职 Onboarding | 规模化培训 | LMS/知识库 | 每模块 2-8 分钟 | 信息过载的讲座式 |
| 活动/展会 Event | 预热+回顾 | 邮件/注册页 | 预告 30-60s；回顾 90s-3 分钟 | 无目标受众 |
| 融资路演 Investor | 融资沟通 | 路演材料 | 2-4 分钟 | 讲产品细节不讲市场机会 |
| 内部沟通 Internal | 组织对齐 | 内网/全员会 | 1-3 分钟 | 照读 PPT |

### 产品演示片的标准结构（转化导向）
```
钩子 Hook → 问题 Problem → 方案 Solution → 怎么用 How it works → 证明 Proof → 行动 CTA
```
（What a Story 推荐结构；核心原则：围绕"结果"而非"功能"组织）

### 企业视频制作要点
- **先定目标再定类型**：视频类型与业务目标匹配是制作前最重要的决策。
- **证言要具体**：具体问题 + 可衡量结果 + 可信讲述者 + 一个聚焦故事。
- **品牌片以好奇收尾**：不硬 CTA，让观众想了解更多。
- **培训片一条概念一个视频**：口述结果 + 视觉引导 + 字幕无障碍。

## 产品/电商视频打法

### 电商主图视频（亚马逊/淘宝等）
- 时长 15-30s；首帧 0.5s 内出现产品+核心卖点文字。
- 结构：产品亮相 → 核心卖点演示（1-2 个）→ 使用场景 → 规格/售后提示。
- 拍摄要点：白底/干净场景、微距细节、360° 旋转展示、多角度补拍。

### 带货短视频（抖音/TikTok 电商）
- 结构：3s 钩子（痛点/效果承诺）→ 产品演示（真用真测）→ 价格与优惠 → 逼单 CTA。
- 要点：真实感（素人感>广告感）、口播+字幕、卡点音乐、挂车引导。
- 常见爆款公式：反差（丑→美/慢→快）、极限测试、过程可视化（使用前后对比）。

## 在 AI 视频生成中的应用

1. **广告脚本生成**：按 15/30/60s 字数规范生成 AV 双栏脚本；生成后按实际语速朗读计时校验。
2. **分镜提示词**：每个节拍一个镜头（痛点特写→产品演示→对比→品牌），保持产品视觉一致性（见 04 文档 identity sheet）。
3. **产品一致性**：同一产品生成多个镜头时固定"产品 identity sheet"（造型、颜色、logo 位置、反光质感）——AI 常见漂移点。
4. **品牌色彩**：全片统一品牌色/调色风格（见 09 灯光色彩文档）。
5. **交付检查**：时长精确（15/30/60s ±0.5s）、CTA 清晰、logo 版本正确、字幕无错字。

## 常见错误

1. 字数超时：不看画面节拍只按字数写，成品超时被平台裁切。
2. 广告没有钩子：前 3 秒讲品牌史——观众划走。
3. 功能罗列而非结果导向：产品演示变说明书。
4. 证言空泛："很好用"三个字没有任何说服力。
5. 宣传片想讲完所有事：什么都讲 = 什么都没讲（制造好奇 > 讲完）。
6. 品牌片硬塞 CTA：破坏品牌气质。
7. 电商视频无逼单：看完不知道去哪买。
8. AI 产品漂移：多个镜头产品外观不一致（颜色/logo/造型）。
