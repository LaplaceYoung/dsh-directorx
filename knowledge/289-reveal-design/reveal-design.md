# 电影悬念揭示设计（Reveal Design — Plant-Payoff, Gradual Revelation & Recontextualization）

> 本页为电影悬念的揭示设计：种植-兑现（Plant and Payoff）、渐进揭示（Gradual Revelation：分片释放信息）、揭示结构（铺垫-埋伏-反语境化）、炸弹时机。知识本体来自 2026 揭示设计（MovieMaker/ScreenwritingU/Fiveable）。AI 应用面向 DirectorX：揭示规划（衔接 268 悬念、289 对应、280 节奏、150 叙事）。
> 来源：MovieMaker「Plant and Payoff Scenes」、ScreenwritingU「The Structure of a Reveal」、Fiveable「Gradual Revelation」、Medium「The Tightrope Before the Twist Ending」。

## 概述

**核心断言**：揭示 = **"信息分片释放的工程"**——种植（早期埋伏线索）→ 兑现（后期回收反语境化）；渐进揭示（分片释放塑造节奏与预期）；炸弹时机（268 原则落地）（衔接 268：知识差；280：节奏）。

## 核心概念

### 种植-兑现（Plant-Payoff）

```
种植（Plant）：早期埋线索（看似无关）
兑现（Payoff）：后期回收（反语境化前文）
→ 两次以上时刻获得深度
```

### 渐进揭示（Gradual Revelation）

分片释放信息（每片塑造预期/节奏）——**信息节奏=悬念节奏**（衔接 280）。

### 揭示结构（ScreenwritingU）

铺垫（建立需求）→ 埋伏（隐藏）→ 揭示（反语境化）→ 情绪落地——**揭示重新定义前文**。

## 技巧与示例

### 揭示设计工作流（AI 映射）

```text
揭示目标 → 线索种植点 → 揭示时机（280）
  → 反语境化设计 → 生成 → 情绪校验
```

### 种植-兑现提示词

"establish the planted detail early（画面早期细节）→ reveal its meaning later"——**线索-回收成对设计**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无种植直接揭示 | 突兀 | 埋伏线索 |
| 线索过显 | 提前猜中 | 隐藏处理 |
| 揭示无反语境 | 浅 | 重释前文 |
| 时机错 | 泄气 | 节奏对齐 |
| 无铺垫 | 无需求 | 建立期待 |

## 工作流应用（AI 映射）

揭示规划（衔接 150/268/280）：

```text
揭示目标 → 种植点 → 时机 → 反语境
  → 生成 → 情绪/意外校验
```

**DirectorX 纪律**：种植-兑现成对；渐进揭示控节奏；揭示重释前文；时机防泄气。
