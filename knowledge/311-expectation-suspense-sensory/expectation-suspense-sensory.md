# 电影预期-悬念-通感整合（Expectation-Suspense-Sensory — Immersive Unified Experience）

> 本页为电影预期-悬念-通感整合：未来导向预期（Expectation 是悬念/张力的来源）、非叙事音乐+叙事线索共同塑造、PAL-D 回路设计决策、主客观+生理信号测量迭代。知识本体来自 2026 沉浸研究（Nature/Tandfonline/Frontiers PAL-D）。AI 应用面向 DirectorX：沉浸设计（衔接 293 悬念通感、311 对应、304 预期、282 三整合）。
> 来源：Nature「Building Blocks of Suspense」、Tandfonline「Immersive Storytelling Design Methodology」、Frontiers「PAL-D」、东京大学「沉浸认知过程」。

## 概述

**核心断言**：沉浸 = **"预期-悬念-感官的统一"**——悬念与张力源于**未来导向的预期与预测**（非叙事音乐+叙事线索增强）；PAL-D 回路指导设计；用主客观+生理信号测量迭代（衔接 293：回路应用；304：预期管理）。

## 核心概念

### 未来导向预期（Nature）

```
悬念/张力 ← 预期与预测过程
非叙事音乐 + 叙事线索 → 增强
（衔接 268 知识差、293 双驱动）
```

### 统一感官氛围（Tandfonline）

声音/图像/环境共塑调性与沉浸——**感官统一=沉浸**（衔接 272 三通道）。

### 测量迭代（PAL-D）

主客观+生理信号（唤起度/注意）→ 多模态影响分析 → 迭代设计——**"测了再改"**（衔接 129 评测）。

## 技巧与示例

### 沉浸设计工作流（AI 映射）

```text
预期设计（304）→ 悬念（268）→ 感官（272）
  → PAL-D 回路 → 生成
  → 主客观测量 → 迭代
```

### 测量要点

唤起度（生理）+ 注意（眼动）+ 主观体验——**三信号**（衔接 246 眼动）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无预期设计 | 悬念无源 | 预期先行 |
| 感官单一 | 沉浸弱 | 统一氛围 |
| 无测量 | 盲改 | 生理+主观 |
| 回路断裂 | 体验断 | PAL-D |
| 不迭代 | 效果未知 | 测后改 |

## 工作流应用（AI 映射）
