| 约 0:30-1:30 | 全景 | 世界观空镜：玫红色记忆洋流连通岛屿与海怪栖息地，荧光水母群 | 航拍 + 水下运镜 | 空灵配乐 |
| 约 1:30-2:30 | 中景 | 角色群像：木偶伙伴（大山竜/竹谷隆之设计）、茉莉（戏曲 × 摇滚） | 快切亮相 | 节奏配乐 |
| 约 2:30-3:30 | 中景→全景 | 海战/探索：舰炮与接舷战，木屑飞溅、海水渗入船体 | 快切 + 慢镜 | 炮声 + 海浪 |
| 约 3:30-4:30 | 全景 | 巨怪高潮：堆积成山的黄金蟹怪、风暴中遮天巨兽 | 仰角 + 快速剪辑 | 低音压迫 + 音效 |
| 约 4:30-5:00 | 中景→字卡 | 收尾：玩法/世界观信息 + "流浪号"封测 2026-02-05 落版 | 黑屏字卡 | 标题音乐 |

- **AI 技术点**（衔接 240 风格参考、117 一致性全体系、93 光线叙事）：
  - **材质即世界观**：木偶质感（木质纹理、关节、纽扣眼）是最高辨识度资产——AI 提示词需锁定"wood grain / joint articulation / button eyes"材质词，任何跨镜材质漂移都会毁掉风格（衔接 117、39 图片一致性）。
  - **2D×3D 混合风格**：2D 漫画张力 + 3D 流动油画质感，可拆成"线稿轮廓 + 油画笔触 + 流动变形"三层风格参考（衔接 126、240）；玫红洋流 × 荧光生物的配色系统可作为全片色彩锚（衔接 93）。
  - **提示词模板**（可直接用）：
    ```text
    木偶美学海洋奇幻，木偶船长（木质关节、纽扣眼、油画肌理）航行于玫红色记忆洋流，
    荧光水母群与哥特式海洋景观，2D漫画张力 + 3D流动油画质感，高饱和玫红与深蓝对冲
    ```
  - **生成后检查与修复**：① 木偶关节/纽扣眼变形 → 材质参考图 + 关键帧锁定重生成；② 洋流颜色跨镜漂移 → 色彩 LUT 统一（衔接 93）；③ 布料/木质次级运动穿帮 → 逐帧抽查刚体与柔体交互（衔接 174、118）。
- **可复用要点**：① **风格化先行**——一条 5 分钟 PV 靠"木偶美学"这一个记忆点破千万，印证 397"美术基调定调句"的价值；② 概念片（2025-06）→ 实机 PV（2026-01）→ 封测（2026-02-05）的**物料节奏**：每次投放同一世界观的新镜头而非重复旧素材。

## 方法提炼

**1. 三种题材打法对照**（承接 396 的单集节奏公式）：

| 打法 | 钩子类型 | 节奏引擎 | 竖屏镜头重心 | 代表作 |
|---|---|---|---|---|
| 谍战智斗 | 险境型（第一天任务即生死局） | 每集反转 + 审讯/追杀强场景 | 特写眼神、手势暗语、封闭空间纵深 | 《暗潮涌动》 |
| 情绪流 | 状态型（花语三阶段） | 关系进度推进，慢镜 + 无对白戏 | 微表情慢镜、剪影、冷暖光对冲 | 《盛夏芬德拉》 |
| 男频基建 | 反差型（工程师穿乱世） | 成果可视化（before/after + 数字） | 全景工程对比 + 特写操作 + 群体场景 | 《一品布衣》 |

三案例共同验证 396 结论：**竖屏单集 2-3 分钟内，情绪节点频率是生命线**；差异只在"节点由什么构成"——反转、状态推进、还是成果展示。

**2. 游戏预告两条新路线**（承接 397 的六段式套路）：
- **实机电影化**（《影之刃零》11 分钟）：用真实可玩内容 + 电影调度（慢镜、特写、字卡）替代 CG 画饼；发售前 10 周超长实机制造预售峰值。
- **风格化概念**（《遗忘之海》5 分钟）：先立材质/配色定调（木偶美学、玫红洋流），再放玩法；概念片与实机 PV 分阶段投放同一世界观。
- 共同点：**时间更长的"内容型预告"在 B 站成为主流**——865 万与 1000 万级播放均来自长实机/长 PV，而非 30 秒广告片（对照 397：KCD2 的 41 秒 150 万；长内容 + 风格记忆点 = 新基准）。

**3. 数据基线**：播放量破亿作品仅占 4.3%、63% 作品不足 500 万（36氪）——头部案例（破 9 亿/40 亿/24 亿）的价值在于提供**可复制的结构模板**而非运气配方；制作成本不再是门槛（《一品布衣》不足 100 万、《盛夏芬德拉》拍摄约 11 天），**分镜与视觉资产的复用率**才是利润来源（衔接 122 质量与变现）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 谍战剧铺陈身份背景超过 10 秒 | 首帧无危机，用户划走 | 开场即险境（第一天任务就是生死局），背景信息后置（《暗潮涌动》） |
| 情绪流拍成"无钩子文艺片" | 完播率崩 | 用状态符号（花语三阶段）作结构钩子，情绪节点按时点排布（《盛夏芬德拉》） |
| 男频基建只拍主角、不拍成果 | 爽感悬空 | before/after 对比 + 数字进度字幕，成果可视化（《一品布衣》） |
| 竖屏谍战用全景叙事 | 小屏信息丢失 | 高密度特写/近景 + 眼神微表情 + 封闭空间纵深（衔接 43/104/231） |
| 游戏预告硬撑 CG 画饼 | 发售被骂"预告欺诈" | 实机/引擎内电影化，所见即所得（《影之刃零》路线，衔接 397） |
| 风格化预告只炫技、无记忆点符号 | 播放量起不来 | 先立材质/配色定调（木偶美学、玫红洋流），符号跨镜复用（《遗忘之海》） |
| 慢镜特写无情绪 | 观众觉得"注水" | 微表情（睫毛/瞳孔）+ 音效留白 + 光线对冲（衔接 93/177） |
| 时代/材质道具跨镜漂移（AI 生产） | 一秒出戏 | 资产库 + 参考图锁定 + 抽帧质检（衔接 117/174/203） |

## 工作流应用（AI 映射）

面向 DirectorX 生产管线（衔接 396 工作流、48 AI 短剧工厂、115 提示词工程、174 质检、118 缺陷修复）：

```text
题材路由（LLM 分镜）
  ├─ 谍战智斗：开场 0-10s 必为险境；每集末尾一个反转钩；审讯/追杀场景池轮换；
  │    特写占比 ≥60%（眼神/手部/暗语），封闭空间纵深构图（衔接 268/274/289）
  ├─ 情绪流：把"关系进度"编码为状态符号（花语三阶段式）；每集 1-2 个慢镜特写 + 1 个无对白戏；
  │    冷暖光对冲场景清单（浴室/隧道/祠堂）（衔接 93/177/246）
  └─ 男频基建：分镜 JSON 显式写 comparison: {before, after} 与 progress_text；
      每 5 集一个"成果可视化"全景（衔接 201/203）
画面与一致性（衔接 116/117/123/240）
  ├─ 时代锚（1940 奉天 / 乱世古代）：场景参考图 + 道具资产库（旗袍/军装/留声机/夯土城墙/图纸）
  ├─ 角色锚：LoRA + IP-Adapter + InstantID；慢镜特写补"pupils dilating / micro-expression"
  └─ 风格锚（游戏预告）：多风格分层参考（武侠/蒸汽朋克/神秘学；木偶材质词 + 玫红洋流 LUT）
游戏预告分镜（衔接 151/397）
  ├─ 实机电影化：慢镜 + 特写 + 字卡节奏表（0-40s 环境 → 2-4min 战斗 → 高潮 → 发售日落版）
  └─ 风格化概念：先立材质/配色定调句，符号跨镜复用；概念片与实机 PV 分阶段投放
生成后检查与修复（衔接 174/118）
  ├─ 时代/道具穿帮 → 换参考图重生成（203）
  ├─ 慢镜运动模糊/抖动 → 调快门角度参数（177）
  ├─ 材质漂移（木偶/金属/服装）→ 材质参考图 + 抽帧比对（117）
  ├─ 光线色温跳变 → 统一 LUT（93）
  ├─ 状态符号跨镜跳变（玫瑰三阶段）→ 三张状态参考按集分段锁（39/240）
  └─ 音画不同步 → TTS 音色固定 + 口型对齐（88/119）
```
