# AI 视频分发矩阵策略（Distribution Matrix — One Asset, Multi-Platform Leverage）

> 本页为 AI 视频的分发矩阵策略：一源多平台（核心资产 + 平台裁剪）、发布节奏（首发 + 24-48h 短平台铺开）、平台决策矩阵、统一测量、90 天节奏建立。知识本体来自 2026 分发策略指南（HubSpot/CreatorSkills/351Studio/Garage）。AI 应用面向 DirectorX：交付后分发（衔接 112 交付、142 平台适配、149 数据测试）。
> 来源：HubSpot「Multi-Channel Content Distribution」、CreatorSkills「Cross-Platform Content Strategy 2026」、351Studio「Multi-Platform Video Strategy 2026」、Garage「Multi-Platform Distribution」。

## 概述

**核心断言**：品牌失败不是缺内容，是**缺内容杠杆**——一个高质量核心资产，按平台裁剪为多格式，用发布节奏放大，统一测量优化。**先选 3-5 个主平台，再做决策矩阵，90 天节奏建立后扩展**。

## 核心概念

### 一源多平台（CreatorSkills 70% 裁剪省时）

```text
核心资产（长视频/完整版）
  → YouTube（完整版）
  → TikTok/Reels（竖屏切片，142）
  → Shorts（SEO 版）
  → LinkedIn（专业版）
  → 图文/播客（衍生）
```

### 发布节奏（Garage）

```text
首发（核心资产，主平台）
  → 24-48 小时内短平台铺开（切片/预告）
  → 数据反馈 → 优化下一轮（149）
```

### 决策矩阵要素

平台 × 格式 × 受众 × 目标（品牌/转化/SEO）× 发布频次。

## 技巧与示例

### 分发矩阵工作流

```text
核心资产（一源）→ 平台选型（3-5 主平台）
  → 决策矩阵（每平台格式/目标/节奏）
  → 裁剪生成（142 平台适配 + AI 批量）
  → 首发 → 24-48h 铺开 → 统一测量
  → 数据迭代（149）→ 90 天节奏
```

### 统一测量（跨平台归因）

统一仪表盘对比各平台表现（衔接 149）：完播/转化/获客成本，按数据分配产能。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 一稿全平台直发 | 平台不适配 | 决策矩阵裁剪 |
| 平台铺太广 | 资源分散 | 3-5 主平台起步 |
| 无发布节奏 | 曝光零散 | 首发+24-48h 铺开 |
| 不统一测量 | 无法归因 | 统一仪表盘 |
| 无节奏建立 | 无法规模化 | 90 天节奏 |

## 工作流应用（AI 映射）

交付后分发（衔接 112/142/149）：

```text
核心资产 → 平台选型（3-5）
  → 决策矩阵 → 裁剪（142 + AI 批量）
  → 发布节奏（首发+铺开）
  → 统一测量 → 数据迭代（149）
```

**DirectorX 纪律**：一源多平台杠杆；3-5 主平台聚焦；首发+铺开节奏；统一测量归因。
