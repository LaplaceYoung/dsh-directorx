# 对白改写实操（Dialogue Rewriting Workshop）

> 本页是 DirectorX 对白改写手册：直白对白的三种失败模式、潜台词改写七步流程、改写对照表、六种潜台词错误、何时允许直接对白、类型平衡、问题测试。与 82 对白写作 / 90 类型剧本衔接。
> 来源：ScreenWeaver 潜台词改写通道（2026）、Filmmaker Genius 对白改写、中文对白"嘴上说走眼神说别走"。

## 概述

**直白对白**：角色准确说出所想、准确在想说时、用治疗工作表式词汇——高效而致命。观众感觉**被说教**而非**被交谈**；读者略读；演员演技扁平因为没有空隙可演。

**潜台词改写通道**不把角色变模糊——它恢复**压力**：想说的话 vs 敢说的话（受权力、羞耻、时机、谁在听约束）。

**潜台词活在台词与意图之间的距离里**：角色用保护面子、试探忠诚、拖延时间、误导对方的言辞追求目标——直白对白把距离塌缩为零。

## 三种失败模式（先识别再改）

1. **主题宣告**："这就是关于家庭。"——角色不宣告主题，他们为钥匙、钱或沉默吵架；
2. **情绪贴标签**："我害怕。"——恐惧表现在话题转移、玩笑、攻击性或过度精确；
3. **情节说明**："如你所知，我们在 2019 年的湖边相遇。"——用冲突迫使部分揭示。

**顺序纪律**：结构/清晰度通道之后再跑潜台词——**坏场景上的潜台词是口红**。

## 七步改写流程

```
① 标出直接陈述主题/感受/前史的行（粉色）——数数；一场超两个=这场在说教
② 写每个说话者的秘密目标（一句：场景结束时他情感/实际需要什么）
③ 间接追求目标重写：问"这个人会说什么来避免丢脸？试探而不坦白？赢而不承认在乎？"
④ 加与言语矛盾的行为（笑着威胁/提供帮助却拒绝亲近）——行为让潜台词可读而不需解释
⑤ 剪重复节拍（对白与动作重复同一信息——留更好的版本）
⑥ 与朋友朗读——每句像同一篇作文腔=按角色分化句法
⑦ 抽查预告片级台词——每剧本 1-2 句可引用直白句足够
```

## 六种潜台词错误（战壕区）

1. **晦涩冒充深度**：没人跟得上=雾，不是潜台词；
2. **统一潜台词声音**：人人说编码警句——按角色分化句法；
3. **潜台词无行为**：台词说一套身体中立——演员需要矛盾；
4. **过度校正**：删掉所有清晰——每场景允许一句定位线；
5. **最后五页主题演讲**：换成看得见代价的选择。

## 何时允许直接对白（操作要求）

- **高风险清晰**：医疗同意/法律警告/军事命令——用语境挣得直白；
- **首次信息**：观众需要事实一次——潜台词不是无限期隐藏基本定位；
- **角色特征**：有些角色天生直白（作为特质）——与潜台词重的对手形成对比；
- **翻译与无障碍**：潜台词不能变成不可理解——行为与语境承载跨文化含义。

## 类型平衡

- **喜剧**：有时用直白做包袱武器，其余用潜台词做关系真相——直线角色可直白，伤口不能；
- **浪漫喜剧**：直白告白=高潮节拍——90 分钟闪避后的第一次停止表演；**通道去除过早的诚实，不去除所有诚实**；
- **恐怖**：角色可命名恐惧，当命名使其受他人嘲笑（暴露脆弱）；
- **法律剧**：质询时可陈述事实。

## 验证测试

- **问题测试**：改写后的每句问"角色能否答非所问仍推进目标？"——能=在潜台词领域；每句完美诚实回答所问=还在直白；
- **非编剧朋友阅读测试**：理解场景但复述不出主题句=成功；困惑=你砍了清晰而非冗余——调整；
- **保存清单**：每剧本 1-2 句必须保持直白的台词（角色/类型理由）——从通道中保护它们。**潜台词是默认，不是宗教**——知道哪个时刻配得上直白是艺术。

## 常见错误

1. 结构未清就跑潜台词通道：口红。
2. 主题宣告不标记：说教场。
3. 无行为矛盾：演员无可演。
4. 全剧本晦涩：雾。
5. 最后五页主题演讲：用选择替换。
6. 所有人同一腔调：句法不分。
7. 把所有诚实都删掉：观众理解受损。
