# 类型片剧本写作（Genre Screenwriting Craft）

> 本页是 DirectorX 类型剧本深化手册：类型片剧作 66 技巧精选（压迫驱动/规则交代/两难抉择/晚进早出等）、类型结构模板（爱情/喜剧/恐怖/动作/惊悚节拍）、剧本格式与页时换算、类型化写作纪律。与 03 结构 / 66 短剧编剧 / 82 对白衔接。
> 来源：孙武类型片剧作 66 技巧（影视工业网）、FreeScreenwriter 20 类型模板、No Film School 节拍表、编剧拉片方法论。

## 概述

**核心前提**：所有技巧都有适用范围——只适合想赢得观众的**商业类型片**。技巧不是人为创造的，而是**对人类心理的分析和模拟**——人心变化，技巧随之变化。

**编剧拉片方法论**（庖丁解牛）：像拆精密手表一样拆类型片——用情节点拆分三幕，研究每个部件的功能，推理各零件如何关联运行——以结构拆解指导创作（→ 83 拉片衔接）。

## 类型片剧作核心技巧（66 条精选）

### 驱动与压迫
- **主人公总是不服规则的人**：压迫是欲望的驱动力——没有驱动力，观众看不到推动故事的必要性；
- 驱动力越强故事越好看，但不能失真——**对抗角色不能无合理性做事**；反派要有正当理由（树立真实性的原则）；
- 任务（困难）**不断升级**，不平级不降级（《速度与激情》陆地→上天，同技巧有创意递进）。

### 规则与游戏
- 游戏性电影**第二幕前交代清楚游戏规则**——不能让观众猜规则或规则随意变；
- 第一关不能太难：调起太高，后面智商不够编不下去；
- 为验证规则真实性，**总要有人在规则中牺牲**。

### 转折与高潮
- 主人公在剧情中点**幡然醒悟、绝地反击**——醒悟之时恰是真正危险来临之时，目的是推向**两难抉择**；
- 最后大矛盾越是不可能完成观众越爱看；
- **大高潮前踩满油门**（情感因素）再弹射；高潮越长观众越爽，但**前戏不够的高潮是假高潮**；
- 最后一分钟营救虽套路但一直管用。

### 转变与选择
- 情节推进完成主人公转变——好电影转变得自然，烂电影说变就变（细节/情节推进/背后大道理）；
- **大道理用选择表明，不用嘴说**——选择反映内心、性格与价值观；
- **观众在乎的是牺牲了什么，不是获得了什么**（《世界末日》《黑暗骑士》）。

### 结构与节奏
- 第一幕要**点题**（不能让观众看半小时不知讲什么）；第一幕篇幅无定数，取决于好不好看；
- 影响观众注意力的不是几幕，**是节奏**；
- **晚进早出**：一场戏去除碎戏直接进事件和矛盾，事件结束赶紧收掉转场；
- 只解决行动线的大矛盾通常不是大结局——**情感线（心理线）的矛盾才是关键**。

### 类型差异
- 喜剧与正剧很大不同：重在**错位、出乎意料、非常规逻辑**；喜剧与演员关系大；
- 反转剧本身是一种类型——不要把反转剧当成所有类型剧的唯一结局；
- 结局体现创作者价值观：大团圆/悲剧/开放式/暗黑式/轮回式。

## 类型结构模板（可直接套用）

### 爱情片（Romance）
```
相遇（meet-cute）→ 障碍（家庭/阶级/误会）→ 假结局（虚假解决）
→ 分离/醒悟 → 和解 → 最终画面（镜像开场）
```

### 喜剧片（Comedy）
```
强前提/高概念设定 → 快速节拍 → 误会计谋升级 → 情感回报
（主角通常拒绝任务再扛起——喜剧与励志不同规律）
```

### 恐怖片（Horror）
```
氛围与隔绝建立 → 恐惧升级（渐进或惊吓）→ 幸存者/最后反转
（→ 37 视觉语言 + 87 拍摄惯例衔接）
```

### 动作片（Action）
```
明确任务 → 升温对抗 → 中点反转 → 大场面 → 最终对决（cathartic）
（→ 87 战争/动作拍摄惯例衔接）
```

### 惊悚片（Thriller）
```
紧迫利害 → 上升张力 → 滴答时钟 → 反转 → 清晰反派
```

## 剧本格式与页时

- 长片 90-120 页；**每页 ≈ 1 分钟屏幕时间**；
- 基本要素：场景标题（SLUGLINE）/动作行/角色提示/对白/转场/蒙太奇；
- **开场与终场画面互为镜像**——标志变化（→ 03 Save the Cat 衔接）。

## 类型化写作纪律

1. 先定类型再动笔（麦基 25 种/细分 40 种题材——结构、情节、人物之前的首要工作）；
2. 勾子越大故事越难写——创意是吸引因素但不是唯一因素；
3. **主人公前史逐步渗透、保留悬念**（《深夜食堂》）——抛出时间点与方式是艺术活；
4. 检测人物真实性：第一幕选一场行为较多戏+第三幕选一场——对比变化理由是否充分；
5. 下笔前想通聊通攒素材；**下了笔别着急回头看，全写完再改**；
6. 主题很重要但**不要拿它说事儿**——怎么用故事诠释主题才是职业编剧的艺术。

## 常见错误

1. 规则不清/随意变：观众弃剧。
2. 反派无合理理由：真实性崩塌。
3. 矛盾平级不升级：无聊。
4. 醒悟无铺垫：说变就变。
5. 大道理靠嘴说：选择才是表明。
6. 情感线矛盾不解决：行动线赢了也空洞。
7. 每场戏不晚进早出：碎戏拖节奏。
