## 概述

**核心断言**：叙事结构可**形式化为角色功能**——格雷马斯行动元：六个功能位（主体/客体/发送者/接收者/帮助者/反对者）揭示底层结构；普罗普：功能目录驱动情节（衔接 150：三幕的符号学版本；100：结构的底层语法）。

## 核心概念

### 行动元模型（Greimas 六位）

```
发送者 Sender → 客体 Object → 接收者 Receiver
主体 Subject（追求客体）
帮助者 Helper / 反对者 Opponent（辅助/阻碍）
```

### 普罗普功能学（Propp）

**叙事功能目录**（主角缺失→考验→胜利→返回）——功能是情节的最小单位（衔接 239 蒙太奇：镜头级 vs 功能级）。

## 技巧与示例

### 结构分析工作流（AI 映射）

```text
故事 → 行动元建模（六位填充）
  → 功能序列（普罗普）
  → 结构校验（角色功能是否完整）
  → 生成（150 叙事落地）
```

### 结构设计应用

写剧本前先填行动元模型——**"谁追求什么，谁帮谁挡"** 定结构骨架（衔接 150 节拍表前）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无行动元设计 | 角色功能模糊 | 六位建模 |
| 功能缺失 | 情节断 | 功能校验 |
| 帮助/反对混淆 | 冲突弱 | 角色分位 |
| 结构先于内容 | 公式化 | 骨架+血肉 |
| 不校验功能 | 结构散 | 序列检查 |
