# 人物设定与世界观（Character & Worldbuilding）

> 本页是 DirectorX 角色与世界观知识库：人物档案、Want vs Need、角色弧、原型、关系网、世界观三支柱、设定一致性、冰山理论与 AI 一致性模板。
> 来源：Brandon Sanderson 2025 世界观讲座、ScreenCraft/No Film School/Final Draft 角色弧与 Want vs Need 指南、行业教材要点（Lajos Egri《The Art of Dramatic Writing》）。

## 概述

人物是故事的发动机，世界观是人物行动的舞台。两条铁律：
1. **人物由选择定义**（Character is action）——观众记住的不是人物说了什么，而是关键时刻他做了什么。
2. **世界观为故事服务**（Sanderson）——最沉浸的世界不一定最详细，而是最"内聚"：每个设定元素彼此关联并为叙事服务。

## 人物设定基础

### 1. 人物小传（Character Bio）的四层模型
| 层 | 内容 | 示例 |
|---|---|---|
| 外貌 | 年龄、体型、穿着、特征、习惯动作 | 40 岁，永远穿深灰风衣，右眉有疤 |
| 性格 | 核心性格特质、优点、缺点、口癖 | 固执、嘴硬心软、说话爱省略主语 |
| 背景 | 出身、家庭、教育、创伤、重大事件 | 消防员出身，妹妹死于火灾，从此怕火 |
| 动机 | 目标、恐惧、价值观、秘密 | 想开一家面包店（完成妹妹遗愿），害怕再次无能为力 |

### 2. 人物档案表模板（可直接复用）
```
【身份】姓名 / 年龄 / 职业 / 社会关系
【外貌】身高体型 / 穿着风格 / 面部特征 / 标志性细节
【性格】3 个核心特质 / 1 个致命缺陷 / 口癖与习惯
【背景】出身 / 关键事件（2-3 个）/ 创伤与执念
【外在欲望】这一部里想要什么（具体目标）
【内在需求】真正需要什么（情感/认知转变）
【恐惧】最怕发生什么（驱动回避行为）
【秘密】不想让人知道的（后期反转燃料）
【关系网】对谁忠诚 / 与谁冲突 / 谁是镜子
【变化轨迹】故事开始的状态 -> 故事结束的状态
```

### 3. 命名与一致性
- 名字承载时代/地域/阶层信息；同名角色之间的称呼变化（"老张"→"张队"）暗示关系变化。
- 一致性不是"不变"：人物可以有矛盾特质（外冷内热），但矛盾要有原因和一致性逻辑。

## 欲望与需求（Want vs Need）

- **外在欲望（Want）**：人物嘴上想要的具体目标（赢得比赛、找到凶手、求婚成功）。
- **内在需求（Need）**：人物潜意识真正缺乏的（学会信任、接纳自己、放下仇恨）。
- **故事的引擎**：人物追逐 Want，但只有当他意识到并满足 Need 时，角色弧才完成。
- **Want 驱动情节，Need 承载主题**（No Film School）：情节线解决 Want，主题线解决 Need。
- **创作检查**：主角的 Want 必须足够强烈和具体（否则观众不投入）；Need 必须与缺陷直接相关（否则转变无逻辑）。

## 角色弧（Character Arc）

三种基本弧线（ScreenCraft 三类型）：

### 1. 变化弧（Change Arc / Transformation Arc）
- 主角经历故事后**变得更好或更糟**（内在转变）。
- 正面变化弧：克服缺陷，满足 Need（《狮子王》辛巴从逃避到担当）。
- 负面变化弧：向恶转变（《绝命毒师》沃尔特·怀特从谨小慎微到冷酷）。
- 公式：缺陷 → 挑战 → 挣扎 → 顿悟 → 新自我（对应三幕结构中的转变）。

### 2. 平弧（Flat Arc / Testing Arc）
- 主角信念基本不变，而是**用信念改变世界**；世界在变，主角坚守。
- 适合"信念坚定的英雄"：主角已经完整，故事考验他的信念（《超人》《疯狂动物城》朱迪）。
- 关键：主角的信念必须被反复挑战并最终证明正确/升华。

### 3. 堕落弧（Fall Arc / Negative Arc）
- 主角从高位跌落（被欲望/环境摧毁）（《教父》迈克尔）。
- 与负面变化弧的区别：堕落弧强调"毁灭的必然性"，负面变化弧强调"选择的过程"。

**弧线检查**：故事结束时，主角与开场相比**内在**变了什么？如果答案只有"他赢了/输了"，弧线不完整。

## 人物原型（Archetypes）

荣格原型在英雄之旅中的功能映射（ScreenCraft 英雄之旅角色原型）：

| 原型 | 功能 | 示例 |
|---|---|---|
| 英雄 Hero | 承担旅程、做出改变 | 卢克·天行者 |
| 导师 Mentor | 传授智慧/工具，推动出发 | 欧比旺、甘道夫 |
| 信使 Herald | 发出召唤、带来改变的消息 | 猫头鹰送信 |
| 守门人 Threshold Guardian | 设置考验、检验决心 | 桥头守卫 |
| 盟友 Ally | 陪伴、互补、人性化主角 | 楚巴卡、山姆 |
| 变形者 Shapeshifter | 立场暧昧、制造不确定 | 兰多、猫女 |
| 阴影 Shadow | 反派/黑暗面外化 | 达斯·维达 |
| 捣蛋鬼 Trickster | 打破僵局、制造意外 | 洛基、小丑 |

**用法与禁忌**：
- 原型是**起点**不是终点：把原型当作人物骨架，再填入独特性（职业、口癖、道德观）避免刻板印象（Stereotype）。
- 反派设计：反派必须有自己的逻辑（"每个反派都是自己故事的主角"）；纯粹的恶 = 纸片人。
- 对位人物（Foil）：性格相反的配角映照主角（理性 vs 冲动），让主角特质更鲜明。

## 人物塑造方法

1. **Lajos Egri 辩证人物观（三棱镜）**：《The Art of Dramatic Writing》主张人物 = 生理（身体条件）+ 社会（阶层、教育、家庭）+ 心理（性情、执念、缺陷）三者的统一；人物设定必须与故事冲突直接相关。
2. **行动揭示性格**：不要写"他很勇敢"，写"他在所有人后退时向前走了一步"。
3. **关键时刻的选择**：人物的真实面目在压力下显现；每个主角至少安排一次"道德选择"。
4. **对白塑造**：说什么、不说什么、怎么说（语速、用词、回避）都是性格。
5. **细节胜过形容词**：一个习惯（转戒指）、一个物品（父亲的怀表）比十句描述更立体。

## 世界观构建（Worldbuilding）

### Sanderson 世界观三支柱

#### 1. 物理设定（Physical Setting）
- 地理：山川如何塑造文化（隔绝、贸易、战争）。
- 气候与天气：影响食物、衣着、建筑、作息。
- 动植物：独特的物种如何与人互动。
- 宇宙观：天体（多月亮影响潮汐与神话）。

#### 2. 文化设定（Cultural Setting）
- 法律与政体：区域治理差异、权力结构。
- 宗教与信仰：崇拜什么、信仰如何影响日常与政治。
- 科技水平：时代定位（中世纪/蒸汽/近未来）。
- 语言与方言：命名规律、语言如何反映历史。
- 社会规范与传统：禁忌、节日、阶层差异。

#### 3. 魔法/超自然体系（Magic System）
- 硬魔法 vs 软魔法：规则明确（可预测、可解谜）vs 神秘模糊（制造敬畏）。
- 对社会的影响：被敬畏、被恐惧、还是日常工具。
- 限制与代价：什么阻止它无敌（消耗、代价、稀缺性）——"能力越大代价越大"是戏剧性来源。

### 桑德森三定律（扩展阅读）与世界观原则
1. **第一定律（硬魔法）**：解决冲突的魔法越强，规则就要越明确（读者才能理解解法）。
2. **第二定律（软魔法）**：制造谜团的魔法，可以弱化规则（保持惊奇）。
3. **第三定律**：先深化已有的，再添加新的（Depth over Density）——不要堆砌设定，让设定互相影响产生深度（如《迷雾之子》：魔法、社会、角色共同演化）。
4. **冰山理论（Iceberg Technique）**：大部分世界细节沉在水下，观众只看到尖角；但"水下部分"让尖角显得真实（N.K. Jemisin、Patricia Wrede 同款建议）。
5. **抽象金字塔（Pyramid of Abstraction）**：用感官细节锚定抽象设定——不要百科全书式解释魔法机制，而写"灼烧金属的金属味"（《沙丘》的香料、《迷雾之子》的金属味）。
6. **避免"世界构建病"（Worldbuilder's Disease）**：无限规划细节会瘫痪写作；设定为叙事服务，只深入影响剧情的关键元素。
7. **一致性（Internal Consistency）**：内部规则必须自洽（PlotLens/Four Cs：Consistency 是第一 C）；读者能原谅奇怪的世界，不能原谅自相矛盾的世界。**设定冲突检查**：每个"能力"必须有"限制"，每个"限制"必须被遵守。

### 信息揭露节奏
- **避免信息倾倒（Info-dump）**：背景通过角色经历、感官细节、冲突中的对质自然揭示（Sanderson）。
- 世界观的"展示顺序" = 观众理解顺序：先感官（这是什么感觉），再功能（它能做什么），最后规则（为什么这样）。

## 世界观与叙事结合

- **设定驱动冲突**：好设定本身产生故事（"如果魔王赢了会怎样"——《迷雾之子》的起点）。
- **设定服务主题与人物**：世界观里的压迫制度要有人物的具体损失才成立。
- **信息差结构**：观众知道的设定信息 > 角色知道（悬念）；< 角色知道（揭秘）。
- **短内容的设定策略**：短视频/短剧只展示 1-2 个"招牌设定"（一个核心规则 + 一个视觉奇观），其余全部省略。

## 在 AI 视频生成中的应用（一致性模板）

### 角色一致性提示词模板（Identity Sheet）
```
[角色名] identity sheet:
- 外貌: [年龄/性别/体型/发色发型/肤色/标志性特征（伤疤、纹身、眼镜）]
- 服装: [主色 + 款式 + 标志配饰]（跨镜头必须一致）
- 性格外显: [姿态/表情习惯/语速]
- 禁止变化: [发型、服装配色、面部特征、体态]（每个镜头提示词都要重申）
- 参考图职责: [哪张图控制身份，哪张控制构图，哪张控制光线]
```

### 场景/环境一致性提示词模板
```
[场景名] environment sheet:
- 空间: [室内/室外，主要元素布局，标志物（钟楼、招牌、特定家具）]
- 光线: [主光源方向/色温/氛围]
- 色调: [主色调 + 强调色]
- 时间: [季节/时段/天气]
- 禁止变化: [标志物位置、招牌文字、墙面颜色]
```

### 连续性账本（对应 DirectorX continuity ledger）
- 每个持久元素（角色/场景/道具/品牌）建立一张卡片：稳定标识符 + 不变特征列表 + 已用镜头记录。
- 生成每个新镜头前，把该元素的"禁止变化"列表写入提示词。
- 审片时逐项核对：发型/服装/面部/标志物/光线方向是否漂移。

## 常见错误

1. **完美主角**：没有缺陷就没有成长空间；观众无法共情。
2. **Want/Need 混淆**：只写目标不写需求，故事有情节没主题。
3. **弧线缺失**：结尾的主角与开头完全相同（除非是平弧且考验充分）。
4. **反派纸片化**：坏得没理由；给反派一个"他眼中的正义"。
5. **信息倾倒**：开场三分钟讲完世界观设定。
6. **设定堆砌**：世界构建病——设定与情节无关。
7. **设定不一致**：魔法/科技规则前后矛盾（观众最先察觉）。
8. **AI 角色漂移**：生成多个镜头后角色外貌变化——必须用 identity sheet 固定特征。
