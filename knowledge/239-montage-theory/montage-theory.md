# 电影蒙太奇理论（Montage Theory — Kuleshov Effect & Intellectual Montage）

> 本页为电影蒙太奇理论：苏联蒙太奇学派、库列肖夫效应（Kuleshov Effect：同镜头因相邻镜头而变义）、爱森斯坦理智蒙太奇（Intellectual Montage：冲突产生第三义）、蒙太奇类型。知识本体来自 2026 蒙太奇理论（Wikipedia/Scriptease/Dyerbolical）。AI 应用面向 DirectorX：序列设计（衔接 127 剪辑、150 叙事、239 对应、158 情绪）。

## 概述

**核心断言**：蒙太奇理论 = **"意义产生于镜头之间"**——库列肖夫效应：同一表情因相邻镜头读出不同含义（饥饿/悲伤/欲望）；爱森斯坦理智蒙太奇：**对立镜头冲突产生第三义**（衔接 127：剪辑节奏的理论根基；150：序列叙事）。

## 核心概念

### 库列肖夫效应

```
同一演员表情 + 不同相邻镜头（汤/棺材/女人）
→ 观众读出不同情绪（饥饿/悲伤/欲望）
→ 意义来自组合，非镜头本身
```

### 爱森斯坦蒙太奇类型

| 类型 | 机制 |
|---|---|
| 节拍蒙太奇 | 长度节奏 |
| 节奏蒙太奇 | 画面内运动 |
| 调性蒙太奇 | 情绪氛围 |
| 泛音蒙太奇 | 多层暗示 |
| 理智蒙太奇 | 对立冲突产义 |

### 蒙太奇在 AI 生成的应用

**镜头配对设计**（画面 A + 画面 B → 新意义）：序列提示词按"意义组合"设计而非单镜头（衔接 127：配对转场；158：情绪曲线）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 单镜头思维 | 无组合义 | 配对设计 |
| 镜头无关 | 意义散 | 意象冲突 |
| 忽视节奏 | 序列平 | 节拍控制 |
| 无校验 | 义不对 | 组合校验 |
