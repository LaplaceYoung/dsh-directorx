# 电影导演风格签名（Auteur Signature — Visual Trademarks & Recurring Motifs）

> 本页为电影导演风格签名：作者论（Auteur Theory：导演=作者）、视觉商标（重复运镜/色板/剪辑模式/母题）、风格签名设计（自建可识别语法）。知识本体来自 2026 作者论（Fiveable/Telegraph/Nightscape/Backstage）。AI 应用面向 DirectorX：风格识别（衔接 126 风格、284 对应、272 标志美学、195 品牌）。
> 来源：Fiveable「Auteur Theory and Visual Signatures」、Telegraph「Directors' Visual Trademarks」、Nightscape「The Director's Signature」、Backstage「Auteur Theory Explained」。

## 概述

**核心断言**：导演风格签名 = **可识别的视觉商标**——重复运镜（库布里克凝视/希区柯克窥视）、色板（韦斯·安德森对称粉彩/塔伦蒂诺风格化暴力）、剪辑模式、母题（衔接 272：标志性美学的作者论；126：风格签名的构建）。

## 核心概念

### 导演商标库（Telegraph）

| 导演 | 商标 |
|---|---|
| 库布里克 | 对称凝视/单向透视 |
| 希区柯克 | 窥视/悬念角度 |
| 韦斯·安德森 | 对称/粉彩/表格镜头 |
| 塔伦蒂诺 | 风格化对白/暴力 |
| 大卫·林奇 | 梦境/诡异 |

### 签名构成（Fiveable）

```
重复运镜（Camera Move）+ 色板（Palette）
+ 剪辑模式（Editing Pattern）+ 母题（Motif）
```

### 自建签名（AI 应用）

**风格令牌系统**（重复运镜词+色板+构图规则）——把导演签名转成可复用提示词（衔接 195 品牌、126 风格令牌）。

## 技巧与示例

### 签名设计工作流（AI 映射）

```text
视觉意图 → 签名构成（运镜/色板/剪辑/母题）
  → 风格令牌（126）→ 提示词
  → 生成 → 识别度校验（"像自己的作品吗"）
```

### 签名提示词示例

"signature style: symmetrical composition, pastel palette, tabletop shots, deadpan tone"——**商标词汇系统**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 模仿他人签名 | 版权/无自我 | 自建令牌 |
| 签名元素散 | 无识别 | 系统化 |
| 色板漂移 | 商标失效 | 色板锁定 |
| 无母题 | 无记忆点 | 母题设计 |
| 不校验识别 | 效果未知 | 识别度检查 |

## 工作流应用（AI 映射）

风格识别（衔接 126/195/272）：

```text
签名构成 → 风格令牌 → 提示词 → 生成 → 识别校验
```

**DirectorX 纪律**：签名=可识别商标；四要素系统化；自建防模仿；识别度校验。
