# AI 图片情绪记忆（Emotional Memory — Nostalgia, Memory Triggers & Mood Evocation）

> 本页为 AI 图片的情绪记忆：怀旧唤起（暖色/柔和光/颗粒/年代物）、记忆触发器（旧照片/雨窗/信件）、情绪记忆配方（Meta AI 提示）、年代线索（中期世纪）。知识本体来自 2026 情绪记忆提示词（Meta AI/Media.io/GetPromptAtlas）。AI 应用面向 DirectorX：怀旧图（衔接 250 氛围、294 对应、283 年代、155 色彩）。
> 来源：Meta AI「AI Photo Prompts: 10 Examples」、Dreamina「Old Memories Photo Prompt」、Media.io「Emotional Memory Photos」、GetPromptAtlas「Nostalgic Mood」。

## 概述

**核心断言**：情绪记忆 = **"视觉记忆触发器"**——暖色板+柔和光+颗粒+年代物组合唤起怀旧/回忆；具体物件（旧照片/雨窗/信件）是记忆锚（衔接 250：氛围的记忆维度；283：年代）。

## 核心概念

### 情绪记忆配方（Meta AI 提示）

```
暖色板 + 柔和光 + 细腻颗粒 + 年代纹理
+ 浅景深 + 记忆物件（旧照片/信件）+ 怀旧物件
+ 安静情绪 + 4K 写实
```

### 记忆触发器

| 触发器 | 唤起 |
|---|---|
| 旧照片 | 家庭/时光 |
| 雨窗 | 沉思/孤寂 |
| 信件/明信片 | 远方/回忆 |
| 复古室内 | 童年/旧日 |

### 怀旧分层（GetPromptAtlas）

暖调 + 柔光 + 年代线索 = **"有记忆温度"**（衔接 270 风格情绪）。

## 技巧与示例

### 情绪记忆工作流

```text
记忆类型（怀旧/沉思/温暖）→ 配方
  → 触发器物件 → 提示词 → 生成
  → 情绪唤起校验（是否有"回忆感"）
```

### 提示词示例（Meta AI 版）

"cinematic nostalgic photo, warm golden hour, soft grain, vintage textures, adult looking at faded family photo, retro objects, quiet sentiment"。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无触发器 | 无记忆感 | 物件锚 |
| 冷色硬光 | 无怀旧 | 暖柔配方 |
| 年代混乱 | 记忆错 | 单年代 |
| 情绪直写 | 无效 | 视觉配方 |
| 不校验唤起 | 效果未知 | 情绪检查 |

## 工作流应用（AI 映射）

怀旧图（衔接 155/250/270/283）：

```text
记忆类型 → 配方 → 触发器 → 提示词
  → 生成 → 唤起校验
```

**DirectorX 纪律**：物件是记忆锚；暖柔颗粒配方；单年代一致；情绪转视觉。
