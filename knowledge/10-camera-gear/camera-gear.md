# 摄影机与器材（Camera & Gear）

> 本页是 DirectorX 器材知识库：传感器与机身选择、镜头体系、稳定设备、曝光三角、ND 滤镜与附件、器材术语。帮助"用合适的器材参数描述需求"与"按预算选型"。
> 来源：Envato Tuts+ 稳定设备指南、PetaPixel 传感器对比、Tools for Film 曝光三角（索引）、行业选型常识。

## 概述

器材决定画面的**上限**（动态范围、分辨率、稳定性），但决定下限的是灯光、调度与故事。选型三问：
1. 拍什么（口播/剧情/产品/户外）？
2. 什么预算（手机/入门/专业）？
3. 什么交付（短视频/流媒体/院线）？

**核心认知**：传感器尺寸 > 分辨率；动态范围 > 像素数；稳定性 > 画质参数（Noam Kroll：动态范围比分辨率更影响"电影感"）。

## 传感器（Sensor）

### 尺寸对比（PetaPixel 标准）
| 规格 | 面积（约） | 等效系数 | 特点 |
|---|---|---|---|
| 中画幅 Medium Format | 44×33mm | 0.79x | 极致画质，大画幅感 |
| 全画幅 Full Frame | 36×24mm | 1.0x | 弱光强、景深浅、行业标准 |
| APS-C | 23.5×15.6mm | 1.5x | 画质与体积平衡，性价比 |
| M4/3 Micro Four Thirds | 17.3×13mm | 2.0x | 轻小、防抖优势、镜头便宜 |
| 1 英寸（手机/卡片机） | 13.2×8.8mm | 2.7x | 便携 |
| 手机小底 | <10mm | — | 计算摄影补偿 |

### 传感器与"电影感"
- **等效焦距**：APS-C 用 35mm 镜头 ≈ 全画幅 52mm（1.5 倍系数）；M4/3 用 25mm ≈ 全画幅 50mm（2 倍）。
- **景深差异**：同构图下，全画幅景深更浅（背景更虚）；小底要"假装大底"：用更长焦距 + 更远距离 + 更大光圈（Noam Kroll 的 crop sensor 攻略）。
- **动态范围（Dynamic Range）**：传感器能同时记录的明暗跨度（档位 EV/Stops）。高档电影机 13-15+ 档，入门 10-12 档。动态范围决定高光/阴影细节，比分辨率更影响"电影感"。
- **弱光与 ISO**：大底高感噪点更少；双原生 ISO 机型（如部分电影机）弱光表现更强。
- **Log 曲线**：电影机/微单的 Log 模式（S-Log、V-Log、C-Log、S35 RAW 等）记录更宽动态范围，供后期调色——"灰片"是常态，不是故障。

## 机身类型（Camera Bodies）

| 类型 | 代表 | 优点 | 缺点 |
|---|---|---|---|
| 手机 | iPhone/安卓旗舰 | 随身、计算摄影、HDR 视频强 | 传感器小、控制少 |
| 微单（Mirrorless） | Sony FX/A7、Panasonic GH/LUMIX、Fujifilm X | 轻便、镜头多、Log 视频 | 长时间录制过热风险 |
| 单反（DSLR） | Canon EOS R 系（过渡） | 便宜二手 | 视频功能弱于微单 |
| 电影机（Cinema Camera） | RED、ARRI、Blackmagic | 动态范围、RAW、接口全 | 贵、重、需外围 |
| 运动相机 | GoPro、Insta360 | 防抖、防水、小巧 | 画质上限低 |
| 无人机 | DJI 系列 | 航拍视角 | 天气/法规限制 |
| 网络摄像头/手机直播 | — | 口播/直播零门槛 | 画质与自由度低 |

**选型建议（预算导向）**：
- 预算有限（<5000）：手机 + 补光灯 + 麦克风 > 买低端相机。
- 入门（5000-15000）：APS-C/全画幅微单 + 24-70 等效变焦 + 稳定器。
- 专业（>30000）：全画幅电影机/微单 + 电影镜头组 + 灯光组。

## 镜头体系（Lenses）

### 镜头类型
| 类型 | 特征 | 用途 |
|---|---|---|
| 变焦 Zoom | 焦段可调，方便 | 纪录片、活动、旅行（效率优先） |
| 定焦 Prime | 单一焦段，画质/光圈优 | 剧情、广告（画质优先） |
| 微距 Macro | 极近对焦 | 产品细节、手表/珠宝 |
| 移轴 Tilt-Shift | 透视校正/浅景深玩具效果 | 建筑、微缩效果 |
| 鱼眼 Fisheye | 180° 夸张变形 | 运动、创意 |
| 电影镜头 Cine Lens | 手动光圈环、跟焦齿、T 光圈 | 专业拍摄（团队协作） |

### 焦段速查（全画幅等效）
| 焦段 | 视角 | 用途 |
|---|---|---|
| 14-24mm 超广 | 夸张空间 | 环境、建筑、冲击 |
| 24-35mm 广角 | 空间感强 | 环境人像、旅行、vlog |
| 35mm | 纪实标准 | 街拍、环境叙事 |
| 50mm | 人眼视角 | 万能叙事、人像 |
| 85mm | 压缩+柔和 | 人像、特写 |
| 100-200mm 长焦 | 强压缩 | 偷窥感、体育、压缩背景 |
| 24-70mm 变焦 | 全能 | 口播/采访/活动主力 |
| 70-200mm 变焦 | 灵活长焦 | 活动、特写、压缩 |

### 光圈（Aperture）
- 数字越小光圈越大（f/1.4 > f/2.8 > f/8）；T 光圈（电影镜头）= 实测透光率。
- **最大光圈影响**：景深（浅=虚化）、进光量（暗光可用）、体积价格。
- 常用电影镜头组：T1.4-T2.8；"套头 f/3.5-5.6"是入门瓶颈。

## 稳定设备（Stabilization）

### 设备谱系（Envato Tuts+ 框架）
| 设备 | 稳定性 | 移动性 | 适用 |
|---|---|---|---|
| 三脚架 Tripod | 最高（静态） | 低 | 访谈、延时、固定机位 |
| 独脚架 Monopod | 中高 | 中 | 体育、活动、跟拍 |
| 云台 Gimbal（电动） | 高（动态） | 高 | 跟拍、走位、移动镜头 |
| 斯坦尼康 Steadicam | 高 | 中高 | 复杂移动长镜头 |
| 肩扛 Shoulder Rig | 中（有机晃动） | 中 | 纪实、战争感 |
| 无人机 Drone | 高（空中） | 极高 | 航拍、跟车 |
| 相机/镜头防抖（OIS/IBIS） | 辅助 | — | 手持兜底 |
| 后期稳定（Warp Stabilizer 等） | 补充 | — | 救急（有裁切与果冻风险） |

### 使用要点
- **三脚架**：先伸粗腿再伸细腿；中心柱尽量低；碳纤维轻便但贵。
- **云台**：平衡调试是关键（未平衡的云台比手持更糟）；走路屈膝小步；跑动双手持、贴近身体。
- **无人机**：平滑推杆、提前规划航线、风大不飞；智能模式（跟随/环绕/航点）出片率高。
- **后期稳定**：裁剪画面、边缘变形——作为兜底而非常规手段。

## 曝光三角（Exposure Triangle）

| 参数 | 作用 | 视频特别注意事项 |
|---|---|---|
| 光圈 Aperture | 进光量 + 景深 | 定下景深需求后锁定 |
| 快门 Shutter | 进光量 + 运动模糊 | **180° 快门规则**：快门 ≈ 1/(2×帧率)——24fps→1/48s，30fps→1/60s；改变快门会破坏电影感运动模糊 |
| ISO | 感光度 | 双原生 ISO 选干净档位；越高噪点越多 |

**视频与照片的差异**：照片可以任意调快门，视频受帧率与运动模糊约束，所以视频曝光主要靠**光圈 + ISO + ND 滤镜**，而不是快门。

## ND 滤镜（Neutral Density）

- **作用**：像"墨镜"一样减少进光而不改变颜色——让你在白天户外也能用大光圈/标准快门。
- **必要性**：拍视频在阳光下 f/1.4 会过曝，必须 ND。
- **类型**：固定 ND（ND4/ND8/ND16/ND64）、可调 ND（旋转调节，方便但有偏色/十字纹风险）、内置 ND（部分电影机/无人机标配）。
- **ND 与快门**：ND 的存在就是为了让快门留在 1/48-1/60（保持运动模糊），而不是为了"调暗"本身。

## 在 AI 视频生成中的应用

1. **提示词器材参数**：`shot on 35mm full frame, 85mm f/1.4, shallow DOF, handheld gimbal movement`——器材语言 = 画面特征语言。
2. **模拟效果**：AI 生成可指定"镜头感"——广角畸变、长焦压缩、浅景深焦外、运动模糊（快门感）。
3. **选型建议输出**：为客户的拍摄需求给出器材清单（机身/镜头/稳定/灯光/收音）+ 预算档位。
4. **拍摄可行性评估**：AI 方案落地前核对器材约束（夜间拍摄需大光圈+灯光、无人机需空域许可、室内收音需领夹麦）。

## 常见错误

1. 只看分辨率不看动态范围：8K 小底 < 4K 大底的电影感。
2. 用快门控制曝光：运动模糊消失，画面"视频感"。
3. 白天户外不用 ND：要么过曝要么快门错误。
4. 云台未平衡就开拍：比手持更晃。
5. 忽略收音：画面 4K、声音手机麦——观众立刻划走。
6. 全焦段一个镜头包打天下：广角拍人像变形、长焦拍环境太窄。
7. 过度依赖后期稳定：裁切+变形+果冻，前期稳定才是正道。
8. 买机身不买灯/麦：预算分配错误（灯光与声音的回报远大于机身升级）。
