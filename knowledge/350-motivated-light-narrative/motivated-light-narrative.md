# 电影实拍光效-动机-叙事三整合（Motivated Light × Narrative — Unmotivated as Tool）

> 本页为电影实拍光效-动机-叙事三整合：动机化布光（光源真实：窗/灯/月光+色温一致）、实用光（画面内可信动机）、**非动机光作为叙事工具**（有意为之服务故事）。知识本体来自 2026 光效叙事（InVideo/CINED/NoFilmSchool）。AI 应用面向 DirectorX：光效统一（衔接 341 实拍光效、350 对应、170 光匹配、272 三通道）。
> 来源：InVideo「Cinematic Vocabulary for AI Prompts」、CINED「Unmotivated Light as Storytelling Tool」、NoFilmSchool「What Is Motivated Lighting」、StudioBinder「Motivated Lighting」。

## 概述

**核心断言**：实拍光效-动机-叙事 = **"光源真实+光即故事"**——动机化布光（光源真实/色温一致）；实用光提供可信动机；**非动机光可作叙事工具**（有意为之）（衔接 341：光效深化；170：匹配）。

## 核心概念

### 动机化三要点（StudioBinder）

```
① 光源真实（窗/灯/月光）
② 色温一致（170 匹配）
③ 环境平衡（环境光+补光）
```

### 非动机光叙事（CINED）

无来源的光=有意为之（梦境/主观/超现实）——**"打破动机=叙事声明"**（衔接 267 通感）。

### 光即故事（NoFilmSchool）

实用光（画面内）讲叙事 + 提供可信动机——**"光有出处也有意义"**。

## 技巧与示例

### 三整合工作流（AI 映射）

```text
叙事意图 → 动机化设计（光源/色温）
  → 非动机点（叙事声明）→ 生成
  → 光效-叙事校验（光说故事吗）
```

### 三整合示例

"motivated window key + practicals + unmotivated color as dream signal"——**动机+实用+非动机**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 光无出处 | 假 | 动机化 |
| 色温乱 | 违和 | 一致 |
| 非动机无意 | 破戏 | 叙事声明 |
| 实用光无叙事 | 装饰 | 故事绑定 |
| 不校验光叙 | 效果未知 | 光故事检查 |

## 工作流应用（AI 映射）

光效统一（衔接 170/272/341）：

```text
意图 → 动机 → 非动机点 → 生成 → 校验
```
