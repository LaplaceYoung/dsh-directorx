## 概述

**核心断言**：剪影-逆光-氛围 = **"轮廓×背景×情绪的融合"**——剪影（背光+高对比背景保可读）+ 氛围（体积雾/偏色/合成波）+ 情绪词（戏剧/神秘/史诗）三层融合（衔接 342：剪影深化；181：氛围）。

## 核心概念

### 三融合要素

```
① 剪影（背光+轮廓清晰）
② 氛围（体积雾/色偏/光晕）
③ 情绪（戏剧/神秘/史诗词）
```

### 背景可读性（Media.io）

简单高对比背景（天空/窗光/霓虹雾）最大化轮廓——**"背景简单轮廓清晰"**（衔接 192 负空间）。

### 情绪配对（Text2Img）

光效提示 + 情绪词（dramatic/cinematic/moody）——**"光+情绪"**。

## 技巧与示例

### 三融合工作流

```text
叙事意图 → 剪影设计（背光/背景）
  → 氛围混合（雾/色）→ 情绪词
  → 生成 → 可读性校验
```

### 融合提示词

"silhouette against neon-soaked city, backlit from rain-lit windows, volumetric fog, cyan-pink cast, moody futuristic"——**剪影+氛围+情绪**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 轮廓混入背景 | 不可读 | 高对比 |
| 氛围过重 | 剪影消失 | 平衡 |
| 无情绪词 | 平 | 情绪配对 |
| 融合过度 | 杂乱 | 层次 |
| 不校验可读 | 效果未知 | 轮廓检查 |

## 工作流应用（AI 映射）

氛围剪影（衔接 181/192/317/342）：

```text
意图 → 剪影 → 氛围 → 情绪 → 生成 → 校验
```
