# 电影手持-见证-纪实三要素（Handheld × Witness × Documentary — Verité Aesthetics）

> 本页为电影手持-见证-纪实三要素：真实电影（Cinéma Vérité：手持=在场即时）、观察式纪实（Observer=见证非记录器）、自然光+未抛光画面+最少干预（真实性）、纪实伦理（真实×同意）。知识本体来自 2026 纪实美学（Wikipedia/Fiveable/Floniks）。AI 应用面向 DirectorX：纪实感（衔接 343 手持、352 对应、199 UGC、166 伦理）。

## 概述

**核心断言**：手持-见证-纪实 = **"在场即真实"**——真实电影（手持=在场/即时）；观察式纪实（见证者非记录器）；自然光+未抛光+最少干预；纪实伦理（真实×同意）（衔接 343：手持的纪实版；166：伦理）。

## 核心概念

### 真实电影（Cinéma Vérité）

```
手持 = 在场/即时/自发
（演员即兴/非舞台化）
```

### 观察式纪实（Fiveable）

见证者（Observer）非记录器——**"我看到了"**（衔接 343 见证视角）。

### 真实性三要素（Floniks）

自然光 + 未抛光画面 + 最少干预——**"不修饰"**（衔接 199 反精致）。

### 纪实伦理（Beverlyboy）

真实性×主体同意（166）——**"真实但有德"**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 抛光过度 | 失真实 | 未抛光 |
| 无在场感 | 记录器 | 见证视角 |
| 干预过多 | 非纪实 | 最少干预 |
| 无同意 | 伦理风险 | 166 |
| 不校验在场 | 效果未知 | 在场检查 |
