# AI 图片光影叙事（Light-Shadow Narrative — Silhouette, Backlight & Shadow as Story）

> 本页为 AI 图片的光影叙事：剪影（Silhouette：形态叙事/匿名性）、逆光/轮廓光（分离/神圣感）、阴影叙事（长影/柔边/锐影的情绪）、情绪先行+光质+方向。知识本体来自 2026 光影提示词（Text2Img/Civitai/HelpingPrompt）。AI 应用面向 DirectorX：光影图（衔接 236 明暗、342 对应、261 光位、181 氛围）。

## 概述

**核心断言**：光影 = **"阴影即故事"**——剪影（形态叙事/匿名/神秘）、逆光轮廓（分离/神圣）、阴影行为（长影=时间/锐影=紧张/柔边=温柔）承载叙事（衔接 236：明暗的叙事版；261：光位）。

## 核心概念

### 剪影叙事（Silhouette）

```
逆光 + 深背景 → 形态叙事
（匿名性/神秘/身份隐藏，衔接 274 威胁藏露）
```

### 阴影行为语义（Civitai）

| 阴影 | 语义 |
|---|---|
| 长影 | 时间/夕阳/孤寂 |
| 锐影 | 紧张/对峙 |
| 柔边影 | 温柔/梦幻 |
| 投影 | 空间/象征 |

### 情绪先行（Text2Img）

先写情绪词再写光质/方向——**"情绪决定光影"**（衔接 261）。

## 技巧与示例

### 光影叙事工作流（AI 映射）

```text
情绪目标 → 光影选型（剪影/逆光/阴影）
  → 提示词（情绪+光质+方向）
  → 生成 → 光影叙事校验
```

### 剪影提示词

"backlit silhouette against deep background, mysterious mood, rim light, crisp edge"——**剪影+情绪**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 剪影无叙事 | 空洞 | 形态意义 |
| 阴影行为乱 | 情绪错 | 语义表 |
| 无情绪先行 | 效果散 | 情绪驱动 |
| 逆光过度 | 细节全灭 | 保留轮廓 |
| 不校验叙事 | 效果未知 | 光影检查 |
