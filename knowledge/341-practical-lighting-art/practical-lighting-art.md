# 电影实拍光效艺术（Practical Lighting — Motivated Sources & In-Frame Light）

> 本页为电影实拍光效艺术：实用光源（Practicals：画面内可见光源装饰+照明）、动机化布光（Motivated Lighting：仿真实光源证明主光）、实用光×非叙事光平衡（曝光/情绪）。知识本体来自 2026 实拍光效（Fiveable/NoFilmSchool/Wedio）。AI 应用面向 DirectorX：光效设计（衔接 125 光线、341 对应、225 布光、170 光匹配）。
> 来源：Fiveable「Practical and Motivated Lighting」、NoFilmSchool「A Primer on Practical Lights」、Wedio「Practical Lighting」、NoFilmSchool「What Is Practical Lighting」。

## 概述

**核心断言**：实拍光效 = **"画面内光源的叙事动机"**——实用光源（台灯/窗/电视）既装饰又照明，动机化布光（仿真实光源）证明主光来源；实用光×非叙事光平衡（曝光+情绪）（衔接 225：布光的动机维度；170：光匹配）。

## 核心概念

### 实用光源（Practicals）

```
画面内可见光源（台灯/窗/电视/蜡烛）
→ 装饰（画面丰富）+ 照明（动机）
```

### 动机化布光（Motivated）

仿真实世界光源（主光"来自"窗口/台灯）——**"光有出处"**（衔接 170）。

### 平衡（Wedio）

实用光 + 非叙事光（补光/轮廓）平衡曝光与情绪——**"实用定调，非叙事补光"**。

## 技巧与示例

### 实拍光效工作流（AI 映射）

```text
场景分析 → 实用光源设计（画面内）
  → 动机化主光 → 补光平衡
  → 生成 → 光效校验（光有出处吗）
```

### 光效提示词

"practical lamps in frame, motivated window key light, soft fill balancing"——**实用+动机+平衡**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 光无出处 | 假 | 动机化 |
| 实用光过弱 | 无照明 | 实用+补光 |
| 装饰过度 | 杂乱 | 克制 |
| 非叙事光过强 | 破动机 | 平衡 |
| 不校验光效 | 效果未知 | 出处检查 |

## 工作流应用（AI 映射）

光效设计（衔接 125/170/225）：

```text
场景 → 实用光 → 动机主光 → 平衡 → 生成 → 校验
```

**DirectorX 纪律**：光有出处；实用定调；非叙事补光；动机不破。
