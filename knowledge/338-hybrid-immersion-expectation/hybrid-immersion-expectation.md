# 电影杂交-沉浸-预期总设计（Hybrid-Immersion-Expectation — Unified Suspense & Experience）

## 概述

**核心断言**：杂交-沉浸-预期 = **"双沉浸+悬念工程"**——时空沉浸×叙事沉浸（维持动量）；电影/游戏融合（跨媒介线索）；悬念=**"等待意外"**（技术化）；节奏/共识/主动角色（衔接 268：悬念；323：沉浸）。

## 核心概念

### 双沉浸（UM Filmic）

```
时空沉浸（环境在场）× 叙事沉浸（故事卷入）
→ 双轨维持动量
```

### 悬念技术（USP 论文）

悬念 = "等待意外"（部分焦虑的不确定）——**"技术化等待"**（衔接 268 知识差）。

### 融合参与（PMC）

跨媒介线索 + 观众主动角色（共识/进展）——**"观众是共谋"**（衔接 322 体验）。

## 技巧与示例

### 总设计工作流（AI 映射）

```text
双沉浸设计（时空+叙事）→ 悬念工程（268）
  → 跨媒介线索 → 主动参与（167）
  → 生成 → 双沉浸校验
```

### 总设计示例

"spatial + narrative immersion, suspense as waiting, cross-medium clues, active audience"——**四要素**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 单沉浸 | 动量断 | 双轨 |
| 悬念无工程 | 无等待 | 技术化 |
| 无跨媒介线索 | 单薄 | 融合 |
| 观众被动 | 无共谋 | 主动角色 |
| 不校验总设计 | 效果未知 | 体验检查 |

## 工作流应用（AI 映射）

总体验（衔接 167/268/304/322/323）：

```text
双沉浸 → 悬念 → 线索 → 参与 → 生成 → 校验
```
