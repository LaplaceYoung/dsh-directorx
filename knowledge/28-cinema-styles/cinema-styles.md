# 摄影风格流派（Cinema Styles & Visual Language）

> 本页是 DirectorX 风格流派知识库：黑色电影、法国新浪潮、真实电影/直接电影、韦斯·安德森对称美学、马利克自然光诗意、写实主义与风格化光谱。每个流派含视觉特征、手法清单、代表作品与 AI 生成提示词。
> 来源：Wikipedia French New Wave、Filmmakers Academy 黑色电影（索引）、Britannica Cinema verite、StudioBinder 风格指南（索引）、行业视觉语言常识。

## 概述

摄影风格（Cinematography Style）是**可识别、可复制的视觉语言**——由光线、构图、运镜、剪辑、色彩的组合定义。掌握流派 = 拥有"风格词汇表"：既能准确描述想要的画面，也能反推一部片子的构成。

**核心认知**：风格不是装饰，是**叙事立场**——黑色电影的低调光表达道德暧昧，新浪潮的跳切表达对"流畅幻觉"的拒绝。选风格 = 选立场。

## 黑色电影（Film Noir）

### 视觉特征（Filmmakers Academy / 行业共识）
| 要素 | 表现 |
|---|---|
| 低调光 Low-key Lighting | 大面积阴影、高光局部（明暗对照 Chiaroscuro） |
| 光线图案 | 百叶窗阴影、霓虹招牌、雨夜反光、烟 |
| 构图 | 荷兰角（失衡）、框架构图（门/窗）、剪影 |
| 角度 | 低角度（压迫）、极端特写 |
| 色彩（彩色时期） | 冷蓝阴影 + 暖琥珀高光（Neo-noir 现代配方） |
| 叙事 | 画外音（VO）、闪回、道德模糊的主角、蛇蝎美人 |
| 城市 | 夜晚街道、湿路面、烟雾 |

### 手法清单（可复用）
- **主光侧置**：硬光 90° 侧光制造"半脸暗"（分割光）；
- **百叶窗阴影**：用窗户格栅投影在墙上/脸上——标志性 noir 图案；
- **烟雾与蒸汽**：给光线"体积"；
- **剪影与轮廓**：人物从亮背景前走过；
- **荷兰角**：用于失衡/危机时刻（克制使用）。

### 代表
《马耳他之鹰》《双重赔偿》《第三人》《唐人街》（Neo-noir）、《银翼杀手》（Neo-noir 科幻）。

## 法国新浪潮（French New Wave / Nouvelle Vague）

### 运动本质（Wikipedia）
- 1958-1962，影评人（《电影手册》派）转行导演；反对"优质传统"（品质电影）的文学改编套路。
- **作者论（Auteur Theory）**：导演是电影的作者，个人签名贯穿作品。
- **核心理念**：不制造"沉浸幻觉"，而是**提醒观众在看电影**——反叛经典叙事的"专制"。

### 技术特征（低成本催生的风格）
| 手法 | 说明 |
|---|---|
| 跳切 Jump Cut | 《筋疲力尽》标志性手法——从长镜头中间删帧（省钱变风格） |
| 手持/便携设备 | 便携摄影机、自然光、直接同期声——纪录片质感 |
| 实景拍摄 | 街头/公寓/朋友家，而非影棚 |
| 打破轴线 | 主动越轴、180° 规则破坏 |
| 长跟拍镜头 | 《周末》堵车长镜等 |
| 旁白与间离 | 角色直接对观众说话、打破第四面墙 |
| 拼贴引用 | 致敬/引用其他电影 |
| 即兴对白 | 不追求完美台词 |
| 开放结局 | 问题不被回答——叙事歧义 |

### 代表
《四百击》《筋疲力尽》《广岛之恋》（左岸派）、《朱尔与吉姆》。

### 现代遗产
- 独立电影的低成本美学、手持纪实感、跳切作为"时间压缩"工具（短视频里已是常态）。

## 真实电影与直接电影（Cinéma Vérité / Direct Cinema）

### 两种传统
| | 真实电影（法国） | 直接电影（美国） |
|---|---|---|
| 立场 | 拍摄者**介入**（采访/在场） | 拍摄者**不介入**（观察） |
| 手法 | 导演提问、镜头在场 | 长时间观察、抓拍 |
| 代表 | 让·鲁什《夏日纪事》 | 梅索斯兄弟、怀斯曼 |

### 视觉特征
- 手持、自然光、同期声、无摆拍、接受"不完美"构图；
- 长镜头、跟拍、抓拍反应；
- 剪辑以"事件"为单位（呼应 13 文档观察式方法）。

## 韦斯·安德森对称美学（Wes Anderson / Andersonian）

### 视觉配方（The Conversation 拆解）
- **正对镜头的中轴对称**：机位与主体垂直，构图左右对称；
- **平面化**：主体居中、背景分层（前景/中景/背景像舞台布景）；
- **调色板**：复古粉彩（粉色/米色/芥末黄/蓝）；
- **运镜**：快速横摇（Whip Pan）、推拉镜头、定格感；
- **道具与细节**：精心布置的对称道具；
- **慢镜头+音乐**：配乐与动作同步的仪式感。

### 用途
喜剧/怀旧/童话感；不适合写实惊悚。

## 泰伦斯·马利克自然光诗意（Malick's Naturalism）

### 视觉特征
- **自然光优先**：黄金时刻（Golden Hour）、逆光、阳光透过树叶；
- **手持/斯坦尼康跟拍**：角色在自然环境中行走；
- **独白旁白（VO）**：内心独白如诗；
- **剪辑**：诗意跳跃、意象并置（天空/手/昆虫特写）；
- **表演**：即兴、非职业演员混用。

### 用途
哲学/冥想/自然主题；不适合快节奏叙事。

## 风格光谱：写实主义 → 风格化

```
纪实/中性（纪录片感）→ 自然写实（马利克）→ 经典好莱坞（隐蔽剪辑）
→ 表现主义（黑色电影）→ 作者风格（安德森）→ 超现实/实验
```
**调色对应**（呼应 09 文档）：写实端用中性平衡；风格化端用明确色板（青橙/去饱和/粉彩）。

## 在 AI 视频生成中的应用

1. **风格提示词库**（可直接复用）：
   - Noir：`film noir style, low-key lighting, chiaroscuro, venetian blind shadows, dutch angle, smoke-filled room, 1940s detective aesthetic`
   - New Wave：`French New Wave style, handheld camera, natural light, jump cuts, Paris streets, black and white, documentary texture`
   - Anderson：`Wes Anderson style, symmetrical composition, pastel color palette, center framing, whip pan transitions, diorama-like set`
   - Malick：`Terrence Malick style, golden hour natural light, handheld tracking, poetic voiceover, nature imagery, contemplative mood`
2. **风格与内容匹配**：先定叙事立场再选风格——不是"哪个好看"。
3. **风格一致性**：同片用同一风格锚（提示词 + 参考图 + LUT）。
4. **混合风格**：明确主风格 + 一个例外元素（如 noir 视觉 + 现代色调）。
5. **版权边界**：风格参考可以，逐帧复制画面不可以。

## 常见错误

1. 风格堆砌：一部片塞 5 种风格，没有统一语言。
2. 只有"像某某导演"没有为什么：风格必须服务内容。
3. 黑色电影滥用荷兰角：全程倾斜 = 失去失衡感。
4. 新浪潮式跳切无动机：跳切是观点不是省事。
5. 对称构图拍写实题材：形式与内容打架。
6. AI 提示词风格词堆叠：模型妥协出"四不像"。
7. 忽视声音风格：视觉流派常有配套的声音美学（noir 的爵士/萨克斯、新浪潮的现场声）。
