## 概述

**核心断言**：产品 3D 展示 = **"每个角度都能看"的信任工具**——360° 旋转台让买家看全产品（降低退货疑虑）。2026 主流：**图生 3D 模型（GLB）+ 360° 旋转视频 + AR 预览 + 页面嵌入**——单图起手，分钟级交付，无实拍设备（衔接 179：材质真实感决定 3D 可信度）。

## 核心概念

### 3D 展示四形态

```
① 360° 旋转台视频（Turntable：自动旋转展示）
② 3D 模型（GLB：交互拖拽）
③ AR 预览（放置真实环境）
④ 嵌入查看器（商品页交互）
```

### 工作流（图 → 3D → 展示）

```text
产品图/描述 → 3D 模型生成（单图起手）
  → 材质细化（179 PBR）
  → 360° 旋转/运动片段
  → 导出（GLB/视频/AR）
  → 页面嵌入 + 广告素材（135）
```

### 与广告素材联动（188/135）

360° 视频切片进广告变体（不同旋转角度 = 不同素材）——**一个 3D 资产 = 多素材源**（衔接 41 素材工厂）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 产品图不清晰 | 3D 变形 | 白底高清源 |
| 材质塑料感 | 不信任 | PBR 细化（179） |
| 旋转不连贯 | 跳变 | 逐角度连贯 |
| 无交互形态 | 页面静态 | GLB/AR |
| 单用途 | 浪费资产 | 多素材复用 |
