# AI 产品三维展示（Product 3D Showcase — Turntable, 360° Spin & Interactive Viz）

> 本页为 AI 产品三维展示：360° 旋转台视频（Turntable）、图生 3D 模型（GLB）、AR 预览、嵌入式展示、电商页面集成。知识本体来自 2026 3D 产品展示指南（Shopify/3DAI Studio/RotateProduct/OpenCreator）。AI 应用面向 DirectorX：电商产品（衔接 179 材质、186 多机位、188 钩子、135 广告、148→已并入 135）。
> 来源：Shopify「Best AI 3D Model Generators」、3DAI Studio「Product Visualization 2026」、RotateProduct「AI-Powered 3D Product Videos」、OpenCreator「AI 360 Product Video」。

## 概述

**核心断言**：产品 3D 展示 = **"每个角度都能看"的信任工具**——360° 旋转台让买家看全产品（降低退货疑虑）。2026 主流：**图生 3D 模型（GLB）+ 360° 旋转视频 + AR 预览 + 页面嵌入**——单图起手，分钟级交付，无实拍设备（衔接 179：材质真实感决定 3D 可信度）。

## 核心概念

### 3D 展示四形态

```
① 360° 旋转台视频（Turntable：自动旋转展示）
② 3D 模型（GLB：交互拖拽）
③ AR 预览（放置真实环境）
④ 嵌入查看器（商品页交互）
```

### 工作流（图 → 3D → 展示）

```text
产品图/描述 → 3D 模型生成（单图起手）
  → 材质细化（179 PBR）
  → 360° 旋转/运动片段
  → 导出（GLB/视频/AR）
  → 页面嵌入 + 广告素材（135）
```

## 技巧与示例

### 旋转台生成（RotateProduct/OpenCreator）

```text
清晰产品图（白底/均匀光）
  → 类别/用途简述（PDP/广告）
  → 360° 旋转视频生成（逐角度连贯）
  → 材质/反射校验（179）
  → 导出（页面 + 社交 + 广告）
```

### 与广告素材联动（188/135）

360° 视频切片进广告变体（不同旋转角度 = 不同素材）——**一个 3D 资产 = 多素材源**（衔接 41 素材工厂）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 产品图不清晰 | 3D 变形 | 白底高清源 |
| 材质塑料感 | 不信任 | PBR 细化（179） |
| 旋转不连贯 | 跳变 | 逐角度连贯 |
| 无交互形态 | 页面静态 | GLB/AR |
| 单用途 | 浪费资产 | 多素材复用 |

## 工作流应用（AI 映射）

电商产品（衔接 135/179/188）：

```text
产品图 → 3D 模型 → 材质（179）
  → 360° 旋转 → 多形态导出（GLB/AR/视频）
  → 页面嵌入 + 广告变体（135/188）
  → 测试（149）
```

**DirectorX 纪律**：单图起手分钟级；材质真实决定信任；360° 连贯；一资产多素材复用。
