# 文案与视觉协同体系（Copy-Visual Synergy System）

> 本页是 DirectorX 文案视觉协同手册：字幕=留存工具、钩子词视觉锚点、语音单位时机、断行规则、内容类型样式映射、钩子文案体系（前 3 秒/钩-反-转结构/8 变体）、字幕安全区。与 51 色彩可读性 / 43 安全区 / 05 钩子衔接。
> 来源：ReelWords 字幕留存指南、AI 工具指南钩子/脚本教程、550W 爆款文案、Blitzcut 字幕位置。

## 概述

**核心断言**：字幕不只是无障碍勾选项——在短视频里，**字幕是留存工具**。帮助与伤害的字幕差异通常是同一组基础：可读性、节奏、强调、时机。难扫、迟到、视觉混乱的字幕让观众感到摩擦而划走。

**目标公式**：可读性 + 节奏 + 选择性强调 = 留存。默认基线——**两行最多 / 每行 6-8 词 / 一思一截 / 高对比 / 位置一致**。每行要能在 1 秒内读完；需要暂停才能读=观众会划走。

## 钩子词作为视觉锚点

**目标不是"让词变彩色"，是"让信息更容易跟"**——每句强调 1-2 个有意义词，其余保持中性；**全强调=无强调**。

**该强调的词（四类工作）**：
- 承诺 Promise："free / fast / in minutes"（免费/快/几分钟）；
- 对比 Contrast："but / instead / here's the trick"（但是/其实/关键在这）；
- 具体 Specificity：数字、时限、结果；
- 利害 Stakes："wasting / losing / missing"（浪费/损失/错过）。

**不强调**：虚词（the/and/just/very）、每行都强调、与口语能量不匹配的强调。

## 时机对齐语音单位

- 按**自然语音块**分段，不按字符数——文字在短语开始时出现、短语结束时消失；
- **无陈旧文字**：说话人进入下一句后旧字幕还在=摩擦；
- 拿不准就**早切**，别让旧文字停留；
- 标点控制节奏：短句=速度、逗号=呼吸、破折号只用在自己一致的样式系统里（否则不用）。

## 断行规则（最大的"隐形"质量信号）

- 短语不分行（"new york" 不拆两行）；
- 语义后断行，不在想法中间断；
- **第二行无孤儿词**（单个词挂尾=乱+慢读）。

```
更优： "You don't need" / "fancy effects."
更差： "You don't" / "need fancy effects."
```

## 内容类型→字幕样式映射

| 内容类型 | 字幕样式 |
|---|---|
| 教程 | 干净、一致、最小强调 |
| 讲故事 | 稍大字号、节奏块、转折点强调 |
| 销售/CTA | 结果词/价格/紧迫/保证强调 |
| 喜剧 | 有意停顿、喜剧时机、选择性强调 |

**一致性建立信任；随机风格变化=噪音。**

## 可重复字幕工作流（六步）

```
① 写钩子词（每句 1-2 个）
② 把脚本切成自然语音块
③ 应用断行规则（6-8 词/行）
④ 字幕对齐语音（无陈旧文字）
⑤ 手机全速预览
⑥ 导出后首 3 秒复查两次
```
**大部分流失发生在开头——字幕在前 3 秒必须最好。**

## 字幕安全区（平台 UI 遮挡）

- 字幕**居中、略高于下三分之一**——除非有明确理由放别处；
- 避开边缘与屏幕下部（Reels/TikTok/Shorts 的 UI 元素区）→ 43 安全区地图；
- 避免盖住脸与关键视觉。

## 钩子文案体系（文案层与视觉层的协同）

**前 3 秒结构**（→ 05 文档 3.1 秒阈值）：画面钩子 + 文字钩子 + 声音钩子三轨齐发——**文字钩子=钩子词的视觉锚点**（大号强调词），画面钩子=强表情/高对比，声音钩子=第一句台词。

**钩-反-转结构**（AI TikTok 脚本）：钩（3 秒抓眼）→ 反（建立期待/反差）→ 转（转折/揭示/CTA）——每段配视觉层级：钩=文字强调+特写、反=信息字幕+演示、转=CTA 字幕+品牌帧。

**8 变体钩子法**（AI 工具指南）：同一选题生成 8 个不同钩子变体（疑问/反共识/数字/恐惧/利益/故事/对比/命令）→ 视觉层对应不同开场画面 → 发布测试选优（→ 56 受控测试）。

## 常见错误（降留存的字幕）

1. 滚动速度下太小：看不清。
2. 每行词过多：读不完。
3. 全强调：视觉噪音。
4. 字幕滞后语音：认知摩擦。
5. 盖脸/盖关键视觉。
6. 位置乱跳：分散注意力。
7. 断行拆短语/孤儿词：被迫重读。
8. 首 3 秒字幕不达标：流失最高峰。
