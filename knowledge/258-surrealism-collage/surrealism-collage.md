## 概述

**核心断言**：超现实 = **"不可能的并置成为意义"**——融化物象（达利钟表）、梦境景观、异质元素拼接（拼贴/照片蒙太奇）；超现实承载潜意识/隐喻叙事（衔接 224：风格体系的超现实维度；181：氛围的梦境版）。

## 核心概念

### 超现实手法库

```
① 融化/变形（熔化物象）
② 梦境景观（不可能空间）
③ 比例错乱（大小倒置）
④ 异质并置（无关物组合）
```

### 拼贴/照片蒙太奇

分层纹理 + 异质元素混合 + 剪切感——**"不同世界在同一画面"**（衔接 232 多主体的超现实版）。

## 技巧与示例

### 超现实提示词模板

```text
"Dalí-style surrealist painting, dreamlike atmosphere, melting objects,
impossible juxtaposition, hyperreal detail, museum-quality"
"photomontage, layered textures, disparate elements blended,
dreamlike collage"
```

### 超现实叙事功能

超现实 = 隐喻视觉化（潜意识/社会批判）——**"不可能的画面"承载"抽象的主题"**（衔接 248 符号学：符号的超现实形态）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无逻辑并置 | 混乱 | 意义驱动 |
| 只堆奇观 | 无叙事 | 隐喻设计 |
| 拼贴无层次 | 平面 | 分层纹理 |
| 风格过度 | 疲劳 | 克制 |
| 点名艺术家 | 版权风险 | 属性化（213） |
