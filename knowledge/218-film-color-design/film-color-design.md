# 电影色彩设计（Film Color Design — Master Palette & Cross-Department Cohesion）

> 本页为电影色彩设计深化：主色板（Master Palette：1-3 锚色）、服装/场景/摄影跨部门统一、暖冷对比（青橙）、情绪板驱动、色板叙事。知识本体来自 2026 色彩设计指南（CINED/NoFilmSchool/StudioBinder/FilmmakerGenius）。AI 应用面向 DirectorX：色彩统一（衔接 155 色彩心理、141 调色、195 品牌、218 对应）。

## 概述

**核心断言**：电影色彩 = **跨部门统一的工程**——1-3 个锚色（Anchor Colors）贯穿服装/场景/道具/摄影，克制使用保叙事清晰（衔接 155：心理学意义的落地；195：品牌套件的电影版）。**情绪板先行，各部门对着同一色板执行**。

## 核心概念

### 主色板结构（CINED）

```
① 锚色（1-3 个主色，跨部门复用）
② 对比色（暖冷成对：青橙，加戏剧）
③ 强调色（关键元素/剧情点）
```

### 跨部门统一（FilmmakerGenius）

| 部门 | 色板执行 |
|---|---|
| 服装（169） | 角色锚色 |
| 场景（165） | 环境主色 |
| 道具（209） | 母题色 |
| 摄影（141） | 调色统一 |

### 五种经典配色方案（CINED）

单色/互补/相似/三色/分裂互补——**每种方案承载不同情绪**（衔接 155 色温情感地图）。

## 技巧与示例

### 色板工作流

```text
主题/情绪 → 锚色选择（1-3 色）
  → 方案选型（互补/相似等）
  → 各部门色板分发（服装/场景/道具）
  → 摄影执行（141 调色）
  → 一致性检查（跨部门）
```

### 克制原则

**锚色克制使用**：全片色板太满 = 视觉疲劳——留白/中性色让锚色突出（衔接 192 负空间同构）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 色板过满 | 视觉疲劳 | 锚色克制 |
| 部门各自为色 | 割裂 | 统一色板 |
| 无方案 | 色彩混乱 | 方案选型 |
| 锚色不突出 | 主题弱 | 强调色 |
| 与心理脱节 | 语义错位 | 155 联动 |

## 工作流应用（AI 映射）

色彩统一（衔接 141/155/195）：

```text
主题 → 锚色 → 方案 → 各部门色板
  → 生成（165/169/209 按色板）
  → 调色统一（141）→ 一致性检查
```

**DirectorX 纪律**：锚色跨部门统一；方案承载情绪；克制使用突出；心理语义联动。
