# AI 图片摄影构图心理学（Composition Psychology — Eye Tracking & Gaze Guidance）

> 本页为 AI 图片的摄影构图心理学：眼动研究（视线路径/注视时间）、引导线认知（Leading Lines 引导注意）、格式塔属性（视觉复杂度/美感）、构图-注视一致性。知识本体来自 2026 眼动研究（PMC 多篇）。AI 应用面向 DirectorX：构图设计（衔接 216 构图法则、210 黄金比例、246 对应、197 运镜心理）。
> 来源：PMC「Leading Line Composition and Visual Cognition」、PMC「Gestalt Properties in Photography」、PMC「Role of Composition in Viewing」、SAGE「How Images Draw the Eye」。

## 概述

**核心断言**：构图是**可测量的注意力工程**——眼动研究证实：引导线有效引导视觉注意并影响观看时间与美感评分；格式塔属性（接近/相似/连续）调节注视模式（衔接 216：法则的实证依据；210：螺旋引导）。

## 核心概念

### 眼动实证发现（PMC）

```
① 引导线：有效引导注意（观看时间+）
② 格式塔：接近/相似/连续调节注视
③ 初始观看：构图强引导（早期注视相似）
④ 长观看：个体差异增大
```

### 构图-注意力映射

| 构图 | 注意力机制 |
|---|---|
| 引导线 | 强制路径 |
| 格式塔接近 | 分组感知 |
| 高对比点 | 注视吸引 |
| 人脸 | 优先注视 |

## 技巧与示例

### 心理学构图工作流（AI 映射）

```text
注意力目标（先看哪/后看哪）→ 构图选型
  → 引导线/对比点设计 → 提示词
  → 生成 → 视线路径校验（216）
```

### 关键元素注意优先

人脸 > 高对比 > 运动 > 文字——**主次设计按注意优先级**（衔接 216 视觉层级实证版）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无引导设计 | 视线乱 | 引导线 |
| 忽略注意优先级 | 主次反 | 优先级设计 |
| 对比点过多 | 注视分散 | 单一焦点 |
| 格式塔破坏 | 分组乱 | 接近/相似 |
| 无校验 | 路径未知 | 视线检查 |

## 工作流应用（AI 映射）

构图设计（衔接 210/216/215）：

```text
注意力目标 → 构图选型（引导/格式塔）
  → 提示词 → 生成 → 视线校验
```

**DirectorX 纪律**：引导线是实证工具；注意优先级设计；单焦点防分散；格式塔分组。
