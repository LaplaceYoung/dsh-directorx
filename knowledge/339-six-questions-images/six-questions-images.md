# AI 图片六问沉浸应用（Six Questions in Images — Engagement Prompts & Frame Progression）

> 本页为 AI 图片的六问沉浸应用：六问逐帧设计（我在哪/与谁/能做什么/发生什么/有进展/为何重要）、互动帧提示（预测下一帧/重混色板）、实时互动（选择/投票引导后续图）、英雄之旅弧跨系列。知识本体来自 2026 六问应用（HBR/Sessions/CreativeAdsLab）。AI 应用面向 DirectorX：图片参与（衔接 323 六问、339 对应、275 情绪弧、254 序列）。
> 来源：HBR「Why the Best Immersive Experiences Succeed」、Tandfonline「Narrate, Act, and Resonate」、Sessions「Visual Storytelling Techniques」、CreativeAdsLab「Visual Storytelling 2026」。

## 概述

**核心断言**：六问图片应用 = **"逐帧设计+互动提示"**——每帧回答一问（建立→关系→能动→冲突→进展→意义）；互动帧（预测/重混）+ 实时选择引导后续；英雄之旅弧跨系列（衔接 323：六问的图片版；275：弧线）。

## 核心概念

### 六问逐帧（HBR 应用）

```
① 我在哪 → 建立帧（地点/语境）
② 与谁 → 角色帧（关系/张力）
③ 能做什么 → 动作帧（能动）
④ 发生什么 → 冲突帧（渐变揭示）
⑤ 有进展 → 里程碑帧（反馈）
⑥ 为何重要 → 意义帧（情绪兑现）
```

### 互动帧（Sessions）

预测下一帧/重混色板（视觉互动）+ 选择/投票引导后续（实时互动）——**"观众参与系列生成"**。

### 英雄之旅弧（CreativeAdsLab）

六问×英雄之旅（普通世界→召唤→考验→蜕变）——**"六问即弧线"**（衔接 150）。

## 技巧与示例

### 六问图片工作流

```text
六问逐帧设计 → 每帧提示词（238 一致）
  → 互动点（选择/投票）→ 生成
  → 六问校验（逐帧答对）
```

### 六问提示词

"frame 1: where (establishing) → frame 6: why (emotional payoff)"——**逐帧问答**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无逐帧问答 | 无台阶 | 六问映射 |
| 无互动 | 被动 | 互动帧 |
| 弧线断裂 | 无旅程 | 英雄之旅 |
| 帧不一致 | 断戏 | 238 一致 |
| 不校验六问 | 效果未知 | 逐帧检查 |

## 工作流应用（AI 映射）

图片参与（衔接 150/238/254/275/323）：

```text
六问 → 逐帧 → 互动 → 生成 → 校验
```

**DirectorX 纪律**：六问逐帧台阶；互动帧参与；六问即弧线；帧一致性。
