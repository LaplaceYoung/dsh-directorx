# AI 开场钩子设计（Opening Hook — Pattern Interrupt & 3-Second Payoff）

> 本页为 AI 视频的开场钩子专项设计：模式打断（Pattern Interrupt）、前 3 秒兑现承诺（Payoff）、钩子类型库（反驳/痛点/证明/社会认同/视觉破格）、三变体测试。知识本体来自 2026 钩子指南（Captions/PlayPlay/Swng/Genra/Vivideo）。AI 应用面向 DirectorX：开场设计（衔接 142 钩子堆叠、158 情绪曲线、135 广告、149 测试）。
> 来源：Captions「Video Hooks: Scroll-Stopper」、Genra「3-Second Opener Templates」、PlayPlay「9 Most Effective Hooks」、Vivideo「First 3 Seconds」。

## 概述

**核心断言**：前 3 秒决定生死——**开场 1-2 秒模式打断（停滑动），3 秒内兑现承诺（给价值）**。2026 钩子公式：**具体承诺/价值（首帧）+ 模式打断（1-2s）+ 结果展示（3s 内）**（衔接 142：微留存的第一决策点；158：情绪曲线的第一拍）。

## 核心概念

### 钩子设计三问（Genra）

```
① 观众是谁（定向框架）
② 张力是什么（痛点/好奇/矛盾）
③ 兑现是什么（3 秒内给价值）
```

### 钩子类型库

| 类型 | 结构 | 适用 |
|---|---|---|
| 反驳/辟谣 | 断言 → 反转 | 认知类 |
| 痛点速解 | 痛 → 快解预告 | 广告/教程 |
| 证明先行 | 结果/拆解 | 产品/数据 |
| 社会认同 | 快速反应/见证 | 种草/UGC |
| 视觉破格 | 异常构图/动作 | 泛内容 |

## 技巧与示例

### 钩子生成工作流（Genra 15 公式）

```text
定向（观众/张力/兑现）→ 选钩子类型
  → 首帧设计（视觉触发）
  → 开场文案变体（3 个）
  → AI 生成 3 变体首帧/开场
  → 测试（2-3 秒停留率，149）
  → 选优 → 完整生成
```

### 一条主线原则

**开场只承诺一件事**——前几秒堆叠多个承诺 = 观众流失（衔接 187 一镜一动作同理：单点聚焦）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 开场无承诺 | 秒划走 | 首帧给价值 |
| 无模式打断 | 无法停滑动 | 1-2s 打断 |
| 兑现太晚 | 流失 | 3 秒内兑现 |
| 多承诺堆叠 | 信息过载 | 一条主线 |
| 不测试变体 | 凭感觉 | 3 变体测试（149） |

## 工作流应用（AI 映射）

开场设计（衔接 135/142/149/158）：

```text
定向三问 → 钩子类型 → 首帧+文案变体
  → 生成 3 变体 → 停留率测试（149）
  → 选优 → 完整成片（158 情绪曲线收尾）
```

**DirectorX 纪律**：模式打断停滑动；3 秒兑现承诺；一条主线；三变体测试驱动选择。
