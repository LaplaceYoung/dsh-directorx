# 视频制作项目管理（Video Production Project Management）

> 本页是 DirectorX 制作管理手册：视频项目为何更难（移动工件）、五阶段管线（70% 时间在审片）、围绕版本的跟踪器、时间码反馈纪律、审片工作流检查清单、交付与归档、中文生态工具。与 41 素材工厂 / 60 UGC / 77 灵感系统衔接。
> 来源：PlayPause 制作管理指南、分秒帧审片平台、Frame.io 工作流、PingCode 剪辑协作实战。

## 概述

**核心断言**：大多数视频项目不是在拍摄时垮掉的——是在"首剪发出"到"终剪批准"之间的缝隙里垮掉的。那个缝隙里，反馈散落在邮件、Slack 和凌晨 2 点的"能让它更炸一点吗"。

**视频为什么比普通项目难**：普通项目有任务；视频有任务**加上每几天就变一次的移动工件（The Cut）**。反馈若不绑定时间码就毫无用处——"开头拖"没意义，"开头 0:04-0:11 拖"才是修复。

**真正的管理单元**：不是任务，是**版本**——每个版本都需要自己的时间码反馈线程。

## 五阶段管线（先命名阶段才能看到卡点）

```
① 简报与脚本锁定 → ② 拍摄与原始素材 → ③ 装配与粗剪 → ④ 审片与修订轮 → ⑤ 终版交付与归档
```

**现实**：大多数团队冲刺过前两阶段，然后悄悄淹死在第四阶段——**修订轮消耗约 70% 的日历时间**，却几乎没人为它做规划。

**规划修订**：预算覆盖几轮，开拍前定死——两轮健康；超过三轮，第一阶段（简报）出了问题。

## 围绕版本的项目跟踪器（关键列）

| 字段 | 为什么重要 |
|---|---|
| 项目+客户 | 打标签可筛选 |
| 当前阶段 | 五阶段之一 |
| **活动版本** | v1/v2/v3——绝不含糊 |
| 审片负责人 | 整合所有意见的单一负责人 |
| 截止日期 | 下一个期限，不是最终期限 |
| **审批状态** | 待定/变更请求/锁定 |

**"活动版本"与"审批状态"两行是视频跟踪器与普通待办清单的分界线**——工具不能一眼显示这两项，你就在项目最容易滑的部分瞎飞。

## 反馈问题就是整个游戏

- 三个客户在三个渠道留意见：一个说"短点"、一个说"把证言加回来"——没人看到彼此的评论，剪辑猜，第四轮开始；
- **结构性修复而非动机性修复**：把成片和反馈放在同一个地方——审片人点 0:14 输入"剪掉这个节拍"，剪辑师看到帧和意见在一起，无翻译无猜测；
- **时间码评论+所有人同一线程** = 修订轮数收缩比任何截止日期都快；
- 共享文件夹（WeTransfer/网盘）只是移动文件——不是审片工具：无帧精确评论、无版本堆栈（v3/v4 两个令人困惑的同名文件）、无审批锁定、无水印。

## 审片工作流检查清单（可直接偷走）

```
① 拍摄前锁定简报与修订轮数
② 指定一个审片负责人（整合所有意见）
③ 每版成片作为新版本上传堆栈，绝不覆盖
④ 反馈收集为同一处的帧精确评论
⑤ 交付前显式锁定审批，然后归档项目
```

**注意缺了什么**：没有"催人给反馈"这一步——审片人能直接评论帧并看到彼此意见时，催促基本消失，他们自助服务，你看着评论落地。

**唯一的纪律**：版本堆栈——两个成片同名的那一刻，线程就断了。**一文件、一版本、一评论线程**。

## 真实案例（产品发布视频）

- 周一锁定简报，合同写两轮修订；
- 周二周三拍摄，周五粗剪 v1 上传；客户+营销负责人+自由声音设计师都拿到链接（免费审片人，不加座）；
- 周一三人都在 v1 上留了帧精确评论，同一线程互相可见；剪辑师从单一整合清单剪 v2，而非三封矛盾邮件；
- v2 周三上线，客户点击审批锁定；共享链接带水印且到期，未完成成片从未泄露；周四归档。

## 母版源文件交付清单（项目结束品牌方应拿到什么）

1. **终版成片**（全格式：母版+平台版本，→ 68 规格）；
2. **工程文件**（剪辑/调色源工程，可再编辑）；
3. **原始素材**（全部拍摄素材+转写记录）；
4. **版权资产**（音乐授权、字体、肖像授权、字体版权证明，→ 72 合规衔接）；
5. **项目文档**（简报/脚本/版本记录/审批记录）。

## 常见错误

1. 反馈不绑时间码：无法修复。
2. 修订轮无预算：70% 时间失控。
3. 版本同名覆盖：线程断裂。
4. 多个审片渠道：矛盾意见不可见。
5. 共享文件夹当审片工具：无帧评论无锁定。
6. 交付不给母版源文件：客户无法再利用。
7. 不归档：复盘无据（→ 40 日志契约同构）。
