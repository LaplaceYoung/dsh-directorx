# 电影类型片表演惯例（Genre Acting — Horror Vulnerability, Noir Restraint & Cross-Genre Versatility）

> 本页为电影类型片的表演惯例：类型-表演风格映射（恐怖=威胁/脆弱/惊吓校准、黑色=克制/道德模糊/精炼对白）、类型杂交的多域表演（快速切换调性）。知识本体来自 2026 类型表演（Wikipedia/LA Times）。AI 应用面向 DirectorX：类型表演（衔接 244 表演理论、265 类型符号、278 对应、69 表演控制）。
> 来源：Wikipedia「List of Horror Films of 2026」、Wikipedia「Film Genre」、LA Times「Spider-Noir Review」、RottenTomatoes「2026 Horror Preview」。

## 概述

**核心断言**：类型片有**表演惯例**——恐怖（威胁/脆弱/惊吓的三校准）、黑色（克制情绪/道德模糊/精炼对白、内在张力+微妙手势）；2026 类型杂交要求**多域表演**（恐怖→惊悚→喜剧快速切换）（衔接 244：体系→类型应用；265：类型符号的表演版）。

## 核心概念

### 类型-表演映射

| 类型 | 表演惯例 |
|---|---|
| 恐怖 | 威胁/脆弱/惊吓校准 |
| 黑色 | 克制/道德模糊/精炼对白 |
| 西部 | 沉默/坚毅/克制 |
| 喜剧 | 节奏/夸张 |
| 科幻 | 冷静/疏离 |

### 黑色表演三要素（LA Times 分析）

内在张力（克制外化）+ 微妙手势（眼神/停顿）+ 精炼对白（简省锋利）——**"危险与腐败的暗示"**。

### 类型杂交表演（2026）

多域切换（恐怖→喜剧）需要**灵活调性**——单项目多表演语域（衔接 69 分段表演）。

## 补充：类型片声音惯例（#295）

类型片有**声音惯例**与表演惯例平行——恐怖（低频音/心理声学线索/静默惊跳架构）、科幻（合成纹理/模块音色/空间感）、西部（稀疏回声/风/蹄声/空旷）、动作（打击/重低音/快速）。

| 类型 | 声音惯例 |
|---|---|
| 恐怖 | 低频音/心理声学/静默惊跳 |
| 科幻 | 合成纹理/模块音色/外星 |
| 西部 | 稀疏回声/风/蹄声/空旷 |
| 动作 | 打击/重低音/快速 |

**静默是惊跳架构核心**（安静→突然爆发）+ 有机-合成混合（呼吸/风/吱嘎×处理合成=超现实）。类型声音惯例 = **声音图符**（sonic icon），与表演图符平行。

提示词："low-frequency drone, psychoacoustic cues, strategic silence before sudden impact, organic-synthetic hybrid textures"。

## 补充：杂交类型设计框架（#296）

杂交类型 = **"主导+对位"的受控设计**——定主导类型（主线）与对位类型（反衬/调味），图符重组（265），用摄影/配乐/剪辑控制调性切换。

**杂交设计三步骤**（Spectrum Film School）：

```
① 主导类型（主线惯例）
② 对位类型（反衬/调味）
③ 调性控制（摄影/配乐/剪辑指示切换）
```

**杂交案例**：

| 案例 | 组合 |
|---|---|
| 《寄生虫》 | 黑色喜剧+惊悚+社会 |
| 《瞬息全宇宙》 | 动作+奇幻+科幻+家庭 |
| 《Sinners》 | 恐怖+修正西部+歌舞 |

杂交调性**需指示**：镜头/配乐/剪辑变化让观众感知类型切换——**"类型语码切换"**（code switching）。

## 补充：杂交声音混合（#302）

杂交声音 = **"声学+电子的融合"**——管弦乐纹理+电子声景混合；跨类型技法（饱和/侧链/粘合）统一调性；总线压缩把异质元素"粘"成统一杂交情绪。

**混合要素**：

```
声学（管弦/实录）+ 电子（合成/纹理）
+ 环境声（Ambience/Foley）
→ 跨类型制作（饱和/侧链/粘合）
```

**混音纪律**（BFI）：对话清晰优先；音效入场景空间；**总线压缩粘合异质元素**（统一杂交情绪）。

提示词："orchestral textures fused with electronic soundscapes, saturated layers, glued bus compression"。

## 补充：杂交表演调性多能（#305）

杂交表演 = **"单项目多语域"**——演员需在恐怖/喜剧/戏剧/科幻间流畅切换；2026 杂交项目爆发要求**调性多能与快速切换**。

**调性多能**（Tonal Versatility）：

```
单项目多类型调性（恐怖→喜剧→戏剧）
→ 语域切换（Register-Shifting）
→ 快速过渡不跳戏
```

**跨类型训练**：恐怖（威胁/脆弱/惊吓校准）+ 科幻（冷静/疏离）+ 惊悚（内心张力）训练——**多语域肌肉**。

提示词："shifts from comedic delivery to horror tension at [beat], maintaining character continuity"。

## 补充：杂交场景声音整合（#313）

杂交场景声音 = **"一个世界的统一声"**——可着色声床 + 模块分层 + 动态过渡支撑叙事节拍；频率雕刻 + 统一粘合。

**杂交场景声音三要素**（Output）：

```
① 可着色声床（管弦+电子+音效纹理）
② 模块分层（颗粒/低频/有机叠加）
③ 动态过渡（音色演变支撑节拍）
```

**频率雕刻**：元素各占频段，不压对话。**统一粘合**：压缩/混响/EQ=一个房间。**张力-释放音色**：多用途声音可变形（morph）→ 映射张力释放。

## 补充：杂交场景设计（#314）

杂交场景 = **"统一简报+灵活系统"**——统一情绪/故事简报（先定调），灵活色彩纹理系统可横跨恐怖/科幻/奇幻，**灯光提示类型切换**（同一场景换光=换类型）。

**设计三原则**：

```
① 统一简报（情绪/故事先定调）
② 灵活色纹系统（可遍历多类型）
③ 灯光提示切换（光=类型语码）
```

**类型切换机制**：同一环境+不同光/色=不同类型感（恐怖暗冷/奇幻暖彩）——**光色即类型开关**。实景+虚拟制作融合（真实+数字无缝）。

## 补充：杂交类型视觉与提示词（#317）

杂交类型视觉 = **"融合提示词"**——清晰分隔符（"cyberpunk meets noir"）、风格权重（60/40）、多模型混合。

**融合提示三技巧**：

```
① 分隔符（"A meets B in [场景]"）
② 风格权重（60/40 主次）
③ 多模型混合（跨生成器）
```

**杂交视觉库**：

| 组合 | 视觉 |
|---|---|
| 赛博朋克+黑色 | 霓虹雨街/铬人/烟雾 |
| 科幻+奇幻 | 生物荧光/魔法科技 |
| 黑色+科幻 | 暗调科技城 |

提示词："cyberpunk city at night meets dark fantasy, neon signs, rain-soaked pavement, chrome characters, cinematic noir atmosphere（60/40 split）"。

## 补充：声学指纹与跨部门统一（#318）

杂交整合 = **"一个声学指纹贯穿全片"**——预定义项目声音身份（清晰度/温暖/亮度），现场声/Foley/配乐/终混统一应用。

**声学指纹**（Sonic Fingerprint）：

```
预定义项目指纹（清晰度/温暖/亮度）
→ 现场声/Foley/配乐/终混统一应用
```

**集成声轨**：声音设计与配乐**互为整体**（概念统一），分离感减少。统一策略：响度目标一致 + 动态范围策略统一 + 跨通道 EQ（元素同频段共存）。

## 补充：纹理优先分层与共享处理（#320）

杂交配乐-声音整合 = **"音效与配乐互为整体"**——集成声轨（概念统一，分离感减少）；纹理优先分层 + 共享处理粘合。

**纹理优先分层**（Paul J Arnold）：

```
① 声床（定制电子纹理匹配画面色板）
② 有机叠加（实录/管弦=旋律心）
③ 共享处理（粘合）
```

**统一声景**（Nathan Fields）：混合配乐（管弦+电子+声音设计）定义今日大片之声——**"一个声音世界"**。声床需匹配画面色板，共享处理保证粘合。
