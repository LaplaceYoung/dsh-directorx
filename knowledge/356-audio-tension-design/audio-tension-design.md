# 电影听觉张力设计（Audio Tension Design — Rhythm × Silence × Suspense）

> 本页为电影听觉张力设计：紧张音频线索（单独即造悬念）、策略静默（负空间驱动预期/锐化聆听）、分层音效（低频/渐强/冲击：不加响度造节奏张力）。知识本体来自 2026 听觉张力（Nature/Requiem/SinisterFilmFest）。AI 应用面向 DirectorX：张力声（衔接 268 悬念、356 对应、347 听觉节奏、260 静默）。
> 来源：Nature「Building Blocks of Suspense」、Requiem「Sound Design to Build Tension」、SinisterFilmFest「Sculpting Silence」、Duende「Build Tension with Sound」。

## 概述

**核心断言**：听觉张力 = **"节奏×静默×悬念"**——紧张音频线索单独即可造悬念（无需可见线索）；策略静默（负空间驱动预期，比声音更有效）；分层音效（低频/渐强/冲击）不加响度造节奏张力（衔接 268：悬念的音频版；260：静默）。

## 核心概念

### 三工具（Requiem）

```
① 紧张线索（音频单独造悬念）
② 策略静默（负空间=预期）
③ 分层音效（低频/渐强/冲击）
```

### 静默力量（SinisterFilmFest）

策略静默比声音更驱动预期/锐化聆听——**"无声胜有声"**（衔接 260）。

### 分层张力（Duende）

低频（Drone）+ 渐强（Riser）+ 冲击（Impact）同键叠层不冲突——**"节奏张力不加响度"**（衔接 347）。

## 技巧与示例

### 听觉张力工作流（AI 映射）

```text
悬念目标（268）→ 三工具设计
  → 静默点（260）→ 分层音效
  → 生成 → 张力校验（预期对吗）
```

### 张力示例

"tense drone + strategic silence before impact + riser layering"——**线索+静默+分层**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无静默设计 | 无预期 | 负空间 |
| 分层冲突 | 噪 | 同键 |
| 响度堆砌 | 疲劳 | 节奏张力 |
| 线索无悬念 | 平 | 268 |
| 不校验张力 | 效果未知 | 预期检查 |

## 工作流应用（AI 映射）

张力声（衔接 260/268/347）：

```text
悬念 → 三工具 → 静默 → 分层 → 生成 → 校验
```

**DirectorX 纪律**：线索造悬念；静默是负空间；分层不加响度；预期校验。
