# 纪录片与口播知识类（Documentary & Talking Head）

> 本页是 DirectorX 纪录片/口播知识库：纪录片采访全流程（场地、画面、灯光、收音）、纪实拍摄方法、纪录片叙事结构、口播视频与知识类内容制作。每个概念含参数与模板。
> 来源：IDA 纪录片采访拍摄指南（Adam Irving）、Teleprompter.com 口播指南、Cinéma vérité 维基词条、Nieman Storyboard 叙事采访要点。

## 概述

纪录片（Documentary）与口播/知识类（Talking Head / Educational）视频共享一个核心资产：**真实的人与真实的信息**。制作目标不是"表演好看"，而是"让观众相信并记住"。

两条铁律（IDA）：
1. **消除一切干扰**（视觉与听觉）：把观众从故事中拽出来的东西都要排除。
2. **声音优先**：画面瑕疵观众会原谅，听不清对白观众会直接关掉——"必须二选一时，永远选好声音"。

## 纪录片采访拍摄（Documentary Interview）

### 1. 场地选择（Selecting the Interview Space）
- **尽量室内**：室外阳光移动、风噪、车声、直升机、施工——素材不可用风险极高。
- **关掉噪声源**：冰箱、空调、嗡嗡的灯、摇晃的风扇；用手机闹钟提醒结束后开回（尤其是冰箱）。
- **关掉顶灯**：天花板灯产生"平、不电影感"的光；关不掉就卸灯泡。
- **无窗或遮窗**：自然光随时间变化；玻璃传声——用隔音毯/黑布遮窗。
- **地毯房间**：防止混响（回声）；没地毯就铺毯子/隔音毯在脚下。
- **椅子选择**：不要转椅/滚轮椅/吱呀的木椅（受访者会转）；不要高背椅（挡在头后）；不要沙发（人会陷下去）。**受访者与采访者视线同高**（可调椅或垫子）。
- **背景禁忌三件套**：书架、植物、台灯——"纪录片采访背景三俗"，避雷。角落比平墙更有层次。

### 2. 受访者准备（Preparing Your Subject）
- 提前告知：不穿 logo、复杂花纹、亮色；细条纹在 HD 下会产生摩尔纹（moiré）。
- 提前发肖像/出镜授权（录制前才给法律文件会让受访者分心）。
- 检查首饰/衣物噪声（手镯、项链、响面料）——录制前取下。
- 面部压粉防油光（用纸巾护住衣物）。
- **录前与录后各录 20 秒环境底噪（Room Tone）**：剪辑填补声音间隙的必需品。

### 3. 画面分离（Subject-Background Separation）
- **主体与背景 ≥ 10 英尺**：大空间才能浅景深分离 + 灯光散热。
- **器材**：大底相机（S35/全画幅）+ f/2.8 或更大光圈镜头。
- **光圈窗口 f/2.4-f/4**：f/2.4 更浅但受访者轻微前倾就脱焦；f/4 以上背景也跟着清晰。
- **焦距 40-135mm**：40mm 以下显鼻子大（变形）；135mm 以上采访者离得太远，失去亲密感。
- **主体光至少是背景光的 3 倍**；背景保持简洁。
- **帧内不要有时钟/显示器/宠物**（时间会变，剪辑连续性事故）。
- **构图**：三分法——受访者放上/下三分线一侧，**留出负空间放名字字幕**；景别腰上到胸口（腰下太远脸小，满脸太压迫）；头顶留"一小撮"。

### 4. 灯光（Lighting，纪录片极简方案）
- **一盏主光足够**（IDA 观点）：明亮（≥500W 或等效 LED）+ 大面积柔光箱。
- 主光位置：高于头一两英尺向下打 + 45° 侧向 → 面部柔和的明暗过渡（电影感）；正对脸 = 平、无立体感。
- **纪录片采访不用背光**：显"90 年代电视棚"感，且对秃顶/薄发不友好；不需要辅光（单侧受光更电影化）。
- 单人作战快速方案：一盏柔光灯 + 备用灯泡 + 加长电源线。

### 5. 收音（Recording Audio）
- **枪式麦（Boom）优于领夹麦（Lav）**：指向性，只收目标方向的声音，拒绝环境噪声；领夹是全向的，还会被首饰/衣物摩擦出杂音。
- 枪麦位置：**45° 角、略低于嘴**（声带发声方向略向下）。
- 必须用领夹时：藏好（衣物下用 moleskin/粘性贴固定）——露领夹 = 业余标志。
- 行业参考：枪麦 Sennheiser MKH 416（标准）、Røde NTG-1（性价比）；领夹 Sanken COS-11D、Tram TR50。

## 纪实拍摄方法（Documentary Methods）

### 观察式（Observational / Cinéma vérité）
- 不干预、不摆拍，记录自然发生（直接电影 Direct Cinema 传统）。
- 拍摄要点：长时间跟拍、广角+长焦组合、抓拍反应、接受"不完美"的构图。
- 剪辑：以"场景"为单位重建（Verité 剪辑——从素材中找"事件"）。

### 参与式（Participatory）
- 拍摄者出现在镜头中/镜头后（提问、对话）——莫里斯、迈克尔·摩尔式。
- 采访者出镜时：双机位（受访者 + 采访者反应）。

### 证据式（Evidentiary）
- 以采访为主要叙事线，配合档案素材（照片、录像、文件）。
- 剪辑：以"证词"为单位组织（Evidentiary Editing）。

## 纪录片叙事结构（Narrative Structure）

### 常见结构
1. **线性时间（Chronological）**：按时间讲故事——人物/事件传记。
2. **主题章节（Thematic）**：按主题分组（专家访谈式）。
3. **问题-追寻（Question-driven）**：一个核心问题贯穿，逐步逼近答案（悬疑式纪录片）。
4. **人物旅程（Character Journey）**：跟随一个人/群体经历变化（类似剧情片角色弧）。
5. **对比/平行（Parallel）**：两线或多线对照（黑白/双城/正反方）。

### 结构原则（Ken Burns 教学要点）
- 纪录片同样需要**三幕结构**（引入-冲突-解决）与节奏曲线。
- **开场 1 分钟决定去留**：第一镜/第一句就要建立"为什么看下去"。
- **人物驱动 > 主题驱动**：观众记住的是人，不是论点（Nieman：找到故事的"弧"——人物想要什么、阻碍是什么、如何变化）。
- **信息递进**：论点由证据逐步堆叠，避免"开头就把结论说完"。

### 采访提问技巧（Interview Techniques）
- **开放式问题**："当时发生了什么？"（封闭式"是不是很难？"只能得到"是"）。
- **追问细节与感官**："你看到了什么？听到了什么？"——细节让故事活。
- **沉默是金**：答完后停 3 秒——对方往往补充最关键的话。
- **不问"你怎么感觉"**（抽象）→ 问"那一刻你做了什么"（具体，情绪自然浮现）。
- **先问事实再问情感**：建立信任后情绪才愿意出来。
- 拍摄前准备问题清单，但**跟随对话**，不照单念稿。

## 口播视频（Talking Head Video）

### 为什么口播有效（Teleprompter.com）
- 直视镜头 = 眼神接触 = 信任与真诚（观众自然联想）。
- 极低成本：手机 + 三脚架 + 麦克风 + 一盏灯。
- 适用：教学、公司公告、产品介绍、内部沟通、课程、短视频口播。

### 口播设置规范
| 项 | 规范 |
|---|---|
| 机位 | 三脚架，**镜头与眼睛同高**（俯拍显矮、仰拍显傲慢） |
| 景别 | 胸到肩以上；眼睛在画面上 1/3 处；头顶留一点 |
| 镜头 | 50-85mm 等效（手机主摄即可，避免超广角变形） |
| 灯光 | 窗光或柔光箱 45°；眼睛要有眼神光 |
| 收音 | 领夹/枪式/USB 麦——**任何外接麦 > 机身麦** |
| 背景 | 简洁干净；与主体有距离（层次） |
| 提词 | 提词器 APP 让视线贴近镜头——视线漂移是留存杀手 |

### 口播脚本（Conversational Script）
- **写得像说话**：按真实口语写，不按书面语；写完**朗读一遍**，把生硬处改掉。
- 分段/分场景写：便于分句重录（不用整段重来）。
- 短句、口语词、停顿（省略号）都写在稿里。
- 避免"首先/其次/最后"式的僵硬连接词（除非内容真的需要结构提示）。
- 时长：社媒 1-3 分钟；教程/课程 5-10 分钟（一个视频一个主题）。

### 口播剪辑
- 剪掉停顿与口误（善用 J 切/L 切平滑，见 02 文档）。
- **加字幕**：30%+ 静音观看（见 05 文档）；关键概念文字层强化。
- B-roll 与图示克制使用：口播的力量在"直接"——别把口播剪成PPT。
- 语速与节奏：语速微快 + 重点放慢 = 专家感。

## 在 AI 视频生成中的应用

1. **AI 数字人口播**：生成数字人时固定"人物 identity sheet"（面部/服装/背景），镜头语言按口播规范（中近景、眼神光、简洁背景）。
2. **采访素材增强**：AI 生成背景/插图/B-roll 填充采访画面，避免长时间"说话头"。
3. **纪录片叙事辅助**：用结构模板生成"问题-追寻"式脚本大纲；用提问技巧生成开放式问题清单。
4. **字幕与总结**：AI 自动字幕 + 章节标题 + 关键信息文字层（双通道强化）。
5. **档案风格化**：老照片/档案素材用 AI 修复、上色、Ken Burns 效果（缓慢推拉）增强叙事。

## 常见错误

1. 户外采访：风噪、日光变化、背景杂乱。
2. 书架/植物/台灯背景三俗：观众分心。
3. 领夹麦外露 + 首饰摩擦声。
4. 忘了录 Room Tone：剪辑间隙"真空"。
5. 受访者坐转椅/高背椅：画面晃动/头后挡板。
6. 机位低于眼睛：显矮显弱。
7. 采访照本宣科：问题念完就等答案，没有追问。
8. 口播无字幕、无眼神接触、机身麦收音。
