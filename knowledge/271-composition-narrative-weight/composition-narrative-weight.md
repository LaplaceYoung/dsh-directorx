# AI 图片构图叙事权重（Narrative Weight — Size, Scale & Visual Hierarchy）

> 本页为 AI 图片的构图叙事权重：大小/尺度=重要性（Size as Significance）、视觉层级（主焦点/支撑/上下文）、光作为强调工具、权重引导情绪。知识本体来自 2026 视觉层级指南（Figma/IxDF/RMCAD/Visme）。AI 应用面向 DirectorX：构图叙事（衔接 216 构图、271 对应、246 注意、192 负空间）。
> 来源：Figma「What Is Visual Hierarchy」、IxDF「Visual Hierarchy 2026」、RMCAD「Designing Visual Hierarchies」、Visme「12 Visual Hierarchy Principles」。

## 概述

**核心断言**：大小 = **叙事权重的可视化**——大元素=重要（主体/价格/标题），小元素=次要；视觉层级（主焦点→支撑→上下文）控制眼动路径（衔接 216：构图法则的权重维度；246：注意优先级的实证）。

## 核心概念

### 视觉层级三阶

```
① 主焦点（Primary）：最大/最亮/最对比
② 支撑元素（Supporting）：次重要
③ 上下文（Context）：背景/环境
```

### 大小即意义（Scale Semantics）

| 大小关系 | 语义 |
|---|---|
| 主体巨大 | 权力/压迫 |
| 主体渺小 | 渺小/孤立 |
| 元素比例失衡 | 超现实/隐喻 |

### 光作为强调

光线指向=强调工具（亮部=重要）——**光与权重协同**（衔接 261 光位、236 明暗）。

## 技巧与示例

### 权重设计工作流（AI 映射）

```text
叙事节拍（谁重要）→ 大小分配
  → 视觉层级（三阶）→ 光强调
  → 提示词 → 生成 → 权重校验
```

### 权重提示词

"dominant subject large in frame, small supporting elements, spotlight on subject"——**大小+光双重强调**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 大小与意义不符 | 误导 | 权重分配 |
| 无主焦点 | 视线散 | 三阶设计 |
| 光强调错位 | 抢焦点 | 光协同 |
| 支撑抢主 | 层级乱 | 大小控制 |
| 不校验权重 | 叙事错 | 权重检查 |
