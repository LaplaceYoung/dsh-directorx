# 电影观众体验设计（Audience Experience Design — AxD Five-Stage & Engagement Framework）

> 本页为电影观众体验设计：AxD 五阶段设计思维（总影院体验：脚本+受众定位+互动概念）、视觉形式-移情-叙事参与（景别减距/复杂度平衡/平滑剪辑）、想象可得性+社交观看语境。知识本体来自 2026 观众体验（Tandfonline/VU/Bora）。AI 应用面向 DirectorX：体验设计（衔接 322 杂交体验、327 对应、304 预期、323 沉浸）。
> 来源：Tandfonline「Audience Dynamics Through Imagined Affordances」、VU「From Frames to Feelings」、Bora「Audience Experience Design for Film」、Torino「Audience Design Introduction」。

## 概述

**核心断言**：观众体验设计 = **"五阶段设计思维"**——AxD（脚本+受众+互动概念整合设计总影院体验）；视觉形式三原则（景别减距/复杂度平衡/平滑剪辑）影响移情与参与；想象可得性+社交语境塑造预期（衔接 322：体验的工程化；304：预期）。

## 核心概念

### AxD 五阶段（Bora）

```
① 受众定位 → ② 脚本整合 → ③ 互动概念
→ ④ 体验原型 → ⑤ 测试迭代
```

### 视觉形式三原则（VU 实证）

```
① 景别缩短观距（特写=近，231）
② 复杂度平衡唤起（生理激活）
③ 平滑剪辑保参与（158 节奏）
```

### 想象可得性（Tandfonline）

观众对电影形式的想象塑造体验——**"预期先行于观看"**（衔接 304）。

## 技巧与示例

### AxD 工作流（AI 映射）

```text
受众定位 → 脚本整合（150）→ 互动（167）
  → 视觉三原则（景别/复杂度/剪辑）
  → 生成 → 体验测试（311 测量）
```

### 三原则应用示例

"close-up to shorten distance + balanced complexity + smooth flow"——**视觉工程**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无受众定位 | 体验错 | 定位先行 |
| 复杂度失衡 | 唤起错 | 平衡 |
| 剪辑突跳 | 参与断 | 平滑 |
| 忽略想象预期 | 预期错 | 可得性设计 |
| 不测试迭代 | 效果未知 | AxD 五阶段 |

## 工作流应用（AI 映射）

体验设计（衔接 150/158/167/231/304/311）：

```text
定位 → 脚本 → 互动 → 视觉三原则 → 测试
```

**DirectorX 纪律**：五阶段工程；视觉三原则；预期先行；测试迭代。
