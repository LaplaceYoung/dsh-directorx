# 电影声音空间叙事（Sound Spatial Narrative — Off-Screen Sound & Perspective）

> 本页为电影声音空间叙事：画外声音（Off-Screen Sound）扩展世界、声音透视（Sound Perspective：响度/空间化/深度传达距离）、声音引导方位、声景叙事（衔接 219 声音理论的空间维度、173 空间音频技术、242 对应）。

## 概述

**核心断言**：声音把观众放进**画框之外的叙事空间**——画外声音（Off-Screen Sound）暗示画外世界/未见的行动，声音透视（响度/空间化/深度）传达距离与方位（衔接 219：辩证声的空间延伸；173：空间音频的叙事用法）。

## 核心概念

### 画外声音（Off-Screen Sound）

```
来源在画框外 → 扩展世界（未见的行动/空间）
→ 制造期待/悬疑（将入画）
→ 增强可信（世界连续性）
```

### 声音透视（Sound Perspective）

| 元素 | 传达 |
|---|---|
| 响度 | 距离 |
| 空间化 | 方位 |
| 深度（混响） | 空间大小 |

### 声景叙事功能

声音定位引导观众注意（画面外有人靠近 → 观众期待入画）——**声音先行，画面跟进**（衔接 158 张力、239 蒙太奇的音频版）。

## 技巧与示例

### 空间声设计工作流（AI 映射）

```text
空间规划（画外声源/方位/距离）
  → 透视设计（响度/空间化/深度）
  → 声音生成（144/173）
  → 画外-入画时机设计（158 张力）
  → 混音（144/161）
```

### 声音先行叙事

"脚步声渐近（响度增大）+ 门把手转动（方位右）" → 观众期待角色入画——**画外声制造悬念**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 画外声缺失 | 世界狭窄 | 画外扩展 |
| 透视混乱 | 方位错 | 响度/空间化 |
| 画外声无时机 | 无悬念 | 先行设计 |
| 声画脱节 | 出戏 | 方位匹配 |
| 全片声场平 | 无空间 | 深度层次 |
