# AI 图片记忆签名系列（Memory Signature Series — Personal Style & Nostalgic Cohesion）

> 本页为 AI 图片的记忆签名系列：单一风格元素（色板/光/情绪/构图参考集）、签名提示框架（常量锁定+只换主体/场景）、图转提示词提取（怀旧锚图→常量）、收藏集=一个卷。知识本体来自 2026 个人风格系列（GetImg/YouMind/LTX）。AI 应用面向 DirectorX：记忆品牌（衔接 301 怀旧系列、319 对应、306 母题签名、294 情绪记忆）。
> 来源：GetImg「Consistent Style 2026」、YouMind「Image-to-Prompt Brand Consistency」、LTX「AI Image Trends 2026」、AIMagicX「AI Brand Image Consistency」。

## 概述

**核心断言**：记忆签名 = **"个人风格的记忆卷"**——单一风格元素（参考集定色/光/情绪/构图）贯穿所有图（系列如一个卷而非散资产）；签名提示框架（常量锁+只换主体）；图转提示词从怀旧锚图提取常量（衔接 301：怀旧系列的风格化；306：母题签名）。

## 核心概念

### 单一风格元素（GetImg）

```
参考集（色板/光/情绪/构图）→ 可复用
+ 一致锚点提示 → 系列如一个卷
```

### 签名提示框架

常量（色/光/纹理）+ 只换主体/场景——**"框架不变，内容变"**（衔接 299）。

### 图转提示词（YouMind）

从怀旧锚图提取常量（色/光/情绪）→ 跨场景复用——**"一图定调"**（衔接 290）。

## 技巧与示例

### 记忆签名工作流

```text
怀旧锚图 → 提取常量（图转提示词）
  → 签名框架（常量+变量）
  → 系列生成（301 章节）
  → 一致性校验（一个卷）
```

### 框架示例

"constants: warm nostalgic palette, soft light, film grain + [memory scene]"——**常量+记忆场景**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无参考集 | 散资产 | 单一元素 |
| 常量漂移 | 卷断裂 | 锁定 |
| 无锚提取 | 每图手写 | 图转提示词 |
| 记忆无主题 | 无灵魂 | 怀旧主题 |
| 不校验一致性 | 散 | 卷校验 |

## 工作流应用（AI 映射）

记忆品牌（衔接 290/294/301/306）：

```text
锚图 → 提取 → 框架 → 系列 → 校验
```

**DirectorX 纪律**：一元素贯全卷；常量锁变量换；锚图提取；怀旧主题。
