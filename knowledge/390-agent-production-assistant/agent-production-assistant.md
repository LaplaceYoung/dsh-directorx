## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只排期不预算 | 失控 | 双管 |
| 无记忆 | 重复 | 知识库 |
| 跳过治理 | 风险 | 生命周期 |
| 剧本解析弱 | 排期错 | 解析强化 |
| 不校验输出 | 排期偏差 | 校验 |
