# 电商视觉全案整合（E-commerce Visual Integration）

> 本页是 DirectorX 电商视觉全案手册：视觉=生产力（93% 决策数据）、平台规格差异、产品摄影基础（布光/构图/品类）、主图黄金法则（3 秒/AIDA/差异化+五类型）、详情页高转化结构、配色 60-30-10 与字体、视频 PDP（视频优先页面）、AI 全链路方案。与 41 素材工厂 / 38 广告视觉 / 51 色彩心理衔接。
> 来源：FocalFlow 电商视觉设计指南、Online Store News 视频 PDP、Rewarx 视觉一致性、阿里云百炼 CLI 全链路方案。

## 概述

**视觉就是生产力**：93% 的购买决策受视觉因素影响；一张好主图能让点击率提升 200%，一个优秀详情页能让转化率翻倍。

**设计公式**：好的电商视觉 = 清晰的产品展示 + 突出的卖点表达 + **统一的品牌调性**。

**三个核心目标**：吸引注意（海量商品中脱颖而出）→ 传递信息（快速理解产品价值）→ 促进转化（引导购买）。

## 平台视觉规格差异（先看平台再设计）

| 平台 | 主图规格 | 风格要求 |
|---|---|---|
| 淘宝/天猫 | 800×800，第 5 张必须白底图 | 可较丰富，允许适度营销文字 |
| 京东 | 800×800，必须白底图 | 简洁专业，限制营销文字 |
| 拼多多 | 750×750 起 | 突出性价比，促销氛围强 |
| 亚马逊 | 2000×2000 推荐，纯白底 (RGB 255,255,255) | 极简专业，**禁止文字装饰**；A+ 页面模块化 |
| 抖音电商 | 1:1 正方形 | 年轻化有冲击力，重视短视频 |

**详情页宽度**：淘宝/拼多多 750px、京东 990px。

## 产品摄影基础（手机+AI 已够用）

**三种基础布光**：顺光（白底图/证件照式）、侧光 45°（质感纹理，最常用）、逆光/轮廓光（透明/玻璃/饮料）。
**实用公式**：主光（侧 45°）+ 辅光（正面补）+ 背景光（可选）= 专业级产品照。

**构图四法**：三分法（交叉点）、中心构图（白底/对称）、对角线（长条形动感）、留白（产品占 30-40% 高级感）。

**品类技巧**：服装=平铺/挂拍/模特图（真人上身转化率最高）；美妆=45° 俯拍+包装质感+使用场景；3C=深色背景+科技感+反光处理；食品=45° 俯拍+色泽食欲+食材道具；家居=场景化+整体风格统一（→ 46 场景设计）。

## 主图黄金法则

**法则一：3 秒法则**——1-3 秒内看清产品、感知卖点、产生点击欲；
**法则二：AIDA 模型**——注意（视觉冲击）→ 兴趣（卖点）→ 欲望（场景效果）→ 行动（促销信息）；
**法则三：差异化**——与竞品不同的背景色/拍摄角度/卖点表达/视觉风格。

**五类型主图**：白底图（平台推荐/★★）、场景图（代入感/★★★★）、卖点图（产品+文字/★★★）、对比图（前后/竞品/★★★）、模特图（真实感转化率最高/★★★★★）。

**主图文案**：卖点型/数据型（销量 100 万+）/促销型（限时 5 折）/场景型；**≤10 字、手机可看清、与背景对比、不遮挡产品主体**。

## 详情页：说服购买的关键战场

**标准结构**：首屏海报（核心卖点+促销）→ 产品展示（多角度细节）→ 卖点详解（3-5 个）→ 使用场景 → 规格参数 → 品牌背书 → 售后保障 → FAQ。

**设计三原则**：
1. **F 型阅读**：先横向扫顶部→向下→垂直扫左侧——重要信息放左上角，每屏有视觉焦点；
2. **信息分层**：核心卖点 3 秒传达 / 产品细节 10 秒了解 / 补充信息按需；
3. **节奏感**：图文交替、每 3-4 屏一个视觉高潮、适当留白。

**高转化模板**：痛点解决型（痛点→方案→展示→证明→购买）；场景代入型（场景→融入→细节→好评→购买）；品质背书型（品牌故事→工艺→材质→认证→购买）。

## 配色与字体（→ 51 色彩心理学衔接）

- **60-30-10 法则**：60% 主色（背景）+30% 辅色（内容区）+10% 强调色（按钮/标签）；
- 同色系（安全）vs 互补色（吸引眼球但控比例）；
- 字体：**一页 ≤3 种**；标题粗体正文常规；层级分明；优先免费商用（思源黑体/阿里巴巴普惠体/站酷高端黑）。

## 视频 PDP：视频优先页面（2026 趋势）

- **视频 PDP 重写转化率**（Online Store News）：产品视频替代静态图成为首屏主角——动态展示增强信任；
- **AI 驱动视频 PDP**：自动生成产品视频（多角度/使用场景/卖点动效）；
- **嵌入纪律**：视频 ≤30-60 秒首屏（→ 68 规格）、静音可读（→ 63 字幕）、自动播放+关闭音效、移动端优先；
- **全链路 AI 方案**（阿里百炼 CLI）：白底主图→场景图→展示视频一站生成（→ 41 素材工厂的电商落地版）。

## 视觉一致性=新竞争力（Rewarx）

- 跨渠道（主图/详情/直播/短视频/广告）统一视觉语言——品牌识别累积信任（→ 45 风格统一）；
- 电商视觉系统（EVI）：主色/辅助色/字体/版式/图标体系固定，营销素材只换内容不换框架（→ 54 锁定元素同构）。

## 常见错误

1. 无视平台规格：白底图带文字投亚马逊=下架风险。
2. 主图信息过载：3 秒内看不清。
3. 详情页无结构：F 型阅读不满足。
4. 一页超过 3 种字体/颜色失控：廉价感。
5. 产品本色被调色扭曲：退货风险（→ 51）。
6. 视频 PDP 无声字幕：静音场景流失。
7. 跨渠道视觉分裂：品牌识别稀释。
