# AI 图片构图母题系统（Visual Motif System — Recurring Elements & Key Visuals）

> 本页为 AI 图片的构图母题系统：视觉母题（Motif：重复视觉元素加深叙事意义）、关键视觉（Key Visual：品牌/系列主视觉）、母题提示词系统（跨帧复用）、主题符号化。知识本体来自 2026 母题设计（Fiveable/Medium/Sweetlava）。AI 应用面向 DirectorX：系列符号（衔接 209 道具母题、288 对应、238 系列一致、284 签名）。
> 来源：Fiveable「Creating and Using Visual Motifs」、Medium「Visual Motifs Across a Story」、Sweetlava「Key Visual Glossary」、TheBrief「Repetition in Design」。

## 概述

**核心断言**：母题 = **"重复即意义"**——跨帧/跨图重复视觉元素（物体/色彩/构图）加深叙事意义；关键视觉（Key Visual）是系列的主母题（可复现构图）（衔接 209：道具母题的图片版；284：签名的母题构成）。

## 核心概念

### 母题三功能

```
① 加深叙事（重复暗示主题）
② 建立识别（系列统一感）
③ 情感锚点（观众记忆点）
```

### 关键视觉（Key Visual）

主母题 = **可复现构图**（图像+字体+色彩组合，品牌/系列统一）——**一图统全系**（衔接 195 品牌）。

### 母题提示词系统

母题令牌（物体/色彩/构图词）跨帧复用——**"母题 DNA"**（衔接 238 角色 DNA 的视觉版）。

## 技巧与示例

### 母题工作流（AI 映射）

```text
主题分析 → 母题选型（物体/色彩/构图）
  → 母题令牌 → 跨帧复用（238）
  → 关键视觉设计 → 生成 → 识别校验
```

### 母题提示词

"recurring motif: red umbrella in every frame, symbolizing protection"——**母题+象征**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 母题无象征 | 装饰 | 意义绑定 |
| 令牌漂移 | 母题失效 | 复用锁定 |
| 母题过密 | 疲劳 | 克制 |
| 无关键视觉 | 无统一 | KV 设计 |
| 不校验识别 | 效果未知 | 识别检查 |

## 工作流应用（AI 映射）

系列符号（衔接 195/209/238/284）：

```text
主题 → 母题选型 → 令牌 → 跨帧复用
  → 关键视觉 → 生成 → 识别校验
```

**DirectorX 纪律**：重复即意义；母题绑定象征；令牌复用；KV 统一全系。
