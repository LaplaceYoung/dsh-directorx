# 拍摄端声画协同（Designing Picture for Sound）

> 本页是 DirectorX 拍摄端声画协同手册：声音设计从剧本开始（POV 是核心）、给角色倾听的机会、饿眼养耳、画面为声音建立锚点、场景选择与美术的声学考量、剪辑为声音留空间、声音职能清单。音频技术部分从简（→ 06/23/31），重点在画面侧的设计配合。
> 来源：Randy Thom《Designing a Movie for Sound》（经典）、Sound on Sound、Pixflow 声音设计指南。

## 概述

**最大误区**：声音设计就是制造很棒的音效——不对，至少不够。Burtt 与 Murch 在《星球大战》《现代启示录》中的发现：**声音开始塑造画面，与画面塑造声音一样多**。只有当每个工艺影响其他工艺时，电影才开始有自己的生命。

**核心断言**（Randy Thom）：
1. 电影**不是"视觉媒介"**——伟大电影中视听元素协同得几乎无法区分；
2. 声音参与叙事的能力，更多取决于故事中**时间、空间与视点的运用**，而非剧本提了多少次声音；
3. **POV 是声音叙事的蓝图**：伟大的声音段落几乎都是 POV 段落——观众透过角色意识过滤所见所闻。

## 拍摄端五条画面侧纪律

### 1. 剧本阶段：为声音写 POV
- 建立 POV 应在演员/摄影机/麦克风/剪辑介入**之前**——剧本包含蓝图；
- 好声音场景=角色"倾听世界"的场景：钢厂（声音调色板极广）、梦境（声音变形自由）、时间边界（声音蜕变：钢厂剪切声→回家火车的咔嗒声）；
- **选材测试**：这个故事能不能让"地点成为角色"——有声音调色板的地方。

### 2. 给角色倾听的机会（观众需要听到他的世界）
- 角色看物体时观众透过他的眼睛看；同样，**角色听世界时观众透过他的耳朵听**；
- 全程对白不让角色听=剥夺观众了解他的一维；
- **对白密度纪律**：拒绝 100% 理论（各工种都塞满=噪音竞争）——角色需要有"不说话"的时刻。

### 3. 饿眼养耳（视觉留白邀请声音）
- 声音是"心的东西"（Alan Splet）——观众用情绪而非理智解读声音；
- 画面处理方式为声音开门：长焦/短焦主观空间、荷兰角与移动摄影（不熟悉的空间）、画框边缘的黑暗（黑色电影）、极特写与极远景、慢动作（梦空间）、黑白（感受而非信息）；
- **共同点=扣留信息**：模糊一点，让"所见不够+所听模糊+组合指向隐约熟悉的容器"——观众倒入自己的经验。

### 4. 画面为声音建立锚点（一次特写够用）
- 想让奇怪机器声带张力？**先给一次近景**建立声音来源——此后每次听到它，观众自动连接（哪怕音量极低）；
- 管子公寓案例：一次管道特写+怪诞声音=观众此后"听到"这个空间的丑陋，无需再看；
- **声音源建立后就可以只闻其声**——声音地理感由此而来。

### 5. 场景选择与美术的声学考量
- 拍摄地点的选择要考虑声音贡献：需要建立钢厂声音覆盖街区？在几个街区外拍一场戏（Randy 的梦想场景）；
- 美术设计：可见的水管/暖气管=声音设计师的素材（"空间有自己的声音，角色安静时我们听到空间"）；
- 现场纪律：灯光嗡嗡声/发电机太近/地板不加垫=后期 ADR 地狱——**画面组为声音组留余地**。

## 剪辑为声音留空间（Murch 无声剪辑法）

- 剪辑师常删掉"无事发生"的时刻——有时应该**在对白结束后停留**，让声音潜入；
- **Murch 技巧**：剪辑时不听同步声——想象最终的声音（音乐/效果），剪辑自然为声音节拍留出空间；
- 为声音留的停顿=故事在呼吸（→ 35 Animatic 测节奏衔接）。

## 声音职能清单（音乐/对白/音效各可承担）

```
暗示情绪 / 激发感受 / 设定节奏 / 指示地理 / 指示时代
澄清情节 / 定义角色 / 连接不相关的想法/人物/地点/时刻
增强或削弱真实感 / 增强或削弱模糊性 / 引人注意或转移注意
指示时间变化 / 平滑或强调转场 / 描述声学空间
惊吓或抚慰 / 夸大或调和动作
```
**任意时刻声音通常同时做几件事**——但声音有自己超越功用的生命。

## 拍摄端协同检查清单（开拍前过一遍）

1. 剧本有 POV 吗？角色有倾听的时刻吗？
2. 地点能提供什么声音调色板？场景选择考虑声音贡献了吗？
3. 画面里有没有为关键声音建锚点（一次特写）？
4. 对白密度是否留白（角色有不说的时候）？
5. 有没有"饿眼"段落（视觉留白邀请声音）？
6. 现场：灯嗡嗡/发电机/地板——画面组给声音组留余地了吗？
7. 剪辑计划有没有为声音留停顿？

## 常见错误

1. 声音当后期补丁：结构定死才想声音=创可贴。
2. 全程对白：声音无处可进。
3. 无 POV：声音无载体。
4. 声音无锚点：观众不知道那是什么声音。
5. 场景选择无视声学：后期 ADR 地狱。
6. 剪辑不停留：声音没有落脚点。
7. 各工种 100% 塞满：互相竞争=噪音。
