## 概述

**核心断言**：口播广告的转化由**脚本/证明/CTA 决定，数字人只是交付层**——选对形象 + 写好脚本 + 测变体才是关键。AI 口播把成本从 1000-10000$ 降到分钟级（省 90-99%），多平台（Meta/TikTok）快速 A/B。**形象是品牌资产，脚本是转化引擎**。

## 核心概念

### 口播广告三件套

```
① 形象（数字人：模板/孪生/品牌人设，137）
② 脚本（钩子 188 + 异议-证明 135 + CTA）
③ 测试（多变体 A/B，149）
```

### 数字人 = 交付层原则

转化率由内容驱动：**脚本/证明/CTA 权重 >> 形象选择**——先写好脚本，再选形象，不颠倒（衔接 135：简报决定质量上限的同构原则）。

## 技巧与示例

### 口播广告工作流（Creatify 2 分钟模式）

```text
产品 URL/信息 → 脚本生成（188 钩子 + 异议-证明）
  → 形象选择（品牌人设，137）
  → 口播生成（对口型 119 + 微表情 175）
  → 多变体（不同钩子/CTA，135）
  → 平台适配（142）→ A/B 测试（149）
```

### 形象一致性（品牌资产）

同一品牌口播用同一数字人形象（跨产品/跨语言）——**形象=品牌资产**（衔接 137 数字孪生、152 IP 经济）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 重形象轻脚本 | 转化低 | 脚本先行 |
| 无 CTA 设计 | 无行动 | CTA 明确 |
| 形象每广告变 | 品牌弱 | 形象统一 |
| 不测变体 | 凭感觉投放 | A/B（149） |
| 表情僵硬 | 假人感 | 微表情（175） |

## 工作流应用（AI 映射）

广告口播（衔接 135/137/149/175）：

```text
产品信息 → 脚本（188+135）→ 形象（137）
  → 口播生成（119+175）→ 多变体
  → 平台适配（142）→ A/B（149）→ 投放
```

**DirectorX 纪律**：脚本决定转化；形象统一为品牌资产；多平台多语言 A/B；表情自然防假。
