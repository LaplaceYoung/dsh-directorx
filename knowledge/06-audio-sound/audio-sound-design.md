# 音频制作与声音设计（Audio & Sound Design）

> 本页是 DirectorX 音频知识库：声音三元素、声音设计基础、录音→剪辑→混音→母带全链、LUFS 响度标准、音乐驱动剪辑、声音桥与口型同步。每个概念含定义、参数、示例与 AI 生成应用。
> 来源：AES TD1008 流媒体响度建议、EBU R128/ITU-R BS.1770 标准要点、Krotos/StudioBinder 声音设计指南、行业混音教材要点。

## 概述

电影声音由三根支柱构成：**对白（Dialogue）、音乐（Music）、音效（SFX/Effects）**，外加**环境声（Ambience）**与**拟音（Foley）**。声音设计（Sound Design）决定"观众听到什么、以什么顺序、多大音量"——它和画面剪辑一样是叙事工具。著名声音设计师 Walter Murch 曾说过：声音是电影的一半，但观众往往意识不到它的存在——**好的声音设计是不可见的**。

核心原则：
1. **声音分层（Layering）**：最终混音是多个声音层的组合（对白层、音乐层、音效层、环境层），每层有自己的音量、频段与声像。
2. **声音为主时钟（Audio as Master Clock）**：当音乐或已完成的音频驱动影片时（MV、卡点视频、对口型），音频时间轴是权威，画面围绕它剪辑。
3. **响度战争是毒药**：内容做"响"不靠增益拉满，靠动态与平衡（AES 明确反对 loudness wars）。

## 声音三元素与辅助层

| 层 | 内容 | 功能 | 常见错误 |
|---|---|---|---|
| 对白 Dialogue | 台词、旁白、内心独白 | 信息与情感主通道 | 音量过小/被音乐淹没 |
| 音乐 Music | 配乐、歌曲、音效化音乐 | 情绪底色、节奏、时代感 | 全程铺满无起伏 |
| 音效 SFX | 动作音、环境提示音 | 真实感、强调、转场 | 缺失（无声的敲击/关门） |
| 环境声 Ambience | 房间氛围、街道、自然声 | 空间感、场所建立 | 完全静音（"录音棚真空感"） |
| 拟音 Foley | 脚步声、衣服摩擦、道具声 | 身体在场感 | 忽略（人走无脚步） |

**检查方法**：闭眼听一遍成片——如果"安静段落"是真空死寂，缺环境声；如果听不清台词，对白层被压制。

## 声音设计基础

1. **声音透视（Perspective）**：声音与画面中的距离感匹配——近景声音细节多、低频多；远景声音混响多、音量小。
2. **主次关系（Foreground/Background）**：每个时刻只有一层是主角（通常是对白或重点音效），其余是配角；两个同样响的声音同时存在 = 观众两耳都听不清。
3. **声音情绪**：
   - 音色：明亮（希望）vs 暗淡（压抑）；
   - 速度：快节奏（紧张）vs 慢节奏（舒缓）；
   - 音量：渐强（逼近/高潮）vs 骤停（惊吓/转折）。
4. **无声的运用（Silence）**：突然的静默是电影里最强的强调手段——在噪音中插入 0.5 秒静音，注意力瞬间集中（惊悚片标准手法）。
5. **声音桥（Sound Bridge）**：声音跨场景延续（见 02 剪辑文档的 J/L 切）——上场景音乐延续到下一场景，情绪不断裂。
6. **非同步声（Asynchronous Sound）**：声音与画面错位制造隐喻/讽刺（见 02 剪辑文档）。

## 音频制作链（录音 → 剪辑 → 混音 → 母带）

### 1. 录音（Recording）
- **收音优先级**：对白永远优先于环境——环境可以后期补，对白补不了。
- **麦克风选择**：指向性（Shotgun，室外/远距）、领夹（Lavaliere，室内/近距）、电容（棚内）。
- **距离法则**：麦克风越近声音越"贴身"（低频越多）；15-30cm 是口播最佳距离。
- **环境噪声控制**：先关空调/冰箱/风扇；室内录对白用软装吸音（毯子、床垫）减少混响。
- **录音备份**：所有对白至少录两条；开拍前 10 秒环境声（Room Tone）——剪辑时的"静音填充"就靠它。
- **电平规范**：峰值 -6dBFS 以内（留余量），避免爆音（Clipping）。

### 2. 剪辑（Editing）
- 对白修剪：去掉喘气、口误、口水声（但保留有情绪价值的停顿）。
- 降噪（Denoise）：只降环境底噪，不过度——过度降噪产生"水声/金属声"（artifact）。
- 补齐环境声：没有 Room Tone 的段落用录好的 Room Tone 垫底，消除"真空感"。
- 音效补齐：门、脚步、衣物声等缺失音效用拟音或素材库补。

### 3. 混音（Mixing）
- **均衡（EQ）**：给每层"让出频段"——人声突出 2-5kHz（清晰度）；音乐让出中频给对白；低频（80-200Hz）管力度。
- **压缩（Compressor）**：压住峰值、提高平均响度；人声 -6dB 起压（约 3:1 比例）是常用起点；避免压得过平失去动态。
- **混响（Reverb）**：空间感——对白小混响（贴近感）、音乐大混响（史诗感）；混响过量 = "澡堂声"。
- **延迟（Delay）**：回声感、制造空间/时间。
- **声像（Pan）**：左右声道分配——对白居中，音乐铺满，音效按画面位置摆放。
- **音量平衡**：以对白为基准（-23~-18 LUFS 对白区），音乐在对白下 -18~-22dB，音效瞬态不盖过对白。
- **层次检查**：每 30 秒暂停一次，问"现在谁在说话/什么最重要"——观众应该永远知道听什么。

### 4. 母带（Mastering）
- 最终响度归一、峰值控制、格式导出。
- **响度目标**：见下节标准表。
- **True Peak 限制**：损失编码前不超过 -1 dBTP（AES 推荐），防止解码后过载。

## 响度标准（LUFS）

**单位**：LUFS（Loudness Units Full Scale，与 LKFS 等价，按 ITU-R BS.1770 测量）；LU = 响度差单位（1 LU ≈ 1 dB，约等于人耳可察觉的最小差别）。

### 平台/场景目标值（行业通行）
| 场景 | 目标响度 | 峰值限制 | 说明 |
|---|---|---|---|
| 流媒体视频（YouTube/B站） | -14 LUFS | -1 dBTP | 主流网络视频默认 |
| Netflix 交付（IMF） | -27 LUFS | -2 dBTP | 平台交付规格（见 112 交付规格） |
| 短视频（TikTok/抖音/Reels/Shorts） | -14 LUFS（交付目标） | -1 dBTP | 平台实践值 -10~-12（响度战争现状，见 161） |
| 广播/电视（EBU R128 / ATSC A/85） | -23 LUFS | -1 dBTP | 欧洲广播标准 |
| 音乐流媒体专辑（Album 归一） | 最响曲目 -14 LUFS | -1 dBTP | AES TD1008 |
| 音乐单曲（Track 归一） | -16 LUFS | -1 dBTP | 无专辑上下文时 |
| 播客/谈话 | -16 ~ -18 LUFS | -1 dBTP | 对白为主 |
| 电影母版（院线） | -24 LUFS 目标（存档） | 各影院自行 | AES 建议内容以 -24 存档 |

### 关键原则（AES TD1008）
- **响度归一化**：平台会把内容统一到目标响度——内容做"响"会被平台压回来（向下归一），过度压缩反而损失动态与清晰度。**对抗响度战争的方式是做"动态"而不是做"响"**。
- **对白与音乐相对关系**：人耳感知上，对白比同 LUFS 的音乐"响 2-3dB"——分别归一化时，音乐应比对白高 2-3 LU（AES 建议对白 -18 LUFS、音乐 -16 LUFS 的平均组合）。
- **高峰-响度比（PLR）**：峰值与平均响度差距大 = 动态好、听感更清晰、更不疲劳；被极限压制的音频 PLR 低 = 又响又累。
- **向上归一风险**：内容过安静会被增益放大，可能削波；需要峰值限制保护。
- **存档建议**：母版按 -24 LUFS 或更低存档（"未来防呆"），发布版再归一。

## 音乐与画面（Music & Picture）

### 音乐驱动剪辑（Cut on Beat）
- **节拍对齐**：画面切换落在鼓点/贝斯/和弦/人声起音上。切换点可以精确到帧（帧率换算：24fps 下 1 拍 60s/BPM×24 帧）。
- **卡点类型**：
  - 鼓点卡点（节奏感最强，动作/舞蹈/快剪）；
  - 人声卡点（口播/歌曲句首，故事感）；
  - 和弦/和声变化卡点（情绪转折，慢节奏）；
  - 能量曲线卡点（段落级：前奏→主歌→副歌切换处放最强画面）。
- **BPM 换算**：120 BPM = 每拍 0.5 秒；镜头时长取 0.5/1/2 拍的整数倍最"顺"。
- **音乐结构映射**：
  - 前奏（Intro）：建立镜头/环境；
  - 主歌（Verse）：叙事展开；
  - 副歌（Chorus）：高光画面、最强视觉；
  - 间奏（Bridge/Interlude）：转场/情绪变化；
  - 尾奏（Outro）：收束画面 + 品牌/CTA。

### 音频为主时钟（Audio as Master Clock）
- 当成品音频（歌曲、旁白、已完成混音）驱动影片时：**音频时间轴是唯一权威**，画面、字幕、特效全部围绕音频时间码对齐。
- 流程：确定音频 → 分析音频（BPM、节拍点、段落、人声起止、能量曲线）→ 冻结镜头结构 → 按音频时间码放置镜头 → 微调（不添加填充镜头）。
- 与 DirectorX 工作流对应：先"测量音频事件"，再"映射视觉节拍"——绝不凭想象时间码。

### 口型同步（Lip-sync）
- **对口型拍摄**：播放参考音频（Playback），表演者跟唱/跟说；用拍板（Clapper）或时间码（Timecode）保证同步点。
- **剪辑同步法**：以音频波形为准——人声起音对齐口型张开的瞬间；"先听见后看见"的偏差 < 2 帧可接受，> 2 帧观众会察觉。
- **唇形等级**：完全对口型（每个音节）> 节奏对口型（只对重音）> 情绪对口型（只对段落情绪）；生成内容视模型能力选择等级，并在提示词中声明。

### 音乐版权意识
- 商业发布使用音乐需确认授权（平台曲库、CC 协议、原创）；短视频平台曲库内的音乐有平台授权，但导出商用需复核。

## 声音转场与声音桥（Audio Transitions）

- **J 切（声音先行）**：新场景声音提前 0.5-2 秒进入（"预告下一个空间"）。
- **L 切（声音延后）**：上场景声音延续到新画面（"情绪不中断"）。
- **声音桥（Sound Bridge）**：音乐/环境声跨场景延续，连接情绪（见 02 文档）。
- **音效转场**：用一声巨响/尖锐音效掩盖剪辑点（撞击声、警报、掌声），让画面切换"顺势"发生。
- **静音转场**：在高潮后突然静音再进入下一段（强对比，观众注意力重置）。

## 混音检查清单（可直接复用）

```
□ 对白全程可听清（无音乐/音效压制）
□ 每一时刻有明确的主声音层
□ 环境声垫底（无真空静音段落）
□ 无爆音（峰值未超 -1 dBTP）
□ 响度归一（流媒体 -14 LUFS；广播 -23 LUFS）
□ 音乐在对白下 -18~-22dB
□ 音效瞬态不盖对白
□ 无过度压缩（动态保留）
□ 无过度降噪 artifact
□ 首尾响度一致（无跳变）
□ 静音段落是有意为之（非漏音）
```

## 交付格式规范（音频）

| 项 | 建议 |
|---|---|
| 响度 | 流媒体 -14 LUFS（±1），广播 -23 LUFS |
| True Peak | ≤ -1 dBTP（损失编码前） |
| 采样率 | 48kHz（视频标准）；音乐 44.1/48kHz 均可 |
| 位深 | 24-bit 交付；16-bit 兼容 |
| 格式 | WAV/AAC/MP4 音轨；无损存档用 WAV/FLAC |
| 声道 | 立体声为主；对白居中 |
| 响度测量 | ITU-R BS.1770（EBU R128 模式） |

## 在 AI 视频生成中的应用

1. **音频先行的制作流**：拿到音乐/配音后先分析（BPM、节拍、段落、人声区间、能量曲线），把分析结果写进提示词（"cut on every beat, chorus at 0:25"）。
2. **卡点生成**：按节拍时间码切分镜头——每个节拍一个镜头提示词；副歌段用最强视觉（推近、特写、慢动作）。
3. **提示词音频字段**（DirectorX prompt-engineering 语法）：`Audio: [driving music, cut on beat], [voiceover, lip-sync to lyric X], [ambience: city night]`。
4. **无声片段利用**：AI 生成画面常无同步音频——用声音桥（旁白/音乐跨镜头）掩盖同步缺口，避免"口型对不上"暴露。
5. **交付前验证**：响度归一、峰值检查、全片可听性（静音段是否故意）。

## 常见错误

1. **全程音乐铺满**：无起伏、无静默，情绪被"熨平"；音乐也应该有呼吸。
2. **对白被音乐淹没**：音乐不做"对白让位"（Ducking/自动避让）——对白响度优先级最高。
3. **录音棚真空感**：缺环境声，成片"死"。
4. **响度拉满**：平台会压回来；动态丢失、听感疲劳。
5. **过度压缩/过度降噪**：artifact 比噪声更刺耳。
6. **卡点只卡鼓点**：慢歌也硬卡鼓点会显得机械；卡点和弦/人声更高级。
7. **口型不同步**：AI 生成人声视频不检查口型——先测后交付。
8. **忽略环境声与 Room Tone**：剪辑时没有填充素材。
