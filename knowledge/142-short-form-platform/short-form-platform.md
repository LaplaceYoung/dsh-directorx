# AI 短视频平台算法适配（Short-Form Platform Fit — Hooks, Retention & Platform Adaptation）

## 概述

**核心断言**：短视频算法 2026 的核心是**微留存**——观众在第一秒、第 3 秒做出的微小"是/否"决定决定流量。**完播率 <70% 是流量骤降的主因**。平台信号：完播、重播、互动、关注转化；高频发布（日 2-3 条）满足平台体量奖励，但每条必须保持强留存。

## 核心概念

### 平台信号（Socialync 7 信号）

1. **完播率（Completion）**：主信号，<70% 流量骤降
2. **重播（Rewatch）**：强信号，重播=高价值
3. **互动（Engagement）**：点赞/评论/分享
4. **关注转化**：粉丝增长
5. **停留时长**：观看秒数
6. **不感兴趣**：快速划走
7. **分享（平台外）**：传播信号

### 钩子堆叠（1-3 秒三件套）

```
视觉触发（Visual Trigger）→ 画面吸引
+ 语言钩子（Verbal Hook）→ 文字/口播悬念
+ 语境（Context）→ 快速建立"这是什么"
```

**八种钩子公式驱动 95% 爆款短视频**（ReelsMaker）。

## 技巧与示例

### 主版本 + 平台适配（ReelsMaker 策略）

```text
主版本（TikTok 优先，最完整节奏）
  → Reels 版（去叠加层/降速/优化封面）
  → Shorts 版（SEO 关键词调整/标题优化）
```

平台差异：TikTok 快节奏原生；Reels 慢一点/社交互动强；Shorts 搜索流量重（SEO）。

### AI 短视频生成适配

```text
脚本 → 钩子优化（1-3 秒三件套）
  → 主版本生成（节奏按 127 节拍）
  → 平台版本（横/竖/封面/字幕样式）
  → 完播率检测（数据反馈，149）
```

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无前 3 秒钩子 | 秒划走 | 钩子堆叠 |
| 忽视完播率 | 流量骤降 | 完播率 <70% 就重剪 |
| 一稿多平台直发 | 平台不适配 | 主版本 + 平台裁剪 |
| 高频发低质 | 互动惩罚 | 每条保持强留存 |
| 不看数据反馈 | 无法优化 | 数据驱动迭代（149） |

## 工作流应用（AI 映射）

短视频交付（衔接 112/127/135）：

```text
内容规划 → 脚本（钩子三件套）
  → 生成（节奏/节拍 127）
  → 平台适配（主版本 + 裁剪）
  → 发布（日 2-3 条节奏）
  → 数据监测（完播/重播）→ 迭代（149）
```

**DirectorX 纪律**：完播率是第一信号；前 3 秒钩子堆叠；主版本 + 平台适配；数据驱动迭代。
