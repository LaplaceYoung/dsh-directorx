# AI 图片全栈工作流（Full-Stack Workflow — LLM + Multi-Model + Production Tooling）

> 本页为 AI 图片的全栈工作流：LLM 提示工程+多模型图像/视频生成+生产工具（运动/编辑/资产管理）、品牌板嵌入（色/字保持）、端到端战役（提示→多格式资产）。知识本体来自 2026 全栈（Dreamina/KlayStudio/Prodia）。AI 应用面向 DirectorX：全栈管线（衔接 375 对应、373 集成工作室、366 全流程、131 资产）。
> 来源：Dreamina「AI Design Stack 2026」、KlayStudio「Top 5 AI Toolstacks」、Prodia「9 Essential Image Tools」、PCTechMag「Unified Platforms」。

## 概述

**核心断言**：全栈工作流 = **"LLM+多模型+生产工具"**——LLM 提示工程 + 多模型图像/视频生成 + 运动/编辑/资产管理；品牌板嵌入（色/字保持）；端到端战役（提示→多格式）（衔接 373：工作室的技术栈版；131：资产）。

## 核心概念

### 全栈三层（KlayStudio）

```
① LLM 提示工程（引导）
② 多模型生成（图/视频/文字渲染）
③ 生产工具（运动/编辑/资产管理）
```

### 品牌保真（Dreamina）

品牌板嵌入（色/字保存）→ 跨输出一致——**"品牌进栈"**（衔接 195）。

### 端到端战役（Prodia）

提示→多格式输出（静态/动效/变体）——**"一提示多资产"**（衔接 41 工厂）。

## 技巧与示例

### 全栈工作流

```text
栈选型（373）→ 品牌板嵌入（195）
  → LLM 引导 → 多模型生成
  → 生产工具 → 多格式交付 → 校验
```

### 全栈示例

"LLM-guided + multi-model generation + production tooling + brand board embedded"——**三层+品牌**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 缺层 | 栈残 | 三层 |
| 品牌不嵌入 | 漂移 | 品牌板 |
| 无生产工具 | 半成品 | 工具链 |
| 多格式缺 | 单一 | 战役 |
| 不校验栈 | 效果未知 | 全栈检查 |
