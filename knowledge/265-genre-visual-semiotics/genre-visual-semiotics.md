## 概述

**核心断言**：类型片靠**视觉图符**识别——服装/场景/灯光/道具的符号组合立即唤起类型预期（西部=沙漠+牛仔+枪；黑色电影=低调光+阴影+城市）（衔接 87：类型清单的视觉维度；248：符号学的类型应用）。

## 核心概念

### 类型图符表

| 类型 | 图符 |
|---|---|
| 西部 | 沙漠/牛仔装/枪/马 |
| 黑色电影 | 低调光/百叶窗影/烟/城市夜 |
| 科幻 | 未来科技/太空/霓虹 |
| 恐怖 | 黑暗/血迹/鬼宅 |
| 喜剧 | 明亮/夸张/日常 |

### 图符功能（Beverlyboy）

**核心物理特征识别类型**——图符引导观众预期（衔接 264：镜语+图符双识别）。

### 类型杂交

新黑色科幻 = 图符混搭（黑色阴影+霓虹）——**类型创新=图符重组**。

## 技巧与示例

### 类型视觉工作流（AI 映射）

```text
类型选型 → 图符清单（场景/服装/灯光/道具）
  → 杂交设计（可选）→ 提示词
  → 生成 → 类型识别校验（"像该类型吗"）
```

### 图符提示词示例

"film noir aesthetics, low-key lighting, venetian blind shadows, cigarette smoke, rainy city night"——**图符堆叠识别类型**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 图符缺失 | 类型模糊 | 图符清单 |
| 图符互斥 | 类型混乱 | 单类型或明确杂交 |
| 无预期引导 | 观众误读 | 图符前置 |
| 图符过密 | 堆砌 | 关键图符 |
| 不校验识别 | 四不像 | 类型检查 |
