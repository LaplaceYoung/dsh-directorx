# 宣传片 / TVC 制作全流程（Commercial & TVC Production Pipeline — Terms & Workflow）

> 本页以真实广告制作行业的标准流程为知识本体：从创意简报（Creative Brief）到母带交付（Master Delivery）的工业化管线。AI 应用面向 DirectorX：把每一阶段的真实产出物与检查点映射到 AI 工作流（提问、调研、素材、脚本确认、分镜、关键帧、生成、审片、交付）。
> 来源：Assemble「The Ultimate Guide to TV Commercial Production」、上海艺虎「TVC 拍摄流程（八大阶段）」、乐晨文化「TVC 广告片制作流程」、Wolves「The Different Stages of a TVC」、Slideshare「TVC Production Process」。

## 概述

TVC（Television Commercial，电视广告片）与宣传片是品牌营销中**投资最重、要求最高、影响最广**的视听作品。它的制作不是"摄像 + 剪辑"，而是一套**高度标准化、工业化的生产流程**——从创意火花到成品播出环环相扣。广告公司（Agency）与制作公司（Production House）按固定阶段推进，每阶段有明确的产出物与审批点（Approval Gate）。

**核心断言**：TVC 制作的成功不取决于某个天才镜头，而取决于**计划性与协同性**——尤其是 PPM 会议（拍摄前会议）这道"避免成本失控与质量偏差的关键防火墙"。

## 核心概念

### 五阶段管线（行业通用骨架）

```
创意简报 Brief → 概念与脚本 Concept & Script → 前期筹备 Pre-production → 拍摄 Production → 后期与交付 Post & Delivery
```

每阶段之间的**客户确认点**是项目推进的节拍器：概念未过不写脚本，PPM 未过不开机，成片未过不投放。

### 关键产出物（术语即交付物）

| 阶段 | 产出物 | 内容 |
|---|---|---|
| 策略 | Creative Brief（创意简报） | 核心信息、目标受众（人口学+心理画像+观看习惯）、基调与情感诉求、预算与时间线 |
| 创意 | Creative Concept（创意概念） | 广告的基调、核心画面构想、大致剧情，需客户认可 |
| 创意 | Storyboard（分镜头脚本/故事板） | 每场每镜的画面、景别、台词、时长的"漫画版"脚本 |
| 创意 | Shooting Script（拍摄脚本） | 每句旁白对应的画面描述、时长、景别、运镜 |
| 筹备 | PPM（Pre-Production Meeting 拍摄前会议） | 制片方向客户/代理确认：脚本、分镜、选景、演员、服装、道具、拍摄日程 |
| 筹备 | Shooting Schedule（拍摄日程表） | 按天/按镜头的排期，含场次、演员、场地、设备 |
| 筹备 | Budget（拍摄预算） | 创意费、制作费、演员费、后期费、设备、场地、许可 |
| 拍摄 | Dailies（样片/每日素材） | 当日拍摄素材的粗看与把关 |
| 后期 | Rough Cut（初剪） | 素材按脚本顺序的粗剪版本 |
| 后期 | Fine Cut（精剪） | 节奏、转场、镜头取舍定稿 |
| 后期 | Color Grade / Sound Mix（调色 / 混音） | 色彩方案（LUT/DI）与声音设计（音效、音乐、对白平衡） |
| 交付 | Master（母带） | 成片母带，符合播出规格（帧率、码率、响度） |
| 投放 | Media Buying / Tracking（媒介购买 / 监测） | 排期购买与效果追踪 |

## 技巧与示例

### 1. 策略与创意：简报先行

真实流程的第一步不是拍，而是**回答简报的问题**：
- 核心信息是什么？
- 理想观众是谁（人口学、心理画像、观看习惯）？
- 基调与情感诉求（幽默/严肃/励志）？
- 预算与时间线？

**示例（真实简报要素）**：某汽车品牌 30 秒 TVC 简报——核心信息"智能驾驶让通勤从容"；受众为 25-40 岁都市通勤者；基调"冷静、科技、从容"；预算 ¥80 万；时间线 6 周。

创意团队（Copywriter 文案 + Art Director 美术指导）据此产出多个概念提案，客户选定后再写脚本。

### 2. 脚本：30/60 秒的减法

商业脚本与电影剧本不同：**30 或 60 秒内每个字都算数**。要点：
- 明确传达信息、突出产品利益点、有强 CTA（Call to Action，行动号召）
- 视觉叙事优先："好的脚本即使没有台词也能讲清楚故事"
- 旁白（VO）与画面逐句对应，标注景别与时长

**示例（拍摄脚本片段）**：
```
#3  特写  方向盘/车载屏幕亮起   旁白："通勤，从此从容。"   2.5s
#4  中景  驾驶员放松微笑，窗外城市掠过   旁白："每天多留 20 分钟给你自己。"   3s
```

### 3. PPM：前期筹备的防火墙

PPM（Pre-Production Meeting）是**客户、代理、制作三方**在开机前的最终对齐会议。真实行业的铁律：**PPM 未过不开机**。PPM 确认的内容：脚本、分镜、选景照片、演员试镜、服装道具、拍摄日程、应急方案。跳过 PPM 是成本失控与质量偏差的第一大原因。

### 4. 拍摄：导演统领，但按计划执行

拍摄阶段导演与摄影指导（DoP）密切协作，但**一切按 PPM 确认的日程与分镜执行**——现场即兴是例外而非常态。突发状况（天气、设备故障、演员档期）需要预案（Contingency Plan）。

### 5. 后期：先粗后精，客户审片迭代

后期顺序：初剪（Rough Cut）→ 客户初看反馈 → 精剪（Fine Cut）→ 调色 + 视效 + 声音设计 → 混音 → 客户终审 → 母带。**审片迭代（Client Review & Revisions）是流程的一部分**：直到客户满意为止，但每轮修改应指向明确反馈，而不是无限循环。

### 6. 交付与投放：合规与效果

- 交付前检查广告法规合规（Truth in Advertising、产品宣称、竞品比较、儿童广告等）
- 母带符合播出规格；媒介购买确定频道与时段；投放后追踪效果并反哺下一轮

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 跳过创意简报直接开拍 | 方向漂移、反复重拍 | 简报先行，客户确认核心信息与受众 |
| 概念未经客户认可就写脚本 | 脚本作废、预算超支 | 概念提案先行，设审批点 |
| 跳过 PPM | 现场争执、成本失控 | PPM 是防火墙，三方对齐后开机 |
| 脚本与画面脱节 | 剪辑缺镜头、节奏垮掉 | 拍摄脚本逐句标注画面/景别/时长 |
| 无 CTA 或 CTA 含糊 | 广告"好看但没效果" | 明确行动号召 |
| 审片无结构 | 无限修改循环 | 每轮反馈指向具体镜头与问题 |
| 母带不符合规格 | 平台拒收/画质劣化 | 交付前按播出规格校验 |

## 工作流应用（AI 映射）

把真实 TVC 管线映射为 DirectorX 的执行编排——**每个真实阶段对应一个 AI 检查点**：

```text
用户需求
  → ① 创意简报（AI 提问 ≤3 个材料性问题：受众/目的/平台/时长/基调/预算）
  → ② 调研（联网搜索竞品与参考，验证事实）
  → ③ 素材与参考（下载/引用素材，画布媒体卡片预览给用户）
  → ④ 创意概念（AI 给出 2-3 个概念方向，用户选定）
  → ⑤ 拍摄脚本 + 分镜故事板（逐镜：景别/角度/运镜/构图/打光/表演/时长/转场/音频，用知识库术语）
  → ⑥ 用户确认脚本与分镜（PPM 等价物）
  → ⑦ 关键帧（每镜 1-3 张视觉参考，画布预览确认）
  → ⑧ 生成（只从图参考或足够详细的镜头描述出发，禁止文本直出视频）
  → ⑨ 审片（对生成结果逐镜审查，反馈指向具体镜头与问题）
  → ⑩ 交付（规格校验：时长/分辨率/比例/音频/字幕/合规）
```

**关键映射**：PPM = 脚本分镜确认点；Dailies = 生成结果逐镜审片；Client Review = 用户确认；母带 = 交付清单。
