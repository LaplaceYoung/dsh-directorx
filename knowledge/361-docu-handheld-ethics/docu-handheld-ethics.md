# 电影纪实-手持-伦理应用（Documentary-Handheld-Ethics — Duty of Care in Practice）

> 本页为电影纪实-手持-伦理应用：知情同意+参与者自主+编辑/AI 透明、关怀义务文档（Duty of Care：补偿/编辑控制/放映参与）、再现/素材/AI 元素不扭曲真实。知识本体来自 2026 纪实伦理（Emory/IDFA/CA10 判例）。AI 应用面向 DirectorX：纪实实践（衔接 352 手持纪实、361 对应、166 伦理、145 版权）。
> 来源：Emory「Documentary Dilemmas」、IDFA「Documentary Distortion: Code of Ethics」、NORC「Ethical Documentary Filmmaking」、GovInfo「Deepfake Harms」。

## 概述

**核心断言**：纪实-手持-伦理 = **"在场真实×关怀义务"**——知情同意+参与者自主+编辑/AI 透明；**关怀义务文档**（补偿/编辑控制/放映参与）；再现/素材/AI 不扭曲真实（衔接 352：纪实美学；166：伦理框架）。

## 核心概念

### 知情同意（Emory）

```
知情同意 + 参与者自主
+ 编辑/AI 使用透明
```

### 关怀义务（Duty of Care）

文档化：补偿/编辑控制/放映参与——**"义务落纸"**（衔接 191 清权文档化）。

### 不扭曲（IDFA）

再现/素材/AI 元素不扭曲真实（标注/边界）——**"真实有边界"**（衔接 139 再现标注）。

## 技巧与示例

### 纪实伦理工作流（AI 映射）

```text
参与设计（同意）→ 关怀义务文档
  → AI/再现标注（139）→ 制作
  → 伦理审查（166）→ 放映参与
```

### 应用示例

"informed consent + duty-of-care document + transparent AI labeling"——**同意+义务+透明**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无同意 | 伦理崩 | 知情同意 |
| 无关怀文档 | 责任散 | 义务落纸 |
| AI 不标注 | 扭曲真实 | 透明 |
| 再现无边界 | 误导 | 标注 |
| 无伦理审查 | 风险 | 166 |

## 工作流应用（AI 映射）

纪实实践（衔接 139/145/166/191/352）：

```text
同意 → 义务文档 → 标注 → 制作 → 审查 → 放映
```

**DirectorX 纪律**：知情同意；义务落纸；AI 透明；真实有边界。
