# 电影美术设计统一（Production Design — Unified Visual World & Art Department）

> 本页为电影美术设计（Production Design）统一：美术指导（Production Designer）总控视觉概念、场景/道具/服装/环境跨部门统一、情绪板→预算→勘景→搭建→陈设→连续性检查全流程、美术部门职责。知识本体来自 2026 美术设计指南（StudioBinder/Wikipedia/LTX/BlockReel）。AI 应用面向 DirectorX：视觉世界统一（衔接 165 环境、169 服装、209 道具、218 色彩、222 对应）。
> 来源：StudioBinder「What Is Production Design」、BlockReel「Art Department Production Guide」、LTX「Production Designer Glossary」、Wikipedia「Production Designer」。

## 概述

**核心断言**：美术设计 = **把剧本翻译成统一的视觉世界**——美术指导（Production Designer）总控，美术指导监督执行，场景/道具/服装/摄影跨部门对齐（衔接 218：色板是统一的先决条件）。**统一性是核心**——各部门对着同一视觉概念执行。

## 核心概念

### 美术部门两角色

```
① 美术指导（Production Designer）：总控视觉概念
② 艺术指导（Art Director）：执行落地（对版）
```

### 全流程（BlockReel）

```text
概念草图 → 情绪板（108）→ 预算目标
  → 勘景 → 搭建 → 道具采买/陈设
  → 现场连续性检查 → 清权（191）
```

### 统一要素

场景（165）/道具（209）/服装（169）/光线概念（125）/色板（218）——**全部对齐剧本情绪与导演视野**。

## 技巧与示例

### 美术统一工作流（AI 映射）

```text
剧本 → 视觉概念（情绪/时代 203）
  → 情绪板（108）→ 色板（218）
  → 各部门生成（165/169/209 按色板）
  → 统一性检查（一致性 117）
  → 现场连续性
```

### 统一性检查清单

- 场景与服装是否同一色板？
- 道具年代是否一致（203）？
- 光线概念是否统一（200）？
- 各元素是否服务同一情绪？

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 各部门各自为政 | 视觉割裂 | 统一概念 |
| 无情绪板 | 方向漂移 | 先行 |
| 色彩不统一 | 杂乱 | 218 色板 |
| 时代错位 | 出戏 | 203 锁定 |
| 无连续性检查 | 累积穿帮 | 现场核查 |

## 工作流应用（AI 映射）

视觉世界（衔接 108/117/165/169/203/209/218）：

```text
剧本 → 视觉概念 → 情绪板（108）
  → 色板（218）→ 各部门生成（165/169/209）
  → 统一性检查（117）→ 连续性
```

**DirectorX 纪律**：美术指导总控；情绪板先行；色板统一各部门；时代锁定；连续性是底线。
