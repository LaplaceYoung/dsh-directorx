# AI 图片参与-六问-互动系列（Interactive Six-Questions — Choice-Driven Visual Series）

> 本页为 AI 图片的参与-六问-互动系列：分支路径（多图/多视频资产）+选择驱动叙事（AI 生成随选择适配）、参与规划（分支点/跨分支角色一致/全路径测试）、实时输入共创。知识本体来自 2026 互动叙事（Tandfonline/Patsnap/ReelMind）。AI 应用面向 DirectorX：互动系列（衔接 339 六问、364 对应、167 分支、238 一致）。
> 来源：Tandfonline「Card-Based Story Writing」、Patsnap「AI Graphics for Interactive Storytelling」、ReelMind「Interactive Storytelling」、ReelMind「Choices: Stories You Play」。

## 概述

**核心断言**：参与-六问-互动 = **"选择驱动系列"**——分支路径（多资产）+ 选择驱动叙事（AI 适配）；参与规划（分支点/跨分支一致/全路径测试）；实时输入共创（衔接 339：六问的互动版；167：分支）。

## 核心概念

### 选择驱动（ReelMind）

多图/多视频资产 + AI 随选择适配 → 分支叙事——**"选择即叙事"**（衔接 167）。

### 参与规划（Patsnap）

分支点设计 + 跨分支角色一致（238）+ 全路径测试——**"先规划后生成"**。

### 实时共创（Tandfonline）

观众实时输入（选择/文本）影响后续图像——**"共创"**（衔接 339 投票）。

## 技巧与示例

### 互动系列工作流

```text
六问设计（339）→ 分支点 → 跨分支一致
  → 逐路径生成（238）→ 全路径测试
  → 实时共创 → 参与校验
```

### 互动示例

"six-question arc + branching choices + cross-branch character consistency + full path testing"——**六问+分支+一致+测试**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无分支点 | 非互动 | 规划 |
| 跨分支漂移 | 断戏 | 一致（238） |
| 路径未测 | 断链 | 全路径 |
| 无实时输入 | 被动 | 共创 |
| 不校验参与 | 效果未知 | 参与检查 |

## 工作流应用（AI 映射）

互动系列（衔接 167/238/339）：

```text
六问 → 分支 → 一致 → 逐路径 → 测试 → 校验
```

**DirectorX 纪律**：选择即叙事；跨分支一致；全路径测试；实时共创。
