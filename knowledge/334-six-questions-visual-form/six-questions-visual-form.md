# 电影六问-视觉形式整合（Six Questions × Visual Form — Empathy & Engagement Framework）

> 本页为电影六问-视觉形式整合：景别/面孔可见性→具身移情、镜头时长/运动动态→参与、六问×形式特征联动（六问是目标，形式是工具）。知识本体来自 2026 移情研究（PMC/VU/UvT）。AI 应用面向 DirectorX：移情工程（衔接 323 六问、334 对应、327 视觉形式、231 景别）。
> 来源：PMC「Embodiment of the Cinematographer」、PMC「From Body to World」、VU「Shaping Film」、UvT「Effect of Motion Dynamics and POV」。

## 概述

**核心断言**：六问-视觉形式 = **"六问是目标，形式是工具"**——景别/面孔可见性→具身移情（特写=近距）、镜头时长/运动动态→参与、编辑节奏→叙事卷入；六问（我在哪→为何重要）每问由视觉形式支撑（衔接 323：六问；327：形式）。

## 核心概念

### 形式-移情映射（VU 实证）

| 形式特征 | 影响 |
|---|---|
| 景别（面孔/身体可见） | 具身移情 |
| 镜头时长/节奏 | 叙事参与 |
| 运动动态/POV | 沉浸/唤起 |
| 平滑剪辑 | 参与保持 |

### 六问×形式（联动）

```
① 我在哪 → 建立镜头/环境（228）
② 与谁 → 人物景别（226）
③ 能做什么 → 动作镜头
④ 发生什么 → 冲突节奏
⑤ 有进展 → 里程碑镜头
⑥ 为何重要 → 情绪特写（231）
```

## 技巧与示例

### 六问×形式工作流（AI 映射）

```text
六问设计（323）→ 每问形式映射（表）
  → 景别/节奏/运动设计
  → 生成 → 移情校验（距离感对吗）
```

### 联动示例

"① where: establishing wide → ② with whom: close-up faces"——**每问一景别**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 六问无形式 | 空目标 | 形式映射 |
| 景别乱 | 移情断 | 面孔可见 |
| 节奏忽快忽慢 | 参与断 | 平滑 |
| 六问形式脱节 | 错位 | 联动 |
| 不校验移情 | 效果未知 | 移情检查 |

## 工作流应用（AI 映射）

移情工程（衔接 226/228/231/323/327）：

```text
六问 → 形式映射 → 景别/节奏 → 生成 → 校验
```

**DirectorX 纪律**：六问是目标；形式是工具；景别驱动移情；每问一形式。
