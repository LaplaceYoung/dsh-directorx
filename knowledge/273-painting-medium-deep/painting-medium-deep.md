## 概述

**核心断言**：绘画媒介 = **"技法词汇库"**——水彩（晕染/透明/留白）、油画（厚涂/可见笔触/罩染）、丙烯（厚实/快干感）、水粉（不透明/哑光）；**技法词进提示词 = 画作质感**（衔接 224：媒介风格深化；250：画作的氛围）。

## 核心概念

### 水彩技法词汇

```
晕染（Wash）、透明层（Transparent Layers）
留白（White Space）、纸纹（Paper Texture）
柔和边缘（Soft Edges）
```

### 油画技法词汇

```
厚涂（Impasto）、可见笔触（Visible Brushwork）
罩染（Glazing）、画布纹（Canvas Texture）
色调过渡（Tonal Transition）
```

## 技巧与示例

### 画作级提示词模板（ZSky）

```text
"oil painting, impasto technique, visible brushwork, canvas texture,
museum-quality, gallery lighting"

delicate color bleed"
```

### 媒介情绪

水彩=轻盈/梦幻，油画=厚重/经典——**媒介承载情绪**（衔接 270 风格情绪）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只写"油画" | 无技法 | 技法词汇 |
| 水彩油画混 | 媒介乱 | 单媒介 |
| 无纹理 | 数码感 | 画布/纸纹 |
| 技法过度 | 堆砌 | 关键技法 |
| 无校验 | 画作感弱 | 画作检查 |
