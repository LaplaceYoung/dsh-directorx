## 概述

**核心断言**：海报/宣传关键帧是**"一图定调"**——把影片气质浓缩进单帧（构图/色彩/情绪），跨渠道复用（横竖版/流媒体/影展/提案）。AI 从 logline/主题/风格生成多版海报，**海报可动效化**（静态→teaser 视频，衔接 193 一资产多形态）。

## 核心概念

### 海报三要素（构图）

```
① 焦点（主体/关键角色）
② 氛围（色彩/光线/情绪，155/125）
③ 类型暗示（题材视觉语法）
```

### 一图多形态

```text
主海报（横版）→ 竖版（流媒体）→ 方形（社交）
  → 动画 teaser（海报动效化）
```

## 技巧与示例

### 海报生成工作流（GetIMG）

```text
Logline/主题 → 情绪方向（类型/色彩）
  → 焦点设定（角色/关键元素）
  → AI 生成多版 → 迭代
  → 多形态导出（横/竖/方）
  → 动效化（teaser，207 长镜头/静态→动态）
  → 品牌规范（195）
```

### 海报动效化（宣传联动）

静态海报 → 局部动效（雨/光/角色微动）→ teaser 素材——**海报即预告片起点**（衔接 188 钩子、207 长镜头）。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 无焦点 | 无记忆点 | 焦点设定 |
| 情绪模糊 | 定调失败 | 氛围明确 |
| 单形态 | 渠道不适配 | 多形态 |
| 文本错字 | 低级错误 | 文字校验 |
| 脱离品牌 | 弱品牌 | 195 规范 |

## 工作流应用（AI 映射）

宣传物料（衔接 54/188/193/195）：

```text
Logline → 情绪/焦点 → 多版生成
  → 迭代 → 多形态导出 → 动效化 teaser
  → 品牌校验（195）→ 分发
```

**DirectorX 纪律**：一图定调；焦点+氛围+类型三要素；多形态复用；海报即 teaser 起点。
