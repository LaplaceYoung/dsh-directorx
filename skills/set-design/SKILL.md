# Set Design & Spatial Storytelling

The script says what happens; set design says to whom. Audiences read the room before they read the actor.

## Character via space
- Every room must answer "who lives here": lived-in vs pristine, half-finished projects, mismatched chairs, yesterday's coffee cup, frozen childhood bedroom.
- Props are evidence: cracked mirror = neglect; fridge child-drawing = family; unopened mail = avoidance/grief; near-empty apartment = new arrival or departure; stripped house = emotional detachment. Each object, and each absence, reveals character — nothing on set is accidental.
- Empty rooms must justify their emptiness.

## World-building from story
- Build from character/theme/era first, then derive the space (layout/floor/decoration); space is externalized character (radius, class, psychology).
- Decide the emotion before choosing colour/texture; context decides meaning (deep green = comfort or secrecy; peeling wallpaper ≠ fresh paint; velvet ≠ linen).
- Set change = character arc: rooms evolve with the story; keep look consistency across the film.
- Era gate: period research (socket styles, wallpaper patterns, object forms) is the believability foundation — one anachronism breaks the contract.
- Genre spatial cues: liminal spaces (corridors, parking lots, night offices) deliver unease before any event; horror sets feel "off" before the plot says so; romance sets feel enveloping; sets carry visual metaphor (inn = power/gender/culture; hotel = era and emotion).

## AI generation recipe
- Four-layer scene prompt: function + emotion (colour/texture/light) + evidence (lived-in props) + era anchor; explicitly name evidence props.
- Reuse one environment description block across all shots of a scene for consistency; review output for anachronisms, floating props, and text artifacts.
