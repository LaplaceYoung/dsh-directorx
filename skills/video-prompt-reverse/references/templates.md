# 反推与增强模板集（可复制）

> 配套 `SKILL.md` 使用。所有模板均为**可直接复制、填空**的结构，AI 在生成结果时套用这些模板输出，保证格式稳定、可迭代。

## 一、还原版反推模板

> **用途**：忠实反推原片"画面里有什么 + 怎么动"。不惊艳、不发挥，先把事实拆清楚。

```markdown
## 还原版反推（原片事实）

**基本信息**
- 时长：___秒 / 镜头数：___ / 画幅：___ / 帧率：___
- 主体：___（人物/物体/场景）
- 场景：___（时间+地点+环境光）

**分镜逐段**
| 时段 | 画面内容 | 运镜 | 主体运动 | 音频 |
|------|---------|------|---------|------|
| 0-3s | ___ | ___ | ___ | ___ |
| 3-8s | ___ | ___ | ___ | ___ |

**风格锚点**
- 色调：___ / 光质：___ / 质感：___
- 情绪基调：___

**物理与逻辑**
- 连续感：___ / 值得复现的细节：___
```

## 二、惊艳增强版模板

> **用途**：在还原版基础上叠加"惊艳"层。每个维度给"原片→增强"的对照，让用户看清升级点。

```markdown
## 惊艳增强版（主推：___ 方向）

**升级总览**
- 原片气质：___
- 目标气质：___（从 enhancement-vocab 选 1 个主方向 + 可选副方向）

**逐维度增强**
| 维度 | 原片状态 | 增强指令（写入提示词） |
|------|---------|----------------------|
| 运镜 | ___ | ___（如：缓慢 dolly-in 建立亲密感） |
| 色彩/光 | ___ | ___（如：电影感青橙分离色调） |
| 动态节奏 | ___ | ___（如：speed-ramp 高潮加速） |
| 质感 | ___ | ___（如：35mm 胶片颗粒 + 柔光） |
| 音频 | 静音/___ | ___（条件块：支持音频模型才填） |
| 负向约束 | — | no morphing, no flicker, no extra limbs, ___ |

**一致性锚点**（多镜头才填）
- 主体命名：___（如 CHAR_A）
- 风格锁：___ / 参考锚：___（首帧/参考图路径或描述）

**一句话惊艳提示词（可直贴生成器）**
___
```

```markdown

**变体 B（___ 方向）**：___ 一句话提示词

> 差异说明：A 偏___，B 偏___，C 偏___。建议先生成___试水。
```

## 五、分镜表模板（多镜头序列核心）

> **用途**：③ 多镜头分镜序列场景的产出物。每段独立可重生，挂一致性锚点，支持模型路由与种子锁定。

```markdown
## 分镜表（Storyboard）

**全局锚点**
- CHAR_A：___（外貌/服饰锁定描述）
- CHAR_B：___
- 风格锁：___ / 调色：___

| shot_id | 时段 | 画面内容 | 运镜 | 主体运动 | 音频 | 锚点引用 | 平台路由 | seed |
|---------|------|---------|------|---------|------|---------|---------|------|
| S01 | 0-4s | ___ | dolly-in | ___ | ___ | CHAR_A | Kling | 1024 |
| S02 | 4-9s | ___ | orbit | ___ | ___ | CHAR_A | Veo3 | 1024 |
| S03 | 9-14s | ___ | crane-up | ___ | ___ | CHAR_B | Sora | — |

> 路由说明：S02 用 Veo3 因其音频强；S01 用 Kling 因其运镜控制准。
> 一致性：所有引用 CHAR_A 的镜头共用同一锚点描述，避免身份漂移。
```

## 六、迭代修订模板（接 diagnosis-matrix.md）

> **用途**：生成后不满意时，先定位维度，再精准改。不要整段推倒。

```markdown
## 迭代修订记录 #N

**诊断（来自 diagnosis-matrix）**
- 失败维度：___（内容/运动/音频/物理/人物/风格 之一）
- 具体表现：___
- 偏差根因（推测）：___

**修订动作**
- 锁定 seed：___（沿用上版接近的 seed）
- 单维微调：只改 [___] 维度 → 新指令：___
- 新增负向词：___
- 模型路由（可选）：本段改走 ___（因其在 ___ 维度更强）

**验收分层**：内容✓ → 运动✓ → 风格✓ → 音频✓
- 本轮结果：___（通过/继续迭代）
```

## 七、零代码 ffmpeg 抽帧命令（内联，供编程 Agent / 用户本地终端）

> 长视频或聊天工具无法原生摄帧时，用以下命令把关键帧抽出来再喂给模型。复制即跑，不捆绑脚本文件。

```bash
# 1) 按固定间隔抽帧（每 2 秒 1 帧，存入 frames/）
ffmpeg -i input.mp4 -vf "fps=1/2" frames/frame_%03d.png

# 2) 按场景切换抽关键帧（更省，适合长视频）
ffmpeg -i input.mp4 -vf "select='gt(scene,0.4)',showinfo" -vsync vfr frames/scene_%03d.png

# 3) 抽首帧做 image-to-video 控制
ffmpeg -i input.mp4 -frames:v 1 first_frame.png

# 4) 降分辨率便于快速分析（可选）
ffmpeg -i input.mp4 -vf "scale=640:-1" preview.mp4
```

> 注：聊天类工具无 Bash 时，请用户或宿主预先抽帧后再粘贴图片给模型。
