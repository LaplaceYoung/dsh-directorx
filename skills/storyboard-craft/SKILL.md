# Storyboard Craft

剧本管戏，分镜管拍——分镜把场次翻译成一张可逐镜独立生成的镜头表。每一镜必须是自足的：遮住前后镜，单看这一行也能无歧义地生成。

## 五维镜头语言（每镜必答全）
1. **景别**：大远（环境压迫/孤独）、远景（人在环境中的位置）、全景（完整动作）、中景（对话与关系）、近景（情绪）、特写（细节/物件/眼神）。景别是信息量阀门，也是情绪阀门——越紧越亲密越压迫。
2. **角度**：平视（中性）、俯拍（弱势/被审视）、仰拍（强势/威胁）、过肩（关系与对峙）、主观（代入）。角度是权力几何：同一场戏换角度就是换立场。
3. **运镜**：固定（克制、观察）、推/拉（强调/退出）、摇/移（跟随、揭示）、跟（代入、紧迫）、升降（格局变化）、手持（呼吸感、不安）。每次运镜必须有动机——没有动机的运镜是噪音。
4. **构图**：三分/中心/框中框/引导线/留白方向；人物视线方向必须留出空间；画面重心与叙事重心一致。
5. **焦段感**：广角（空间张力、畸变）、标准（纪实感）、长焦（压缩、窥视、肖像感）。镜头语言与 camera-gear 的焦段表对齐。

## 覆盖顺序
- **先立主镜头（master）**：一场戏先给一镜完整覆盖（通常全景/中景固定），交代空间关系和完整动作，再用切镜强调。没有 master 的场，观众没有空间地图。
- 切镜服务于转折与反应：对话戏的切镜锚在转折句和反应上，不是每句话切一刀。
- 节奏即剪辑：镜头长度本身是节奏——紧张用短镜密集切，抒情用长镜留白。

## 生成感知的分镜设计（本工作室特有）
镜头表下游是逐镜/逐段生成，分镜必须为生成器写作：
- **为分段而设计**：一个长镜头只承载一个清晰的动作弧（一个完整的起势-完成）；宁可多拆短镜，不要一镜塞多个动作——生成器对复合动作的可控性差。
- **尾帧是链条资产**：每镜的最后一帧会被用来衔接下一镜或下一段——让镜头结束在一个稳定、完整、无运动模糊的构图上；不要让镜头停在快速动作中途（除非显式声明这里就是硬切点）。
- **收敛锚点**：长场景每隔 3-5 镜设计一个构图明确、可被复用为主参考的画面（人物完整入画、光线典型），供生成层周期性重新锚定，防止漂移累积。
- **连续性意图写进镜表**：相邻镜之间的视线方向、动作承接、光线方向，在描述里显式写出（"她转头望向画左——与上一镜的门外声源方向一致"），不指望生成器自己接住。
- **运动状态要能过剪辑点**：写明动作的起止状态（"从坐姿起身到一半"），让接缝两侧的运动状态可对账。

## 镜头间连续性契约
每镜声明三件事，生成层据此执行：
- **帧链**：本镜首帧承接谁的尾帧（上一镜尾帧 / 参考图 / 无）。
- **参考锚**：人物与场景的一致性参考（角色形象卡、场景卡、收敛锚镜）。
- **转场声明**：与下一镜是硬切、叠化还是匹配剪辑——动态画面上禁止叠化过渡，叠化只用于静态或近似静态构图。
帧链与参考锚是互补的双保险：帧链接住动作与构图的瞬间连续性，参考锚拉住跨镜的身份与光影一致性——两者都要，不是二选一。

## 常见病
| 病 | 症状 | 治法 |
| --- | --- | --- |
| 中景病 | 全场都是中景对话 | 先立 master，用景别阶梯制造信息落差 |
| 运镜炫技 | 无理由的推拉摇移 | 每镜运镜写出动机，写不出就固定 |
| 跳轴 | 对话双方视线方向翻转 | 全场统一轴线，越轴给过渡镜 |
| 跳切 | 同机位同景别硬切 | 景别或角度至少变一档（≥30° 或一档景别） |
| 复合动作 | 一镜塞"进门、坐下、开口" | 拆成多镜，一镜一动作弧 |
| 空帧结尾 | 镜头淡出或停在虚焦 | 尾帧是资产：结束在清晰稳定的构图 |

## 画布工艺（落到无限画布）
- **铺成分镜行**：文本卡里的剧本（Fountain 场次标题、`镜头N：`、`第N场`）用 `directorx_canvas_script` 拆成「本 → 首帧 → 视频」一行一镜。只写 idea 空卡，不生成。
- **抽帧上板**：成片视频用 `directorx_canvas_frames`（ffmpeg 均匀抽帧）铺一组图片卡，出处写在连续性戳上，不建 video→image 边。
- **一键解析**：`directorx_canvas_parse` 用亮度切点拆镜，钉分镜稿文本卡 + 每镜代表帧。可再对文本卡铺成分镜行。
- **片段重做**：`directorx_canvas_reshoot` cut 切掉头尾并抽出窗内首尾帧，中段只铺 idea 卡；生成回写 path 后 assemble 拼回。窗长 1–15 秒。
- **按引用连线**：`directorx_canvas_autolink` 按角色库名字和卡片词令重叠补参考边。不新建节点。
- **拼成片**：多段已成片视频用 `directorx_canvas_pack` 硬切拼成一条「成片」卡。预告片/片花只用 cut，不要 fade。
- **接触表**：选中的图/视频用 `directorx_canvas_sheet` 抽中点帧拼成一张接触表，钉在画布上给评审。
- **宫格切开**：一张有成片的图用 `directorx_canvas_split` 按列×行 crop 成一组独立图片卡。
- **宫格拼回**：多张成片图用 `directorx_canvas_join` 拼回带镜号的宫格大图，给评审或交付。
- **分屏对照**：2–4 张图/视频用 `directorx_canvas_stack` 拼成一条对照条。
- **去硬字**：成片底栏字幕用 `directorx_canvas_desub` crop 或 blur，不重绘。
- **续写位**：`directorx_canvas_extend` 抽出尾帧并铺一张 idea 空视频卡。生成仍走 craft/ready，回写续写卡。
- **导出动图**：成片用 `directorx_canvas_gif` 钉一张 GIF 卡。
- 整板仍先 `directorx_confirm` 再 `canvas_plan` / `canvas_script`。WebUI 菜单可直接跑这些步，因为它们不写 generating。

## 边界
- 分镜不写台词内容本身（台词在脚本层），只写"谁在说话、说什么的情绪"；对白时长由 DX 层按 ~4.5 字/秒估算分配。
- 每镜时长是预算不是承诺：镜头表给出的秒数按动作弧估算（动作镜 ~2.5s 起，对白镜按字数），容差 ±15%。
- 器材与焦段的真实感描述见 camera-gear；短视频的钩子与留白节奏见 short-video。
