# 预告片工艺

预告片卖的是承诺，不是故事。遮住后半段，前三秒仍要让人留下。

## 四拍结构（25–45 秒）
1. **钩子**（3–6s）：异常已经发生。远景裂缝、一只眼睁开、一把刀出鞘。不要演职员、不要日常建立。
2. **世界**（4–8s）：一眼看懂空间规则（轨道城、烬海、夜校）。信息只够让冲突成立。
3. **升级**（12–20s）：对手现身、一次对斩、一次 mentorship 抛刀。每镜一个动作弧，4–6 秒。
4. **片名**（3–6s）：最后一刀硬切到冲击构图 + 片名。不要把结局打完。

## 切
- 只硬切。动态画面禁止 fade / 叠化。
- 冲击帧停在清晰、稳定、可被下一刀砸碎的构图上。
- **H3**：不要把预告拆成多条 FL2VA 慢动作再拼。官方预告入口是全参考（风格图+人物图）+ `[Shot N]` 镜内硬切 + 画内文字用双引号原文。一条 10–15s 里打完钩子或高潮。有首尾帧时 H3 不会自动加切。
- 超过 15s 再 `directorx_canvas_pack` `transition=cut`。评审用 `directorx_canvas_sheet`。
- 什么时候别用：叙事短片、产品演示、需要时间流动的长镜头。那些走别的配方。

## 日漫热血（剧场版调）
- 赛璐璐平涂、干净黑描边、两到三级明暗、高对比冷暖。剧场版可加一层数字光，不要写成实电影。
- 先出 16:9 角色设定表（左栏半身 + 右栏正/侧/背），再拍。
- 提示词只写视觉特征：发色形状、衣襟颜色、刀的几何。禁止把现存作品名、作者名、招式专名送进 generate。
- 高危组合主动拆开：竖金发 + 橙色道服 + 金色光环不要叠在同一人身上。换色不换型。
- 战斗镜写打击轨迹、重心、低机位。轴线先声明，故意越轴要写明。

## 每镜必答
景别、角度、运镜动机、冲击点（哪一帧是海报）、与下一刀的硬切理由。一镜一个动作弧。

## 常见病
| 病 | 症状 | 治法 |
| --- | --- | --- |
| 短片病 | 把三幕讲完 | 删掉结局，只留承诺 |
| 淡入病 | 镜间 fade | 改 cut |
| 中景病 | 全是半身对峙 | 远景钩子 + 特写眼 + 全景对斩 |
| 专名病 | 提示词里出现现存 IP | 改写成特征，走 ip_scan |
| 复合动作 | 一镜进门拔刀对斩 | 拆成三刀 |

## 画布
签字后 `directorx_canvas_plan` 或 `directorx_canvas_script`。生成回写 path。最后 `directorx_canvas_pack` 硬切，`directorx_canvas_sheet` 钉接触表。
