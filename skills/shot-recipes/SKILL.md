# 镜头语汇

词汇层（景别枚举、运镜词）不够。缺的是**命名过的切法**，而且能被机器复核。

| 族 | 回答什么 | 例子 |
| --- | --- | --- |
| 配方 | 这场戏这一刀怎么切 | 正反打、进场三件套、情绪停住、揭示、反应插入、产品主视觉、对镜头说 |
| 技法 | 手段是什么、**什么时候别用** | 固定、推近、手持、仰拍、浅景深 |

技法卡如果只写「什么时候用」，读的人一定会滥用。`never` 是门。

## 怎么用

1. `directorx_shot_vocab list` 或带 query（正反打 / 手持）。
2. `show` 读意图、适用、禁用、必备短语。
3. 按必备短语写这一格的分镜图/成稿。
4. `check` 复核。中文稿会跳过英文短语，改写成生成稿再查。

不要另出 HTML 画廊。语汇缺口用 list 看缺哪一类，画布和 DSH 会话展示同一份 Markdown。

## 和分镜的关系

`novel-storyboard` 只认领剧本节拍，不发明情节。切之前先查配方。`directorx_bible` 过门之后才生成。
