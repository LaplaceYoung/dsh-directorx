# Data-Driven Iteration

1 in 10-20 tested creatives wins; unstructured testing is buying noise — most accounts have a process problem, not a testing problem.

## Modular system
- Store Hook/Body/CTA components with functional tags: hooks (pain/curiosity/social-proof/demo-open), bodies (problem-agitate/feature-demo/objection/testimonial), CTAs (scarcity/trial/download/founder-close) + production tags (format/platform/style/audience).
- Template-first creation: problem-agitate-solve, UGC testimonial remix, listicle, demo-first, before/after, founder talk, comment-response — each with Hook/Body/CTA placeholders.

## Test protocol
- One variable per test, always against a control (current best creative); if the team cannot name the single changed variable, it is not a test — it is another ad.
- Order by impact: Hook first with big contrasts (UGC vs polished, pain vs vision, demo-first vs spoken, question vs statement — never micro-edits like subtitle style), then Body (keep winning Hook; isolate problem-solution/testimonial/product-walkthrough/objection/contrast), CTA last (usually least important).
- Predefine decision rules before launch: which metric crossing which line triggers which action; no post-hoc gut decisions.

## Funnel diagnosis
Thumbstop (first-frame stop-scroll power) → CTR → V100/conversion: low Thumbstop → iterate Hook/thumbnail; low CTR → rebuild Body (stronger problem-solution or social proof); low V100/conversion → CTA-landing consistency and audience match. Fix the layer that is broken — a weak Hook is not fixed by changing the CTA.

## Winner and lifecycle
- On a winner: do not just scale — disassemble and archive the winning mechanism (hook opening type, body proof style, CTA directness, creator tone) into the asset library; iterations become compound R&D instead of guessing.
- Lifecycle: cold start (7 days, small budget/bid/time-slot, prove the cost-conversion positive feedback loop before scaling) → ramp → mature (do not touch creatives; move audience/bid) → decay signals (CPM up / CTR down / cost breaks line) → replacement inherits the proven hook mechanism and changes only the delivery layer (angle/person/scene).

## AI automation loop
Component library → auto-combine variants → performance data (CTR/V100) feeds back into library labels → next generation reuses winning mechanisms. AI produces and recombines; humans own hypotheses and judgment.
