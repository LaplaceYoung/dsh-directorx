# 赛博巨构硬科幻影像

## 技能定位

本技能是一套"硬科幻世界观可视化"方法论：把世界观写成可执行的数据（尺寸、高度、间隔、反射率、脉冲频率），把尺度对比变成每镜必含的视觉语言，用手持呼吸感运镜替代锁定机位，用物理光源纪律杜绝虚假光效。硬科幻的"硬"来自可量化的世界规则与光学纪律：f/11 景深、35-50mm 标准镜头、1/250s 快门、无运动模糊、无皮肤平滑、无无源光晕。流程六步：全局规格锁定 → 素材分析 → 世界观与分镜设计 → 关键元素素材生成 → 逐镜头视频生成 → 音频与合成导出。

## 适用场景

- 世界观向科幻短片、巨物震撼揭示、45-60 秒宏观切片式叙事。
- 未来城市群像、多阵营生态（原始人类/赛博改造/基因融合/数字意识）。
- 需要"巨 vs 人""天 vs 地"尺度对比作为核心视觉语言的影片。
- 用户提供科幻参考图、设定文本或参考音频，需要忠实提取信号并扩成成片。

## 制作流程

### 第一步：全局规格锁定

写规格文档：标题、类型、画幅 16:9、分辨率 4K、帧率 24fps、目标时长 45-60 秒、视觉风格（超写实电影感、高反差、巨小尺度悬殊）、色板（冰蓝/暖金/淡紫/琥珀/淡粉）、输出语言。时长、标题、输出语言三项与用户确认，锁定后才继续。

检查点：规格参数经用户确认后锁定。

### 第二步：素材分析

只忠实提取可量化信号，禁止风格迁移与创意再解读：参考图提取光照结构、色板、尺度关系、材质分级、镜头语言；设定文本提取场景分布、阵营出场顺序、核心节拍；参考音频提取情绪基调、BPM、关键音色。输出结构化文本并标注资产编号。

### 第三步：世界观与分镜设计

世界观基调示例：巨型机械鲲鹏（翼展 518m、身长 322m）悬停于钢之森林上空 900-1100m，底部结构把阳光切成平行光带；地面四个阵营共享同一基础设施，"繁荣与废墟的边界不是墙，是光"。坚持宏大叙事视角：每镜背景体现城市纵深、天空层次或群体生态；尺度对比是核心视觉语言，每镜至少包含一次（巨vs人/楼vs行人/天vs地），孤立特写之后必须接宏观空间镜头。

世界观数据化表模板：

| 条目 | 可量化参数 |
|---|---|
| 巨物 | 翼展/身长/悬停高度/装甲板尺寸/缝隙/能量纹脉冲 |
| 区域 | 楼间距/车道类型/脉冲断率/锈蚀比例/过渡带宽 |
| 阵营 | 改造比例/骨架材质/电路脉冲/透明度 |
| 光学 | 光圈/焦段/快门/ISO/黑位/白位/反差档数 |

四阵营代表角色：原始人类（0% 改造、纯有机躯体、真实皮肤质感、亚欧面孔各半）；赛博人类（40-70% 改造、外露金属骨架、皮下发光电路约 0.8Hz 脉冲）；基因融合（100% 基因级改造、全身生物纹路、可随环境变色）；数字意识（无实体人形光雾、透明度 40-60%、含原人类五官残影）。场景：钢之森林（楼间距 20-40m、磁悬浮车道+信息光脉冲+悬浮平台）；废弃区（光脉冲断率 40-60%、锈蚀 ≥30%）；过渡带（宽 30-50m）；机械鲲鹏（装甲板 2.5x4m、缝隙 3cm、暗蓝能量纹 0.5Hz 脉冲）。

运镜决策树（每镜必选，禁止"锁定机位/简单推拉"）：

| 情绪/叙事 | 机位方案 |
|---|---|
| 情绪爆发 | 荷兰角 10-25°+面部极特写 |
| 压迫 | 高角度俯压 30-60°+手持微晃、角色置画面下 1/3 |
| 觉醒 | 低角度仰推 20-45° |
| 行走 | 过肩跟随 |
| 对话 | 正反打且角度差 ≥30° |
| 巨物揭示 | 低角度环绕+手持微晃 |
| 宏观 | 高空俯拍 45-75° |

标准五镜头结构：宏观揭示（4-6s，高空俯拍+鲲鹏入画占 20-30%）；压迫特写（3-4s，荷兰角+低仰面部特写，瞳孔倒映鲲鹏轮廓）；光影切割（4-6s，阴影扫过建筑群、明暗边界穿过角色）；多阵营同框（4-5s，弧线环绕、f/11 深景深、密度比 3:3:2:1、正反打捕捉对视）；高空收尾（4-6s，低仰弧形仰升至俯视、鲲鹏占 60-70%）。

单镜头多机位（7-14s 镜头）：以叙事事件为切换依据，禁止时间码切点。格式：[机位A] 景别/角度/运动——画面+情绪 → 切换依据:（叙事事件）[机位B]……→[机位C] 收束；相邻机位角度差 ≥30%，禁止同角度再切。

巨物与尺度规则：单体 ≥100m 必须同框人类/车辆作参照（占画面 0.5%-2%）；垂直透视必须含中间高度参照物，视觉落差 ≥500m；巨物禁平视锁定拍摄。光学系统（全局固定）：f/11 深景深；35-50mm 标准镜头；快门 1/250s 禁运动模糊；ISO 100-400；主色冰蓝/暖金/淡紫/琥珀/淡粉；黑位 RGB≥15、白位 ≤245；同帧反差 6-7 档且明暗区保留纹理；阴影方向明确。

飘渺段（仅情绪转折段启用）：压迫起手（慢摇 ≤3cm/s、轴偏移 15-25°、光束边界自画外入画）→ 沉思核心（摇速 ≤1.5cm/s 近静、切眼睛/手极特写）→ 震撼转折（低仰仰升 20-35°、巨物入画）。禁突然剪切，切他机位须 ≥0.8s 渐变。

检查点：分镜（含运镜决策、五镜头结构、尺度规则）交用户确认。

### 第四步：关键元素素材生成

图像生成模型 2K、16:9。角色生成横版多视图参考图：左胸像特写+右正面/侧面/背面全身横排，白底。描述顺序：年龄→性别外貌→发型→身高体型→阵营改造特征→服装；必须含可量化细节——皮肤毛孔（0.1-0.2mm）与细纹（0.05-0.1mm）、生理色差，禁止皮肤平滑；改造角色写金属骨架材质分级、电路光色与脉冲（0.8Hz）、皮肤金属衔接缝；数字意识写"人形光雾、透明度 40-60%、边缘随机扰动、禁止实体化"。场景图写清主光源、色板锚点、量化材质。用户已传参考图直接注册绑定；初始元素偏离规格时用图生图定向修正并保留身份特征。

### 第五步：逐镜头视频生成

视频生成模型，720p、16:9，单镜 3-6 秒（上限 15 秒）。每镜引用本镜全部角色+场景图；仅当与上一镜有极强视觉连续时才追加参考视频。有声纹绑定的角色逐镜传入保证音色一致；无对话镜头不传音频信息。

运动堆栈顺序：摄影机运动（决策树选择+速度与情绪意图）→ 主体动作与情绪弧（按叙事顺序，禁止时间码分段）→ 特写聚焦（对象+情绪目的）→ 空间变化（位移遮挡；多机位切换写明角度差 ≥30°）→ 音频描述（台词文本标注、音效尖括号、音乐圆括号；已规划独立旁白轨时不重复旁白文案）。

固定负向约束（每条末尾追加）：无字幕、无音乐、无运动模糊、无假镜头光晕、无皮肤平滑、无过曝。强化光学：每镜必含 f/11 深景深、6-7 档反差、真实物理光源且主光方向明确；允许真实镜头光晕（主光源位置三层渐变、最外层直径 ≤ 光源 1.5 倍、中心 40% 透明度衰减至边缘 0%），禁止外溢光/圣光/无源光晕/假霓虹。含鲲鹏镜头必写翼展 518m/身长 322m/悬停 900-1100m。

检查点：每镜生成后逐一展示，允许用户要求单镜重拍。

### 第六步：音频与合成导出

音频层：全局 BGM（史诗低频、BPM 60-90，情绪转折可拆两段）；旁白轨（低沉男声、克制史诗感，严格按文案朗读）；环境音层独立（钢之森林=电磁嗡鸣+信息脉冲；废弃区=风声+间歇电弧；鲲鹏过顶=超低频振动+气流切割声）。

混音电平表：

| 音轨 | 电平 | 特殊规则 |
|---|---|---|
| BGM 铺底 | -12dB | 首尾 3s 淡入淡出；旁白时自动降 3dB |
| 旁白 | -6dB | 不与镜内台词重叠 |
| 镜内音效 | -18dB | 按镜头事件对齐 |
| 环境音 | -20dB | 鲲鹏过顶段升至 -14dB 且 BGM 降 4dB；废弃区 -16dB 保留高频反差 |

剪辑：基准节奏对齐 BGM 低频鼓点——大远景 4-6s→快切大小景别 3-4s→光影切割 4-6s→多阵营 4-5s→高空收尾 4-6s，总长 45-60s；硬切优先，仅情绪转折用 0.5-1s 交叉淡化；鲲鹏阴影扫过建筑群的运动帧对齐最强低频鼓点。导出 16:9、4K、24fps，黑位 ≥15、白位 ≤245。

### 提示词模板（逐镜视频）

[角色图+场景图绑定]；[运镜决策树选择：低角度环绕+手持微晃]；[主体动作与情绪弧，按叙事顺序]；[特写聚焦：对象+情绪目的]；[空间变化：位移遮挡，角度差 ≥30%]；f/11 深景深、6-7 档反差、[主光源方向明确]；[鲲鹏参数：翼展 518m/身长 322m/悬停 900-1100m]；[台词/音效/音乐标注]；无字幕、无音乐、无运动模糊、无假镜头光晕、无皮肤平滑、无过曝。

## 进阶技巧

- 世界观数据化是硬科幻命脉：给巨物/区域/阵营写死可量化参数，提示词照抄参数可显著抑制模型对尺度的误读。
- 飘渺感只能来自物理光源：允许阳光穿装甲缝隙光束、能量体周围低密度粒子雾（透明度 ≤25%）、夜间建筑自发光向雾中扩散（≤3 倍光源尺寸）；无光源锚定的弥散雾/迷幻彩雾禁止。
- 情绪-镜头映射是导演感来源：荷兰角对应失衡、俯压对应无力、仰推对应觉醒，把"为什么这么拍"写进分镜。
- 宏微观交替防坍缩：特写后必接宏观空间镜头；多层合成按灯光/阴影/颗粒/景深匹配清单核对。
- 参数继承纪律：鲲鹏/区域/阵营参数写进规格文档后，所有提示词逐字照抄同一组数字，禁止在提示词里改写（如"约 500 米"）；跨镜参数漂移是硬科幻最隐蔽的穿帮。
- 手持呼吸感量化：微晃幅度写"±1-2% 帧宽"级而非"轻微晃动"；镜头越近晃幅越小（特写 ±1%），越远越大（全景 ±2%），保持"人在现场"而非"摄影机在抖"。

## 常见问题

- 锁定机位与简单推拉泛滥：原因是运镜未对照决策树。解决步骤：① 对照决策树逐镜替换；② 全片保持手持呼吸感；③ 每镜分镜表标注决策树选项；④ 检查是否存在未选择机位方案的镜头。
- 巨物无尺度参照：原因是巨物同框物缺失。解决步骤：① 单体 ≥100m 必须同框人物/车辆（0.5%-2%）；② 垂直透视含中间高度参照物（路灯/楼层）；③ 提示词写入具体尺寸对比。
- 虚假光效：原因是光晕/光雾无光源锚定。解决步骤：① 光晕/光雾必须有物理光源锚定（阳光缝隙/能量体/建筑自发光）；② 无源弥散雾禁用；③ 镜头光晕按三层渐变规范执行；④ 复查每镜光源方向。
- 镜头切换用时间码：原因是多机位按时间切。解决步骤：① 多机位切换以叙事事件为依据；② 角度差 ≥30%，禁止同角度再切；③ 分镜表写"切换依据:（叙事事件）"而非时间点。
- 皮肤过度平滑：原因是缺少可量化皮肤细节。解决步骤：① 强制毛孔/细纹/生理色差描述；② 改造角色写金属衔接缝与电路脉冲；③ 负向词含无皮肤平滑。
- 音乐与台词抢频段：原因是混音层级未执行。解决步骤：① 按 -12/-6/-18/-20dB 层级混音；② 旁白时段 BGM 降 3dB；③ 检查鲲鹏过顶段 BGM 降 4dB；④ 复听确认台词清晰度。
