# 科幻真人影像短片

## 技能定位

本技能以制片人与美术指导的方法论制作"超写实科幻真人电影"质感短片：可信的物理材质、有光源依据的布光、克制的配色、严谨的空间尺度与电影叙事感。全流程执行"创意结构化—资产提示词—资产整合分镜与视频制作"三步法，所有决策基于用户确认的故事、角色、场景与参考素材。本技能维持"非赛博朋克"基线：霓虹、高饱和撞色、雨夜街道、全息投影与义体改造不得主导视觉。

## 适用场景

- 硬核深空探索、史诗太空歌剧、废土科幻、异星有机生态短片。
- 用户指定自定义风格的超写实科幻。
- 需要"可信物理与有源布光"而非霓虹堆砌的科幻叙事。
- 以材质、光线、空间尺度为视觉卖点的质感型短片。

## 制作流程

### 第一步：风格选择与全局锁定

用户已指定风格则直接精炼为光照、色彩、空间、材质与氛围的可执行规则。未指定时用卡片呈现四种方向：

| 方向 | 光照 | 色彩 | 空间 | 材质与氛围 |
| --- | --- | --- | --- | --- |
| 硬核深空探索 | 舱内实用点光 | 冷调高对比 | 严谨航天工业结构 | 金属、浮尘、失重感 |
| 史诗太空歌剧 | 庄严自然光 | 克制冷灰金 | 极简与粗野主义巨型建筑 | 宏大负空间、肃穆 |
| 废土科幻 | 烈日漫射 | 去饱和暖黄土棕 | 黄沙侵蚀的科技废墟 | 深锈钢铁、干燥粗粝 |
| 异星有机生态 | 局部生物源荧光 | 克制饱和 | 有机建筑、湿润介质 | 生物质、湿润反光 |

用户拒绝或泛泛要求时默认"超写实科幻电影"。锁定规格：所选风格、非赛博朋克边界、16:9、总时长（默认 60-90 秒）、分段数、叙事语言。

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 总时长 | 75 秒 | 30-180 秒 | 决定分段数与镜头时长 |
| 画幅 | 16:9 | 16:9 / 2.39:1 | 史诗感可选 2.39:1 |
| 分段数 | 3 段 | 1-6 段 | 每段一段一镜 |
| 分辨率 | 4K | 1080p / 4K | 视频输出 720p 起 |
| 叙事语言 | 中文 | 用户指定 | 台词与字幕统一 |

失败处理：用户拒绝全部四方向且不给描述 → 默认超写实科幻电影风格，锁定"无霓虹、有源布光、物理材质"三原则后继续，并在全局规格中标注推定值请用户确认。

### 第二步：故事大纲与角色关系

确认故事大纲与艺术方向，显式询问结尾是否需要反转。大纲必须含主角身份、核心事件、世界观逻辑、基调与分段数；开场 3 秒以冲突、异常或悬念起手，中段有高潮，结尾收得紧。

- 大纲判定标准：开场 3 秒有钩子（异常/冲突/悬念）；中段有唯一高潮点；结尾无悬空问题；每段能用一句话说清"发生什么、为什么重要"。
- 角色关系清单字段：

| 字段 | 填写要求 | 示例 |
| --- | --- | --- |
| 姓名/代号 | 唯一可引用 | 副驾驶 林 |
| 叙事身份 | 与事件的关系 | 逃生舱唯一幸存者 |
| 关系 | 与其他角色连线 | 与舰长的从属关系 |
| 冲突/目标 | 一句话 | 修复推进器返回母舰 |
| 跨段一致外观 | 是/否 + 关键外观项 | 是：制服、伤疤 |

无角色参考图时，先按情节梳理全部角色及其关系，用户确认关系清单后才生成基础资产与四视图。失败处理：角色关系冲突或目标模糊 → 列出冲突项并暂停，请用户重写对应字段；跨段一致外观标注"是"的角色，其资产图必须在首段生成前完成。

### 第三步：场景资产（单图确认→四视图绑定）

每个元素场景先用场景单图模型生成一张 16:9 设定图（有参考用图生图），确认空间结构、材质、天气、光照与风格信号后，用该图作主参考生成 16:9、4K 四视图并绑定为最终场景资产。

- 四视图锁定"正面中央、左前 45 度、右前 45 度、沿中轴向外纵深"的连续视角；四格必须是同一时空同一光源同一结构的连续空间说明，绝不允许生成四个不同场景；场景必须空无一人。
- 判定标准：四格出现不同天气、不同光源方向、不同建筑结构任一情况即判分裂，重写提示词强制"同一时间、同一天气、同一光源方向、同一空间结构"。
- 失败处理：单图通过但四视图分裂 → 用通过的单图作为唯一参考重新生成四视图，最多 2 次；仍分裂则回到单图阶段微调空间描述后重来。

### 第四步：资产整合分镜与镜头生成

一个情节段对应一个镜头、一个视频段，未经授权不得拆小；段内可用约 3-4 秒的叙事节拍安排动作与运镜，但全部属于同一次生成任务。全片以中景、特写、大特写为主，超远景只在建立深空、巨型建筑、废土废墟或异星生态尺度时使用。

分镜表字段：段号、节拍、时长、景别、运镜、内容要点、声音。

| 段号 | 节拍 | 时长 | 景别 | 运镜 | 内容要点 | 声音 |
| --- | --- | --- | --- | --- | --- | --- |
| S1 | 异常出现 | 12s | 特写 | 缓慢推近 | 仪表盘告警灯亮起，主角抬头 | 低频警报 + 环境嗡鸣 |
| S2 | 决断 | 14s | 中景 | 静态 | 主角检查舱门，转身取工具 | 金属碰撞 + 脚步 |
| S3 | 反转收束 | 15s | 大特写 | 静态 | 瞳孔反光中出现光源变化 | 静默后一声提示音 |

- 生成前让用户选择"先预览第 1 镜"或"一次性生成全部"。每段严格按分镜 10-15 秒、16:9、720p；优先输入本镜角色、场景四视图与道具资产（最多 9 张参考图并写明用途）；只有连续性严格依赖前一镜时才追加参考视频。
- 失败处理：生成失败优先在同路径内处理（重写提示词、换约束措辞、降低动作复杂度），不随意切换路径；同一路径重试 2 次仍失败 → 回退简化该节拍动作（拆成更小的可见动作）后重试，并告知用户原因。

### 提示词模板

语法约定：{占位符} 为必填替换项，<可选> 为按需保留项，填入后删除全部括号；模板按"主体/资产参考 → 场景与空间 → 动作与情绪 → 镜头与构图 → 有源布光与物理介质 → 风格色彩与材质 → 约束"顺序组织。

逐段视频提示词模板：

```
{角色四视图引用}，{场景四视图引用}，{道具引用}，
动作节拍：{动作1→动作2→动作3}，
空间：{空间结构与尺度}，{天气/介质状态}，
镜头：{景别}，{运镜}，
布光：{光源类型+方向+物理依据}，
材质：{材质清单+表面状态}，
风格：{四种风格之一}，{风格关键词}，
<约束：无霓虹、无全息投影、无高饱和撞色、无义体>
```

示例成句：主角四视图参考，舱内场景四视图参考，动作节拍为抬头看仪表盘→伸手按开关→转身取工具，空间为狭窄金属舱室，特写，缓慢推近，左上顶灯点光源，拉丝金属带磨损涂层，硬核深空探索、冷调高对比，无霓虹。

纯白背景资产提示词模板：

```
{角色身份}，{面部与发型}，{肤色}，{上装}，{头饰}，
姿态：{站立/半身}，正面平视，
背景：纯白、均匀布光、无场景无叙事事件，
风格：超写实、可信物理材质，<约束：仅身份与材质稳定>
```

示例成句：深空工程师，短发左侧剃线，冷白肤色，深灰工装制服带橙色反光条，半身正面平视，纯白背景，超写实材质。

### 第五步：合成

各段按确认时间线顺序装配，不得把段内节拍拆成额外片段；段间保持动作、视线、光线、色彩或环境元素连续。转场用直切、动作接续、光线连续或短暂环境音桥接，禁止无叙事动机的特效转场。调色与音频氛围严格遵循锁定风格：

| 风格 | 调色 | 音频氛围 |
| --- | --- | --- |
| 硬核深空 | 冷调低噪 | 机械环境音 |
| 太空歌剧 | 庄严阴影 | 肃穆声场 |
| 废土 | 去饱和暖黄 | 呼啸风 |
| 异星生态 | 湿反射局部生物光 | 有机环境音 |

失败处理：段间色彩跳变 → 以锁定风格调色基准统一处理；动作连续性断裂 → 回看前一段末帧与后一段首帧，补一个动作接续镜头或调整时间线顺序。

### 风格关键词与推荐参数

所有资产与视频提示词携带本风格关键词，禁用项写入负向提示词。

| 类别 | 内容 |
| --- | --- |
| 核心关键词（正向） | 超写实、电影质感、可信物理材质、有源布光、克制配色、严谨空间尺度、工业结构、金属磨损、湿润介质、局部生物荧光、真实景深、颗粒感 |
| 语气关键词 | 冷静、克制、肃穆、悬疑、疏离 |
| 高频限制词 | 无霓虹、无全息投影、无高饱和撞色、无义体 |

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 时长 | 75 秒 | 30-180 秒 | 一段一镜 |
| 画幅 | 16:9 | 16:9 / 2.39:1 | 锁定后不换 |
| 分辨率 | 4K | 1080p / 4K | 视频 720p 起 |
| 节奏 | 中慢 | 慢 / 中 | 段内 3-4 秒一节拍 |
| 景别主体 | 中景/特写 | 中景 / 特写 / 大特写 | 超远景仅建立尺度时用 |
| 色调 | 随风格 | 冷调 / 暖黄 / 湿绿 | 锁定后全片统一 |
| 参考图上限 | 9 张 | 0-9 | 每张写明用途 |

| 禁用项 | 说明 |
| --- | --- |
| 霓虹、高饱和紫粉蓝撞色 | 赛博朋克主导信号 |
| 全息投影、义体改造 | 非赛博朋克边界 |
| 雨夜街道 | 与本技能风格冲突 |
| 无光源依据的发光 | 一切发光必须有物理来源 |
| 特效转场 | 只用直切/动作接续/光线连续 |
| 创作者或影片名作为执行指令 | 拆成可见的空间、光线、构图语言 |

## 进阶技巧

- 一致性控制的"参考绑定法"：每个视频段输入该段角色四视图、场景四视图与道具图，提示词按固定顺序组织；参考图数量到上限时优先保角色与场景四视图，道具以文字描述替代。生成后逐项核对材质、光源方向、服装细节三处是否与参考一致，不一致项单独重试。
- 迭代策略"单镜验证、逐段验收"：首段先预览第 1 镜，确认材质与布光可信后再放行全部；每段验收只调整一个维度（动作复杂度/运镜/提示词顺序），记录上版与新版差异，避免多变量同时调整；废土与异星生态类对材质词敏感，先固定材质词表再改其他维度。
- 翻车点规避清单：赛博朋克漂移 → 负向提示词常驻霓虹、全息投影、高饱和撞色、义体四项；四视图分裂 → 单图通过后再生成四视图，四格共用同一句空间描述；一段一镜被打散 → 生成前向用户声明交付关系，段内节拍不拆；资产混入场景风格 → 纯白背景资产只保身份与材质，场景风格由场景资产承载。

## 常见问题

- 跑偏成赛博朋克：原因：风格约束词缺失或过于笼统，模型按常见科幻元素自由发挥。解决步骤：1) 正向提示词写明锁定风格（深空/歌剧/废土/异星四选一）；2) 负向提示词常驻霓虹、高饱和紫粉蓝、全息投影、义体改造四项；3) 逐处检查发光是否有物理光源依据，无依据则替换为有源布光，仍漂移则回退该段风格关键词表重写提示词。
- 场景四视图分裂：原因：四格提示词未共享空间描述，模型按独立场景生成。解决步骤：1) 用通过的单图作为唯一主参考；2) 四视图提示词共用同一句"同一时间、同一天气、同一光源方向、同一空间结构"；3) 依次核对四格的空间结构、材质、光源三个维度，分裂则重新生成最多 2 次，仍失败回退单图阶段。
- 一段一镜被打散：原因：段内节拍被当作独立镜头处理，破坏交付关系。解决步骤：1) 生成前向用户说明"一段一镜"交付关系；2) 段内动作写成连续节拍序列而非分镜列表；3) 生成后检查视频是否存在硬切，被打散则合并回单次生成任务重做。
- 角色资产混入场景风格：原因：纯白背景资产提示词携带环境风格词。解决步骤：1) 纯白背景资产只写身份、面部、发型、服装、材质，不写场景词；2) 环境风格全部由场景资产承载；3) 生成后检查背景是否纯净、无叙事事件，混入则删除资产提示词中的风格词后重新生成。
- 材质塑料感或反光失真：原因：材质词过少或介质描述缺失。解决步骤：1) 材质词写具体（拉丝金属、磨损涂层、湿润生物质）；2) 补充表面状态（划痕、锈蚀、水珠、浮尘）；3) 增加光源类型与方向描述，优先用大特写镜头验证材质可信度。
