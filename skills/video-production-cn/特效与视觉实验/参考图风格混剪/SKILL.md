# 参考图风格混剪

## 技能定位

本技能以参考视频为"镜头语言蓝本"重构新视频：先对参考视频做完整逐段拆解，提取每个叙事节拍的时间范围、镜头类型、运镜、构图与节奏；新分镜与拆解段落一一对应，保留参考的切点、景别、运镜、构图与节奏，只把"谁在做什么、哪个产品/角色"替换成新主体。参考视频的关键帧直接提取为新镜头的构图参考。

## 适用场景

- 翻拍参考视频的运镜与剪辑节奏，替换成自己的角色或产品。
- 想要"同款镜头语言"的品牌片、剧情片、产品片。
- 需要精确复刻参考片节奏与构图的项目。
- 有参考视频但需规避版权主体、只保留镜头语言的项目。

## 制作流程

### 第一步：参考视频分析

对参考视频做完整分镜拆解，输出每段格式"起始-结束时间，镜头描述"。每段描述必须用自然语言完整包含：人物动作、对白、场景/背景及其动态、构图、镜头运动、景别与角度等镜头语言细节（镜头语言要尤其详尽）。分段逻辑：不要为源片每个剪辑都建新段，一个时间段内可描述多个剪辑；按完整叙事节拍分段——每段完整传达一个节拍——但单段不得超过 15 秒。同时提取关键参考帧（标志性构图、取景、时刻）直接作为后续关键帧使用。拆解表字段：

| 字段 | 内容 |
| --- | --- |
| 段落号 | S-01、S-02… |
| 时间范围 | 起始-结束（≤15 秒） |
| 人物动作/对白 | 自然语言 |
| 场景及动态 | 背景、环境动态 |
| 构图 | 主体位置、画幅分割 |
| 镜头运动/景别/角度 | 详尽描述 |
| 关键参考帧 | 帧编号（构图蓝本） |

### 第二步：规格与元素

写入标题、类型、画幅、时长、视觉风格、语言与模型偏好。元素按独立实体分配编号；人物多造型分列描述并写入音色；用户已提供的元素直接绑定不重生成；人物优先三视图支持跨镜一致。若参考有对白/旁白且需要复刻声音，生成或指定一条声线参考音频用于旁白生成对齐。

### 第三步：分镜设计

每镜与拆解段落一对一或显式对应：保留参考的切点、景别、运镜、构图与节奏，只替换主体。优先 10-15 秒含内部切换的长镜，镜内切换用明确标记（如"镜头1（0-4秒）…特写。镜头2 切至（4-8秒）…"）。每镜含：场景引用、剧情内容（精确台词）、镜头语言（景别、角度、运动，与对应拆解段落对齐）与构图参考帧标注（如"构图参考关键帧 02"）。

### 第四步：镜头视频生成

每镜引用元素图与关键帧图双参考。视频提示词按"镜头-主体-空间-音频"四层顺序：镜头运动与切换、主体动作与表情、空间与背景运动、音频标记；动作锚定具体身体部位并加程度副词；多节拍用"镜头1/镜头2"承接；复杂多阶段动作用"cut to"按顺序连接；禁止秒级精确时间计划。

### 第五步：音频与合成

配乐风格与节奏匹配参考片或全局规格，参考有明显幕/情绪变化时拆配乐段；旁白内容、音色、语气与时机严格按分镜，有声线参考时对齐生成。按分镜顺序合成全部镜头、旁白与配乐；无画面内对白或旁白的镜头静音内嵌音频只依赖音频层。

## 提示词模板

**镜头视频提示词模板（四层结构）：**
```
严格参考[元素图]与[构图参考关键帧 NN]；
镜头层：{景别}{角度}{运动}，与拆解段落 S-NN 对齐；
主体层：{部位动作+程度副词}；
空间层：{背景与动态}；
音频层：{音频标记}；{对白}（花括号，仅原文）；
[电影感六规则词]，no text, no watermark
```

**示例成句（替换主体镜头）：**
```
严格参考角色三视图与构图参考关键帧 03；
镜头层：中景侧跟，与拆解段落 S-03 对齐；
主体层：她缓缓推开门走进房间，目光先扫向窗口；
空间层：窗帘随风轻动，午后光线斜落；
音频层：<门轴声> <布料摩擦声> {我回来了。}；
电影感构图，克制冷色调，no text, no watermark
```

**镜内切换标记示例：**
```
镜头1（0-4秒）：全景，他走进旧仓库，环视四周。镜头2 切至（4-8秒）：
特写，手电光束扫过货架标签。镜头3 切至（8-12秒）：
中景，他拿起[产品]，cut to 特写产品 Logo。
```

## 风格关键词与参数表

**核心关键词清单：** 镜头语言蓝本、逐段拆解、叙事节拍分段、切点/景别/运镜/构图保留、主体替换、构图参考帧、四层提示词结构、声线参考。

**拆解-分镜对应规则表：**

| 保留项 | 替换项 | 处理方式 |
| --- | --- | --- |
| 切点、景别、运镜、构图、节奏 | 主体（谁/哪个产品） | 一一对应 |
| 叙事节拍时间范围 | 内容 | 单段 ≤15 秒 |
| 关键帧构图骨架 | 画面细节 | 引用帧号 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 拆解段落 | ≤15 秒/段 | 按叙事节拍分段 |
| 单镜时长 | 10-15 秒（内部切换） | 与段落对应 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率 | 720p 生成、1080p 输出 | — |
| 参考绑定 | 元素图+关键帧图双参考 | 每镜必引 |
| 声线参考 | ≤15 秒 | 复刻声音时 |

**禁用项清单：** 未保留切点景别运镜、构图无关键帧标注、按剪辑数而非节拍分段、秒级精确时间计划、无声音参考的语音复刻、主体与素材矛盾。

## 进阶技巧

- 构图参考帧直接来自参考视频的关键帧提取，替换主体后保持构图骨架不变，是"同款感"的核心。
- 六条电影感核心规则：专业风格术语（引用作者导演与具体影片锚点）、构图与景别、强调负填充的光线、克制的单一主色调（约 90% 面积）、渲染质感、氛围与潜台词。
- 提示词中为每个参考图点名主体身份（面部参考用头像图、发型妆容服装用全身图），连续编号便于模型正确读取。
- 节拍优先于剪辑：分段按"完整传达一个节拍"而非源片剪辑数，一段内可含多个剪辑；单段超 15 秒拆段，节奏宁可细分不可超限。
- 一致性控制：关键帧图与元素图逐镜成对引用；构图骨架稳定，替换主体保持位置/角度/景别对齐。
- 规避翻车：参考片运镜极端（甩镜/急推）时降级为同向缓移，保留方向感但降低生成失败率。

## 常见问题

- 复刻失真：原因：新分镜没有保留参考的切点、景别与运镜。解决步骤：回第三步按拆解段落逐段对齐；逐段比对"切点/景别/运镜/构图"四项。
- 构图漂移：原因：未引用参考关键帧做构图参考。解决步骤：补"构图参考关键帧"标注并绑定关键帧图；每镜提示词显式写帧号。
- 节奏对不上：原因：分段逻辑按剪辑数切而非按叙事节拍。解决步骤：改按完整节拍分段且单段不超过 15 秒；一段可含多剪辑。
- 语音不符：原因：需要复刻参考声音但没建声线参考。解决步骤：补建声线参考并在旁白生成时对齐；声线参考 ≤15 秒。
- 主体与场景割裂：原因：替换主体后未继承场景动态。解决步骤：空间层写明背景与动态并引用场景图；构图骨架保持原参考帧。
