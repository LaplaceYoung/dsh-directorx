# 福特式西部史诗

## 技能定位

本技能把"大地即主角"的西部片电影语言系统化：史诗地貌（纪念碑谷式壮阔景观）、自然光、深焦三段式构图（前景/中景/背景同时清晰）、35mm 彩色胶片质感与分章色彩脚本。叙事遵循九拍结构，决斗遵循八步节奏——张力靠等待而非剪辑。全流程以"环境先行、人物后入"为总原则：任何镜头先交代大地、光线与空间，再让角色在其中行动。

## 适用场景

- 2-10 分钟的西部题材叙事短片。
- 壮阔地貌、边疆开拓、英雄传说主题。
- 用户提供故事素材或章节规划的项目。
- 需要传统西部片质感与史诗节奏的内容。
- 以自然环境为主要叙事角色的景观类短片。

## 制作流程

### 第一步：收集创作信息

收集故事素材、基本参数与章节规划，分析后输出全局规格档案（暂停确认）。

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 总时长 | 5 分钟 | 2-10 分钟 | 决定镜头总数与章节深度 |
| 画幅 | 2.39:1 | 1.85:1 / 2.39:1 | 宽银幕更贴合史诗地貌 |
| 分辨率 | 4K | 1080p / 2K / 4K | 大远景需要高分辨率支撑细节 |
| 帧率 | 24fps | 23.976 / 24 | 电影感帧率，禁用高帧率 |
| 章节数 | 4 章 | 2-6 章 | 每章对应一个色彩脚本阶段 |
| 叙事结构 | 九拍 | 九拍 | 缺拍时按节奏表补足 |
| 年代地域 | 未定 | 如 1870 美国西南 | 决定服装、道具与禁用项 |
| 语言 | 古典文学短句 | 见旁白规则 | 旁白与字幕统一 |

判定标准：时间、地点、主角目标、核心冲突、章节划分五项齐全，缺失时列出清单并暂停等待补充。

失败处理：用户仅给一句创意时，按默认参数（5 分钟、4 章、2.39:1）搭建骨架档案并标注推定值，请用户确认；禁止边生成边补参数。

### 第二步：视觉风格咨询

A 自动决定 / B 参考经典西部片（如《搜索者》《要塞风云》《双虎屠龙》等）/ C 分章配色方案（可自定义年代地域），循环确认或修改。

- 路径 A：自动决定后输出一句话风格说明（如"暖沙黄基调、午后侧逆光"），用户确认或修改。
- 路径 B：从参考片提炼光照、构图、配色三要素各 2-3 条，转化为可见镜头语言，不直接复制镜头内容。
- 路径 C：逐章给出主色与辅色，每章不超过 4 个颜色，相邻章节至少保留 1 个共享色。

判定标准：风格与故事基调、年代地域一致；相邻章节共享色不少于 1 个。不一致则回对应路径重提。

失败处理：用户对风格无明确偏好且参考路径不适用时，回退默认方案——建置章暖黄沙黄天蓝、冲突章土灰铁灰、终局章高对比黑赭石、结尾章日落橙蓝，作为兜底配色。分章调色时主色占比不低于 60%，辅色只做点缀，相邻章节至少共享 1 个颜色，禁止本章出现上一章的主导色。

### 风格关键词与推荐参数

本小节为全局风格基准，所有资产提示词与视频提示词必须携带核心关键词，禁用项写入负向提示词或约束句末尾。

| 类别 | 内容 |
| --- | --- |
| 核心关键词（正向） | 史诗地貌、砂岩台地、广袤地平线、深焦三段式、自然光、晨侧逆光、金色时分、沙尘颗粒、35mm 彩色胶片质感、复古西部、边疆小镇、土坯与木质建筑 |
| 语气关键词 | 苍凉、辽阔、庄重、孤寂、等待感 |
| 高频限制词 | 无现代元素、无散景、静止镜头优先、单一光源 |

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 节奏 | 慢 | 慢 / 极慢 | 平均镜头 5-8 秒，决斗可 20 秒 |
| 色调 | 暖沙黄 | 建置暖黄 / 冲突土灰 / 终局高对比 | 随章节色彩脚本变化 |
| 对比度 | 中高 | 中 / 高 | 决斗章最高 |
| 天空占比 | 40% | 30-50% | 人物占画面下三分之一 |
| 光照时段 | 午后 | 晨 / 正午 / 午后 / 日落 / 夜 | 每镜明确一个时段 |

| 禁用项 | 说明 |
| --- | --- |
| 现代建筑、车辆、电灯、手机、水泥路、玻璃幕墙 | 任何现代痕迹即穿帮，写入负向提示词 |
| 塑料感、高饱和卡通色 | 破坏胶片质感 |
| 散景、浅景深 | 破坏深焦三段式 |
| 快速变焦、手持摇晃、MV 式剪辑、FPV 无人机运镜 | 破坏史诗静默感 |
| 电子乐、游戏式枪声、网络流行语旁白 | 破坏年代氛围 |
| 无叙事目的的空镜头与无意义走动 | 每镜头须推进角色、空间或秩序之一 |

### 第三步：视觉规格转换

角色元素图 → 场景元素图 → 关键道具图 → 融合关键帧（暂停确认）。

- 角色元素表：正面/侧面/背面、站立/行走/骑马/持枪/坐/剪影/表情参考；同一角色各姿态共用同一份面部与服装设定，禁止不同姿态各自出图。
- 每匹马独立档案：

| 档案项 | 内容要求 |
| --- | --- |
| 颜色 | 与角色服装形成可辨识对比 |
| 品种 | 西部常见品种，体型符合年代 |
| 装备 | 马鞍、缰绳、毯子式样统一 |
| 主人 | 绑定唯一角色，禁止中途换马 |

- 重要道具统一编号（如 枪械 P01、水壶 P02），编号写入分镜表。

判定标准：三类元素图光照方向与色调一致；融合关键帧中人物占比 5-15%。冲突则单独重生成冲突项，不整组重来。

失败处理：融合关键帧比例失调或透视矛盾 → 回退对应角色元素图单独修正后重新融合，最多 2 次；仍失败则暂停，向用户展示对比并确认方向。

### 提示词模板

语法约定：{占位符} 为必填替换项，<可选> 为按需保留项，填入后删除全部括号；模板按"主体 → 场景 → 动作 → 镜头 → 光照 → 风格 → 约束"顺序组织。

分镜镜头提示词模板：

```
{角色/马匹/道具资产引用}，{角色动作：身体部位+幅度}，
场景：{地貌与建筑}，时段：{晨/正午/午后/日落/夜}，天气：{晴/风/尘暴}，
景别：{大远景/全景/中景/特写}，运镜：{静态/慢横摇/慢推/慢拉}，
构图：天空{数字}%土地{数字}%人物{数字}%，人物居下三分之一，
光照：{自然光类型}，<尘土：{程度}>，<马匹：{行进状态}>，
风格：史诗地貌、深焦三段式、35mm 胶片质感、复古西部，
<负向：无现代元素、无散景、无快速变焦>
```

示例成句：骑手策马，马蹄慢步踏过沙脊，场景为砂岩台地与土坯小镇，午后，晴，全景，慢横摇，天空 40% 土地 50% 人物 10%，侧逆光，史诗地貌、35mm 胶片质感。

### 第四步：分镜

可选一次全生成、逐章或先出角色三视图与马匹设定。镜头数参考：2 分钟 8-18、3 分钟 12-28、5 分钟 20-45、8 分钟 35-70、10 分钟 50-90。标准镜头 5-8 秒、史诗大远景 8-15 秒、决斗镜头可延至 20 秒。分场景节奏：建置世界 8-15 秒、角色互动 6-10 秒、骑马 8-12 秒、篝火 10-15 秒、决斗预备 8-20 秒、枪战 3-6 秒、英雄离去 10-20 秒、结尾大远景约 15 秒。

分镜表每行一个镜头：

| 镜号 | 章节 | 时长 | 景别 | 运镜 | 画面内容要点 | 声音设计 |
| --- | --- | --- | --- | --- | --- | --- |
| S1-01 | 建置 | 10s | 大远景 | 静态主镜头 | 砂岩台地与地平线，无人物，天空占 40% | 风声底噪 + 低鸣 |
| S1-02 | 建置 | 6s | 全景 | 慢横摇 | 骑手沿山脊线行进，尘土轻扬 | 马蹄声 + 风声 |
| S2-03 | 冲突 | 4s | 中景 | 静态 | 两人对峙，前景木栅栏，背景镇街 | 脚步 + 木质吱呀 |
| S3-01 | 决斗 | 15s | 特写 | 锁定静止 | 双方站立不动，风卷沙土，手垂腰间 | 风声 + 心跳感低频 |
| S4-01 | 结局 | 20s | 大远景 | 日落定格 | 英雄骑马远去，地平线吞没身影 | 口琴 + 风声渐弱 |

镜头数核对：成片秒数除以平均镜头时长得出应配数；实际超出 ±20% 时，超出则合并冗余镜头，不足则在既有镜头内延长，不新增无叙事镜头。

失败处理：用户对镜头数量无意见时，按"每章 5-8 镜、含至少 1 个大远景与 1 个静止镜头"的底线结构自动补齐或裁剪；分镜经用户确认前不进入生成。

### 第五步：生成视频

生成前自动做一致性检查，冲突项先重试 1 次，仍失败回退对应资产图后重来：

- 角色/服装/帽子与元素图一致，无明显变形；
- 武器/道具编号形态一致，马匹颜色、装备、主人正确；
- 天气与太阳方向同分镜表时段且无随机变化；
- 尘土、地平线、背景山连续不断裂，相邻镜头机位不越轴。

允许的角色演变仅限磨损增加、灰尘、胡须生长、伤痕、疲惫；演变随章节递进且必须有叙事理由，禁止发型、服装、马匹突变。

失败处理：同镜连续 2 次检查不过 → 停止该镜，回退第三步修正资产后重来；整体偏现代或卡通 → 末尾追加"35mm 胶片质感、复古西部、无现代元素"后重试。

### 第六步：旁白、音效与 BGM

- 旁白用古典文学短句（每句 10-25 字），禁网络流行语与现代口语，只出现在章节开头与结尾大远景处，不逐镜解说。
- 音效分环境/物件/场所三层：环境层（风、沙、虫鸣）每镜头至少 1 层；物件层（马蹄、枪械、靴声）按动作点放置；场所层（酒吧人声、篝火噼啪）按场景放置。判定标准：全片静音不超过 1 秒。
- 音乐按章节配器：建置民谣吉他口琴 → 旅途弦乐铜管 → 冲突鼓铜管 → 决斗静默加低频打击 → 终章口琴弦乐。决斗段音乐密度最低，靠环境音与低频撑张力。

失败处理：音乐风格与章节不搭（如冲突章出现轻快旋律）→ 回退该章节默认配器并重新指定情绪词（苍凉/压迫/肃穆）；旁白被判定为现代口语 → 按古典短句规则重写并减少句数。

### 第七步：最终剪辑合成

每镜头输出 21 字段镜头数据库：场景号、章节、镜号、时长、地点、时间、天气、角色、马匹、道具、机位、构图、光照、色板、图像/视频/负向提示词、声音设计、BGM 风格、旁白。数据库在生成前按分镜表预填，生成后逐字段核对补差。

- 转场规则：默认直切；章节之间可用日落或尘土升起的短镜头过渡；禁止特效转场与闪白。
- 字幕默认关闭，启用则用 19 世纪衬线字体、暖白/旧纸色、下三分之一。
- 剪辑节奏核对：按决斗八步重排决斗段落，确认"沉默—风起—观察—拔枪"的等待感保留；总时长超出目标 ±10% 时，优先压缩角色互动镜头而非大远景。

失败处理：成片节奏偏快或等待感缺失 → 把关键静止镜头时长加回 8-15 秒并减少剪辑点；声音与画面不同步 → 逐镜头核对音效时间码后重新对齐。

## 进阶技巧

- 叙事九拍：建立世界 → 建立社群 → 外部冲突 → 角色选择 → 英雄行动 → 终局对决 → 秩序恢复 → 英雄离去 → 故事结束。每镜头必须推进角色、空间或秩序之一；分镜时逐拍核对，前 3 拍以环境与空间镜头为主，第 6 拍进入决斗段落，末 2 拍以长镜头收束。

决斗八步节奏表——逐镜对照，等待感靠步与步之间的静默维持：

| 步 | 内容 | 默认时长 | 判定标准 |
| --- | --- | --- | --- |
| 1 | 建立空间 | 4-6s | 双方与背景同时清晰 |
| 2 | 双方 | 2-3s | 各给一个对切中景 |
| 3 | 距离 | 2-3s | 全景交代间距 |
| 4 | 沉默 | 4-8s | 无对白无音乐 |
| 5 | 风起 | 2-3s | 尘土或衣摆运动 |
| 6 | 观察 | 3-5s | 眼神特写交替 |
| 7 | 拔枪 | 1-2s | 大特写快切 |
| 8 | 结束 | 3-6s | 枪声回响后静止 |

- 一致性控制的"三板斧"：一是资产编号表（角色 R01、马匹 H01、道具 P01），所有提示词以编号引用资产图；二是太阳方向表，每章固定同一时段与光源方位，跨镜不符即判冲突；三是机位轴线表，标注每章主轴线，越轴镜头一律重做。三项在分镜阶段完成，不在生成阶段补救。
- 迭代策略"先静后动、单变量修改"：每章先出 2-3 张静态关键帧（角色+场景+光照），用户确认后才生成该章视频；章节按顺序验收，前章未通过不改后章。每次迭代只改一个变量（光照/构图/服装），改完对比前后两版，防止无法定位问题。
- 翻车点规避清单：天气突变 → 分镜表强制写入时段与天气字段，提示词末尾追加"天气稳定"；人物比例失调 → 融合关键帧阶段把人物占比控制在 5-15%；现代元素混入 → 生成前跑一遍禁用项清单；决斗张力不足 → 用"多等两秒"原则，拔枪前至少留 2 秒静止。

## 常见问题

- 现代元素穿帮：原因：提示词缺少年代约束，模型默认生成现代场景。解决步骤：1) 负向提示词加入现代建筑、车辆、电灯、手机、水泥路、玻璃幕墙、塑料感；2) 正向提示词追加"1870 年代美国西南边疆、木质与土坯建筑、复古西部"；3) 重新生成前对照禁用项清单逐项检查，仍穿帮则回退场景元素图补充时代细节后重试。
- 背景虚化：原因：默认浅景深设定与深焦三段式冲突。解决步骤：1) 提示词写明"前景、中景、背景同时清晰"；2) 负向提示词加入散景、浅景深、背景模糊；3) 优先用大远景或全景景别验证，单镜仍虚化则拆为两段分别固定焦点后拼接。
- 运镜夸张：原因：未声明运镜风格，模型默认炫技运镜。解决步骤：1) 每镜头显式声明运镜类型（静态/慢横摇/慢推慢拉）；2) 负向提示词加入快速变焦、手持摇晃、MV 式剪辑、FPV 无人机；3) 运镜速度用"缓慢、匀速"修饰，决斗段一律声明锁定静止镜头。
- 天气乱变：原因：提示词未固定时段与天气。解决步骤：1) 分镜表写入该镜天气字段（晴/风/尘暴）；2) 提示词开头声明"单一时段单一天气"；3) 生成后核对太阳方向与阴影，冲突镜头重试 1 次，仍失败回退场景元素图。
- 角色凭空出现：原因：镜头缺少入画逻辑，角色被随机放置。解决步骤：1) 分镜表补充角色入场方式（入画方向、遮挡关系）；2) 提示词写明"角色从画面左侧边缘入画"等明确动作；3) 删除无叙事目的的空镜头，角色出现的镜头必须能回答"他从哪来、要去哪"。
- 音乐不搭：原因：音乐情绪词缺失或过于宽泛。解决步骤：1) 按章节配器表指定乐器组合并标注情绪词（苍凉/压迫/肃穆/孤寂）；2) 决斗段降低音乐密度，保留低频与静默；3) 仍不搭则回退默认配器，改在音效层补张力。
