
name: 北野武蓝调美学
description: >-
  适用于制作北野武式蓝调美学短片：冷灰蓝低饱和影像、非对称叙事弧、
  荒诞日常与物哀并存、极简对白与静默、控制符号驱动的配音与表演。

## 技能定位

本技能复现"蓝调式"作者电影美学：低饱和冷灰蓝调、对称构图、粗颗粒胶片质感；叙事上采用非对称弧——超过 80% 的日常平静与不足 5% 的突然转折，用省略法留白；人物在死亡阴影下保留孩子气的荒诞游戏，形成"废墟上的游戏"式的温暖与诗意。配音与表演用一套控制符号系统驱动（动作括号、显式停顿、省略号断句、双语映射），追求粗糙真实的呼吸感。

## 适用场景

- 黑帮/暴力题材但追求安静与诗意而非血腥的短片。
- 极简对白、长静默、物哀氛围的叙事创作。
- 中日双语配音的项目（输出语言可选中文或日文）。
- 以"沉默承载情绪"的表演型短片。

## 制作流程

### 1. 锁定全局规格
画幅 16:9 或 2.39:1（带上下黑边）；资产画幅与成片隔离——角色全身三视图锁定 16:9 横版、场景 2x2 四格图锁定 4:3，禁止继承成片比例导致拉伸裁切；目标 720p 生成、1080p 输出。规格默认值：帧率 24fps、色彩低饱和冷灰蓝、颗粒粗粝、非对称弧（日常 ≥80%、转折 <5%、余韵收尾）。

### 2. 语言美学红线
选日文时用"俺/お前"式粗粝称谓、短句简体（如"来い"而非敬语）、频繁省略号制造叹息与沉默；选中文时同样冷硬极简（"走。"而非"我们该走了"）、短促碎片化、大量省略号与无声叹息。建立双语句对映射表锁定配音/口型/字幕三轨同步。句对映射表字段：中文原文、日文译文、语气标记、停顿点、口型时长。

### 3. 剧本孵化
接收零散情绪（如"海边站着一个人"）时主动扩写——围绕"日常平静-荒诞游戏-突发危机-物哀余韵"构造冲突与冷角色设定，提炼标志性视觉隐喻（海风中的玩具风车、夏日尾声的手持烟花、带数字的蓝色卡片）。检测到重大情绪爆发/枪击后空虚/死亡离别/夏末物哀节点时，在剪辑关键处插入 1-2 个"手绘素描/质朴油画"艺术转场镜作为情绪呼吸空间，禁止平铺直叙过渡。

### 4. 分镜设计
固定机位为主、负空间构图（天空/海面占画面 2/3）、无表情凝视、省略式剪辑节奏；对白遵循"沉默重于声音"——悲伤/深情/离别绝不用台词直陈，用长凝视、低头、无意义抽烟、递一个小物件、微微颤抖的肩膀外化。分镜表逐镜登记：景别（固定机位）、负空间占比、主体状态（无表情凝视/微动作）、对白控制符号串、时长。

### 5. 控制符号系统（写入所有对白/旁白）
圆括号标动作情绪（长叹、苦笑、哽咽停顿）；[pause: X.Xs] 标纯静默时长（阻止配音、锁定闭嘴凝视/微弱呼吸状态）；省略号标约 0.5 秒喘息、长省略号标 1 秒以上空白凝视；纯凝视镜写成 {（沉默）[pause: 3.0s]} 不得留空；双语项目用 {（动作）原语对白 <-> （动作）目标语配音} 映射并附生理微颤标记（嘴唇轻抖、吞咽喉结动、眼皮颤动、手指颤抖握紧）。符号速查表：

| 符号 | 含义 | 默认值 |
| --- | --- | --- |
| （动作情绪） | 动作/情绪提示 | 长叹/苦笑/哽咽停顿 |
| [pause: X.Xs] | 纯静默时长 | 0.5-3.0 秒 |
| … | 喘息 | 约 0.5 秒 |
| …… | 空白凝视 | ≥1 秒 |
| {（动作）原语 <-> （动作）译语} | 双语映射 | 附微颤标记 |

### 6. 资产生成与绑定
角色必须为"全身三视图"（含正/侧/背，禁半身或单角度）；场景必须为"无人物 2x2 四格"（全景建立/道具特写/纵深透视/氛围光效）；风格不符或格式不符时用图生图重制；艺术转场资产按"手绘素描/质朴油画"专属公式生成 2K 静帧；有对白角色绑定 5-10 秒独白声音样本。逐项核对：每个角色/场景/道具都有图、每镜都有场景引用、有对白必有声音资产，缺一不可，禁止带缺进入视频生成。

### 7. 逐镜生成
以静帧艺术图为首帧生成动态转场镜——画面微颤、炭笔线条随呼吸极缓移动、厚涂油画光影细微变化、风车/火花缓慢转动；禁止僵硬静止。每镜生成前对照分镜检查：参考图绑定（同场景连续镜强制用同一张四格图）、对白与声音样本对齐、环境音完整、运镜与分镜 100% 一致。

### 8. 音频与合成
生成 BGM（禁用知名音乐人名）与环境音层；按省略式剪辑与静默美学组装时间线；艺术转场镜控制为短促 4-6 秒或超长留白 8-12 秒，进入转场瞬间执行 J/L 切错位或日常声轨避让与超缓淡入淡出；章节或片尾允许 1.5-2.5 秒黑场淡出承接余韵。最终 1080p、24fps 输出，锁定传统影像的动态阻尼。

## 提示词模板

**角色三视图模板：**
```
[角色]全身三视图（正/侧/背并排），低饱和冷灰蓝调，粗颗粒胶片质感，
冷峻神情，无表情凝视，[服装：朴素/和服/深色西装]，16:9，
no bright colors, no smile, no half body
```

**对白镜模板（控制符号内联）：**
```
固定机位，[景别]，[角色]（无表情凝视）[pause: 2.0s]，
{（长叹）走。…}，海面占画面 2/3 负空间，风车缓缓转动，
低饱和冷灰蓝调，粗颗粒胶片质感，no bright colors
```

**双语映射示例：**
```
{（缓缓抬头）行こう。 <-> （缓缓抬头）走吧。}，
生理微颤：嘴唇轻抖、喉结微动，[pause: 1.5s]
```

**示例成句（海边告别镜）：**
```
固定机位中景，男人（无表情凝视海面）[pause: 3.0s]，
{（苦笑）……来い。}，海面占画面 2/3，
玩具风车在风里缓慢转动，低饱和冷灰蓝，粗颗粒胶片质感，
no bright colors, no fast camera movement
```

**核心关键词清单：** 低饱和冷灰蓝、对称构图、粗颗粒胶片、非对称叙事弧、日常平静、突然转折、省略法留白、物哀、无表情凝视、负空间（天空/海面 2/3）、固定机位、控制符号系统、生理微颤。

**叙事弧比例表：**

| 段落 | 占比 | 内容 | 视听特征 |
| --- | --- | --- | --- |
| 日常平静 | ≥80% | 荒诞日常、孩子气游戏 | 静默、固定机位、环境声 |
| 突然转折 | <5% | 爆发/枪击/离别 | 画外音+死寂（4-5 秒） |
| 物哀余韵 | 收尾 | 长凝视、艺术转场 | 4-6 或 8-12 秒留白 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 画幅 | 16:9 或 2.39:1 | 资产画幅隔离（角色 16:9、场景 4:3） |
| 分辨率/帧率 | 720p 生成、1080p/24fps 输出 | — |
| 艺术转场 | 短促 4-6 秒或留白 8-12 秒 | 关键节点插入 1-2 个 |
| 黑场淡出 | 章节/片尾 1.5-2.5 秒 | 承接余韵 |

**禁用项清单：** 知名音乐人名、平铺直叙过渡、暴力画面直陈（枪击画外）、敬语腔/现代长句、机械连读、无停顿念白、高饱和撞色、镜头炫技、僵硬表情。

## 进阶技巧

- 枪击等暴力永远放在画外：一声干响+环境音瞬间归零+4-5 秒死寂，比任何画面都沉重；这是"转折 <5%"的实现方式。
- 字幕避让视觉重心：当视觉焦点位于画面下 1/3 时，字幕水平移到左右或缩小至 60% 字号，给物哀意象让路。
- 生理微颤写入对白：吞咽/喉结/眼皮颤动与台词逐拍对应，配音与画面 1:1 物理对齐，阻断僵硬表情。
- 沉默是节奏单元：把 [pause: X.Xs] 当作镜头语言的一部分设计，而不是留白空隙——静默镜写 {（沉默）[pause: 3.0s]} 不得留空。
- 一致性控制：同场景连续镜强制用同一张场景四格图；角色三视图锁定冷灰蓝服装基调，防跨镜跳色；艺术转场资产统一"手绘素描/质朴油画"公式。
- 规避翻车：无表情≠空表情，提示词写"无表情凝视+微微呼吸起伏"保生理真实；海浪/风车等微动态写"缓慢转动"，禁僵硬静止。

## 常见问题

- 配音机械连读：原因：控制符号缺失。解决步骤：检查省略号断句、括号动作提示与显式停顿是否写全；逐句对照符号速查表补齐。
- 画面过度流畅无呼吸感：原因：静-动-静结构缺失。解决步骤：补入静-动-静结构与负空间构图，让沉默成为节奏的一部分；每镜核对负空间占比与固定机位。
- 参考素材风格不符：原因：直接使用未转绘。解决步骤：一律按"提取物理特征+风格重制+格式标准化"流程处理，不直接使用。
- 转折段过直白：原因：暴力或情绪直接入画。解决步骤：枪击画外处理（干响+归零+死寂）；离别用长凝视与物件外化，不靠台词直陈。
- 双语不同步：原因：句对映射表缺失。解决步骤：建立中文/日文句对映射表，锁定配音/口型/字幕三轨同步并附生理微颤标记。
