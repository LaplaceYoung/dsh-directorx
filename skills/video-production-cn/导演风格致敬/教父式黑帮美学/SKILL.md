## 技能定位

本技能把"古典黑帮家族美学"（红木办公室、沉重顶光、明暗对比、黄金三角构图、胶片颗粒与暗部棕调）固化为资产克隆式工作流：先锁定 1970 年代胶片设备与老镜头光学特征作为全片质感锚，再逐层生成角色参考卡、空间蓝图与 3x3 分镜网格，最后驱动一段 15 秒 720p 成片，保证概念图、分镜与成片三者在设备纹理与布光参数上完全一致。

本技能把黑帮美学拆解为可复制的参数系统：影调、布光、构图、服装道具场景、剪辑节奏五项，每项都有数值与判定标准；质感锚文本作为全链唯一描述串，概念图、分镜、成片三处逐字复用。

## 适用场景

- 古典黑帮/家族权力题材的短片或广告概念片。
- 需要"旧胶片电影感"（颗粒、光晕、深黑、暗部暖调）的叙事内容。
- 从概念图一步到位到成片的快速验证。
- 对白主导的权力戏，需要固定构图语言支撑。

## 制作流程

### 影调与布光参数

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 主光 | 顶光或 45 度伦勃朗光 | 单侧主光+对侧弱补光，明暗比 4:1 至 8:1 |
| 阴影 | 深黑、边缘硬 | 阴影区保留暗部棕调细节，不纯黑死黑 |
| 色温 | 暖调 2700-3200K | 红木/琥珀/烛光基调，冷色只做点缀 |
| 颗粒 | 高对比胶片颗粒 | 全片一致，暗部颗粒明显 |
| 光晕 | 暖色镜头光晕 | 逆光与点光源处出现 |
| 对比度 | 高对比、暗部为主 | 画面约六成处于暗部，主体面部始终受光 |

判定标准：主体面部轮廓在阴影中仍可辨；概念图、分镜、成片三处布光参数一致。失败处理：暗部吞没主体时降低明暗比至 4:1，保留阴影区棕调细节。

### 服装/道具/场景规范

| 类别 | 规范 | 示例 |
|---|---|---|
| 服装 | 深色三件套西装、大衣、礼帽 | 深灰/黑色羊毛西装、白衬衫、黑色领带 |
| 道具 | 红木、皮革、金属、雪茄、老式电话 | 皮质座椅、黄铜台灯、木质雪茄盒 |
| 场景 | 红木办公室、昏暗走廊、餐厅长桌 | 大书桌、书架墙、百叶窗、厚重窗帘 |
| 色彩 | 棕/金/黑三色为主 | 暗部暖调贯穿，禁高饱和彩色 |

### 构图规则

- 黄金三角站位：对话三人呈三角顶点分布，主体位于画面兴趣点。
- 框式构图：门框/百叶窗/栏杆做前景遮挡，形成"权力框"，暗示角色被规则与家族框住。
- 对称构图：长桌、办公室等权力场景用对称轴线强化庄严与压迫。
- 轴线纪律：对话镜轴线固定，过肩构图保持同一侧，不越轴。
- 俯视蓝图：中心格 [2,2] 固定放空间运动俯视蓝图，所有动作镜头在俯视图中有逻辑起点。

### 慢节奏剪辑参数

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 单镜时长 | 10-15 秒 | 对话镜可到 15 秒，动作镜 6-10 秒 |
| 剪切频率 | 低 | 剪切跟随呼吸节奏，不追动作 |
| 动作镜 | 9 格连续序列 | 按 00:00-00:03 式时间码切分驱动 |
| 运镜 | 缓慢推/拉、静态为主 | 禁快速横摇与手持晃动 |
| 节奏 | 前慢后快收尾 | 15 秒内情绪逐步加压，结尾给定格 |

### 六步流水线

1. 剧本孵化：基于用户需求自动起草三份符合古典黑帮风格的剧本大纲（可按用户要求调整），用户选定后生成核心场景与角色概念图，锚定旧胶片设备质感与老镜头光学特性。
2. 简化角色参考卡：把已确认剧本的核心角色变量直接输入文生图引擎，产出"左侧全身三视图+右侧六格头像与服装纹理细节"的简化角色卡。里程碑确认①：确认核心角色与声音档案，同时确认成片画幅（默认 16:9，可指定 9:16 竖屏）。
3. 空间美学建立：生成纯全景空场景图与俯视 3D 蓝图，锁定核心空间资产——红木家具、垂直顶光、明暗对比结构。
4. 自适应 3x3 网格分镜：按剧情密度弹性决定网格数——单独对话拆 4-6 格，快节奏动作拆 9 格连续动作序列；文生图渲染 3x3 分镜板，所有内部镜头严格继承概念图的设备纹理（重机位、镜头光晕、胶片颗粒、暗部棕调），形成绝对资产灯光锁定；中心格 [2,2] 固定放空间运动俯视蓝图，周围格按古典构图逻辑排布（黄金三角定位、百叶窗/门框权力构图）。
5. 单镜成片：合并全部已锁定资产，驱动 15 秒 720p 成片生成（严格对齐锁定画幅）。
6. 审计与输出：分镜与概念一致性审计（对话场景轴线/过肩构图、动作场景连续运动与高频运动模糊，两者都不得偏离初始概念质感）；画幅一致性校验；输出前注入刚性负向约束，拦截乱码文字、错误闪烁与意外形变。

### 提示词模板

#### 质感锚描述串（全链复用）

```
1970 年代重型摄影机拍摄，老式定焦镜头光学特征，
高对比度胶片颗粒，强制显影效果，深黑阴影，
暗部暖棕色调，逆光暖色光晕，轻微镜头呼吸感
```

概念图、3x3 分镜板、成片三处提示词必须逐字复用这段描述串；任何一处改写都会造成质感漂移。

#### 单镜成片提示词模板

```
[场景与角色动作]，
[质感锚描述串]，
[构图与布光]；[运镜]，
[时间码分段：00:00-00:03 …]
负向：乱码文字, 错误闪烁, 意外形变, 现代物品, 高饱和色彩
```

占位符说明：
- [场景与角色动作]：引用场景与角色元素标识，写物理可见的动作，表演用"缓慢/克制"程度词。
- [构图与布光]：对称/黄金三角/框式构图之一 + 主光方向。
- [时间码分段]：动作镜按 3 秒一段切分，写明每段发生的事。

示例成句：

```
S1 红木办公室内，R1 坐在大书桌后缓缓抬头，双手交叠置于桌面，
1970 年代重型摄影机拍摄，老式定焦镜头光学特征，高对比度胶片颗粒，
强制显影效果，深黑阴影，暗部暖棕色调，逆光暖色光晕；
对称构图，顶光直射，缓慢推近，00:00-00:05 缓缓抬头，
00:05-00:12 开口说话，00:12-00:15 定格
负向：乱码文字, 错误闪烁, 意外形变, 现代物品, 高饱和色彩
```

## 进阶技巧

- **质感锚的写法：概念图、网格分镜与成片提示词共用同一段"设备+胶片+镜头"描述串**：重型摄影机、定焦镜头、高对比胶片颗粒、强制显影、深黑阴影、暖光晕——三处一致即全链一致。改动时三处同步，不允许只改一处。
- **对话场景的构图纪律：黄金三角站位、门框/百叶窗/栏杆做权力遮挡**，是"教父式"画面的速成法；对话镜轴线固定，过肩构图保持同一侧，不越轴。
- **网格中心永远放空间蓝图**：所有动作镜头都能在俯视图中找到逻辑起点，防止调度失控；9 格连续动作严格按时间顺序生成，15 秒内按 00:00-00:03 式时间码切分驱动。
- **翻车点规避：表演浮夸是古典黑帮片最常见失败**——所有动作描写统一加"缓慢/克制/小幅"，运镜限定缓慢推拉与静态，成片前先用单帧验证表情基调。

## 常见问题

- **成片影调过暗**：原因：深黑阴影与暗部暖调叠加过度，主体细节被吞没。解决步骤：① 检查质感锚中"深黑阴影"与主光参数是否冲突；② 把主体面部明暗比降到 4:1，阴影区保留暗部棕调细节；③ 重出该镜并与概念图对比亮度，确认主体轮廓可辨。
- **分镜与成片质感漂移**：原因：三处提示词未复用同一质感锚文本。解决步骤：① 逐字比对概念图、分镜、成片三处描述串；② 统一为同一质感锚；③ 重出漂移环节并复核。
- **表演浮夸、动作过度**：原因：提示词写了剧烈动作或快速运镜，破坏慢节奏基调。解决步骤：① 动作描写全部改为"缓慢/克制/小幅"；② 运镜限定缓慢推拉与静态；③ 重新生成该镜，先出单帧确认表情基调再出成片。
- **画幅错乱**：原因：分镜网格与成片未校验比例。解决步骤：① 分镜网格与成片导出前都校验 16:9 或 9:16 一致性；② 发现错乱先回规格确认画幅；③ 重出对应环节。
