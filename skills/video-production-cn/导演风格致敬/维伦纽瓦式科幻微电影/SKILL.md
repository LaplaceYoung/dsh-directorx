# 维伦纽瓦式科幻微电影

## 技能定位

本技能把"尺度与宿命"美学（巨物压迫、极简对称、低饱和、末世与宗教肃穆）固化为严格参数系统：人-建筑尺度比量化（1:50-1:100，人物画面占比<1-2%）、运镜按刚性权重分配（中轴慢推 70% / 慢横摇 20% / 绝对静态 10%）、每镜"静-动-静"三段时间比、戏剧冲突用标签渲染模板驱动。全流程模型锁定、逐资产确认，任何镜头缺失场景引用都不得进入生成。流程为：灵感孵化与规格锁定 → 分镜深化 → 视觉与音频资产绑定 → 逐镜生成 → 音轨与合成，每阶段输出可核对的判定物。

## 适用场景

- 科幻/废土/末世题材微电影或概念片。
- 需要"微小人物 vs 巨大结构"宗教感与宿命感的视觉内容。
- 用户只有零散灵感（如"沙丘里一座废弃雕像"）需要孵化成完整剧本。

## 制作流程

1. 灵感孵化与规格锁定：用户只有碎片灵感时先做导演级孵化，提供 3 个不同情绪取向的方案（悲剧宿命/神圣缥缈/冷冽绝望），并推荐子风格（黄沙废土/冷钢深蓝科幻/黑色巨石工业）；确认后锁定规格（16:9、720p、低饱和、末世荒凉、宗教肃穆等）。
2. 分镜深化：以已确认大纲为核心生成分镜（关键元素/镜头表/独立音轨）；脚本细节不足时主动补足高电影感的符号动作、环境细节、镜头技法与张力对白；用户上传素材先做多模态分析再继承。
3. 视觉与音频资产绑定：用户素材符合"全身三视图（16:9）+无人物四格场景图（4:3）"且风格契合则直接绑定；风格不符或格式不符（半身三视图/非四格）一律用图生图按规范重塑；未提供则系统生成（角色全身三视图、场景四格：全景建立/道具特写/纵深透视/氛围光照）。角色音色有参考直接绑定，无参考则为有对白角色设定一致声音并登记。进入视频前做反跳变审计：每个元素有资产、每镜都绑定了场景引用（同场景连续镜强制同一张场景图）、有对白必有音色绑定。
4. 逐镜生成：每镜绑定角色三视图+场景四格图；含对白镜引入角色音色做自动克隆；一般不使用前镜视频作参考（仅极强动作连续时例外）。生成前逐镜对照分镜检查场景/角色/对白/音效引用无遗漏。
5. 音轨与合成：生成低频环境音轨（低弦乐嗡鸣/原始鼓脉冲/宗教吟唱/高强度次声振动，禁高旋律音乐）与肃穆旁白；按静默节奏组装，巨物全景或宿命判决台词处设计"声学真空"（音效与 BGM 骤停，只留弱风声或沉重呼吸）；导出成片。

### 成片质检清单

① 每镜运镜类型唯一（中轴慢推/慢横摇/绝对静态三选一）；② 慢横摇扇区 15°-30°；③ 静-动-静比例与分镜表一致；④ 人物画面占比 <2% 且建筑尺度比为 50-100 倍；⑤ 中轴对称构图无倾斜；⑥ 逆光剪影或明暗对比生效；⑦ 声学真空点落实（巨物全景/判决台词处）；⑧ 同场景连续镜引用同一张四格场景图；⑨ 低频音景无高旋律乐；⑩ 导出画幅与帧率符合规格。全部通过才交付。

## 进阶技巧

- 呼吸节奏与生理声学标记（叹息/吞咽/颤抖/气声）直接写进台词，配合低音域配音模板，宿命感最强。
- 巨物全景与判决台词处设计"声学真空"（骤停至只剩弱风或呼吸），是张力释放的黄金手段。
- 用户素材不符规范时只保留核心物理特征（脸型/服饰/几何线），风格与格式一律重塑，禁止直接使用。
- 声学极化写进对白提示词：压迫方高响度收窄喉音（音调+10-20%），承受方低响度气声颤抖（音调-15%）；两角色严禁同音调同响度，用听感差异直接表达权力关系。
- 微表情毫秒时序：审判场景的"延迟干吞咽+下眼睑微颤"按毫秒级先后描述（先吞咽后颤），比笼统写"紧张"更能被模型捕捉。

## 常见问题

- 镜头花哨失格：原因是混入快速推拉/横摇/手持晃动。解决步骤：① 检查每镜是否单一运镜类型（中轴慢推/慢横摇/绝对静态三选一）；② 慢横摇扇区限制 15°-30°；③ 对照静-动-静比例表核对该镜时间分配；④ 重跑违规镜头。
- 声音太满：原因是全局铺满音乐与音效。解决步骤：① 全局低频音景为主，禁高旋律音乐；② 巨物全景与判决台词处必须做声学真空；③ 环境音层只保留弱风声/沉重呼吸；④ 混音时检查是否存在三轨以上同时满音量。
- 人物与环境脱节：原因是尺度比失真或场景引用不统一。解决步骤：① 人物面积占比 <2%、建筑为人物 50-100 倍写进提示词；② 同场景连续镜强制同一张四格场景图；③ 逐镜核对场景引用无遗漏；④ 逆光剪影让主体轮廓融入环境光场。
- 尺度被模型缩小：原因是缺少量化参照。解决步骤：① 提示词写入具体比例（人物 1.7m，建筑 120m）；② 加入中间参照物（路灯/车辆/门洞）递进尺度；③ 检查人物是否被误放大，必要时用图生图重制场景四格图。
