
name: 东亚作者电影氛围营造
description: >-
  适用于制作情绪驱动、去情节化的东亚艺术电影风格短片，以呼吸式节奏、负空间与向内收敛的情感表达为核心。
  用户提供情感走向、剧本或参考影像时触发，负责情感轨迹确认、分镜设计、逐镜生成与呼吸式剪辑组装。

## 技能定位

本技能是一套"情绪驱动氛围电影"制作方法论，叙事引擎不是事件推进而是人物情绪随时间缓慢变化：观众感受到的不是"发生了什么"，而是"角色内心有什么在慢慢改变"。方法论强调三点：一是"先确认情感轨迹而非剧情大纲"——开工先与用户对齐"观众感觉如何变化"，再落到规格；二是"内向表达纪律"——东亚式情感用微表情、环境共鸣与物件隐喻承载，禁止直接哭泣、嘶吼、肢体爆发等外向表演；三是"呼吸式结构"——全片按吸气（情绪铺设）→ 屏息（情绪凝滞）→ 呼气（情绪释放）编排，镜头间以黑场与空镜缓冲，禁止硬切。

## 适用场景

- 情感留白、生活流、家庭与孤独主题的短片；诗性叙事与观察式影像。
- 用户只有情绪方向（如"黄昏的告别感"）而没有完整剧情时的工作流。
- 需要微表情、空镜转场、物件符号叙事、声画分离承载情感的项目。
- 情绪浓度高于信息量的个人表达、品牌氛围片、城市漫游影像。

## 制作流程

### 第一步：确认情感轨迹

与用户对齐"情绪的起点与终点"以及中间的变化曲线，而非剧情事件；整理成规格文件。规格至少包含下表字段，缺省值按括号标注，未对齐前不得进入分镜。

| 字段 | 内容要求 | 默认值/判定标准 |
| --- | --- | --- |
| 标题 | 一句话情绪命题（如"黄昏的告别感"） | 必须可被观众感知而非剧情概括 |
| 情绪主题 | 3-5 个情绪关键词，按浓度排序 | 全片只能有 1 个主情绪、2 个次级情绪 |
| 情绪曲线 | 起点→中段→终点三档浓度（低/中/高） | 曲线不得平直，必须存在至少一次"屏息"平台期 |
| 预计时长 | 目标成片时长 | 15-90 秒，默认 30 秒 |
| 画幅 | 16:9 / 9:16 / 2.39:1 | 默认 16:9，竖屏另需重排构图 |
| 语言 | 对白/旁白语言，可为"无语言" | 默认无对白 |
| 视觉氛围 | 光线方向、色温倾向、天气、时段 | 与情绪主题一致，记录为全局色调契约 |

### 第二步：设计分镜

重点不是推进事件，而是设计停顿、负空间与情绪流动：每 3-4 个镜头构成一个情绪单元（总时长 30-50 秒），单元之间用 1-2 秒黑场或 8-12 秒环境空镜过渡。每个镜头必须按下表登记，缺字段的镜头视为未完成：

| 字段 | 填写要求 | 判定标准 |
| --- | --- | --- |
| 镜头号 | 按单元-序号编号（如 U2-3） | 连续无跳号 |
| 场景锚定 | 场景元素 ID、时段、主光源方向 | 同场景镜头必须复用同一场景图 |
| 角色状态与微动作 | 眼神移开、指节微动等，禁止剧烈动作 | 动作幅度上限="能被画框安静容纳" |
| 运镜方式 | 从允许清单中选一（静态/极慢推/轻微手持漂移/极慢横移） | 单镜只允许一种运镜 |
| 情绪阶段标注 | 铺设/累积/峰值/释放 | 与情绪曲线表对照，不得跳段 |
| 时长 | 单镜不低于 6 秒 | 6-15 秒，默认 8 秒 |
| 声音备注 | 该镜主导声音层（环境/单乐器/静默/音乐） | 与情绪-声效映射表一致 |

情绪单元内部的镜头次序遵循"起-承-转-留"：起=环境/空间建立；承=角色微动作累积；转=物件或光线变化；留=留白定格。检查点：分镜完成后暂停，等待用户确认整体节奏与情绪结构；用户反馈"节奏太快/太慢"时，优先调整空镜与黑场密度而非重排镜头。

### 第三步：生成关键元素

角色元素重点描述稳定外貌特征（年龄感、肤色、发型、衣物质感）与情绪性格（"习惯用沉默代替表达"），刻意避免完美妆容；场景元素描述"生活痕迹"（旧壁纸、乱中有序的厨房、窗台盆栽）并记录主光源方向与时段；反复出现的象征物件单独注册为元素资产，并描述其随情绪阶段的状态变化（同一只杯子：冒热气 → 无热气 → 被收走）。元素描述模板：

```
角色：{年龄感}岁{性别}，{肤色}，{发型}，{衣物质感}；
性格化描述：{一个具体习惯动作或沉默方式}；
场景：{空间类型}，{生活痕迹细节1}、{细节2}、{细节3}，
主光源{方向}，时段{晨/午/黄昏/夜}；
象征物件：{物件名}，情绪阶段状态变化链：{初始态}→{累积态}→{峰值态}→{释放态}。
```

检查点：元素生成后暂停，等待用户确认视觉方向"氛围对不对"。若用户说"太精致/太像广告"，删除完美妆造与高光反射描述，追加"aging textures, lived-in details, imperfect surfaces"。

### 第四步：逐镜生成视频

以角色与场景元素图为参考，严格按镜头描述中的情绪、空间关系与呼吸节奏执行；单镜 6-15 秒；仅当与上一镜有极强的视觉连续性（同一空间同一角色的连续动作）时附加尾帧参考。生成前自查清单（任一答案为"是"即改写镜头）：

- 是否存在"强加戏剧冲突"的镜头？（改为负空间/转喻/声画分离/情绪余震）
- 是否有人物直接表演强烈情绪？（改为空镜、环境变化、物件细节或让声音承载）
- 是否缺乏停留感？（单镜时长不足 6 秒或动作过密）
- 镜头间是否有呼吸空隙？（没有则补空镜或黑场）
- 情绪推进是否太"直白"？（应在峰值前设置至少一个屏息镜头）
- 东亚场景是否被拍成"游客视角"？（对照本地纹理清单检查）

失败处理：单镜生成失败只在同规格内重试该镜，不换风格词；连续两镜失败则回退检查该镜运镜是否越界或动作是否超幅度，修正描述后重生成。

### 第五步：生成音频层

声音不止补充画面，而是承载"情绪连续性"。按下表映射，不得错位：

| 情绪阶段 | 画面内容 | 主导声音层 | 音频特征 |
| --- | --- | --- | --- |
| 铺设（吸气） | 长镜固定机位、空间建立 | 环境声 | 鸟鸣、远处车流、钟摆、水龙头 |
| 累积（屏息） | 负空间、微动作 | 单一乐器线 | 单音钢琴、大提琴长音，低频持续 |
| 峰值 | 空镜、物件特写（声画分离） | 音乐主导 | 音量略升，和声加厚，画面几乎静止 |
| 释放（呼气） | 环境空镜、物件特写 | 环境声"变空" | 风声、远人声渐远，音量低于开头 |

连续 3 镜以上无音效/音乐变化时，第 3 镜结尾必须引入微弱音效层（单音钢琴或环境声变化），防止观众注意力漂移。峰值段执行声画分离——画面给空镜与物件，情绪全由音乐承载。

### 第六步：呼吸式剪辑组装

全片节奏模拟呼吸频率：吸气段长镜固定机位建立空间感；屏息段延长单镜负空间、不加速，音乐/环境声权重大于画面；呼气段用空镜或物件特写配合"变空"的音效。转场纪律：镜头间用 1-2 秒黑场淡入淡出或插入 6-8 秒环境空镜；情绪单元内部用约 1 秒短黑场，单元之间用长空镜或 2 秒长黑场；禁止硬切与任何花哨转场（划像、缩放转场、光效转场均禁止）。全片最后一镜结束后保留 2-3 秒纯黑加音频淡出再进片尾。慢动作只用于微时刻（回头、伸手、闭眼、雨滴落水），减速 2-3 倍封顶，禁止对动作戏使用，同一段素材不得做两次减速。

## 提示词模板

**基础结构：** `[风格锚定词×3] + [光线条件] + [主体/角色状态] + [具体微动作] + [环境细节] + [情绪方向] + [质感词×2] + [运镜指令] + [负向约束]`

占位符填写规则：

| 占位符 | 填写要求 | 示例 |
| --- | --- | --- |
| 风格锚定词 | 至少 3 个，从锚定词表选 | slow cinematic, observational, emotionally restrained |
| 光线条件 | 一个主光源 + 方向 + 质感 | 黄昏窗边侧光，柔和的自然光 |
| 主体/角色状态 | 谁 + 处于什么静止状态 | 深夜小厨房餐桌前独坐的女性 |
| 具体微动作 | 部位 + 动作 + 幅度，禁止心理描写 | 目光空茫，肩头有细微的呼吸起伏 |
| 环境细节 | 2-3 个生活痕迹物件 | 面前的冷饭菜未动，头顶荧光灯投下苍白阴影 |
| 情绪方向 | 一个情绪词或情绪短语 | quiet stillness |
| 质感词 | 至少 2 个 | film grain, muted cool tones |
| 运镜指令 | 从允许清单选 1 个 | static camera |
| 负向约束 | 固定负向块 | no fast motion, no dramatic acting, no bright colors, no text |

**锚定词表（每次至少选 3 个）：** slow cinematic、observational、emotionally restrained、East Asian arthouse、intimate、contemplative、naturalistic。

**质感词表（至少选 2 个）：** film grain、soft focus、natural lighting、muted palette、shallow depth of field。

**运镜允许清单（必选 1 个）：** static camera / subtle handheld, gentle drift / very slow push-in / slow lateral tracking。

**固定负向块：** no fast camera movement, no dramatic acting, no direct crying or shouting, no bright saturated colors, no text, no watermark。

**示例成句（情绪单元·独处）：**
```
slow cinematic, static camera, low angle, 深夜小厨房餐桌前独坐的女性，
面前的冷饭菜未动，头顶荧光灯投下苍白阴影，她目光空茫，
肩头有细微的呼吸起伏，杂乱的厨房背景与老化壁纸，
quiet stillness, film grain, muted cool tones, shallow depth of field,
East Asian apartment interior, no fast motion, no text
```

**示例成句（声画分离空镜）：**
```
slow cinematic, static camera, 老旧公寓楼的空走廊，
午后阳光穿过积尘的窗户，光柱中浮尘漂浮，完全静止无人，
门边一双旧拖鞋，worn tiles, atmospheric silence,
film grain, warm muted tones, no people, no text
```

## 风格关键词与参数表

**核心关键词清单：** slow cinematic、observational、emotionally restrained、East Asian arthouse、intimate、contemplative、naturalistic、quiet stillness、worn textures、aging architecture、humid air、monsoon season、film grain、muted palette、soft focus、negative space。

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 6-15 秒（默认 8 秒） | 低于 6 秒破坏停留感 |
| 情绪单元时长 | 30-50 秒（3-4 镜） | 单元间留呼吸 |
| 成片时长 | 15-90 秒（默认 30 秒） | 不建议超过 3 分钟 |
| 画幅 | 16:9 默认，9:16 / 2.39:1 可选 | 竖屏需重排负空间构图 |
| 分辨率 | 720p 生成，1080p 输出 | 保留胶片颗粒质感 |
| 帧率 | 24fps | 禁 60fps 的"视频感" |
| 节奏 | 慢；每 10 秒至少 1 处停顿/空镜 | 剪辑点密度 ≤6 个/分钟 |
| 黑场 | 单元内 1 秒，单元间 2 秒 | 收尾 2-3 秒纯黑 |

**禁用项清单：** 硬切、快推快拉、甩镜、环绕、无人机俯冲、单镜内频繁变焦、直接哭泣/嘶吼/肢体爆发、多人强互动、单镜复杂场景转换、对白解说化、慢动作超过 3 倍速、高饱和撞色、游客视角的景点大全景。

## 进阶技巧

- 物件符号叙事：用同一物件跨镜状态变化表达时间与关系——"时间流逝"用同一只杯（冒气→无气→收走）；"关系破裂"用两把椅（并排→空一把→被移走）；"等待"用窗台盆栽（发芽→生长→枯萎）；"决定离开"用行李箱（角落→拖出→出现在门口）。物件状态变化链在元素注册时就写死，跨镜复用同一资产。
- 声音与画面分离承载爆发：必须表现强烈情绪时，画面给环境/物件/空镜，情绪全部交给音乐与音效——这是情绪峰值段的最高优先级手法，也是规避模型崩坏的第一选择。
- 情绪前置/后置：爆发前拍"前一秒"（眼眶湿润但未哭、指节握紧但未砸桌），爆发后拍"后一秒"（空椅子、碎杯子、雨中的空街）。两招配合，观众会自行补完中间的情绪爆发。
- 转喻替代：用环境突变代替人物情绪（灯突然熄灭、纸被风吹走、门被关上）——环境变化比人脸表演更稳、更耐看。
- 拍摄"当地人日常的东亚"而非"旅游宣传的东亚"：窄巷、阳台晾衣、菜市场、便利店夜灯、老居民楼楼梯间、雨天骑楼；元素写入场景描述与提示词（local texture, humid air, aging architecture, monsoon season）。
- 一致性控制：同一空间的连续镜头强制复用同一张场景元素图；拍摄时段的光线方向写入每镜提示词（"黄昏窗边侧光"），防止相邻镜光线跳变。
- 迭代策略：先出"情绪单元样片"（3-4 镜、30 秒内）给用户确认情绪浓度，再批量扩片；样片阶段调整比全片返工便宜一个数量级。

## 常见问题

- 模型崩坏场景：激烈情绪爆发（哭喊/砸物）、快速运动（奔跑/打斗）、多人强互动、单镜复杂场景转换都容易变形。对策：一律先在分镜层替换为声画分离、情绪前置/后置、转喻方案，禁止直接生成；确需保留时拆成多镜并降低动作幅度。
- 运镜越界：快推快拉、甩镜、环绕、无人机俯冲、单镜内频繁变焦都会破坏氛围或导致主体变形。对策：只从允许清单选运镜；发现越界立即改回静态或极慢推，并重生成该镜而非硬接。
- 对白与旁白抢位：画面内同期声与独立旁白重叠时必须检查时间线并手动错开，旁白优先级高于模型自带同期声。对策：音频层先定旁白位置，再补环境声，最后检查重叠区间并给旁白让路。
- 慢动作过度降速导致模糊：减速限制在 2-3 倍，同一段素材不得做两次减速处理；需要更慢时回到生成端重新生成，不用二次减速。
- 情绪单元节奏单调：全片只有一种节奏等于没有呼吸。对策：按吸气-屏息-呼气重排情绪曲线，段落间用黑场与空镜制造落差；逐单元核对情绪阶段标注是否重复。
- 提示词写动机不写画面：不写角色心理与画外背景，只写镜头能拍到的东西——"她慢慢翻开桌上的文件，目光停在第 3 行，手指无意识地敲着桌面"，而不是"她在思考"。自查方法：提示词里每个词都必须能被摄像机拍到。
