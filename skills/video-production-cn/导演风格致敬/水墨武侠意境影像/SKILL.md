# 水墨武侠意境影像

## 技能定位

本技能以五行配色爆发体系为核心制作水墨武侠动画：火红、水蓝、木青、土褐、金白的爆发配色按固定比例组合，鞭甩镜头（急推、急拉、横扫）制造高速动感，黑白水墨闪定格强化碰撞冲击，书法字卡标记技能与角色登场。全片 16:9、720p，线稿随镜头动能切换（静态工笔、高速焦墨）。产出形态为 30-90 秒高强度打斗短片：单镜 4-12 秒，五行爆发配色、动作编排、声音设计均按硬参数执行，逐镜质检合格才进入剪辑，任何"像 CGI"的镜头一律回炉。

## 适用场景

- 高强度水墨打斗动画短片（单镜 4-12 秒）。
- 五行元素、法术对决题材。
- 用户提供角色设定或打斗创意的项目。
- 需要书法字卡与国风配乐的动画内容。
- 不适合：无战斗的纯文戏长片、现代题材动作（武器与场景假设不匹配）、需要写实物理质感的内容。

## 制作流程

### 风格关键词与禁用清单

主风格标签（每镜提示词开头固定沿用，保证全片风格统一）：

| 类别 | 关键词 |
| --- | --- |
| 基础风格 | 水墨写意、泼彩叠彩、石绿、石青、朱砂、赭石、洒金 |
| 静态线稿 | 工笔细描、湿晕、宣纸留白 |
| 高速线稿 | 粗犷焦墨勾线、枯笔飞白、爆裂泼墨 |
| 特效媒介 | 矿物泼彩碎屑、金箔爆裂碎屑、焦墨烟尘、宣纸纸灰、飞白霜沫 |
| 碰撞转场 | 墨晕开、飞白拖尾、墨色蔓延 |

禁用词清单：

| 禁用词 | 原因 | 替代方向 |
| --- | --- | --- |
| 3D 渲染、CGI | 破坏水墨二维感 | 矿物系特效词 |
| 写实照片 | 破坏墨色质感 | 宣纸纹理词 |
| 西方水彩 | 笔触与用色体系不同 | 水墨晕染词 |
| 平滑现代动漫 | 高光与线条不符 | 焦墨枯笔词 |
| 魔法粒子、体积烟 | 特效显 CGI | 矿物泼彩、焦墨烟尘 |

### 第一步：锁定规格

写规格档案并逐项确认：

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 画幅 | 16:9 | 16:9 | 本技能锁定横屏，不支持竖屏 |
| 分辨率 | 720p | 720p / 1080p | 确认后全片统一，禁止中途升档 |
| 目标时长 | 60 秒 | 30-90 秒 | 决定打斗段落数量（约 1 主战+1-2 小战） |
| 单镜时长 | 按强度分档 | 4-12 秒 | 严禁低于 4 秒、严禁统一默认 5 秒 |
| 帧率 | 24fps | 24 / 30 | 定格与加速计算的帧数基准 |
| 语言 | 中文 | 中文 | 配音、字幕、字卡语言统一 |
| 打斗强度 | 中高 | 轻/中/高 | 决定配色浓度与闪定格频率 |

### 第二步：分镜设计

产出结构化分镜：核心角色/场景关键元素、镜头表（含书法字卡）、独立音轨。镜头时长按强度分档：

| 时长档 | 适用内容 | 动作密度要求 | 字卡/音轨特征 |
| --- | --- | --- | --- |
| 4-6 秒 | 高速打斗、瞬移、特写 | 动作节拍 2-3 拍 | 短促音效点、可无字卡 |
| 6-9 秒 | 连招、终极碰撞 | 连招链条完整 | 技法字卡落点、战鼓砸点 |
| 9-12 秒 | 对话、蓄力、氛围空镜 | 蓄力要有可视变化 | 角色登场字卡、BGM 铺陈 |

对话单句不超过 10 字，按 2-3 字/秒预算口型时长。

镜头表结构：

| 镜头 | 时长 | 景别 | 运镜 | 画面内容要点 | 五行爆发配色 | 字卡内容 | 音效标签 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01 | 5 秒 | 全景 | 急推 | 对峙起势、墨色流动 | 火 70% | 无 | 风压声、衣袍猎猎 |
| 02 | 7 秒 | 特写 | 横扫 | 出招—相击—爆裂 | 金 50% | "金锋" | 金属交鸣、爆响 |

判定标准：每镜五行配色标注与爆发内容对应（火系招式才标火配色）；字卡镜头写出文案与落点时刻，未写即回补；音效标签与动作特效吻合，不吻合的改提示词。

### 第三步：资产准备

- 角色必须标准三视图；场景必须无人物四宫格（全景定场/陈设特写/纵深透视/气氛光效）。
- 用户素材风格不符或格式不合规时，以原图为空间配色参考重建 2K 三视图与四宫格，严禁直接绑定不合规资产。

| 素材类型 | 合规标准 | 不合规处理 |
| --- | --- | --- |
| 角色图 | 三视图、水墨武侠风、全身 | 以原图为配色参考重建 2K 三视图 |
| 场景图 | 无人物四宫格、四格分工正确 | 重建四宫格并逐格说明分工 |
| 道具图 | 有特写戏份的道具单独出图 | 补绘，与主武器配色一致 |

- 同一场景 ID 全片绑定唯一四宫格资产，绝对禁止不同批次场景图（源头上根治场景跳切）。
- 五行爆发配色比例固定（三项分别为主色/辅色/点缀色）：

| 五行 | 配色比例 | 典型媒介 | 适用招式 |
| --- | --- | --- | --- |
| 火 | 70/30 | 朱砂熔金对焦墨骨架 | 烈焰、爆破、怒击 |
| 水 | 60/25/15 | 深蓝墨、飞白霜、冰刃 | 寒潮、巨浪、冰封 |
| 木 | 65/20/15 | 藤蔓主色、辅色、点缀 | 生长、束缚 |
| 土 | 55/35/10 | 飞沙主色、辅色、点缀 | 山石、防御、镇压 |
| 金 | 50/35/15 | 金光主色、辅色、点缀 | 刀气、剑芒、切割 |

### 第四步：逐镜生成

- 生成前铁律预检：角色引用齐全、场景 ID 唯一绑定四宫格资产、对话 100% 进语法块、动作特效运镜与音效标签吻合、音色凭证绑定。预检清单逐项勾选：

| 预检项 | 合格标准 | 不达标动作 |
| --- | --- | --- |
| 角色引用 | 出场角色均绑定三视图 | 补绑后再生成 |
| 场景绑定 | 场景 ID 唯一对应四宫格 | 更正绑定 |
| 对白 | 100% 进入语法块且带情绪标签 | 回写格式 |
| 动作-特效-音效 | 三者标签吻合 | 改提示词 |
| 音色凭证 | 有对白角色绑定声音样本 | 绑定后再生成 |

- 主风格标签开头（水墨写意+泼彩叠彩：石绿/石青/朱砂/赭石/洒金）。
- 线稿随动能切换：

| 动能状态 | 线稿描述 | 使用场景 |
| --- | --- | --- |
| 静态 | 工笔细描、湿晕、宣纸留白 | 对峙、对话、蓄力、空镜 |
| 高速 | 粗犷焦墨勾线、枯笔飞白、爆裂泼墨 | 冲刺、连招、爆发、击飞 |

- 四宫格参考必须加防分屏声明链：逐格解释四格内容并要求合成单一连续空间，否则视频会被生成成四格拼贴。
- 负向词：3D 渲染、CGI、写实照片、西方水彩、平滑现代动漫。
- 高连续性镜头可加前镜成片作参考视频并继承末帧动势（方向/姿态/残粒）。

镜头生成提示词模板：

```
水墨写意+泼彩叠彩动画镜头{镜头号}：{景别}，{运镜}，时长{秒数}秒。
{线稿状态描述}。画面内容：{动作逐拍}，{五行爆发效果与配色比例}，
{环境与墨色流动}。角色{角色名}按绑定三视图形象出现，{该镜服饰与状态}。
场景四宫格参考说明：左上{全景定场}、右上{陈设特写}、左下{纵深透视}、右下{气氛光效}，
请将四宫格特征合成单一连续空间，禁止分屏、禁止拼贴、禁止格线。{字卡内容与出现时刻，若有}。{对白与情绪标签，若有}。
负向词：3D渲染、CGI、写实照片、西方水彩、平滑现代动漫。
```

占位符说明：{镜头号} 与分镜表一致；{线稿状态描述} 按上表静态/高速二选一；{动作逐拍} 至少 2 拍并写明发力方向；{五行爆发效果} 写清配色比例与媒介（矿物泼彩碎屑/金箔碎屑/焦墨烟尘）。示例成句："水墨写意+泼彩叠彩动画镜头07：特写，横扫，时长6秒。粗犷焦墨勾线、枯笔飞白、爆裂泼墨。画面内容：横刀出鞘—刀光横扫—正中冰柱，冰柱碎裂为飞白霜沫，金 50/35/15 配色，墨色沿裂纹蔓延。角色刀客按绑定三视图形象出现，劲装束发。场景四宫格说明：左上峡谷全景、右上刀架特写、左下纵深石径、右下战前晨光，请将四宫格特征合成单一连续空间，禁止分屏、禁止拼贴、禁止格线。字卡"金锋"于第 2 秒砸入。无对白。负向词：3D渲染、CGI、写实照片、西方水彩、平滑现代动漫。"

失败处理：单镜生成崩坏或像 CGI，先查负向词是否齐全、特效媒介词是否为矿物系（禁止魔法粒子/体积烟），修正后重试，最多 3 次；连续 3 次失败暂停，复核该镜四宫格资产与配色标注，回退到资产环节。

### 第五步：声音生成

- 角色音色与宿命感说书老人旁白；国风 BGM 与刀剑/技法爆炸音效。

| 声音层 | 内容 | 参数要求 |
| --- | --- | --- |
| 角色音色 | 按角色设定锁定音色画像 | 跨镜绑定同一音色凭证 |
| 旁白 | 宿命感说书老人 | 语速 180-240 字/分钟、气声低沉 |
| BGM | 国风器乐 | 战斗段鼓点密度与动作节拍对齐 |
| 音效 | 刀剑交鸣、技法爆炸 | 峰值留余量，命中点毫秒对齐 |

- 口型波形与开口帧毫秒对齐（±20 毫秒）。

### 第六步：剪辑合成

节奏参数表：

| 操作 | 参数 | 说明 |
| --- | --- | --- |
| 打击前摇压缩 | 0.2-0.4 秒 | 前摇过长会泄劲 |
| 命中定格 | 1-2 帧 | 微重力定格，配黑白闪 |
| 击飞加速 | 1.5-2 倍速、0.8-1.2 秒 | 尾部加 0.2-0.3 秒指数衰减 |
| 连招编辑 | 轻到重 | 试探不冻结，终结一击 2-3 帧定格+大闪 |
| 字卡 | 硬切入+1.5-2 秒画面冻结 | 古钟战鼓零延迟砸入、BGM 归零 |

战斗瞬间环境声压低且单声道塌缩；五行碰撞做动态 EQ 雕刻（如金克木削 2-6kHz、水克火削 150-500Hz）：

| 相克组合 | EQ 雕刻 | 听觉效果 |
| --- | --- | --- |
| 金克木 | 削 2-6kHz | 金属切割感、空间变窄 |
| 水克火 | 削 150-500Hz | 蒸汽嘶鸣、能量被压熄 |

### 第七步：全片质检

合成完成后按清单终检，任何一项不达标都回到对应步骤返工：

| 质检项 | 合格标准 | 不达标返工点 |
| --- | --- | --- |
| 五行配色 | 每镜配色标注与爆发内容对应，比例正确 | 回第四步重写重生成 |
| 线稿匹配 | 静态无焦墨、高速无工笔 | 回第四步改线稿状态 |
| 字卡落点 | 字卡时刻与画面冻结、战鼓砸点三者同帧 | 回第六步重排 |
| 打击节奏 | 前摇、定格、击飞参数全部生效 | 回第六步调整 |
| 口型对齐 | 开口帧偏差在 ±20 毫秒内 | 回第五步重对齐 |
| 无 CGI 感 | 特效媒介全部为矿物系，烟尘有双重质感 | 回第四步重生成 |

交付物：规格档案、镜头表、提示词草稿、资产图、字卡文案、音轨、成片，确认后交付。

## 进阶技巧

- 鞭甩镜头三件套的可执行细则：1) 急推——用于蓄力、爆点、面部极特写，推进速度取中快（0.5-0.8 秒），推到极特写时定格 1 帧再接爆发；2) 急拉——用于冲击波扩散、击飞，先快后慢，尾部留出墨色残影扩散空间；3) 横扫——用于闪避、近身混战，镜头扫速与角色位移速度同步，背景墨色高速失焦成印象流线。三条规则：单镜内只做一种主运动，禁止推拉扫叠加；鞭甩落点必须是动作节拍点；鞭甩前后各留 4-8 帧缓冲防眩晕。
- 五行相克强色彩对比（碰撞时使用）：

| 相克 | 视觉表现 |
| --- | --- |
| 水克火 | 巨浪墨染熄焰成白汽 |
| 火克木 | 烈焰沿藤蔓如墨蔓延炭化 |
| 木克土 | 狂草藤蔓刺裂枯笔巨石 |
| 土克水 | 飞沙吸干墨流 |
| 金克木 | 金光白刃风扫断藤 |

使用时保证被克方配色比例先占满画面再被吞噬，形成"满场—吞没—余烬"三拍，节奏与战鼓砸点对齐。

- 一致性控制与迭代策略：1) 动势矢量对齐硬切——前镜发力方向与后镜受力方向同轴，剪辑时逐对检查（发力向左则受力向右或同向卸力），错轴重排；2) 0.2-0.5 秒多重水墨残影桥接镜头；"墨晕开""飞白拖尾"作文戏转场；3) 先做"单镜五行爆点验证"——挑最高强度碰撞镜完整跑通（画面+音效+定格），达标后再批量，批量按"同场景同资产"分组；4) 长卷式微速横摇加画面"呼吸"（边缘墨色渐隐渐显、云雾微速吞吐），空镜统一用此节奏。
- 翻车点规避：特效像 CGI 的根因是用了魔法粒子、体积烟等通用特效词，替换为矿物泼彩碎屑、金箔爆裂碎屑、焦墨烟尘、宣纸纸灰；烟尘边缘须"枯笔刮擦+湿晕"双重质感；逐镜核对线稿与动能匹配，静态镜出现焦墨飞白即回改。

## 常见问题

- 生成四格拼贴：原因：四宫格参考缺少防分屏声明，或逐格说明被省略。解决步骤：1) 检查提示词是否含"将四宫格特征合成单一连续空间，禁止分屏、禁止拼贴、禁止格线"；2) 补上逐格说明（左上全景定场、右上陈设特写、左下纵深透视、右下气氛光效）；3) 重新生成并核对无分隔线；4) 仍失败则重绘四宫格图。
- 场景跳切：原因：同一场景 ID 绑定了不同批次场景图，或镜头未绑定场景资产。解决步骤：1) 核对分镜表场景 ID 与绑定资产；2) 全片统一为同一四宫格资产；3) 重生成受影响镜头；4) 将同场景同图列入铁律预检。
- 特效像 CGI：原因：负向词缺失，或特效媒介用了通用特效词（魔法粒子、体积烟）。解决步骤：1) 补全负向词（3D 渲染、CGI、写实照片、西方水彩、平滑现代动漫）；2) 特效媒介词全部替换为矿物系（矿物泼彩碎屑、金箔爆裂碎屑、焦墨烟尘、宣纸纸灰）；3) 烟尘类特效加"枯笔刮擦+湿晕双重质感"；4) 重生成并逐镜比对。
- 口型对不上：原因：音色凭证未跨镜绑定，或口型波形与开口帧未对齐。解决步骤：1) 确认该角色声音锚点已绑定；2) 按台词字/秒预算核对口型时长；3) 以波形开口帧为基准对齐（±20 毫秒）；4) 仍偏移则缩短该句或重生成该镜。
- 情绪表演单一：原因：把"疲惫"等状态当统一标签，缺乏生理细节与墨媒介外化。解决步骤：1) 情绪爆发走生理细节（咬牙、青筋、瞳孔收缩）；2) 加墨媒介重塑（泪汗血用枯笔墨痕、飞白刮痕外化）；3) 提示词写清"情绪阶段+生理细节+墨媒介"后重生成。
- 模型报错：原因：中途切换模型或资产格式冲突。解决步骤：1) 全片锁定同一模型，报错不降级；2) 立即暂停并向用户反馈问题与上下文；3) 待恢复后从断点镜头重试，禁止用低规格替代。
