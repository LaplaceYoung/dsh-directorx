# 伊斯特伍德式西部片

## 技能定位

本技能将意大利西部片的视觉语言系统化：褪色胶片感、风沙漫天的边境小镇、牛仔与赏金猎人的宿命对峙，以及"极端静止到瞬间爆发"的决斗节奏。核心是把"对峙的张力"通过空间锁定、长焦特写与极简对白翻译成可执行的镜头序列，产出具有古典史诗宿命感的决斗短片。

## 适用场景

- 以双人对决为核心情节的短片（街头拔枪、峡谷对峙、酒馆冲突）。
- 需要表现孤独、荒凉、宿命感的角色小传或品牌叙事。
- 用户提供角色或场景照片，希望进行西部风格转绘与动态化。
- 需要口哨、风沙、金属马刺等标志性声音层次的西部主题片。

## 制作流程

### 第一步：建立全局规格书

开工前先写一份全片规格档案，作为所有下游环节的参数锚点，包含：

| 字段 | 默认值/要求 |
| --- | --- |
| 项目名与对决主题 | 必填 |
| 类型定位 | 动作 / 心理对峙 / 西部片 |
| 画幅 | 默认 16:9 电影宽银幕；短视频平台可切 9:16 |
| 分辨率与帧率 | 默认 720p，最终成片升格至 24 或 30fps |
| 输出语言 | 对白与旁白的语言 |
| 视觉风格 | 风蚀粗粝、褪色胶片、逆光体积光、高对比明暗 |
| 音频基调 | 口哨主题、风声、风铃、金属马刺声 |

检查点：画幅、分辨率、风格、音频基调四项参数确认无误后再进入分镜。

### 第二步：素材分析与资产重建

用户提供参考图时，先做格式与风格双重校验：

- 角色图必须是全身三视图（正/侧/背并排的完整全身像）；半身像、头像一律判定格式不符，需要重建。
- 场景图必须是无人物的四宫格参考图：左上全景建立、右上道具特写、左下透视纵深、右下氛围光。
- 风格不符时按原图脸型与空间结构重绘，服装改为宽檐帽、披风、皮质枪套、皮靴，保留用户原面部特征。
- 上传参考视频则提取运镜路径、动作反馈（拔枪瞬间、枪烟扩散、中弹颤抖）与光影质感，写入分镜描述。

检查点：每个关键角色与场景元素都绑定资产编号，缺绑定禁止进入视频生成。

### 第三步：分镜设计与空间锁定

遵循"先对峙、后爆发"的两阶段节奏：

- 对峙阶段（约六成篇幅）：用超长焦中景或过肩镜头建立"对峙空间锁"——明确双方站位、距离、朝向、画面左右与纵深轴、弹道与倒地方向。此后所有特写只能改变景别，不得改变两人真实距离与位置。空间锁参数写进分镜：A 位（左 1/3、面向右）、B 位（右 2/3、面向左）、两人间距（如 12 步）、弹道轴线（画面水平中线）、倒地方向（沿弹道反向）。
- 细节特写一律对切，不得用"两人的手"这类同框模糊描述。
- 对白极简，用省略号引导疲惫沙哑的停顿式念白。
- 爆发阶段（约四成篇幅）按下表编排：

| 节拍 | 内容 | 镜头要点 | 时长 |
| --- | --- | --- | --- |
| 拔枪 | 手落压枪套 | 特写、悬停蓄力-握柄-滑出枪套物理过程 | 1.5 秒内 |
| 枪口火光 | 低角度中近景、青白浓烟 | 火光与烟扩散同帧 | 1-2 秒 |
| 子弹擦帽 | 微距慢动作 | 帽沿、弹道、尘埃 | 2-3 秒 |
| 中弹倒地 | 继承空间锁 | 背先着地、沙尘环形炸开、沿弹道反向 | 2-4 秒 |
| 收尾 | 缓拉远景、落日剪影 | 固定机位缓拉 | 3-5 秒 |

### 第四步：生成视觉资产

- 无参考图时，用文生图生成全身三视图与四宫格场景图，强制完整全身（帽子、披风、腰带、枪套、皮靴、整体剪影），禁止半身与头部特写。
- 有参考图但格式不符时，用图生图按重建计划转绘。
- 生成后逐一校验所有分镜中的角色与场景元素均已绑定资产。

检查点：所有元素绑定完成前，禁止进入分镜视频生成。

### 第五步：逐镜头生成视频

- 单镜头时长控制在 4-15 秒，低于 4 秒的镜头禁止生成。
- 每个镜头必须同时绑定角色资产与场景四宫格作为参考图（双重锚定），防止背景漂移与角色跳变；相邻强动作衔接镜头可额外绑定上一镜成片作参考视频。
- 含对白的镜头必须绑定该角色的声音资产，保证音色跨镜头一致。
- 眼部特写即使不露全身，也要绑定全身三视图，防止模型幻觉出他人面孔。
- 拔枪、手指、压枪套等手部交互，提示词拆解为"悬停蓄力-握柄-滑出枪套"的物理过程描述。

### 第六步：音频设计与合成

- 音乐与音效独立分层：口哨主题、荒漠风声、金属风铃、马刺金属响、心跳节拍，逐层生成后叠加。
- 旁白选择低沉沙哑、风蚀感的经典男声。
- 转场默认硬切；仅场景大幅跳转或时间跨越时使用 1.5-2 秒黑场淡入淡出。
- 成片用超分与补帧升格至 24/30fps，保持粗粝质感的同时提升清晰度。

检查点：合成前展示所有单独生成的视频与音频资产，确认后再做最终时间线。

## 提示词模板

**角色三视图模板：**
```
[角色]全身三视图（正/侧/背并排），西部风格，宽檐帽、披风、皮质枪套、皮靴，
风蚀粗粝质感，褪色胶片色，高对比明暗，逆光体积光，
完整全身剪影，no half body, no head shot
```

**决斗对峙镜模板：**
```
超长焦中景/过肩镜头，[角色A]（左 1/3 面向右）与[角色B]（右 2/3 面向左）对峙，
两人间距[步数]，弹道轴线沿画面水平中线，风沙掠过，
风蚀粗粝、褪色胶片、高对比明暗、逆光体积光，
no camera whip, no fast zoom
```

**拔枪镜模板（物理过程三段式）：**
```
特写，[角色]右手悬停蓄力于枪套上方，随即握柄，迅速滑出枪套举枪，
慢镜捕捉枪口青白火光与浓烟扩散，
悬停蓄力-握柄-滑出枪套完整过程，no teleport
```

**示例成句（中弹倒地）：**
```
中景，子弹命中[角色B]胸口，身体沿弹道反向后仰，背先着地，
沙尘环形炸开，镜头缓拉远景，落日剪影，
风蚀粗粝、褪色胶片、高对比明暗，no teleport, no fast cuts
```

## 风格关键词与参数表

**核心关键词清单：** 意大利西部片、风蚀粗粝、褪色胶片、逆光体积光、高对比明暗、风沙弥漫、荒野小镇、宽檐帽/披风/皮质枪套/皮靴、超长焦、宿命感、极端静止到瞬间爆发。

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 对峙/爆发比例 | 6:4 | 对峙六成篇幅 |
| 单镜时长 | 4-15 秒 | 低于 4 秒禁止 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率/帧率 | 720p 生成，24/30fps 输出 | 超分补帧升格 |
| 转场 | 默认硬切 | 全片仅 1 次黑场淡入淡出 |
| 音频 | 口哨/风声/风铃/马刺分层 | 独立生成叠加 |

**禁用项清单：** 半身/头部特写做角色参考、同框模糊描述（"两人的手"）、快速变焦/甩镜、花哨运镜、超长对白、现代口音念白、无空间锁的乱切、多人混战。

## 进阶技巧

- 用马刺特写的金属声提前于画面 0.3-0.5 秒出现，制造"未见其物先闻其声"的压迫感；音效先于画面是西部片声音设计的标志手法。
- 风沙与尘埃是低成本氛围放大器：逆光下让飞尘穿过光束，中远景带轻微热浪扭曲；风沙方向全片保持一致（与弹道轴线垂直更出张力）。
- 决斗前的静默镜头故意留长 1-2 秒再开枪，观众在真空里自行积累紧张；静默镜内只保留风声与心跳节拍层。
- 中弹倒地方向必须与第一颗建立镜头的弹道方向一致：空间锁里写死的弹道轴线就是倒地方向，跨镜核对。
- 全片只允许一次"大尺度转场"使用黑场，其余全靠硬切；黑场留给时间跨越（如"次日"），滥用会稀释决斗节奏。
- 一致性控制：每镜双重锚定（角色三视图+场景四宫格）；拔枪镜拆三段物理过程描述防手部变形；对白镜绑定声音资产防音色漂移。
- 规避翻车：多人同框只出现在远景，中近景一律对切单人，防止身份混淆。

## 常见问题

- 角色在特写镜头间脸型漂移：原因：特写未绑三视图。解决步骤：特写也必须绑定全身三视图参考，且提示词限定五官描述范围（"保持三视图面部特征"）。
- 背景跳变：原因：镜头无场景锚定。解决步骤：每个镜头都强制绑定场景四宫格参考图，禁止无场景锚定的镜头。
- 手部变形：原因：瞬态动作直接生成。解决步骤：拔枪类镜头必须绑定角色与场景双重参考，并分阶段描述手的动作（悬停蓄力-握柄-滑出）。
- 对白太长：原因：现代叙事习惯残留。解决步骤：西片对白要"惜字如金"，长句会破坏对峙节奏并让配音显得现代；压缩到省略号断句的短句。
- 生成时长低于 4 秒被拒：原因：镜头设计过短。解决步骤：把动作合并进更长的镜头，或用补帧在合成期拉长；重排分镜保证单镜 ≥4 秒。
- 枪烟、马刺声等音频元素缺失：原因：音效未独立分层。解决步骤：音频要独立分层生成，先出音效层再混入音乐；音效头可提前 0.3-0.5 秒入画。
- 用户素材是半身照：原因：格式不符直接使用。解决步骤：先转绘为全身三视图再绑定，保留用户脸型特征；禁止直接以半身照进生成。
