# 汤浅政明式狂想动画

## 技能定位

本技能产出"情绪驱动的表现主义动画"：画面必须锚定在可辨认的真实生活空间（街道、车站、教室、居酒屋、出租屋、海边小镇），普通段落是日常的、可读的，空间扭曲与透视变形只在情绪升腾时逐步浮现。核心能量来自夸张表情、弹性节奏、空间扭曲与侵入式镜头的组合，而非肢体形变——四肢比例始终正常，禁止橡皮管拉伸、液化、碎片化。产出形态为 30-120 秒情绪爆发短片，遵循"日常可读→渐进失衡→极端释放"变形梯度，超现实变化须有可追溯的视觉来路。

## 适用场景

- 疯癫、狂喜、孩童式天真的情绪爆发短片。
- 梦循环、意识流、无限循环主题；奔跑突破、挣脱束缚的高潮段。
- 歌舞高潮段（群舞、原创歌）的动画短片。
- 适合有明显情绪弧线（压抑→爆发）的叙事；不适合信息量为主、情绪平缓的内容。

## 制作流程

### 风格关键词与禁用清单

核心关键词（按段落取用，普通段与高潮段用量不同）：

| 类别 | 关键词 | 使用提示 |
| --- | --- | --- |
| 手绘质感 | 手绘动画线条、线条轻微抖动、拼贴纹理、相纸颗粒、粗糙色块 | 每镜常驻 |
| 空间锚定 | 街道、车站、教室、居酒屋、出租屋、海边小镇 | 每镜开头写清一种 |
| 变形手段 | 地平线倾斜、鱼眼、建筑比例失衡、不对称几何、环境色突变 | 按情绪阶段取用 |
| 表情外化 | 瞪大的眼、大张的笑口、夸张挑眉、咧嘴哭嚎 | 按表情设定页取档 |
| 弹性节奏 | 瞬间加减速、停顿爆发、速度线、残影 | 爆发段使用 |

禁用项清单：

| 禁用项 | 原因 |
| --- | --- |
| 橡皮管拉伸、液化、碎片化 | 破坏"四肢比例正常"的核心设定 |
| 无来由的超现实意象 | 必须从上一镜元素生长出来 |
| 霓虹堆砌、赛博灯光 | 与现实锚点冲突 |
| 通用炫光、体积光 | 破坏手绘平面质感 |

### 第一步：锁定规格与叙事孵化

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 画幅 | 16:9 | 16:9 | 锁定横屏，不支持竖屏 |
| 分辨率 | 720p | 720p / 1080p | 确认后全片统一 |
| 目标时长 | 60 秒 | 30-120 秒 | 歌舞段约占 30-40% |
| 语言 | 日语 | 日语 / 中文 | 日语张力最饱满，中文需确认 |
| 帧率 | 24fps | 24 / 30 | 弹性节奏的帧数基准 |

用户只有零散灵感时，作为导演与编剧共创：套用"梦循环"或"奔跑"模板构思 2-3 个方案，暂停交用户选择；给全稿则严格按其构思推进。

| 模板 | 核心结构 | 关键场景建议 | 高潮落点 |
| --- | --- | --- | --- |
| 梦循环 | 同一清晨重复 N 次，细节逐次偏离 | 卧室、通勤路、教室或公司 | 第 N 次循环崩坏+奔跑 |
| 奔跑突破 | 日常压抑→一次奔跑挣脱 | 出租屋、走廊、街道、海边或车站 | 群舞或长镜奔跑+平面化切换 |

叙事方案提示词模板（用于共创阶段）：

```
围绕{核心人物}与{核心冲突}，按{模板名}模板构思{目标时长}秒短片。
方案需包含：1) 三段式情绪弧线（{压抑起点}→{升级转折}→{爆发终点}）；
2) 1-2 个核心视觉母题（反复出现的{物件/形状/颜色/手势}）；
3) 3 个表现性关键场景（{场景1}、{场景2}、{场景3}）；
4) 歌舞高潮段的位置与人数；5) 结尾落点画面。语言：{输出语言}。外化情绪，拒绝含蓄。
```

占位符说明：{核心人物}{核心冲突} 取自用户输入；{模板名} 梦循环/奔跑二选一；{压抑起点}{升级转折}{爆发终点} 各填具象场景词；{物件/形状/颜色/手势} 填母题候选。示例成句："围绕不愿起床的高中生与升学压力，按梦循环模板构思一支 60 秒的短片：三段情绪弧线（赖床麻木→闹钟错乱→掀翻书桌）、核心母题（歪斜的闹钟指针）、关键场景（卧室、楼梯间、天台）、歌舞段位置与结尾落点。"

### 第二步：分镜设计（扭曲递进规则）

变形程度必须随情绪强度逐级递进，不能每镜都极端扭曲。三级梯度与镜头手段绑定：

| 情绪阶段 | 变形强度 | 允许的手段 | 禁止项 |
| --- | --- | --- | --- |
| 普通段 | 轻微 | 地平线微斜、比例略夸张 | 鱼眼、大幅倾斜、建筑失衡 |
| 情绪升级段 | 失衡 | 鱼眼渐显、倾斜加大、建筑失衡 | 全屏扭曲、环境色突变 |
| 高潮段 | 极端 | 极端鱼眼、大幅倾斜、不对称几何、环境色突变 | 无（可全开） |

所有超现实变化必须从上一镜已有的动作、物体或视觉元素自然生长出来，禁止凭空切入无关的超现实意象。

镜头时长与节奏：

| 时长档 | 适用段落 | 节奏特征 |
| --- | --- | --- |
| 8-15 秒 | 安静流动段 | 长镜缓移、呼吸感节奏 |
| 4-6 秒 | 疯癫爆发段 | 高频动作镜、瞬间加减速 |

镜头表结构：

| 镜头 | 时长 | 情绪阶段 | 景别 | 运镜 | 变形手段 | 画面内容要点 | 声音/台词 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01 | 10 秒 | 普通 | 中景 | 缓推 | 地平线微斜 | 主角赖床、闹钟响、指针歪斜 | 闹钟滴答、哈欠 |

其他铁律：情绪表达全面外化，避免含蓄内敛；全片建立 1-2 个核心视觉母题并持续变奏；每镜声明场景 ID 并锁定四格参考图的特定子格；相邻切换镜优先换格，同格续接须注明意图。

歌舞群舞段规则：舞者肢体比例正常，靠高度同步与错落动作、加减速对比、穿梭旋转镜头、色彩与纹理高频闪烁释放能量；最高潮可整屏切 2D 或环境色爆散。

### 第三步：元素资产

- 人物：日常便装（校服、宽松外套、旧球鞋、雨衣、睡衣、卫衣、皱衬衫），服装色与场景 2-3 个平涂主色对比可辨；定义各情绪档的夸张表情方案（瞪大的眼、大张的笑口）；不达标人物图用图生图重塑为全身三视图。

| 资产 | 合规标准 | 不合规处理 |
| --- | --- | --- |
| 人物 | 三视图、日常便装、主色对比可辨 | 图生图重塑为三视图 |
| 表情方案 | 3 档情绪（平静/升级/爆发）各有夸张表情设计 | 补绘表情设定页 |
| 场景 | 四格参考图、无人物、每格固定分工 | 重建四格图并逐格说明分工 |

- 场景：用 2-3 个平涂主色建色场，日常段柔和水彩，高潮段才升级高饱和对比色；线条有手绘抖动感，混入拼贴纹理、相纸颗粒、粗糙色块。
- 声音：有台词角色必须绑定专属声音样本；配音要求极致情绪表现力与夸张个性，拒绝平板通用音色。

人物三视图提示词模板：

```
{角色名}的全身三视图：正面、侧面、背面，统一站立，日常便装{服装清单}，
{体型与年龄特征}，服装主色{主色1}{主色2}与场景平涂色保持对比，
手绘动画质感、线条轻微抖动，背景纯净，多角度完整展示。
```

示例成句："阿彻的全身三视图：正面、侧面、背面，统一站立，皱衬衫加宽松外套、旧球鞋，偏瘦身形，靛蓝米白主色与场景平涂色对比可辨，手绘质感、线条抖动，背景纯净，多角度完整展示。"

### 第四步：镜头生成与逐镜确认

生成前逐项核对（检查清单）：

| 核对项 | 合格标准 | 不达标动作 |
| --- | --- | --- |
| 镜头类型宣言 | 与分镜一致 | 回写宣言 |
| 面板锁定声明 | 四格子格引用完整 | 补声明 |
| 角色绑定 | 分镜角色均有绑定 | 补绑 |
| 场景绑定 | 四格图显式绑定 | 补绑 |
| 动作节拍 | 覆盖分镜全部节拍 | 补写 |
| 台词格式 | 带情绪标签的完整文本 | 回写 |
| 机位轨迹 | 与分镜机位一致 | 改写 |
| 主色配置 | 主色声明与分镜一致 | 补声明 |

连续场景需无缝动作接续时才传上一镜成片作参考，并注明本镜与上一镜的核心差异；机位切换、情绪跳切、场景转换不传参考视频。

镜头生成提示词模板：

```
{情绪阶段}段落镜头{镜头号}：{景别}，{运镜}，时长{秒数}秒。
{镜头类型宣言}：{切换或续接；续接须写明继承上一镜的机位与动作相位}。
空间：{可辨认的真实空间描述}，{变形手段}；超现实元素如有须从{上一镜元素}自然生长而来。
角色{角色名}：{动作逐拍}，表情{情绪档位夸张表情方案}，四肢比例正常，禁止肢体形变。
场景四格参考：锁定{子格分工}子格，{场景描述}。
台词："{带情绪标签的台词}"。主色配置：{主色1}{主色2}，{升级或维持平涂}。
```

占位符说明：{情绪阶段} 取普通/升级/高潮；{镜头类型宣言} 二选一写明；{上一镜元素} 填具体承接物（如"飞起的纸张"）；{情绪档位夸张表情方案} 从表情设定页取档。示例成句："高潮段落镜头12：特写，鱼眼急推，时长5秒。切换。空间：教室，极端鱼眼+大幅倾斜，纸张风暴从上一镜飞起的纸张自然生长而来。角色阿彻：掀桌—踢椅—抱头嚎哭，表情爆发档，四肢比例正常，禁止肢体形变。四格参考锁定光照氛围子格。台词：'骗人的吧——！'（狂躁、崩溃、尾音拉长）。主色配置：朱红与墨黑，高饱和升级。"

失败处理：单镜出现"无中生有的超现实意象"或"变形脱钩"，定位上一镜承接关系改写提示词重试；机位误判则补写继承状态重生成，最多 3 次；仍失败暂停核对分镜与资产。

### 第五步：音频与歌舞

- 歌舞高潮段把怪诞歌词转成完整原创歌曲，不规则节拍、高亢或童趣演唱。
- 配乐走实验路线：不协和和弦、神经质电子、古怪乐器。
- 旁白像意识流散文，长短句交替、充满戏剧性停顿。
- 对白情绪标签原样传给语音合成；长音用延长拼写（如"不要——！"）引导尾音拉长、音高跳变与破音。

对白格式模板：

```
{台词全文}{情绪标签}，{延长拼写：如"不要——！"尾音拉长 2 拍}，{语气要求：跳变/破音/气声}。
```

示例成句："不要——！狂躁、崩溃、孩子气，尾音拉长 2 拍、跳变带破音。"

| 声音层 | 参数/特征 |
| --- | --- |
| 歌曲 | 不规则节拍（如 7/8、5/4 混用），高亢或童趣 |
| 配乐 | 不协和和弦、神经质电子、古怪乐器音色 |
| 旁白 | 意识流散文，长短句交替，戏剧性停顿 |

### 第六步：合成

高强度快切蒙太奇装配，声画同步，突出爆发力。字幕不烧录。输出规格跟随确认过的版本。

| 合成项 | 参数 | 说明 |
| --- | --- | --- |
| 蒙太奇节奏 | 爆发段平均镜长约 3 秒 | 与分镜配合二次切分 |
| 声画同步 | 音效齐点帧级对齐 | 歌舞段按节拍网格对齐 |
| 字幕 | 不烧录 | 后续单独压制 |
| 色彩 | 高潮段整体提饱和 | 日常段保持柔和 |

### 第七步：全片质检

| 质检项 | 合格标准 | 不达标返工点 |
| --- | --- | --- |
| 变形梯度 | 情绪阶段与变形手段匹配，无越级 | 回第二步重排重生成 |
| 空间锚点 | 每镜有可辨认的真实空间名 | 回第四步补写 |
| 母题在场 | 核心视觉母题全片持续出现并变奏 | 回第二步补镜头 |
| 肢体规则 | 全片无橡皮管拉伸、液化、碎片化 | 回第四步重生成 |
| 情绪标签 | 对白情绪标签与长音拼写原样保留 | 回第五步重合成 |
| 歌舞同步 | 群舞动作落点与节拍对齐 | 回第六步重排 |

交付物：分镜表、提示词草稿、资产清单、音轨、成片。

## 进阶技巧

- 平面化切换的执行细则：1) 只在情绪顶点使用；2) 切换前 1 镜运镜要"收"（减速、拉平、收紧景别）制造反差；3) 平面段持续 2-5 秒即回三维空间；4) 回切时从平面段末物件反向生长回空间（如纸片展开回房间）。
- 群舞镜头三式的可执行步骤：1) 穿行俯冲——从队形缝隙高速穿过，机位平视降到腰部再拉起，穿过瞬间叠加速度线；2) 螺旋环绕——贴近舞群 360 度升降旋转，圈数与音乐小节对齐（4 小节一圈）；3) 动态追踪——锁定人物快速位移轨迹，保留表情残影，跟丢即切，禁止硬追。三式统一要求：动作高度同步，错落靠起跳差半拍，肢体比例全程正常。
- 一致性控制与迭代策略：1) 母题变奏表——为每个母题建"出现镜头+变奏方式"记录，每镜生成后勾选；2) 三镜验证法——先做普通段、升级段、高潮段各一镜验证梯度与情绪外化，再批量；3) 同格续接写明继承状态（沿用上一镜机位与动作相位），否则会被误判为跳切；4) 批量生成按场景分组，同场景同四格子格引用，减少环境漂移。
- 翻车点规避：变形失控根因是梯度表未执行，逐镜对照"情绪阶段-变形手段"表；霓虹堆砌根因是锚点丢失；配音平板化根因是情绪标签被简化，台词格式原样透传。

## 常见问题

- 画面变成霓虹梦境堆砌：原因：场景失去现实锚点，变形全开且无梯度。解决步骤：1) 逐镜核对空间名与场景 ID；2) 普通段只用轻微变形；3) 超标镜头按梯度表重排变形强度；4) 重生成并复核。
- 变形与情绪脱钩：原因：全片平均用力，变形未与情绪阶段绑定。解决步骤：1) 为每个镜头标注情绪阶段（普通/升级/高潮）；2) 按梯度表核对是否越级（普通段出现鱼眼即违规）；3) 重排后重生成越级镜头；4) 以三镜验证法复测梯度。
- 超现实意象突兀：原因：变形未从上一镜元素生长出来，凭空切入。解决步骤：1) 定位突兀镜头的上一镜；2) 找出可承接的视觉元素；3) 提示词写明从{上一镜元素}自然生长；4) 重生成该镜。
- 配音变播音腔：原因：情绪标签与长音拼写被简化删除。解决步骤：1) 全部情绪标签原样传回语音合成；2) 追加"狂躁、孩子气、情绪起伏剧烈"表演指令；3) 长音按延长拼写重写（"不要——！"）；4) 抽样对比对白模板勾选。
- 群舞段节奏混乱：原因：加减速未与音乐节拍对齐，多人动作不同步。解决步骤：1) 以歌曲节拍网格为基准重排动作落点；2) 错落改为统一动作+半拍起跳差；3) 旋转圈数与音乐小节对齐；4) 重生成后按拍点抽检 3 处。
