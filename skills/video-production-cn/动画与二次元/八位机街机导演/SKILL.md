# 八位机街机导演

## 技能定位

本技能把模糊的"想做像素游戏视频"转化为一整套可执行、可复现、可审查的八比特像素街机制作方案。其核心方法论是"以游戏逻辑替代电影逻辑"：画面不是电影分镜，而是可游玩的游戏片段——横版滚动视角、左进右出、明确的关卡目标、低帧率逐帧动画、可见的复古 UI 反馈。全程围绕像素美术规则（限定色板、低分辨率像素块、干净像素边缘、瓦片化环境）与游戏节奏（每 2-4 秒一次操作反馈）展开，避免滑向高清动画或写实影视质感。

## 适用场景

- 像素游戏角色、敌人、道具、关卡的单张图像制作（含角色精灵图、精灵表、开场帧）。
- 五秒图生视频：单个简单动作循环（行走拾币、跳跃落台、挥剑击退）。
- 十五秒横版过关短片：包含完整关卡推进、收集、通关结算的叙事结构。
- 需要 UI 体系（血条、金币、分数、关卡标题）与街机音效的复古风格短片。
- 有参考图需要提取风格规律再原创，或完全没有参考需主动提案方向的场景。

## 制作流程

### 第一步：需求理解
先确认用户要做什么：单图、精灵、场景、开场帧、五秒图生视频还是十五秒成片；是否需要 UI、参考图、中英文提示词。输出需求摘要（类型、风格、主题、时长、画幅、UI 需求），缺项主动询问。需求类型判定：单图→文生图；精灵表→文生图+切片；5 秒循环→图生视频；15 秒成片→完整流程。

### 第二步：游戏主题定位
将想法固化为游戏设定，必须输出下表：

| 字段 | 内容 | 示例 |
| --- | --- | --- |
| 游戏类型 | 横版冒险/射击/平台跳跃等 | 横版冒险 |
| 视觉关键词 | 森林金币、太空射击等 | 森林关卡、金币、跳跃平台 |
| 主角目标 | 一句话 | 收集金币抵达终点旗 |
| 关卡目标 | 从左向右推进并躲避小怪 | 同左 |
| 核心交互 | 行走/跳跃/拾取/闪避/通关 | 行走/跳跃/拾取 |
| 适配像素尺寸 | 按素材类型 | 主角 32x32 |
| 适配色板 | 6-8 色锁定 | 深绿/亮绿/棕/土黄/浅蓝/黑 |
| 适配视频结构 | 5 秒循环或 15 秒过关 | 15 秒过关 |

### 第三步：像素美术风格设计
无参考图时主动给出 3-5 个创意方向（森林金币冒险、地牢钥匙逃脱、太空射击、城堡骑士、城市夜霓虹跑酷、雪山顶平台跳跃、机械工厂 Boss 关等），每个方向注明主角、关卡、敌人、道具、核心玩法与视觉焦点，让用户选定。有参考图时只提取风格规律（像素粒度、色板倾向、角色比例、剪影、UI 特征、场景分层），最终输出必须是原创设计，并明确"可借鉴元素"与"必须原创元素"。

### 第四步：素材规划
按固定命名规范规划全部素材：`PX-[类型]-[序号]-[名称]`。类型包括 HERO 主角、ENEMY 敌人、NPC、PROP 道具、LEVEL 关卡、UI 界面、START 开场帧、END 结尾帧、FX 特效。推荐像素尺寸与色板表：

| 素材 | 推荐像素尺寸 | 色板要求 |
| --- | --- | --- |
| 金币 | 16x16 | 主题色板内 |
| 小怪 | 24x24 | 主题色板内 |
| 主角 | 32x32 | 醒目剪影特征 |
| Boss | 64x64 | 主题色板内 |
| 关卡 | 320x180 | 6-8 色锁定 |
| 竖屏短片 | 216x384 | 主题色板内 |

色板按主题锁定 6-8 色（如森林关：深绿、亮绿、棕、土黄、浅蓝、黑色描边；太空关：深紫、蓝黑、青、白星、霓虹粉、亮黄），禁止现代插画式渐变。

### 第五步：提示词编写
所有图像与视频提示词必须包含核心风格词：`8bit pixel art, retro arcade game, side-scrolling game view, limited color palette, low resolution pixel blocks, clean pixel edges, tile-based environment, simple readable silhouette`。角色精灵强调简单轮廓、可读剪影、醒目特征（红围巾、蓝披风、发光剑），禁用复杂五官、布料褶皱、写实材质。关卡强调瓦片逻辑、前景平台/中景角色/背景主题/顶部 UI 四层结构。开场帧构图：主角居左或下中，面向关卡，前方排布平台、金币、敌人与目标物，顶部完整 UI。负向提示词统一包含：高清 3D、写实渲染、插画平滑、马赛克滤镜、虚假像素化、像素密度不一、边缘模糊、抗锯齿、比例漂移、乱码 UI、飞镜头、3D 旋转。

### 第六步：分镜设计
五秒结构任选其一：走+拾币（0-1 秒待机金币闪烁，1-3 秒走近，3-4 秒拾取，4-5 秒金币消失 UI+1）；跳+落台；挥剑+击退（击退闪烁+得分增加+胜利待机）。十五秒固定节奏：0-3 秒展示关卡角色与目标，3-7 秒移动或遭遇敌人，7-11 秒收集或触发机关，11-15 秒通关/UI 结算/定格。每镜只允许 1-2 个动作，禁用复杂战斗、写实跑酷、电影级运镜、3D 旋转、写实表演。优先使用的动作库：待机、走两步、小跳、挥剑、发射像素弹、拾币、开箱、拿钥匙、站平台、进传送门、胜利姿势、敌人巡逻/击退、硬币闪烁、宝箱开启、机关门开、UI 计分、屏幕微闪、关卡标题出现。

### 第七步：视频生成
按序生成：主角精灵、敌人、道具、关卡、UI、开场帧、结尾帧，再做图生视频。视频提示词结构：时长 + 画幅 + 引用素材 + 画面内容 + 动作（低帧率逐帧动画）+ UI 变化 + 运镜（固定横版视角，仅轻微左→右滚动或固定+微闪）+ 风格一致性 + 负向要求。禁用：过度流畅动画、写实摄影、复杂灯光、3D 旋转、飞镜头、比例突变。

### 第八步：剪辑与音效
剪辑遵循"街机片段感"而非电影预告感：短促利落、硬切为主、2-4 秒一个游戏反馈；允许像素化白闪、跳帧、关卡标题卡、复古游戏边框；禁用复杂电影转场、戏剧化淡入淡出、写实镜头晃动。音效按事件配置：开场提示音、上升跳跃音、清脆拾币音、短促打击音、低频受击音、开锁触发音、宝箱开箱音、通关 jingle、计分 tick、CRT 微闪噪声。BGM 用芯片音乐（chiptune）：方波旋律、简单鼓点、清晰节奏、可无缝循环，约 120 BPM。UI 动效保持简单：金币计数 00→01、分数上涨、血条微闪、LEVEL 1-1 出现、STAGE CLEAR 结算，禁止现代 HUD 质感。

### 第九步：复核与修订
按三类清单逐项检查：

| 类别 | 检查项 |
| --- | --- |
| 像素美术 | 是否真像素、颗粒一致、边缘锐利、无高清 3D 污染、无马赛克滤镜感 |
| 游戏逻辑 | 横版关卡、平台敌人道具、UI、通关目标、左进右出、交互反馈、结尾结算 |
| 视频动作 | 逐帧动画感、低帧率保持、无过度流畅、无 3D 旋转、横版轴稳定、UI 稳定、比例稳定 |

任何一项不通过即重跑对应环节。修订时输出问题清单与强化句，例如在提示词末尾追加："严格保持 8bit pixel art、低分辨率像素块、像素颗粒一致、干净像素边缘、限定色板、横版游戏视角，画面必须像真实街机游戏截图，禁止高清 3D、写实、普通插画、马赛克滤镜、流畅动画、3D 旋转"。

## 进阶技巧

- 用参考图做"风格提取-原创再造"两步法：先表格化参考图的像素密度、色板、比例、UI、分层，再按提取结果重画原创设定，禁止直接沿用参考构图。
- 角色三视图、精灵表与关卡图保持同一色板契约，避免单镜一色；统一使用负向提示词块降低漂移。
- 把屏幕效果当成叙事工具：CRT 扫描线、低频闪烁、像素化白闪分别对应"怀旧、紧张、爆发"三种情绪。
- 十五秒短片把"通关结算"视为必交的最后一个镜头，结尾定格帧要能单独截图传播。
- 一致性控制：所有素材锁定同一色板契约与同一组风格词；视频生成引用素材时按"开场帧→角色→关卡"顺序点名。
- 规避翻车：像素密度写"一致"（consistent pixel density），防止近景放大糊、远景缩小的颗粒不均；动作数每镜 ≤2 个，防比例漂移。

## 常见问题

- 生成结果像高清动画：原因：负向提示词未生效或风格词被稀释。解决步骤：加强核心风格词并追加"must look like an authentic retro arcade game screenshot"；检查是否混入高清/写实词。
- 像素颗粒不一致：原因：缺少颗粒一致性约束或混入抗锯齿描述。解决步骤：提示词加"consistent pixel density / pixel-perfect edges"，删除抗锯齿/平滑词。
- 出现 3D 旋转与飞镜头：原因：运镜未锁死。解决步骤：明确写死"fixed side-scrolling view, only slight horizontal scroll"；追加 no 3D rotation, no flying camera。
- UI 乱码：原因：UI 文字过多或内容未限定。解决步骤：限制 UI 文字数量与内容，负向提示词加"broken text, messy UI"；UI 只保留计分/标题/结算。
- 角色比例忽大忽小：原因：镜头缩放或动作过密。解决步骤：强调"stable proportions, no sprite scaling changes"，并在分镜中锁定每镜动作数。
