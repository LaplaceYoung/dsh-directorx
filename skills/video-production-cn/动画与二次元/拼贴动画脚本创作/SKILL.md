
name: 拼贴动画脚本创作
description: >-
  把文字脚本转译为拼贴纸艺动画短片。当用户提交播客逐字稿、演讲、评论或品牌观点文本，希望批量生成"一句话一个视觉双关"的系列化拼贴动画时触发。
  支持先分析选点、再逐条生成静帧与定格动画的完整流水线，可系列化复用。

# 技能定位

本技能是一条"文字到拼贴动画"的批量化生产线：把冗长脚本切成 3-5 个观点，每个观点凝练成一个"尖锐创意/视觉双关"（如"长翅膀的时钟=时光飞逝"），再用固定的材质风格字段加上可变的创意字段逐条产出静帧与 12 帧定格动画。它的设计哲学是一镜一意——每条动画只讲一个想法，全部视觉信息为这个双关服务；固定字段锁定批次风格，可变字段承载创意，从而实现高效的系列化复用。

# 适用场景

- 播客、演讲、行业评论、观点文的配图动画（单集多条、多集批量）。
- 品牌观点短视频、知识科普的视觉化表达。
- 用户有参考拼贴海报需要拆解还原风格，或有现成静帧需要直接动画化。
- 需要"同一风格、批量产出、可复现"的系列内容。

# 制作流程

## 第一步：脚本分析与选点

读取用户提供的逐字稿/脚本，提取适合拼贴动画表达的观点：

- 每个观点凝练成一句话"视觉双关"（尖锐创意），优先选择对比强烈、可视化潜力高、带反讽或隐喻的句子。
- 每篇脚本推荐选 3-5 个观点，输出简短说明与对应的场景/双关概念。
- 以列表呈现给用户确认，可增删调整后进入下一步。

观点选点判断标准表（逐条候选打分，至少满足 3 项才入选）：

| 判断标准 | 判定问题 | 达标示例 | 不达标示例 |
|---|---|---|---|
| 对比强烈 | 句子是否存在至少一对可视觉化的对立面？ | "时间都去哪了"（时间↔去向） | "今天天气不错" |
| 可视化潜力 | 核心名词能否换成具象物件？ | "焦虑=背后的大石头" | "经济下行"（抽象术语） |
| 反讽/隐喻 | 是否有言外之意可翻译成视觉玩笑？ | "加班=给老板的礼物包装" | 平铺直叙的事实陈述 |
| 画面记忆点 | 是否能一眼认出主元素？ | "长翅膀的时钟" | 多个元素堆叠无主次 |
| 单句可承载 | 是否一句话能说清，无需解释？ | "钱包瘦了" | 需要三句背景才能懂的行业梗 |

落选观点处理：不是删除而是降级——把落选观点合并进相邻观点的卫星元素，或留作系列续集素材，避免硬凑双关。

双关创意写法模板（填空式，可直接套用）：

```
模板：[具象物件] + [超现实改造] = [观点一句话]
写法步骤：
1. 提取观点里的核心名词 → 具象物件（时钟/钱包/雨伞/石头/梯子/气泡）
2. 给物件加一个"违反常识的改造"（长翅膀/变瘦/漏雨/长出裂缝/悬空/破洞）
3. 用"= 观点"收束，确认改造与观点有直接隐喻关系
示例：长翅膀的时钟 = 时光飞逝；瘪掉的钱包 = 钱不够花；漏水的雨伞 = 安全感流失
```

## 第二步：锁定风格规格

把本批次的风格参数写入规格文档，分两类：

- 固定字段（整批锁定，禁止修改）：媒介材质（如"混合媒介手工纸拼贴"）、半色调密度（疏/中/密网点+报纸/杂志/照片印刷质感）、剪纸与阴影（粗黑描边+手撕毛边+厚重柔阴影）、构图规范（居中/散落/对角构图+N 个卫星元素+留白多寡）、运动规范（从空背景装配、12 帧定格抖动、阴影位移、轻微摇镜）。
- 可变字段（每条动画单独填写）：创意双关（一句话）、色场（本条主色）、烧录文字（画面内文字，可为空）。

批次参数速查表（默认值，按批次锁定后写入规格文档）：

| 参数 | 默认值 | 判定标准 |
|---|---|---|
| 单条时长 | 6-10 秒 | 短于 6 秒装配不完；长于 10 秒节奏拖沓 |
| 画幅 | 与首条静帧一致 | 整批统一，禁止中途改画幅 |
| 分辨率 | 静帧 2K、成片 720p | 静帧按 2K 生成，成片保持 720p 不做超分 |
| 动画帧数 | 12 帧定格 | 禁止改帧数，定格感依赖固定帧率 |
| 节奏 | 装配轻快、落位顿挫 | 同一时间只有 1-2 个元素在动 |
| 色场 | 每条 1 个主色 | 整批可多色，但单条只允许 1 个主色 |

## 第三步：分镜与静帧生成

每条动画对应单镜头，避免多镜头叙事：

- 主元素（角色或核心物件）：描述半色调质感、描边、投影及其与视觉双关的关系。
- 背景色块：单一纯色，写清主色值，无光效、无景深、无渐变。
- 卫星元素 3-5 个：标注各自视觉职能（强化主题/平衡构图/增加信息密度）。
- 镜头描述必含四项：场景绑定、核心双关一句话、装配顺序、烧录文字。
- 装配顺序是动态叙事的核心：必须逐元素写明"从空背景到完整画面"的过程——哪个元素先入场、从哪个方向飞入、如何落位卡定、哪个元素收尾。禁止写成"元素依次滑入"之类的笼统描述。

视觉 DNA 自检（逐条核对）：是否从空背景开始；是否包含三项材质特征（半色调网点+粗黑描边+实心阴影）；背景是否单一纯色（无光效/无景深）；是否只有一个清晰锐利的双关；装配顺序是否逐元素写明。

静帧提示词模板（固定前缀逐字保留，可变段按占位符替换）：

```
固定前缀（逐字保留）：混合媒介手工纸拼贴艺术风格，复古剪纸质感；主体以半色调印刷贴纸形式出现，
粗黑描边，边缘有手工裁剪的粗糙毛边；背景由粗糙燕麦纸、做旧格纹纸与旧报纸碎片构成；
各层卡纸元素之间有清晰厚重的交叠阴影，呈现真实物理的三维层叠厚度；平铺 2D 纸艺构图，
保留纸纤维质感；无平滑数字渐变、无精细 3D 渲染、无透视畸变。
可变段：[本条双关场景：一句话]；背景为[单一纯色+色值]；画面烧录文字"[烧录文字，可空]"。
```

占位符说明：
- `[本条双关场景]`：填第一步定稿的双关一句话（如"长翅膀的时钟悬停在报纸堆上方"），主元素描述写在这里。
- `[单一纯色+色值]`：如"燕麦色 #D6C9A8"——只允许一个主色，禁止多色渐变。
- `[烧录文字]`：画面内文字逐字写出（如"时光飞逝"），无文字则删去该项。
- 卫星元素 3-5 个必须在双关场景句中各占一句，标注"从[方向]进入，落于[位置]，作用是[强化主题/平衡构图/增加信息密度]"。

示例成句（可直接套用）：

```
混合媒介手工纸拼贴艺术风格，复古剪纸质感；主体以半色调印刷贴纸形式出现，粗黑描边，
边缘有手工裁剪的粗糙毛边；背景由粗糙燕麦纸、做旧格纹纸与旧报纸碎片构成；各层卡纸元素之间
有清晰厚重的交叠阴影，呈现真实物理的三维层叠厚度；平铺 2D 纸艺构图，保留纸纤维质感；
无平滑数字渐变、无精细 3D 渲染、无透视畸变。长翅膀的时钟从右上角飞入，悬停在报纸堆上方，
钟面是半色调网点印刷贴纸；背景为燕麦色 #D6C9A8；三张撕开的报纸碎片从左侧依次滑入叠在底部，
一只墨水瓶从下方升起落在右下角压住报纸，平衡构图；画面烧录文字"时光飞逝"。
```

关键词六项检查：半色调、粗黑描边、粗糙手工裁剪边缘、厚重交叠阴影、平铺 2D 纸艺、纸纤维质感。同组已通过一张静帧且需强风格一致时，用图生图以上一张为参考生成后续，保留材质与构图、替换核心创意。

检查点：全部静帧生成后暂停展示，用户标注满意/不满意项，不满意项改提示词重生成直至通过。

## 第四步：动画生成

整批统一使用同一条生成管道（提示词驱动或帧插值），禁止混用。

默认管道（提示词驱动）：以已确认静帧为参考图。固定前缀必须逐字保留："12 帧定格动画风格运动，轻微顿挫节奏；遵循手工剪纸的物理规律——各卡纸元素在帧间有微小抖动、晃动与颤振；交叠纸层下的阴影随元素移动动态位移，突出三维层叠纸艺的深度与空间感；背景纸纤维纹理与噪点在帧间闪烁脉动；轻微慢速摇镜或视差位移；保持平铺 2D 层叠纸艺美学；无平滑数字过渡动画、无 3D 空间畸变。"随后写装配叙事段："场景从空纯色背景开始，[元素A]从[方向]滑入落位，随后[元素B]从[方向]飞入……直至所有元素最终装配成完整画面。"装配顺序逐字抄自分镜的装配顺序字段，逐一命名元素并写明入场方向与定位。运动关键词六项检查：12 帧定格、顿挫节奏、帧间抖动/晃动/颤振、动态阴影位移、纸纹/噪点闪烁、摇镜/视差。装配效果不干净时改提示词重跑，不换管道。

动画装配段模板（填空式，逐元素一行）：

```
场景从空纯色背景开始；
[元素A]从[方向]滑入，[落位动作]；
随后[元素B]从[方向]飞入，[落位动作]；
然后[元素C]从[方向]飘入，[落位动作]；
最后[收尾元素]从[方向]落下，[收尾动作，卡定全画面]。
```

示例成句（可直接套用）：

```
场景从空燕麦色背景开始；长翅膀的时钟从右上角扇动翅膀滑入，悬停在画面中上；
随后三张撕开的报纸碎片从左侧依次飘入，叠落画面底部；然后墨水瓶从下方升起，
落在右下角压住报纸边缘；最后一张写着"时光飞逝"的标签条从上方落下，贴在钟面下方，装配完成。
```

回退管道（帧插值）：默认管道多次失败后才启用。先用图像生成模型产出"空背景版"静帧（只留背景色块，去掉全部元素），以空背景为起始帧、完整静帧为结束帧执行帧插值，保证装配运动出现。此管道必须写正向音频描述段：有配乐则写与装配节奏同步的纸质节拍/低保真风格；有旁白则写旁白内容与语气摘要；两者皆无则写纸感环境音（纸摩擦、卡纸落定声）并同步元素入场节奏。禁止写"无音乐"式负向词——帧插值管道需要正向音频描述驱动音频生成。

检查点：全部动画生成后暂停展示，用户验收后才进入合成。

## 第五步：合成与导出

- 每条动画独立导出 6-10 秒；系列内容按条分别输出，不自动拼成长视频。
- 保持原始 12 帧定格感，禁止施加平滑/缓动处理。
- 有 BGM 时，首元素入场时刻对齐一个强拍；同时有旁白时保证旁白与音乐不重叠。
- 不加字幕层——画面文字已在静帧阶段烧录，合成层不再叠加。
- 保持生成分辨率（720p），不做超分放大。

批量一致性检查清单（每条导出前逐项核对）：

| 检查项 | 判定标准 | 不达标处理 |
|---|---|---|
| 固定字段未改 | 材质/构图/运动规范与批次规格逐字一致 | 回规格文档核对，改回后重生成 |
| 单管道单模型 | 整批同一条生成管道，无混用 | 统一管道后重跑混用条目 |
| 材质关键词齐全 | 六项运动关键词与六项静帧关键词逐条命中 | 补关键词后重跑该条 |
| 双关唯一 | 每条只有一个锐利双关 | 拆分或删减多余元素 |
| 装配顺序完整 | 逐元素写明入场方向与落位 | 回分镜补装配段后重跑 |
| 音频正向驱动 | 帧插值管道有正向音频描述 | 补纸质节拍/纸感环境音描述 |
| 无字幕叠加 | 合成层无额外字幕轨 | 删除字幕轨，保留烧录文字 |

# 进阶技巧

- 参考图拆解双输出：用户上传拼贴海报参考时，输出"白话拆解+分字段结构化规格"两组信息；拆解覆盖主视觉、色调、纹理（网点密度/描边粗细/阴影深度）、创意核心四方面；结构化规格按固定/可变字段填写，直接供生产调用。
- 四静态特征自检：分析参考图时核对是否具备拼贴动画的四项静态特征（半色调元素、干净剪边+阴影、平底纯色背景、一个尖锐创意）；缺项时在拆解中明确标注"生产时需补充"。
- 批量一致性：同一批次全部使用同一条生成管道与同一视频模型，杜绝视觉割裂；新脚本复用已锁定的固定字段，只改创意/色场/烧录文字即可再次生产。
- 动效克制原则：同一时间只有 1-2 个元素在动（其余静止），符合"表演/强调"原则；装配节奏快慢应服务于双关的呈现，而非单纯炫技。
- 帧插值管道谨慎选择：它是单镜补救方案而非批量默认，使用前确认默认管道确实反复失败。
- 迭代策略：失败时一次只改一个变量（先修装配顺序，再调材质词，最后动色场），改完对比上一版确认差异，避免多变量同时改动无法定位问题。

# 常见问题

- 装配顺序写得太笼统：
  原因：分镜装配段写了"元素依次滑入"之类概括句，模型无法推断入场方向与落位。
  解决步骤：① 回分镜把每个元素拆成一行，写明入场方向与落位动作；② 用动画装配段模板逐元素填写；③ 装配段逐字抄入动画提示词；④ 重跑。
- 静帧与动画风格割裂：
  原因：动画固定前缀丢失了纸艺材质关键词，或整批混用了不同管道/模型。
  解决步骤：① 动画固定前缀逐字保留纸艺材质关键词；② 整批统一同一条管道与同一模型；③ 逐条对照六项运动关键词检查；④ 重跑不一致条目。
- 定格感被平滑化：
  原因：合成阶段施加了平滑/缓动处理，或导出时被插帧。
  解决步骤：① 合成阶段禁止施加平滑/缓动；② 保持 12 帧顿挫节奏；③ 导出时关闭任何自动补帧；④ 重导出。
- 帧插值管道没有音频描述：
  原因：该管道由正向音频描述驱动声音生成，缺省会导致无声或错声。
  解决步骤：① 有配乐则写与装配节奏同步的纸质节拍/低保真风格；② 有旁白则写旁白内容与语气摘要；③ 两者皆无则写纸感环境音（纸摩擦、卡纸落定声）；④ 禁止写"无音乐"式负向词。
- 一镜多意：
  原因：单镜塞进两个以上双关，创意被稀释。
  解决步骤：① 坚持一镜一意；② 多余双关拆成下一条动画；③ 卫星元素只承担强化/平衡职能，不再承担第二双关；④ 重新过视觉 DNA 自检。
- 字幕叠在画面文字上：
  原因：画面文字已在静帧阶段烧录，合成层又加字幕轨。
  解决步骤：① 合成层不再叠加字幕；② 检查是否重复添加字幕轨；③ 删除后重导出。
- 固定字段被改：
  原因：生产中途修改了材质/构图/运动规范等固定字段。
  解决步骤：① 回规格文档确认批次固定字段；② 同批次内只允许改创意/色场/烧录文字；③ 改固定字段需全批重跑；④ 记录变更原因到规格文档。
