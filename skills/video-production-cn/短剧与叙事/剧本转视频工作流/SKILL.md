# 剧本转视频工作流

## 技能定位

本技能以"剧本保真"为最高优先级，把用户上传的剧本文件转成短片：分镜中的对白、旁白、动作结果与场景顺序必须与上传剧本及解析结果保持一致，只允许技术性编辑（拆分 ≤15 秒镜头、补充镜头语言字段），绝不虚构情节或改写台词。流程上独有的"提示词草稿确认"机制——生成任何图像或视频资产之前，必须先把全部提示词草稿逐条呈现给用户确认，禁止跳过或默认直接生成。

## 适用场景

- 用户已写好完整剧本（图片/PDF/文本）的短片制作。
- 需要严格忠于剧本对白与情节的叙事短片。
- 希望"每条提示词都可见可控"的精细化制作流程。
- 剧本含多角色对白、需要逐条审核提示词的协作项目。

## 制作流程

### 第一步：剧本摘要与规格

用一句话概括上传剧本的故事，确认理解无误后写入全局规格（标题、类型、画幅、时长、视觉风格、语言、模型偏好）。规格默认值：画幅 16:9、单镜 ≤15 秒、分辨率 720p 生成 1080p 输出。剧本解析输出三清单：人物清单（含造型/音色）、场景清单（含物件位置朝向）、关键情节点清单（不得改动的动作结果）。

### 第二步：分镜设计

- 分镜与剧本保真：对白、旁白、动作结果与场景顺序与剧本一致；剧本未覆盖的镜头可从类型与基调出发专业推断构图与运动，但不得改变情节事实与台词。保真核对表：对白逐字一致、动作结果一致、场景顺序一致、旁白逐字一致——四项任一不符即回退。
- 元素按独立实体分配编号；人物多造型分列描述并写入音色特征；场景写明重要物件位置与朝向；用户提供的参考资产描述必须与素材一致。
- 优先 10-15 秒含内部切换的长镜，按故事节奏设计镜内切换而非拆成许多短镜；每镜不超过 15 秒。镜内切换用明确标记（如"镜头1（0-4秒）…特写。镜头2 切至（4-8秒）…"）。

### 第三步：提示词草稿编写与确认（强制前置）

- 在生成任何元素图或镜头视频之前，基于分镜与规格为所有待生成资产逐一编写提示词草稿。每条草稿必须包含：资产类型（元素图/镜头视频）、对应元素编号或镜头编号、完整提示词文本、推荐模型与分辨率参数。草稿表字段：

| 字段 | 内容 |
| --- | --- |
| 草稿编号 | D-序号 |
| 资产类型 | 元素图 / 镜头视频 |
| 关联编号 | 元素编号或镜头编号 |
| 提示词文本 | 完整可执行提示词 |
| 推荐参数 | 模型、分辨率、画幅 |
| 状态 | 待确认 / 已确认 / 已修改 |

- 分批确认：先汇总呈现元素图提示词草稿，用户确认后才生成元素图；元素图生成后再汇总呈现镜头视频提示词草稿，确认后才生成镜头视频。
- 强制暂停点：必须等用户审阅并明确确认提示词草稿后才执行对应生成操作，严禁跳过或默认直接调用生成。用户要求修改时先更新草稿再确认，通过后才能生成。
- 用户已上传可直接绑定的资产无需写草稿或重生成。

### 第四步：元素与镜头视频生成

元素图：用户已指定资产直接使用不生成；否则人物用横版 16:9 单张图（自左向右：特写＋正/侧/背全身三视图，便于模型读取身份与服装信息）；同一角色多状态用图生图引用首图保持一致性。镜头视频：引用该镜元素图；项目中有声音参考时同时引用元素图与对应角色的声音参考，并在提示词中指明哪个角色用哪条参考音频。

### 第五步：音频与合成

配乐至少一条全局轨，风格与节奏匹配规格或参考；参考有明显节奏/情绪变化时拆配乐段并定义范围。旁白/对白在音频层设计（内容、音色语气、时间范围），有声线参考时在布局指令或备注中链接对齐。全部就绪后按分镜与时间线顺序合成并引导导出。各阶段间暂停确认。

## 提示词模板

**镜头视频草稿模板：**
```
[镜头编号]：{景别}{角度}{运镜}，{主体动作（部位+程度副词）}，
{空间与背景动态}，{对白}（花括号包裹，仅台词原文），
{音频标记}，{参考图点名：角色图提供面容、全身图提供服装}，
[风格/电影感词]，[负向约束]
```

**示例成句（对白镜头）：**
```
镜头3：中景过肩，她缓缓举起一只手，指尖轻触窗玻璃，
窗外雨丝斜落，{你真的要走吗。}，<雨声渐强>，
角色头像图提供面容、全身图提供服装，
电影感构图，克制冷色调，no text, no watermark
```

**示例成句（镜内切换长镜）：**
```
镜头1（0-4秒）：全景，他推门进入旧书店，环顾四周；切至镜头2（4-8秒）：
特写，他手指划过书脊，停在《[书名]》上；切至镜头3（8-12秒）：
中景，他抽出书翻到某一页，{找到了。}；
动作按故事顺序列出，禁止秒级精确时间计划外的跳切
```

## 风格关键词与参数表

**核心关键词清单：** 剧本保真、提示词草稿确认、对白花括号、镜内切换、电影感六规则（风格术语/构图景别/负填充光线/单一主色调/渲染质感/氛围潜台词）、动作锚定部位+程度副词。

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 10-15 秒（含内部切换） | 每镜 ≤15 秒 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率 | 720p 生成、1080p 输出 | — |
| 元素图 | 横版 16:9 单张（特写+三视图并排） | 人物 |
| 主色调 | 单一主色约 90% 面积 | 禁霓虹撞色 |
| 确认节奏 | 元素草稿批→镜头草稿批 | 强制暂停点 |

**禁用项清单：** 未确认草稿即生成、虚构情节、改写台词、花括号内带引号、秒级精确时间计划、与用户素材矛盾的描述、跨镜音色漂移。

## 进阶技巧

- 提示词六条电影感核心规则：专业风格术语（引用作者导演与具体影片锚点）、构图与景别、强调负填充的光线、克制的单一主色调（约 90% 面积，禁霓虹撞色）、渲染质感、氛围与潜台词（冻结在戏剧瞬间的微表情，拒绝僵硬摆拍）。
- 对白用花括号包裹且只放台词原文不带引号；非项目语言的对白在花括号前标注语言；独立旁白轨存在时视频提示词不写旁白文本。
- 动作描述锚定具体身体部位并加程度副词（缓缓举起一只手、猛地甩头向左）；多节拍按故事时间顺序列出主动作与次动作；禁止秒级精确时间计划。
- 保真与可执行的分工：剧本保真管"做什么"，镜头语言补充管"怎么拍"——补充字段永远不改动作结果，只加机位/景别/运动。
- 一致性控制：人物三视图+声音参考双绑定，跨镜防面容与音色漂移；同场景镜头复用同一张场景图。
- 规避翻车：长句对白拆成镜内多个节拍并分段标注情绪；多角色同框镜提示词按"主角→配角"顺序逐人描述。

## 常见问题

- 提示词未确认就生成：原因：跳过草稿确认环节。解决步骤：回第三步补齐"草稿呈现-用户确认-再生成"的强制流程；草稿表状态字段留档，未确认状态禁止生成。
- 剧情被改动：原因：分镜阶段虚构了情节或改写了台词。解决步骤：回退到剧本保真原则，仅允许拆分与技术字段编辑；按保真核对表逐项核查。
- 角色音色跨镜漂移：原因：声音参考未绑定或未指明对应关系。解决步骤：补绑定并在提示词中写明角色-音频映射（"角色 A 用音频 ref1"）。
- 台词带引号残留：原因：花括号内混入剧本引号。解决步骤：只保留台词原文；草稿确认阶段逐条核对花括号内容。
- 镜头节奏与剧本脱节：原因：拆成过多短镜。解决步骤：优先 10-15 秒长镜+内部切换，按故事节奏设计镜内切点而非拆镜。
