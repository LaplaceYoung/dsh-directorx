# 叙事驱动美学影像

## 技能定位

本技能的核心是"风格基准板"工作流：先用风格码为全片锚定统一的视觉基调（基准板），再由精修模型在基准板上做轻量合成与微调得到每镜关键帧，最后驱动镜头视频生成。关键纪律是分层分工——基准板负责"观感"，关键帧只做"微调"，不做二次创作；冗长的电影感描述反而会破坏风格锁定。

## 适用场景

- 需要强风格统一性的叙事短片（黑色电影、赛博、暖治愈等）。
- 多场景多人物但要求全片"一个观感"的项目。
- 想让风格先于内容确定、便于快速迭代调色的项目。
- 需要"同一风格码批量铺开"的多镜头项目。

## 制作流程

### 第一步：规格与分镜

锁定标题、类型、画幅、时长、视觉风格、语言与模型偏好。分镜每镜含场景引用、剧情内容（写出精确台词）、镜头语言（景别、角度、运动）；配乐至少一条全局轨，长片按段落拆配乐段；旁白在音频层定义音色、语气与精确文案并用布局指令限定镜头范围。规格默认值：画幅 16:9、单镜 ≤15 秒、分辨率 720p 生成 1080p 输出。

### 第二步：风格基准板（元素图生成）

- 用风格码模型生成人物、道具与大场景的基准图：写清内容（谁/什么/在哪、可读轮廓、环境解读），末尾追加风格码。不要把全局规格里的整篇风格论文塞进提示词——风格码加主体/场景措辞就足够。
- 风格码选择规则：用户有码就用用户的；否则自选一个有效整数（0-4294967295 之间）并记录，全项目所有调用复用同一码；多个码可用空格分隔堆叠，用户提供多码则记录全列表复用。
- 元素图提示词应用六条电影感核心规则：专业风格术语、构图与景别、强调负填充的光线、克制的单一主色调（约 90% 面积，禁霓虹撞色）、渲染质感、氛围与潜台词。

### 第三步：关键帧生成（精修而非重绘）

- 每个镜头生成一张首帧静态图，与分镜镜头描述对齐。基准板是"观感的唯一事实源"，精修模型在基准图上做轻量合成/调整，而不是从长文本提示词重画整张图。
- 关键帧提示词要短：只指明"哪张参考图提供环境/纹理、哪张提供风格/光线词汇"，再补分镜脚本要求的内容（姿态、布局、谁拿着什么）。禁止粘贴重新描述调色、光线、电影参考与情绪的长段落——那会迫使模型整体重绘并削弱对基准图的遵循。

### 第四步：镜头视频生成

每镜以关键帧为输入生成视频。视频提示词先为每张参考图点名角色（面部参考用头像图、发型妆容服装用全身图），再按"镜头-主体-空间-音频"四层顺序补动作与动态：镜头运动与切换、主体动作与表情、空间与背景运动、音频标记。多节拍可用"镜头1/镜头2/镜头3"承接，禁止秒级精确时间计划，用顺序描述。

### 第五步：合成

按分镜与时间线顺序合成全部镜头、旁白轨与配乐。若最终镜头无画面内对白或旁白，合成时静音该镜头内嵌音频，只依赖音频层（设计好的配乐/音效），避免与混音冲突。就绪后引导导出。各阶段间暂停确认。

## 提示词模板

**基准板元素图模板：**
```
{内容：谁/什么/在哪、可读轮廓、环境解读}，
{风格码：整数或整数列表}，[六条电影感核心规则词]，
no text, no watermark
```

**关键帧模板（短提示词，槽位标签式）：**
```
[基准板-角色图]提供面容与服装，[基准板-场景图]提供环境与纹理，
[基准板-光线图]提供风格与光线词汇；
本镜脚本要求：{姿态、布局、谁拿着什么}；
no text, no watermark
```

**示例成句（基准板·黑色电影）：**
```
穿风衣的男人站在雨夜巷口，可读轮廓清晰，环境为湿漉的沥青路与霓虹招牌倒影，
风格码 482910，高对比侧光、负填充构图、单一冷色调、胶片质感、戏剧性微表情，
no text, no watermark
```

**示例成句（关键帧·精修）：**
```
基准板-角色图提供面容与服装，基准板-场景图提供环境与纹理，
基准板-光线图提供风格与光线词汇；
本镜：男人背靠墙点燃火柴，火光映亮半张脸，右手持帽；
no text, no watermark
```

**视频提示词示例（四层结构）：**
```
严格参考[关键帧]；镜头层：中景缓慢推近；主体层：他缓缓抬头，目光扫向巷口；
空间层：霓虹倒影在积水里晃动，雨丝斜落；
音频层：<雨声> <火柴擦燃声> (低沉爵士氛围)；
no text, no watermark
```

## 风格关键词与参数表

**核心关键词清单：** 风格基准板、风格码（0-4294967295 整数）、观感唯一事实源、关键帧只做微调、槽位标签短提示词、六条电影感核心规则、分层分工。

**分层分工表：**

| 层 | 职责 | 提示词长度 | 禁止 |
| --- | --- | --- | --- |
| 基准板 | 观感（风格码锚定） | 内容+风格码 | 长篇风格论文 |
| 关键帧 | 微调（轻量合成） | 短（槽位标签） | 重绘调色/光线/情绪段落 |
| 视频 | 动态（四层结构） | 镜头-主体-空间-音频 | 秒级时间计划 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 风格码 | 有效整数 0-4294967295 | 空格分隔堆叠多码 |
| 单镜时长 | ≤15 秒 | 全片统一 |
| 画幅 | 16:9 默认，9:16 可选 | — |
| 分辨率 | 720p 生成、1080p 输出 | — |
| 主色调 | 单一主色约 90% 面积 | 禁霓虹撞色 |
| 基准板数量 | 人物/道具/场景/光线各 1 张 | 全项目复用 |

**禁用项清单：** 关键帧阶段长电影感散文、风格码超范围或格式错误、基准板中途更换、重绘而非微调、霓虹撞色、秒级时间计划、无对白镜内嵌音频与混音冲突。

## 进阶技巧

- 关键帧是六条规则的例外：长篇电影感散文会让精修模型无视或对抗参考图，坚持"槽位标签＋分镜对齐"的短提示词写法。
- 复杂多阶段动作按顺序描述，用"cut to"标签连接（镜头 A…，cut to 镜头 B…，cut to 镜头 C…）。
- 视频提示词中为每个角色连续编号参考图（主角 1 头像、主角 1 全身、主角 2 头像、主角 2 全身…），便于模型正确读取面容与造型。
- 风格码即"观感哈希"：同一整数在不同镜头间锁定统一基调，调色迭代只改关键帧、不动基准板——先基准板后关键帧的依赖顺序是快速迭代的关键。
- 一致性控制：全项目所有基准板调用复用同一风格码列表；关键帧只引用基准板，不引入新参考。
- 规避翻车：风格码在 0-4294967295 区间且格式正确（整数、空格分隔）；关键帧提示词超过 3 句即开始稀释基准板权重，控制在 2-3 句内。

## 常见问题

- 风格全片漂移：原因：关键帧阶段用了长电影感描述导致重绘。解决步骤：改回短提示词＋槽位标签，让基准板当观感事实源；逐镜核对关键帧与基准板观感一致。
- 风格码失效：原因：码值超出整数范围或格式错误。解决步骤：核对 0-4294967295 区间并用空格分隔堆叠；记录全列表并在所有调用复用。
- 关键帧与分镜脱节：原因：关键帧没有对齐分镜的"谁、在哪、做什么动作"。解决步骤：补上脚本要求的最小路由文本（姿态、布局、谁拿着什么）。
- 混音冲突：原因：镜头内嵌音频与旁白/配乐打架。解决步骤：按规则静音无对白镜头的内嵌音频，只依赖音频层。
- 基准板被忽略：原因：关键帧提示词过长或混入新参考。解决步骤：压缩到 2-3 句槽位标签式；禁止在关键帧阶段引入基准板外的新图。
