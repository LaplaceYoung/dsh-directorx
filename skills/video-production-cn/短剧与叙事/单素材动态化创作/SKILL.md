
name: 单素材动态化创作
description: >-
  适用于先有散装产出（单张图、单段视频、单段音频）再续拍成完整影片的场景。
  强调素材盘点、围绕已有资产叙事、缺口补齐三原则，避免推倒重来。

## 技能定位

本技能解决"手里已经有零散素材，如何拼成一部完整片子"。核心法则是"素材即承诺"：先对已有资产做全量盘点并登记为事实来源，再让故事、分镜与音轨围绕这些素材生长，只在确有空缺时补生成。任何已存在的可用素材都不得被重新生成替代。

## 适用场景

- 用户已生成或上传若干图片/视频/音频片段，要求在此基础上续编成有头有尾的成片。
- 已有产品图、角色图、B-roll 片段或音乐主干，需要组织成叙事短片。
- 需要复用既有素材库做剪辑式创作，而非从零立项。

## 制作流程

### 1. 素材盘点
列出步骤 1 的全部独立产出（登记资产标识、一行内容摘要、类型：元素参考/B-roll/音乐主干等）；可选地对文件做多模态分析以明确结构与时间戳。此清单是全片"必须出现的素材"的唯一事实来源，不得丢弃。盘点表字段：

| 字段 | 内容 |
| --- | --- |
| 资产标识 | A-01、A-02… |
| 内容摘要 | 一行 |
| 类型 | 元素参考 / B-roll / 音乐主干 / 声音参考 |
| 结构/时间戳 | 可选，多模态分析 |
| 分镜归属 | 后续填入（绑定槽位） |

### 2. 锁定规格
写入成片规格文档（标题、类型、比例、时长、视觉风格、语言、模型偏好），并声明成片锚定于已有素材，除非用户明确授权替换。规格默认值：画幅 16:9、单镜 ≤15 秒、分辨率 720p 生成 1080p 输出。

### 3. 设计分镜（硬规则）
分镜必须把每个已有素材至少分配到一处——绑定到关键元素（造型/环境/道具）或某一最终镜头（如"第 3 镜使用某资源作为主镜头/关键画面"）；叙事围绕这些片段展开，只为覆盖缺口（缺失的衔接镜、转场、环境）规划新生成。硬规则核对表：每个资产标识都出现在至少一个分镜槽位；无资产标识的槽位即为待补缺口。

### 4. 缺口审计与补齐
分别对照分镜检查图片元素、视频镜头、音轨三层，只生成缺失项；生成前先把已有资产绑定到对应槽位，绝不重复生成同一节拍。缺口清单三层：图片缺口（缺角色三视图/场景图）、视频缺口（缺衔接镜/转场）、音轨缺口（缺 BGM/旁白/音效）。

### 5. 长镜头设计
优先 10-15 秒长镜头+内部剪切（如"0-4 秒：场景、角色做 X、特写；切到 4-8 秒：…；再切 8-12 秒：…"），剪切频率跟随故事节奏；单镜不超过 15 秒。

### 6. 音频设计
至少一条全局 BGM；3 分钟以上且有明显幕次转折时可分多段（各自独立音频标识与覆盖范围）；旁白单独一条音轨，写明音色、语气与完整文案，并限定覆盖镜头范围。

### 7. 生成与合成
先绑定、后生成；成片后若镜头内无对白或旁白，建议静音镜头自带声音，交由 BGM/音效层主导混音，避免冲突。

## 提示词模板

**新生成素材提示词模板（与旧素材同观感）：**
```
严格参考已有素材[A-01][A-02]的{风格/色板/质感}，
复用元素描述词汇，生成{缺口内容}，
{镜头-主体-空间-音频四层结构}，
no text, no watermark
```

**示例成句（补衔接镜）：**
```
严格参考已有素材 A-01 的冷蓝夜景色调与颗粒质感，复用其环境描述词汇，
生成"人物从街角走入画面"衔接镜，中景侧跟，步伐平稳，
路灯在湿地上拉长倒影，<远处车流声>，no text, no watermark
```

**示例成句（补转场）：**
```
严格参考 A-03 音乐主干的节奏，生成 2 秒光影溶解转场，
从室内暖光溶解到室外冷光，光斑流动，
<风声渐入>，no text, no watermark
```

## 风格关键词与参数表

**核心关键词清单：** 素材即承诺、素材盘点、围绕已有资产叙事、缺口审计、先绑定后生成、长镜头内部剪切、观感复用（元素描述词汇回填）。

**缺口审计三层表：**

| 层 | 检查项 | 补齐方式 |
| --- | --- | --- |
| 图片元素 | 角色三视图/场景图/道具图 | 按已有观感生成 |
| 视频镜头 | 衔接镜/转场/环境镜 | 长镜内部剪切优先 |
| 音轨 | BGM/旁白/音效 | 独立标识分段 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 10-15 秒（内部剪切） | 每镜 ≤15 秒 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率 | 720p 生成、1080p 输出 | — |
| BGM | ≥1 条全局；3 分钟以上分段 | 独立标识 |
| 旁白 | 单独音轨+音色语气+文案 | 限定镜头范围 |

**禁用项清单：** 重生成已有可用素材、素材不入分镜、与用户素材矛盾的描述、单镜超 15 秒、无标识音轨、音画混音冲突。

## 进阶技巧

- 元素描述复用步骤 1 的提示词语汇，保证新生成与旧素材观感一致；角色多造型按 Look 1/Look 2 记录。
- 角色元素优先生成三视图（正面/侧面/背面），跨镜一致性显著提升；多造型用图生图引用首图。
- 旁白如需复刻既有声音，先登记一段 15 秒内的声音参考素材，生成旁白时对齐音色。
- 素材盘点即叙事线索：把资产标识按"谁/在哪/发生什么"排序，天然得到故事骨架；B-roll 型资产优先做情绪空镜，音乐主干优先定节奏。
- 一致性控制：新生成素材提示词开头声明"严格参考已有素材 + 资产标识"，并回填元素描述词汇；色板/质感词从盘点表原样复制。
- 规避翻车：转场缺口优先用光影溶解类轻转场（2-3 秒），避免新生成重特效转场与原素材质感打架。

## 常见问题

- 把已有素材当可选、另起炉灶：原因：盘点清单未当作事实来源。解决步骤：分镜硬规则要求每个素材必须入镜，缺失才允许补生成；逐资产核对绑定槽位。
- 用户素材与分镜描述冲突：原因：元素描述与素材内容矛盾。解决步骤：元素描述必须与用户素材内容一致，不得自相矛盾；描述从盘点摘要回填。
- 单镜超时：原因：内容超长。解决步骤：当前模型单镜上限 15 秒，超长内容用内部剪切而非拆成多段短镜。
- 新生成与旧素材观感割裂：原因：未复用元素描述词汇。解决步骤：提示词开头引用资产标识并回填风格/色板/质感词。
- 音画冲突：原因：镜头内嵌音频与音轨层打架。解决步骤：无对白/旁白的镜头静音内嵌音频，交由 BGM/音效层主导。
