# 闽南语短剧工坊

## 技能定位

本技能把"台腔短剧"做成六阶段工坊：输入解析与故事方向锁定、角色设计、场景设计、镜头表、样片验证、全片生成与质检。核心特征是真实质感优先：角色皮肤要有毛孔、细纹与生理色差，杜绝塑料感；运镜遵循"每镜有运动、手持呼吸感、S 曲线加减速"等硬性规则；声音方面台腔配音全程一致、唇形误差不超过 0.05 秒、全片无 BGM 无字幕。

## 适用场景

- 台湾腔普通话配音的剧情短剧、漫剧化改编。
- 用户提供完整剧本或一句话灵感，需要自动扩写成剧本并成片。
- 需要真实表演质感与运镜纪律的短剧项目。

## 制作流程

1. 输入分析：完整剧本直接解析；一句话灵感自动扩写成有头有尾、对白紧凑（每 3-5 秒至少一句）的剧本并标注"自动扩写请核验"；无内容则引导上传。解析用户参考资产（图/视频/文档）用于后续元素设计。
2. 锁定规格：标题、类型、预估时长、画幅 16:9、生成分辨率 720p/输出 1080p、帧率 24fps、风格基调、语言（台腔普通话）、配音规则（镜头内原生配音、无 BGM、无字幕）。暂停确认（可调时长/改方向）。
3. 角色设计：按剧本角色表设计外貌/年龄/服装/声线档案（年轻女/男、中年、老年四档）；有参考图则图生图生成四视图卡（16:9 白底，左侧胸像特写、右侧正/侧/背全身并列）；无参考则文生图初始版再补其余视图。皮肤写实标准：鼻翼两侧毛孔 0.1-0.2mm、眼周放射细纹、额头略亮下颌略暗、鼻翼微红、眼白有血丝、瞳孔有高光、手背比脸深；面部要有骨相层次与不对称特征（单双睑、眉高差、疤痕痣等），禁止完全对称的网红脸。为每角色配套 8 种表情特写库（平静/微怒/悲伤/惊讶/焦虑/喜悦/恐惧/委屈）供镜头调用。暂停确认。

| 字段 | 内容示例 |
|---|---|
| 角色 | 阿明（男主） |
| 声线档位 | 年轻男 |
| 音色描述 | 清亮、带台湾腔尾音上扬 |
| 情绪标注 | [疲惫但强装镇定] |
| 语速节奏 | 中速、句尾拖音 |
| 绑定音色样本 | 唯一样本 ID，全片沿用 |

4. 场景设计：空间结构、布光类型、道具、人群行为（每场景至少 3 种不同行为）；生成多角度场景参考图。暂停确认。
5. 镜头表：剧本转镜头表，每镜 7-15 秒，字段齐全；有旁白则单独设计旁白轨（不设计任何 BGM 轨）；按质检规则自查并修正。暂停确认。

### 镜头表字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 镜号/场景 | 场景 ID+时间 | 02-客厅-夜 |
| 时长 | 7-15 秒 | 10s |
| 景别/机位角度 | 景别+角度号 | 中景/机位 2 |
| 对白 | 台词原文+语气 | [焦急]“阿母，你袂按怎？” |
| 动作/视线 | 动作+视线方向 | 推门、视线扫向沙发 |
| 运镜 | 类型+加减速 | 缓推+S 曲线 |
| 光源方向 | 与邻镜一致 | 左侧窗光 |

6. 样片验证：选 1-2 个情绪最强镜头先生成样片，检查运镜合规、手持呼吸感、台腔自然度、唇形误差≤0.05 秒；不合规自动重试一次，仍失败标注警告由用户接受或跳过。暂停确认。
7. 全片生成与质检：逐镜生成（含旁白轨合成）；按最终质检清单逐项打勾——每镜有运动（无静止超 1.5 秒）、手持呼吸感（垂直±2-3 像素、水平±1 像素）、机位角度≥4 种、推拉有 S 曲线加减速（急推带 0.1 秒惯性过冲）、特写有情绪动机、同场景相邻镜时长差≤±3 秒、相邻镜光轴夹角≥30°、动作与视线匹配无丢帧、有荷兰角/急推/环绕等张力镜头、人群行为清晰、台腔音色全程一致、唇形误差≤0.05 秒、无 BGM 无字幕、每镜光源方向明确且相邻一致、有光影分离/轮廓光/眼神光、场景三层次（前中背景）有生活痕迹、无意义空镜（超 3 秒无叙事作用）为零、对白清晰不吞字、语速随情绪起伏。输出质检报告，暂停确认后交付。

## 进阶技巧

- 角色差异优先于完美：保留轻微不对称与生活痕迹（长期户外晒痕、缺觉痕迹），是真实感的关键。
- 用户连续修改超过 3 次时给出 3 个替代方案，避免无限循环。
- 台腔一致性靠声音档案锁定：每个角色只绑定一个声音样本，所有镜头沿用。
- 对白压缩规则：自动扩写剧本时每 3-5 秒至少一句对白，句长控制在 15 字以内，句尾用台语语气词（哦/咧/呢）增强口音识别度，但书面标记统一用标准汉字。
- 唇形误差的实测法：生成后取对白首字与末字两帧，与音频波形起止点比对，超 0.05 秒即标记重生成，不靠肉眼目测。

## 常见问题

- 皮肤像橡胶/滤镜脸：原因是真实皮肤标准未写入。解决步骤：① 检查真实皮肤四标准（毛孔/细纹/生理色差/肤色过渡）是否写入角色描述；② 面部补不对称特征（单双睑/眉高差/疤痕痣）；③ 负向词加"无磨皮、无美颜、无塑料感"；④ 重跑角色卡并确认。
- 镜头呆板：原因是运镜多样性不足。解决步骤：① 按质检清单检查运镜多样性；② 检查 S 曲线加减速与光轴夹角；③ 每镜至少一个运动词（推拉摇移升降跟）；④ 补荷兰角/急推/环绕等张力镜头。
- 音画不同步：原因是唇形误差超限。解决步骤：① 唇形误差超过 0.05 秒即标记重生成该镜；② 不得带病合成；③ 生成时锁定 24fps 与原生配音；④ 质检阶段逐镜实测首末字帧对齐。
- 台腔音色漂移：原因是多段生成使用了不同样本。解决步骤：① 每角色只绑定一个声音样本；② 全片镜头沿用同一样本 ID；③ 生成后抽检 2-3 镜音色一致性；④ 漂移镜重跑并锁样本。
- 对白吞字：原因是语速或句长失控。解决步骤：① 句长控制在 15 字以内；② 语速随情绪起伏（急段快、缓段慢）；③ 复核对白是否清晰不吞字；④ 问题句重生成。
