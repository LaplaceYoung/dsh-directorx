description: >-
  适用于故事驱动型视频完整生产：角色卡头像+全身横版布局、音色参考锁定、
  首尾帧动势设计、音频驱动表演提示词与六规则电影感提示词。

## 技能定位

本技能面向需要"角色一致+表演自然+多镜连贯"的故事型视频。区别于基础版，它强调三件事：角色参考图采用"左头像右全身"横版布局锁定身份与造型；每镜提示词围绕"变化与动势"展开而非重复静态细节；音色通过短参考样本锁定，支持对白驱动的口型与表演。

本技能把整片划分为若干"镜头连续性组"：同一场景、同一角色状态、共享同一套元素资产的镜头归为一组。连续性组是跨镜一致性的管理单元——组内后镜引用前镜、组间以新的关键帧锚点衔接，也是排查漂移时的最小回溯范围。

## 适用场景

- 多镜段故事短片，含对白、内心独白或旁白。
- 角色需要跨镜保持形象与音色一致的项目。
- 需要音频驱动（对白/演唱）的表演镜头。
- 同一角色多造型、多场景穿插叙事的项目，需按连续性组管理资产。

## 制作流程

### 元素资产命名规范

所有资产统一命名，保证引用不串位、不漂移：

| 资产类型 | 命名格式 | 示例 |
|---|---|---|
| 角色 | R<序号>_<角色名>_<Look 编号> | R1_父亲_Look1 |
| 场景 | S<序号>_<场景名> | S1_书房 |
| 道具 | P<序号>_<道具名> | P1_怀表 |
| 音色参考 | V<角色序号>_<用途> | V1_旁白 |
| 关键帧 | K<镜号>_<瞬间类型> | K3_开场 |

命名确定后全片沿用：分镜表与提示词都用标识引用，不写全名描述，避免各镜措辞不一致导致形象漂移。

### 六步流水线

1. 锁定规格（标题、类型、画幅、时长、视觉风格、语言）。
2. 设计分镜：关键元素（人物/场景/道具）、镜头表、音轨；先扫描并绑定用户已有或历史生成的匹配资产。
3. 元素配置：已上传的图直接绑定；否则生成全部元素图——每个角色一张"左头像右全身"横版参考图（左侧紧构图头像用于确认身份/肤色/眉眼/发际线，右侧全身用于服装/发型/妆造/鞋履/剪影）；角色音色参考音频（15 秒内）。
4. 逐镜生成视频：每镜引用本镜全部元素图；仅当前镜与前一镜存在极高连续性时才附加前一镜成片。
5. 生成音轨：全局 BGM；旁白按需设计为独立音轨（音色、语气、完整文案、覆盖镜头范围）。
6. 合成导出。

### 镜头连续性组

| 组号 | 包含镜头 | 共享元素 | 衔接规则 |
|---|---|---|---|
| G1 | 镜 1-3 | R1_Look1、S1 | 组内后镜可引用前镜成片；关键帧链式引用 |
| G2 | 镜 4-6 | R1_Look2、S2 | 跨组首镜先出新的关键帧锚点再生成 |

分组规则：同场景+同角色状态归一组；组内镜头按时间顺序生成，后镜引用前镜；跨组首镜必须重新锁定关键帧锚点，禁止跨组引用成片，防止造型状态串位。

### 首尾帧设计清单

首帧（动势意图）：写动作发生前的准备——重心偏移、视线方向、四肢预载、未触发的效果、环境基线、机位初始取景。尾帧（动势结果）：写动作落地后的接触/冲击/结束姿态、环境变化、为下一镜衔接准备的机位落点。检查项：主体意图→运动方向→环境状态（前/后）→机位设置→道具状态一致性锚。

### 视频提示词写作规范

- 结构：提示词=主体+运动、背景+运动、镜头+运动；用简洁直接句，模型会基于帧内容自行扩展。
- 主体动态：写自身动作（表情变化、移动、相对镜头的主动转向）；静止必须显式写"完全静止、目视前方"；动作务必带程度副词（快速/剧烈/大幅/高频）。
- 多动作序列：支持"主体 1+动作 1+动作 2"或多主体并列，用 First/Then/Finally、时间戳（0-3 秒/3-6 秒/6-9 秒）或"切到"标记组织顺序。
- 镜头运动：自然语言描述轨道/航拍/变焦/横摇/跟拍/手持/切；含镜头运动的提示词基参数为非固定机位；相机静止必须写"静态镜头/固定机位"。
- 手持微晃与胶片颗粒（写实默认）：写入"极轻微手持微晃、轻微自然漂移、微呼吸感"（小幅连续）；画面"细腻 35mm 颗粒、轻微化学胶片颗粒"，克制使用。
- 对白与音效：写清逐字台词；无对白必须写"无对白"；关键同步音效（雷声、电话铃）单独写明；不需要则写"无音效"。
- 音频驱动表演（对嘴/演唱）：按"运镜+说话人情绪+说话状态+具体身体动作+（可选）背景事件"组织。

#### 音频驱动表演提示词模板

```
[运镜描述]，[说话者情绪]地[说话状态]，
[具体身体动作序列]；[可选背景事件]
负向：无音乐、无字幕、无多余人物
```

占位符说明：
- [运镜描述]：镜头运动自然语言，或"固定机位"。
- [说话者情绪]：亲切/严肃/激动/喜悦等单一情绪词。
- [说话状态]：正在说话/唱歌/含泪讲述/讲解。
- [具体身体动作序列]：用"先…再…"连接 2-3 个动作，如"先整领口再张开双臂仰头"。

示例成句：

```
镜头跟随人物转向镜头边走边唱，喜悦地开口演唱，
先整领口再张开双臂仰头望向天空；背景人群逐渐虚化
负向：无音乐、无字幕、无多余人物
```

### 图片提示词六规则

专业风格术语、构图景别、布光（强调负空间光）、调色（单一主色调约占 90%、极度克制、禁默认红蓝霓虹）、画面呈现（细腻渲染/丰富细节/柔焦）、情绪与潜台词（微表情凝固戏剧瞬间；条件项：屏幕文字用引号精确引用）。元素图围绕"主体与身份、特征细节、情绪基调"组织；首尾帧按静态单一瞬间描述。

### 音轨设计参数

| 音轨 | 电平参考 | 说明 |
|---|---|---|
| 旁白 | -6dB 上下 | 主轨，清晰可闻；逐字稿与分镜台词一致 |
| BGM | -18 至 -20dB | 全局一条，氛围层；人声出现时自动闪避 |
| 音效 | -12 至 -15dB | 关键同步音效单独成轨，与画面时间码对齐 |
| 视频自带音 | 静音/衰减 | 合成时全部静音，防止叠音 |

### 合成检查清单

| 检查项 | 判定标准 | 不通过处理 |
|---|---|---|
| 时长 | 误差≤±0.1 秒 | 按时间码逐镜对齐 |
| 音画同步 | 偏差≤1 帧@30fps | 调整音频轨起点 |
| 画幅 | 全片一致 | 回到规格确认 |
| 音轨层级 | 旁白>音效>BGM，无叠音 | 静音视频自带轨 |
| 镜头衔接 | 无跳帧无残影 | 重出问题镜 |

## 进阶技巧

- **角色参考图"左头像右全身"布局是身份与造型的双重锁定**：头像定五官肤色，全身定服装剪影；生成时严格保持左右分区比例，不要改成单图全身或双头像，否则约束力减半。
- **首尾帧只描述单一静态瞬间，动态全部交给视频提示词**：分工明确可大幅提升出片稳定性；首帧写动势准备（重心/视线/预载），尾帧写动势结果（落地/接触/机位落点），按"主体意图→运动方向→环境状态→机位→道具状态"逐项核对。
- **关键帧链式引用按连续性组管理**：组内后镜引用前镜相似帧形成链条，链条中断时从最近的成功帧重新派生；跨组必须先出新的关键帧锚点，禁止跨组引用成片，防止造型状态串位。
- **音频驱动表演按"运镜+情绪+说话状态+身体动作+背景事件"结构写**：对嘴型与肢体联动最自然；对白逐字稿写入镜头表，口型由音频驱动模型自动对齐，提示词不要描述嘴部细节。

## 常见问题

- **角色造型跨镜漂移**：原因：各镜提示词对服饰/发型描述不一致，或未引用元素卡。解决步骤：① 所有提示词沿用元素卡中的同一套服饰/发型词汇，逐字复制不缩写；② 每镜同时引用元素图与首尾帧双轨约束；③ 核对命名规范，确认使用的是同一资产标识。
- **动作幅度含糊**：原因：运动描述缺少程度副词，模型自行放大或缩小动作。解决步骤：① 任何运动描述都必须带程度副词（快速/剧烈/大幅/高频）；② 静止必须显式声明"完全静止、目视前方"；③ 复核镜头表，每个动作都有程度词才进入生成。
- **音频冲突**：原因：旁白轨与视频提示词内嵌音频、视频自带音轨三者叠在一起。解决步骤：① 独立旁白轨的镜头不写入视频提示词；② 成片提示词固定加"无音乐、无字幕"；③ 合成时静音所有视频段原音轨，只保留旁白与 BGM。
