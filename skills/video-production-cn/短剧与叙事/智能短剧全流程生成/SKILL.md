# 智能短剧全流程生成

## 技能定位

本技能把短剧生产组织成一条环节间数据契约明确的流水线：剧本解析→规格锁定→分镜设计→设定图→轨迹图→逐镜视频→音频→合成，每一步的输出格式固定、可被下一步直接消费。核心方法论有三：一是以"空间锚定卡"保证跨镜空间一致性——每个镜头开头的固定格式声明场景基准点、角色当前站位朝向与灯光基调，相邻镜头以此对齐；二是"每镜一次生成"的单镜头思维——镜头时长硬上限 15 秒、单镜 2-6 个内部剪辑、同镜角色不超过 3 人，优先设计长镜头而非拆碎短镜；三是逐阶段暂停确认——每完成一阶段必须停下等用户确认，禁止一次性全流程输出导致返工成本爆炸。

## 适用场景

- 小说/散文改编短剧：需先完成短剧化改编再进入分镜，禁止擅自补充脚本未描述的角色外貌与场景细节。
- 成熟分镜脚本（按场/镜划分、含景别运镜台词）：可直接进入分镜设计。
- 半结构化脚本（有场景描述但缺完整镜头语法）：分镜阶段自动补全景别角度运镜。
- 竖屏短剧（9:16）与横屏剧集，目标时长数分钟内的单集或多集项目。

## 制作流程

### 第一步：脚本解析与分类

接收 txt/docx 文件或粘贴文本，通读后判定类型：A 类成熟分镜脚本可直接进入分镜；B 类散文/纯对话文本必须先告知用户完成短剧化改编（把叙述转化为分镜脚本）；C 类半结构化脚本可直接进入分镜但需补全镜头语法。无论何种类型都必须提取结构化信息：角色表（姓名、出场场景、外貌服装描述——只提取脚本明确写出的内容，缺失项标注"待用户提供"）、场景表（名称、空间特征、覆盖镜头范围）、关键道具、剧情结构（起承转合各幕及镜头数估计）。缺失信息一律主动询问，禁止默默假设。

单集结构按"钩子-冲突-反转-悬念"四段排布（以 3 分钟单集为例）：

| 时段 | 功能 | 时长 | 内容要点 | 镜头策略 |
|---|---|---|---|---|
| 0-15 秒 | 钩子 | 15s | 开场即冲突或悬念，抛出问题，不铺垫背景 | 1-2 镜，中近景起步，信息集中 |
| 15-90 秒 | 冲突升级 | 75s | 目标受阻，矛盾逐级放大，每 20 秒一次小推进 | 3-4 镜，正反打为主，守住轴线 |
| 90-150 秒 | 反转 | 60s | 关键信息翻面，立场互换，节奏加快 | 2-3 镜，特写收束，剪率提高 |
| 150-180 秒 | 悬念收尾 | 30s | 新问题出现，留钩子给下集 | 1-2 镜，节奏放慢，收在悬念 |

多集项目：每集钩子与前集结尾呼应；连用两集同款钩子必须换式；单集超过 3 分钟按 60 秒一个节拍块拆分，每个节拍块内保持一次情绪升降。

### 第二步：规格锁定与关键元素注册

写入全局参数：画幅、目标时长、画面风格基调、输出语言。注册全部关键元素：角色（年龄/性别/外貌/发型/服装/标志性细节，多套服装或时间线分别列出）、场景（空间结构、固定参照点、材质/光源/色温/氛围词）、关键道具；角色音色单独注册并与角色关联。

### 第三步：镜头拆解与空间锚定

每镜等于一次视频生成任务，时长 ≤15 秒（超限必须拆分）。批量拆分规则：单镜 2-6 个内部剪辑；同镜角色 ≤3 人（超出拆分）；单镜内保持同一物理空间（跨空间必须新镜）；优先设计 8-15 秒长镜头，避免把连续场景拆成过多短镜。每个镜头描述必须包含：场景（引用场景 ID）、角色动作与台词（按时间顺序写明具体台词）、镜头语法三件套（景别+角度+运镜，三者缺一不可）。每个镜头开头必须以空间锚定卡声明：【空间锚定/场景名】固定参照点（不可移动的视觉地标）、角色当前状态（位置+朝向）、灯光基调（光源类型+色温+氛围词）。相邻镜头必须保持角色站位/朝向/手持物一致，同场连续镜头归入同镜或相邻镜，跨场转场必须明确标注。

### 第四步：分镜交付前自检

逐项检查并报告，判定标准与失败处理见下表：

| 检查项 | 判定标准 | 失败处理 |
|---|---|---|
| 原稿覆盖 | 关键动作/台词/反转全部出现 | 补镜，不静默删减 |
| 位置连续性 | 前后镜站位/朝向/手持物一致 | 修正锚定卡或重排镜序 |
| 轴线规则 | 无越轴，出入画方向一致 | 插正面或过肩过渡镜 |
| 单镜时长 | ≤15 秒且内部剪辑符合景别建议 | 拆镜或改用节奏词 |
| 空间一致 | 同镜无场景穿越，灯光与上镜一致（剧情硬切除外） | 拆新镜并标注转场 |
| 代号统一 | 角色代号全片一致 | 全局替换后再交付 |
| 音画对齐 | 音效/台词与动作对齐 | 调整台词位置或拆镜 |

内部剪辑时长按景别取值：极特写/手足特写 1.5-2.5 秒，带台词特写 2-4 秒，中近景带台词 2.5-4 秒，中景/中远景 3-5 秒，全景/建立镜头 3-5 秒，推拉摇移镜头=基础时长+1 秒。发现问题先与用户确认，不得静默改稿。

### 第五步：设定图与镜头轨迹图生成

角色用"三视图"：单图横向并排正/侧/背三个全身视角，服装配饰发型体型三视完全一致，中性灰背景均匀棚光。场景用"四视图"：2×2 网格展示建立镜头/主入口中景/关键道具特写/反打角度四角，四格灯光色调陈设一致，画面内禁止出现人物。设定图生成后暂停确认风格。

角色一致性策略四件套与复用规则：

| 资产 | 绑定时机 | 复用规则 |
|---|---|---|
| 三视图 | 每镜必引 | 逐镜引用同一张，不换图 |
| 特征描述块（60-100 字锁定词） | 每镜必写 | 原样复制，禁止改写措辞 |
| 服装时间线 | 换装镜头 | 提示词标注"当前为第 X 套服装" |
| 音色资产 | 带台词镜 | 跨镜必须同一声源 |

随后为每个镜头生成"镜头运动轨迹图"作为视觉施工蓝图：相机运动轨迹箭头（不同颜色区分推/拉/摇/升降/跟/固定）、每个内部剪辑的中文动作说明、景别与时长标注、机位指示（相机图标+虚线轨迹）。轨迹图只用于确认镜头逻辑，不作为视频生成的参考输入。

### 第六步：逐镜视频生成

每镜引用该镜涉及的全部角色元素图+对应场景元素图。仅当与前一镜连续性极强（同一动作延续、未剪辑场景推进）时才把前一镜结尾视频作为参考视频传入，通常不加视频参考以免模型过度继承上一镜构图而弱化本镜运镜设计。带台词镜头传入该角色音色以保证跨镜音色一致。

### 第七步：音频生成与合成

BGM 独立生成（不嵌入视频），情绪转折明显的长片可分多段并标注覆盖范围；旁白注册为解说轨道（音色、语气、脚本全文、覆盖镜头范围）。合成按分镜顺序装配：同物理空间相邻镜头用无缝硬切，跨空间用 0.3 秒内淡入淡出；发现越轴时插入正面或过肩过渡镜而非强行拼接。音量层级：BGM 比对白低 8-12dB，情绪高潮可加 3-5dB；解说与对白同级并严格对齐画面；BGM 与对白/解说间用 0.5 秒交叉淡化防跳变。导出前处理常见故障：角色外貌漂移→强化特征描述重生成；越轴→插过渡镜；时长偏差→用"缓慢/快速/停留"节奏词替代绝对秒数并在时间线微调；画面出现字幕→负向词强化"无字幕无文字叠加"。

### 第八步：首尾帧衔接策略

第一镜以关键元素四视图的建立镜头视角作为起始帧；后续镜头把上一镜结尾帧作为本镜起始帧，与空间锚定卡的本镜初始状态逐一核对站位朝向手持物，不一致则重生成上一镜或修正本镜锚定描述，禁止跳过检查直接拼接。导出规格：帧率 24fps；慢动作段落先对目标镜头插帧提升至 60fps 再合入时间线；画幅与生成最高规格一致，升级先超分再导出。

### 第九步：批量生成流水线

- 批次规划：按场景分组批量生成（同场景镜头一批，保持光照与空间一致）；每批 4-6 镜，批间暂停核对。
- 排队策略：先设定图与关键帧，再 B 级镜头（过场、空镜），最后 A 级镜头（核心情绪/动作镜）——把失败风险最高的 A 级镜头留到风格验证之后，避免风格未定就浪费核心镜头。
- 重试与失败处理：单镜失败同配置重试一次；连续 3 镜同类失败，回退到设定图阶段检查风格参数；失败镜头登记原因，禁止静默换参数蒙混过关。
- 资产缓存：已通过的镜头、设定图、音色一律入资产库，跨集复用不重复生成；系列剧第二集起直接引用第一集资产。

## 提示词模板

单镜视频提示词按六段结构组织：

```
【视觉风格】{电影级质感，变形宽银幕，胶片颗粒，24fps，自然景深，三点戏剧布光，电影级调色}
【场景】<<<场景图_场景ID>>>，{当前灯光基调}
【角色】<<<角色图_角色ID>>>，{当前服装状态}
【运镜】{景别}，{角度}，{运镜}
【动作台词】{主动作}，然后{次要动作}，{“台词”}（{情绪}）
【结尾】无字幕，无背景音乐，无文字叠加，无水印，时长约 X 秒
```

占位符说明：

| 段 | 填写要求 | 示例 |
|---|---|---|
| 视觉风格 | 全片复用同一套风格词，不换措辞 | 电影级质感，胶片颗粒，24fps，三点戏剧布光 |
| 场景 | 引用场景图并标注灯光基调 | <<<场景图_教室>>>，午后暖光，色温 4200K |
| 角色 | 逐个引用角色图并标注服装状态 | <<<角色图_林晓>>>，身着校服 |
| 运镜 | 景别+角度+运镜三者齐全 | 中景腰部镜头，固定机位，平视 |
| 动作台词 | 主动作→次要动作按叙事顺序，台词用花括号 | 她快步走到窗边，{“我真的受够了”}（愤怒） |
| 结尾 | 固定负向词+时长 | 无字幕，无背景音乐，无文字叠加，无水印，时长约 8 秒 |

示例成句（可直接套用）：

```
电影级质感，变形宽银幕，胶片颗粒，24fps，自然景深，三点戏剧布光，电影级调色，<<<场景图_教室>>>，午后暖光色温 4200K，<<<角色图_林晓>>>身着校服，中景腰部镜头，固定机位，平视，她快步走到窗边，然后猛地拉开窗帘，{“我真的受够了”}（愤怒），无字幕，无背景音乐，无文字叠加，无水印，时长约 8 秒
```

背景音乐由独立音频层在合成时混入，对白与音效可嵌入视频。

## 进阶技巧

- 把"空间锚定卡"当作跨镜一致性的唯一事实源：所有镜头描述都从锚定卡出发，生成前逐镜对照，能系统性消灭角色瞬移与灯光跳变。
- 长镜头内部切换用"先主后次"顺序：主动作→次要动作，用速度形容词（缓慢/快速/停留）描述节奏，避免绝对秒数导致模型无感。
- 同一物理空间的连续戏尽量合并到同一次生成长镜头中，既省生成次数又天然保连续；跨空间才拆镜。
- 轨迹图阶段是免费的纠错窗口：发现运镜或节奏问题在轨迹图阶段改，比视频生成后改便宜一个数量级。
- 集间一致性：多集项目每集开头用"上集回顾"锚定卡对齐角色站位、服装状态与灯光，第二集起直接复用第一集资产库。
- 批量出片节奏：单集 180 秒按 3 批生成，批间核对并休息，避免连续生成导致疲劳返工；单批内同场景镜头优先。

## 常见问题

- 角色跨镜变脸
  原因：角色描述不具体或三视图未绑定。
  解决步骤：① 补全特征描述块（60-100 字）并锁定措辞；② 确保每镜都引用同一张三视图；③ 生成后与首镜同屏对比；④ 漂移明显则强化特征词重生成。
- 同场景相邻镜位置跳变
  原因：未执行空间锚定卡核对。
  解决步骤：① 逐镜补站位朝向声明；② 用上一镜结尾帧对照本镜初始状态；③ 不一致则重生成上一镜或修正锚定描述；④ 禁止跳过检查直接拼接。
- 越轴造成方向混乱
  原因：相邻镜违反 180 度规则。
  解决步骤：① 分镜阶段标注轴线；② 合成时发现越轴，插入正面或过肩过渡镜；③ 不强行拼接。
- 镜头时长超标
  原因：内部剪辑过多或提示词含绝对秒数。
  解决步骤：① 按景别建议值核对内部剪辑；② 超 15 秒拆镜；③ 用"缓慢/快速/停留"节奏词替代绝对秒数。
- 视频内混入字幕与音乐
  原因：负向词未写全。
  解决步骤：① 固定结尾统一写"无字幕，无背景音乐，无文字叠加，无水印"；② 强化负向词并重生成；③ BGM 由独立音频层在合成时混入。
