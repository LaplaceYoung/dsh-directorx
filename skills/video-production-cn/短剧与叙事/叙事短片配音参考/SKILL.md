# 叙事短片配音参考

## 技能定位

本技能以"剧本保真"为最高优先级制作叙事短片：分镜中的对白、旁白、动作结果与场景顺序必须严格忠于用户剧本，只允许技术性编辑（拆分镜头、补充镜头语言字段），不得虚构情节或改写台词。流程上独有"声音锚点"机制——每个有台词的角色都要建立专属声音参考，作为镜头生成的音频条件输入，保证跨镜头音色一致。

## 适用场景

- 用户自带剧本（图片/PDF/文本）或口头故事想法的短片制作。
- 需要多角色对白且音色稳定的叙事短片、微短剧。
- 以"对白表演"为核心、对音色一致性要求高的项目。

## 制作流程

### 第一步：剧本获取（二选一）

- 用户已上传剧本文件：解析后输出一句话故事摘要与结构化关键信息（人物、场景、故事线索），先请用户确认理解无误再继续。
- 用户未上传剧本：用两轮卡片收集——第一轮收集核心需求（主题一句话、视频类型、主要角色数量与大致背景），第二轮收集风格与约束（整体视觉风格与色调、大致时长、特殊要求或参考作品）；随后起草完整剧本（含场景拆分、角色对白、动作描述）全文输出供审阅。剧本确认必须显式二选一（确认制作/需要修改），循环修改直到确认。

### 第二步：规格与分镜

把标题、类型、画幅、时长、视觉风格、语言与模型偏好写入全局规格。规格默认值：画幅 16:9、单镜 ≤15 秒、分辨率 720p 生成 1080p 输出。分镜设计：优先 10-15 秒含内部切换的长镜头，按剧情节奏设计镜头内切换而非拆成许多短镜；每镜不超过 15 秒。每镜含场景引用、剧情内容（写出精确台词）、镜头语言（景别、角度、运动）；镜内切换用明确标记（如"镜头1（0-4秒）：…特写。镜头2 切至（4-8秒）：…"）。

### 第三步：元素资产与声音锚点

- 元素按独立实体分配编号；人物多造型分列描述并写入音色特征；用户已上传的元素直接绑定。
- 人物参考图用横版并排布局：左侧头部特写（锁定面容、肤色、眼睛、发际线），右侧全身（服装、发型、妆容、鞋型与轮廓）。
- 每个有台词角色建立声音锚点：用户上传声线参考则直接绑定；未上传提供两条路径（并说明消耗差异）：路径 A 用自然语言生成配音（由旁白/对白文本＋角色情绪、语气、表演细节与场景语境构建提示词，不需要用户选任何音色 ID）；路径 B 从角色视频提取（引用角色元素图生成约 3-5 秒含角色说话的视频，再从中提取音频注册为声音锚点，消耗更多需提示用户）。锚点表字段：角色、锚点来源（上传/路径 A/路径 B）、音色特征描述、状态。

### 第四步：镜头视频生成

每镜引用该镜涉及的角色元素图与场景/道具图，同时输入对应角色的声音锚点作为音频条件输入保证音色一致。与前镜连贯性极强时才追加前一镜成片作为参考视频。

### 第五步：音频与合成

至少一条全局配乐，有明确节奏/情绪变化的参考片按段落拆分配乐段。旁白或对白在音频层设计（含内容、音色语气、时间范围）。全部就绪后按分镜与时间线顺序合成并引导导出。每个阶段之间暂停确认。

## 提示词模板

**对白镜头模板：**
```
[镜头编号]：{景别}{角度}{运镜}，{主体动作（部位+程度副词）+微表情}，
{空间与背景动态}，{对白}（花括号，仅台词原文，不带引号），
[角色声音锚点]引用，{音频标记}，
[参考图点名：头像图提供面容、全身图提供服装]，
[电影感六规则词]，no text, no watermark
```

**示例成句（情绪对白镜）：**
```
镜头2：中景侧光，她缓缓抬起头，眼睑微垂，指尖轻抚茶杯边缘，
窗外雨丝斜落，{我早该知道的。}（声音锚点引用角色 A），
<雨声渐强>，头像图提供面容、全身图提供服装，
电影感构图，克制冷色调，戏剧性瞬间微表情，no text, no watermark
```

**路径 A 配音提示词模板（自然语言生成）：**
```
旁白/对白文本：{台词原文}；
角色情绪：{情绪词}；语气：{语气描述}；表演细节：{微动作/停顿标记}；
场景语境：{场景一句话}；音色画像：{年龄/质感/语速}
```

## 风格关键词与参数表

**核心关键词清单：** 剧本保真、声音锚点、音频条件输入、横版并排参考图（特写+全身）、路径 A/B 配音、对白花括号、电影感六规则、镜内切换。

**声音锚点路径对比表：**

| 路径 | 做法 | 消耗 | 适用 |
| --- | --- | --- | --- |
| 上传声线 | 直接绑定 | 无 | 用户有声样 |
| 路径 A | 自然语言生成配音 | 少 | 快速起步 |
| 路径 B | 角色视频提取音频 | 多 | 需要角色专属音色 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 10-15 秒（内部切换） | 每镜 ≤15 秒 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率 | 720p 生成、1080p 输出 | — |
| 声线参考 | ≤15 秒 | 绑定角色 |
| 配乐 | ≥1 条全局，可按段拆分 | — |
| 声音锚点 | 每有台词角色 1 个 | 逐镜输入 |

**禁用项清单：** 虚构情节、改写台词、花括号带引号、缺声音锚点的对白镜、音色跨镜漂移、摆拍式僵硬表演、秒级精确时间计划。

## 进阶技巧

- 提示词六条电影感核心规则：专业风格术语（引用作者导演与具体影片锚点）、构图与景别、强调负填充与对比的光线、克制的单一主色调（约 90% 面积，除非用户要求否则禁霓虹洋红/青紫撞色）、渲染质感、氛围与潜台词（冻结在戏剧性瞬间的微表情，拒绝僵硬摆拍）。
- 动作描述锚定具体身体部位并加程度副词（缓缓举起一只手、猛地甩头向左、用力蹬地弹起）；多节拍按故事时间顺序列出主动作与次动作。
- 不要写秒级精确计划（"0-3 秒""在 2 秒时"），用顺序描述而非时间表；单次生成可标"镜头1/镜头2/镜头3"承接多节拍。
- 对白花括号内只放台词原文，不带剧本里的引号；非项目语言的对白在花括号前标注语言。
- 一致性控制：每镜提示词显式引用声音锚点；角色多造型按 Look 分列并绑定同一音色特征描述。
- 规避翻车：长对白拆成镜内多节拍并分段标注情绪；多角色同框镜按"主角→配角"逐人描述并逐人绑定锚点。

## 常见问题

- 角色音色跨镜漂移：原因：声音锚点缺失或未作为音频条件输入。解决步骤：补建锚点并逐镜输入；锚点表登记来源与状态，缺锚点禁生成对白镜。
- 剧情被擅自改动：原因：分镜阶段出现虚构情节或改写台词。解决步骤：回退到剧本保真原则，仅允许拆分与技术字段编辑；逐镜核对台词原文。
- 台词显示残留引号：原因：花括号里带了剧本引号。解决步骤：只保留台词原文；非项目语言在花括号前标注语言。
- 生成结果像摆拍：原因：缺少微表情与氛围潜台词描述。解决步骤：按六条核心规则补写戏剧性瞬间与情绪潜台词；动作加程度副词。
- 音色与角色不符：原因：路径 A 缺音色画像。解决步骤：路径 A 提示词补音色画像（年龄/质感/语速）与情绪语气；或改走路径 B 提取角色专属音色。
