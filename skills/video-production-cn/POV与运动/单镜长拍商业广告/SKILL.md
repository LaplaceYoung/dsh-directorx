# 单镜长拍商业广告

## 技能定位

本技能用"多镜串接"实现一镜到底效果：每个镜头 10-15 秒、内部自带节奏切换，镜头之间通过"首帧衔接"（前一镜尾帧作为后一镜首帧）或"参考视频"（前一镜成片作为后一镜运动参考）两种模式无缝对接，最终合成时相邻镜头一律硬切、禁止任何淡入叠化转场，呈现出近乎完美的一镜到底长镜观感。

## 适用场景

- 需要连续流畅视觉的产品广告、品牌片。
- 一个镜头穿越多个场景空间的展示类项目。
- 强调"无缝衔接"炫技感的商业短片。
- 产品贯穿多个使用场景、需要"一镜带过"的品牌叙事。

## 制作流程

### 第一步：规格与分镜

锁定标题、类型、画幅、时长、视觉风格与语言。规格默认值：画幅 16:9、单镜 10-15 秒、分辨率 720p 生成 1080p 输出。分镜优先 10-15 秒含内部切换的长镜头；从第 2 镜起，每镜描述必须包含"续接描述"——本镜开场状态（人物位置、视线方向、手势、场景光线、起始景别与角度）必须与上一镜结束状态严格一致；相邻镜之间避免瞬移与大幅场景变化，除非是刻意设计的匹配剪辑或艺术性平滑转场。

### 第二步：元素与音频

人物参考图横版并排（左侧头部特写锁定面容、右侧全身锁定服装造型）；声线参考音频时长限制在 15 秒内。配乐至少一条全局轨，长片按转折拆段；长段旁白在音频层定义音色、语气与精确文案。

### 第三步：镜头生成（两种模式，先让用户选择）

向用户说明两种模式的利弊并让其选择，未选择不得继续。模式对比表：

| 模式 | 速度 | 消耗 | 效果 | 适用 |
| --- | --- | --- | --- | --- |
| 模式一（首帧衔接） | 快 | 少 | 可能有轻微卡顿感 | 预算/时间有限 |
| 模式二（参考视频） | 慢 | 很高（慎重选择） | 更连贯流畅 | 追求极致丝滑 |

- 模式一（首帧衔接）：首镜以元素资产生成；后续每镜先解析上一镜最后一秒的最后一帧（必须是清晰完好的画面，不能是黑场或渐隐损坏帧）提取为关键帧，绑定为本镜起始帧，再连同本镜元素资产生成。逐镜强制暂停确认，满意才提取尾帧进入下一镜。
- 模式二（参考视频）：首镜以元素资产生成；后续每镜直接把上一镜成片绑定为参考视频，再连同本镜元素资产生成。逐镜强制暂停确认。

### 第四步：不理想镜头的重做机制

若中间某镜不满意需重做：取后续镜头 N+1 的首帧参考图绑定为本镜 N 的结束帧，以本镜原起始帧（模式一为提取的尾帧图/模式二为前一镜视频）为起点、新绑定结束帧为终点，用"起止双帧"模式重做本镜，再辅以元素资产。重做后暂停确认，满意后重新插入时间线。

### 第五步：合成

一镜到底无缝装配规范：相邻镜头已经由起止帧对齐，时间线上严格禁止淡入、叠化、白闪或任何第三方转场，所有连接点一律硬切，表现镜头间物理动势的无限连续；全局配乐与旁白在硬切点之间保持平滑不间断，不得在切换点出现音频顿挫或音量突变。

**首镜模板：**
```
[产品/品牌]在[场景]的[初始状态]，{10-15 秒内部节奏切换}，
[元素资产引用]，[光线]，电影感商业广告，
no text, no watermark
```

**续接镜模板（首帧衔接模式）：**
```
严格以[上一镜尾帧图]为起始帧；
本镜开场状态：{人物位置、视线方向、手势、场景光线、起始景别与角度}与上一镜结束状态一致；
{本镜内容与内部切换}，[元素资产引用]，电影感商业广告，
no text, no watermark
```

**示例成句（续接镜）：**
```
严格以上一镜尾帧为起始帧；
本镜开场：人物位于画面右 1/3 面向左、视线朝镜头、右手持产品、
暖侧光、中景起幅与上一镜结束状态一致；
镜头平稳右移跟拍穿过厨房进入客厅，产品从右手交到左手再举向镜头，
配乐延续上一段鼓点，电影感商业广告，no text, no watermark
```

## 风格关键词与参数表

**核心关键词清单：** 多镜串接、一镜到底观感、首帧衔接、参考视频、续接描述六要素（位置/视线/手势/光线/景别/角度）、起止双帧重做、硬切无缝、音频平滑。

| 要素 | 核对要求 |
| --- | --- |
| 人物位置 | 与上一镜尾帧一致 |
| 视线方向 | 与上一镜尾帧一致 |
| 手势 | 与上一镜尾帧一致 |
| 场景光线 | 与上一镜尾帧一致 |
| 起始景别 | 与上一镜尾帧一致 |
| 角度 | 与上一镜尾帧一致 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 10-15 秒（内部切换） | 全片串接 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 分辨率 | 720p 生成、1080p 输出 | — |
| 声线参考 | ≤15 秒 | 绑定角色 |
| 转场 | 一律硬切 | 禁淡入叠化白闪 |
| 重做模式 | 起止双帧 | 两头无缝 |

**禁用项清单：** 淡入/叠化/白闪/第三方转场、黑场或渐隐尾帧入帧、相邻镜瞬移与大幅场景变化、切换点音频顿挫、音量突变、未选择模式即生成。

## 进阶技巧

- 续接描述要写"状态"而非"动作"：位置、视线、手势、光线、景别、角度六要素与上一镜尾帧严格对齐，是衔接成功的核心。
- 尾帧提取要避开片尾渐隐与花屏帧，选最后一秒内最清晰完整的一帧；宁可多试几帧，不取损坏帧。
- 重做镜头用"起止双帧"模式：起点接上一镜、终点接下一镜，保证重做后两头都无缝。
- 内部节奏切换的锚点设计：单镜 10-15 秒内的切换用"动作接动作"（产品交接、转身、推门），切换点天然成为续接参照。
- 一致性控制：全片配乐/旁白轨在硬切点间保持连续，音量包络平滑；同产品跨镜复用同一元素资产。
- 规避翻车：大幅场景变化镜（如室内→室外）先做"过渡空间"（门口/走廊）缓冲，避免直切穿帮。

## 常见问题

- 镜头衔接卡顿：原因：尾帧提取到黑场或渐隐帧。解决步骤：重新提取清晰尾帧；或改选模式二参考视频；逐镜确认后再进下一镜。
- 出现跳切感：原因：合成时用了转场或相邻镜状态未对齐。解决步骤：改硬切并核对续接描述的六要素；逐要素比对上一镜尾帧。
- 串接后人物瞬移：原因：分镜阶段相邻镜间设计了大幅场景变化。解决步骤：回写续接描述并调整；大幅场景变化加过渡空间缓冲。
- 音频在硬切点顿挫：原因：配乐与旁白轨在切换点出现音量突变。解决步骤：补平滑包络并保持连续性；全局轨在硬切点之间不间断。
- 模式选错后悔：原因：未提前权衡消耗。解决步骤：生成前展示模式对比表让用户选择；中途切换模式从当前镜重新开始，禁止混用。
