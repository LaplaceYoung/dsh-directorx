# 游戏宣传演示视频

## 技能定位

本技能把游戏体验转化为三段式演示视频：开场还原登录与角色选择的界面交互，中段呈现剧情对话与世界探索，末段以高烈度战斗与结算画面收尾。核心难点是游戏 UI 的像素级一致与"可玩感"——通过 UI 锚点锁定、角色四视图资产与场景关键帧的统一，让 AI 生成的画面看起来像真实游玩录屏。

三段结构是硬性框架：A 段建立"可操作的游戏"认知，B 段建立"有世界的游戏"代入，C 段建立"有爽点的游戏"记忆。任何一段缺失都会让成品退化为"CG 动画"，三段不可合并、不可省略。

## 适用场景

- 游戏宣传演示、商店页预告、展会物料。
- 独立游戏开发者的快速概念演示。
- 已有角色立绘或场景图，需要动态化的项目。
- 需要模拟点击、悬停、战斗特效等交互反馈的游戏短片。
- 不适合用于：剧情长片、纯 CG 宣传片、无 UI 的过场动画需求（本技能画面必须服务于"像真实游玩"这一目标）。

## 制作流程

### 第一步：建立全局规格

- 收集用户输入的题材关键词，自动设定故事背景与整体风格（写实/奇幻/赛博朋克等）。
- 写全局规格档案：片名、类型、画幅、总时长（默认 45 秒，三段各 15 秒）、视觉风格、语言。
- 规格确认后进入分镜，不在中途变更风格参数。

全局规格参数表：

| 参数 | 默认值 | 取值范围 | 说明 |
| --- | --- | --- | --- |
| 总时长 | 45 秒 | 30-60 秒 | 三段均分，按总时长取整 |
| 画幅 | 16:9 | 16:9 / 9:16 / 1:1 | 商店页展会 16:9，社媒竖屏 9:16 |
| 分辨率 | 1080p | 720p / 1080p / 4K | 展会 4K，概念演示 720p |
| 帧率 | 30 fps | 24 / 30 / 60 fps | 战斗段可声明 60fps 观感 |
| 视觉风格 | 由题材决定 | 写实/奇幻/赛博朋克/卡通渲染等 | 全片唯一，禁止中途切换 |
| 输出语言 | 简体中文 | 中/英/日等 | UI 与字幕同语言 |
| 色调倾向 | 由题材决定 | 冷灰/暖金/霓虹紫蓝等 | 写入每段提示词并提取全片 LUT |

判定标准：规格档案与用户需求一致、无未决项时暂停确认；有分歧先改规格再开工。失败处理：中途变更风格时回退重写规格档案，已生成分段作废重跑，不做"只改提示词"的补丁式修改。

### 第二步：三段式脚本拆分

- 视频 A（15 秒）系统交互与觉醒：登录界面、角色选择、场景过渡、首次入游戏体验。
- 视频 B（15 秒）叙事交互与追踪：NPC 对话、世界观展示、遭遇目标。
- 视频 C（15 秒）核心战斗与结算：高速战斗、终极技能演示、Boss 击败、胜利结算弹窗。

每段结束都向用户展示并确认，再进入下一段生成。

各段判定标准：A 段须出现至少一次界面交互（点击/悬停/按钮反馈）；B 段须出现对话框与一个对话回合；C 段须出现血条变化与结算界面。缺必备元素即不合格，重写脚本再生成，不向后段推进。

### 第三步：角色与场景资产

- 先用文生图产出角色原始设计稿，再转绘为四视图卡：左侧面部特写，右侧并排全身正面、背面、侧面，全部视图与原始设计在造型、配色、材质上严格一致。
- 将四视图转成 3D 写实角色卡，供后续视频绑定。
- 用图生图生成风格统一的 UI 界面与场景关键帧：开始界面、选人界面、加载界面、场景出生点、第三人称观察视角、Boss 战入场。
- UI 像素锚定：分析带 HUD 的截图，记录血条、技能栏、对话框的精确像素位置，设定为"禁止变形区"。
- 提取全片 LUT 色彩倾向，保证三段视频色调亮度一致，防止色偏。

资产清单与校验标准：

| 资产 | 产出方式 | 校验标准 | 失败处理 |
| --- | --- | --- | --- |
| 角色原始设计稿 | 文生图 | 造型完整、无畸形肢体 | 重写提示词重生成，3 次后暂停询问 |
| 角色四视图卡 | 设计稿转绘 | 四面造型/配色/材质一致 | 与设计稿比对，偏差大则回退重绘 |
| UI 界面关键帧 | 图生图 | 按钮/血条/技能栏位置对齐 | 追加像素锚点描述重生成 |
| 场景关键帧 | 图生图 | 出生点/观察视角/Boss 入场三帧风格统一 | 复用同一 LUT 描述词重生成 |
| 全片 LUT | 提取合成 | 三段取色一致，无色偏断层 | 统一调整色彩倾向描述后重跑 |

### 第四步：分镜设计

- 镜头 A：0-3 秒封面呼吸灯与开始按钮交互；3-10 秒角色展示与悬停高亮；10-15 秒第一人称切入，由特定视角过渡到开阔环境。
- 镜头 B：15-25 秒 NPC 对话（对话框逐字弹出，背景保持环境动画）；25-30 秒镜头跟随角色快速移动至地标，营造遭遇感。
- 镜头 C：30-40 秒实战对抗，血条技能栏实时动态变化；40-45 秒 Boss 击败动作、胜利 UI 弹出与奖励结算特效。

分镜表（三段共 9 镜）：

| 镜头 | 时段 | 景别 | 运镜 | 画面内容要点 | 声音/音效 |
| --- | --- | --- | --- | --- | --- |
| A1 | 0-3 秒 | 全屏 UI | 固定+呼吸光 | 封面 Logo、开始按钮悬停高亮、按下反馈光效 | 点击音、确认音 |
| A2 | 3-10 秒 | 中景 | 缓慢推近 | 角色展示、悬停描边、轻微待机动画 | 环境底噪、悬停提示音 |
| A3 | 10-15 秒 | 第一人称 | 前进+视野展开 | 视角切入、场景由窄变阔、光照渐亮 | 风声渐入、脚步切换 |
| B1 | 15-20 秒 | 过肩中景 | 轻微手持 | NPC 对话、对话框逐字弹出、背景持续动画 | 对话语音、打字音 |
| B2 | 20-25 秒 | 中近景 | 过肩反打 | 主角回应、表情变化、世界观信息浮现 | 对话语音、环境音 |
| B3 | 25-30 秒 | 全景 | 跟随移动 | 快速移动至地标、目标出现、遭遇感建立 | 脚步急促、目标提示音 |
| C1 | 30-34 秒 | 对峙全景 | 固定+震屏 | 对峙图起手、技能蓄力、粒子聚集 | 蓄力音、心跳低鸣 |
| C2 | 34-40 秒 | 中近景 | 快速摇镜+震屏 | 高频连击、技能释放、血条下降、技能栏冷却 | 打击、技能、震屏低频 |
| C3 | 40-45 秒 | 全景+UI | 定格+结算弹窗 | Boss 倒地、胜利 UI 弹出、奖励结算特效 | 胜利号角、结算音效 |

每镜生成后核对 UI 锁定、角色一致、动作连贯，任一不符即重生成该镜，不进入下一镜。

### 第五步：分段视频生成

- 各段以关键帧为参考图生成：交互段用界面节点图模拟点击、悬停、高亮与光效反馈；对话段保持对话框绝对清晰不晃动；战斗段以对峙图为首帧、结算图为尾帧。
- 强制锁定 UI：血条与技能图标不允许位移、伪影或变形。
- 战斗动作描述包含高频移动、粒子特效与震屏冲击。

生成参数与重试策略：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 每段参考图 | 2-3 张关键帧，首帧必给 | 战斗段首尾双锚定 |
| 单段生成次数上限 | 3 次，超限暂停 | 展示失败样本后调整提示词 |
| UI 锁定声明位置 | 提示词末尾 | 用"禁止位移、禁止变形、禁止伪影"收尾 |
| 动作描述粒度 | 先动作后结果 | 如"角色前冲→三段连击→镜头震屏" |

失败处理：UI 漂移时先检查是否遗漏锁定声明，补齐后重试；连续两次失败则回退重生成该段关键帧。每段完成后暂停，用户确认后才拼接。

### 第六步：合成与交付

- 按顺序拼接三段，同步匹配音效（UI 音、环境音、打击音），输出完整演示视频。
- 渲染规格：分辨率、帧率、运动流畅度按规格档案执行，确保视频层与音频层同时启用。

交付检查清单：

- 三段首尾衔接：A 段结尾与 B 段开头视角连续，无跳变。
- UI 全程锁定：抽检 6 个时间点 HUD 位置，无位移无变形。
- 色调统一：三段取色与全片 LUT 一致，无色偏断层。
- 音画同步：点击音、打击音与画面动作误差小于 2 帧。
- 总时长：与规格档案一致，误差 ±1 秒内。
- 收尾完整：结算弹窗完整展示后结束。

任一检查项不通过即定位到对应分段重做，全部通过后才交付。

### 提示词模板

语法约定：尖括号 <...> 内为可整体替换的短语，花括号 {...} 内为单值填空；同一占位符出现多次时须填相同内容。模板按"画面主体→交互/动作→反馈效果→UI 锁定→风格与色调"顺序书写。

交互段模板：

```
游戏登录界面，<界面风格与配色>，鼠标悬停在{按钮名称}上显示高亮描边，
点击后{界面元素}响应{反馈光效}，过渡到{下一界面名称}，
UI 保持像素级一致，禁止位移、禁止变形、禁止伪影，
画面风格：{风格关键词}，色调：{色调关键词}。
```

示例成句：游戏登录界面，暗黑科技风蓝紫配色，鼠标悬停在"开始游戏"上显示高亮描边，点击后按钮响应扩散光效，过渡到角色选择界面，UI 保持像素级一致，禁止位移、禁止变形、禁止伪影，画面风格：写实科幻，色调：冷蓝霓虹。

对话段模板：

```
第三人称视角，{角色}与 NPC 对话，对话框逐字弹出文字，
背景{环境描述}持续动画，镜头缓慢推近，
人物表情随对话内容变化，对话框绝对清晰，无晃动无模糊，
{角色}服装与{角色}面部严格参照四视图资产，色调：{色调关键词}。
```

示例成句：第三人称视角，猎人少女与 NPC 对话，对话框逐字弹出文字，背景黄昏集市持续动画，镜头缓慢推近，人物表情随对话内容变化，对话框绝对清晰，无晃动无模糊，服装与面部严格参照四视图资产，色调：暖金暮色。

战斗段模板：

```
以{对峙图}为起始帧、{胜利结算图}为结束帧，{角色}释放{技能名}，
高频连击，粒子特效炸开，镜头随冲击震动，
血条实时减少，技能栏冷却转圈，最终 Boss 倒地，
胜利 UI 弹出并结算奖励，UI 禁止位移变形，色调：{色调关键词}。
```

示例成句：以对峙图为起始帧、胜利结算图为结束帧，猎人少女释放"霜刃风暴"，高频连击，粒子特效炸开，镜头随冲击震动，血条实时减少，Boss 倒地，胜利 UI 弹出并结算奖励，UI 禁止位移变形。

### 风格关键词与参数

核心关键词清单（按题材组合使用）：

- 写实系：真实光照、次世代材质、电影级景深、物理布料、皮肤质感。
- 奇幻系：浓郁色彩、法术光晕、浮空元素、古堡遗迹、体积光。
- 赛博朋克系：霓虹紫蓝、雨夜反射、全息投影、义体细节、故障艺术。
- 通用交互词：可玩感、实时 UI、悬停反馈、HUD 锚定、镜头震屏。

推荐参数表：

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 时长 | 45 秒（三段各 15） | 商店页标准长度 |
| 画幅 | 16:9 | 展会与商店页首选 |
| 分辨率 | 1080p / 30fps | 平衡质量与速度 |
| 节奏 | 慢-中-快 | A 缓 B 推 C 爆的情绪曲线 |
| 色调 | 全片统一 LUT | 禁止三段各自调色 |
| 运镜密度 | 每 5 秒一个镜头变化 | 保证"录屏感"而非"PPT 感" |

禁用项清单：真实水印角标、跨段 UI 风格突变、角色换装、三段调色、纯静止超 3 秒、战斗段慢放抒情、无 UI 的纯 CG 感画面、画幅段间切换。

## 进阶技巧

- 首帧-尾帧双锚定控制过程逻辑：战斗段以对峙图为首帧、结算图为尾帧，模型在两端约束下更易保持中间过程合理。操作步骤：1) 产出对峙图与结算图两张关键帧作参考；2) 动作按"起手→过程→收尾"三拍书写；3) 核对中间帧与两端匹配，不匹配则保留一端重跑。
- 把"交互感"写成可见反馈链：抽象词如"有交互感"会被模型忽略，必须写成"悬停高亮→点击反馈→界面跳转→加载"的因果链。操作步骤：1) 每个交互动作拆成触发与结果两段；2) 结果必须有可见变化（高亮、光效、转场、弹窗）；3) 反馈链缺环即重生成。
- 用真实 HUD 兜底 UI：AI 生成的 HUD 再稳定也可能细微漂移，不如在合成阶段叠加真实素材。操作步骤：1) 生成时保留纯净画面区域，提示词声明"HUD 区域留空或简化"；2) 合成时按镜头坐标贴上真实血条/技能栏/对话框素材；3) 锚点以首帧为准，全片锁定同一套坐标。此技巧同时解决字体乱码与图标变形。

## 常见问题

- 血条技能栏变形漂移：原因——模型对 UI 位置记忆不可靠，提示词未声明锁定或参考图分辨率不足。解决步骤：1) 提示词末尾追加"UI 禁止位移、禁止变形、禁止伪影"；2) 参考关键帧缺少完整 HUD 则重生成；3) 仍漂移则合成阶段叠加真实 HUD；4) 抽检 6 个时间点确认锁定。
- 角色在界面间不一致：原因——各段提示词角色描述不统一，或未绑定同一四视图资产。解决步骤：1) 全片引用同一张四视图卡；2) 首段角色描述逐字复制到后两段；3) 换装只改服装层，脸型毛色发型关键词原样保留；4) 仍不一致则重出四视图。
- 战斗段节奏松散：原因——缺少起止约束，动作描述过于抽象。解决步骤：1) 对峙图与结算图双锚定首尾帧；2) 动作按"起手→高频连击→终极技能→收尾"四拍书写；3) 加入震屏、粒子等强度词；4) 中间帧烈度不足则强化动作词重跑。
- 三段色调不统一：原因——各段色调描述不一致，或生成后各自调色。解决步骤：1) 规格档案固定色调基准描述；2) 每段提示词直接复制该描述；3) 生成后套全片 LUT；4) 合成前并排比对取色，色偏段重跑。
- 对话文字乱码或抖动：原因——模型对细密文字渲染弱，对话框区域未做清晰度声明。解决步骤：1) 声明"对话框绝对清晰、无晃动无模糊"；2) 对话框区域保持静态，镜头只推近不横移；3) 文字密集时改后期叠加字幕层；4) 逐字弹出时放慢速度、减少每屏字数。
- 总时长超限：原因——规格未确认就开跑，或各段未按 15 秒上限取舍。解决步骤：1) 先确认规格再生成；2) 超限段精简镜头数量；3) 总长超限优先压缩 B 段（叙事段弹性最大）；4) 重新合成并复核音画同步。
