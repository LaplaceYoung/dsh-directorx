# 单镜长拍叙事短片

## 技能定位

本技能制作"一镜到底"叙事短片：总时长不超过 15 秒就规划为 1 个镜头；超过 15 秒则科学拆分为多个连续镜头（每镜 4-15 秒），镜头间只允许"纯粹的物理直接续接"——以起止帧像素锁定与物理轨迹连续为基准，严格禁止遮挡转场、甩镜、空镜转场、穿门等刻意的人工转场花招。全片由一条连贯、不间断、流经空间的单一镜头运动构成。

## 适用场景

- 单镜穿越多个空间、人物的电影感短片。
- 强调运镜炫技与"呼吸感"的长镜叙事。
- 十三种风格任选的风格化一镜短片。
- 以"空间连续性"为卖点的沉浸式影像项目。

## 制作流程

### 第一步：全局参数与风格选择

锁定 16:9、720p、总时长与"一镜到底"视觉风格。用户未指定风格时，先列出十三种经典风格（电影写实、动画、赛博朋克、科幻废土、蒸汽朋克、中国水墨、哥特暗黑、超现实梦境、手绘动画、黏土定格、极简包豪斯、70 年代复古、繁复巴洛克）供其选择，确认后才写入规格。风格参数表：画幅 16:9、分辨率 720p 生成 1080p 输出、帧率 24fps（可补帧 60fps）、总时长按内容 15-90 秒。

### 第二步：资产分析与标准校验

- 人物图必须是标准全身三视图（正/侧/背）；非三视图（单张半身、插画）判定不合格，用图生图以原图为特征参考转绘成符合短片风格的标准三视图。
- 场景图必须是标准无人物四格图（左上全景建立、右上细节/道具特写、左下纵深透视、右下氛围光照）；不合格则转绘重建。
- 有台词的角色的专属声音样本先生成并绑定，保证视频生成时口型与音色绝对稳定。

### 第三步：分镜设计（直接续接规范）

- 分镜用连续叙述，禁止"cut to""硬切"等转场中断词。
- 起止状态镜像闭环：上一镜结尾与下一镜开头必须形成镜像闭环，人物的物理姿态、绝对空间位置与视线方向在文本描述中像素级对接（例：上一镜末"右脚前迈、身体前倾、视线朝右下、位于走廊中段"，下一镜开头必须精确接续该姿态继续行走）。
- 四维续接锚点：

| 锚点 | 内容 | 写法示例 |
| --- | --- | --- |
| 镜头动量续接 | 上一镜末的镜头速度向量，下一镜开头完整继承 | "继续以 1.2 米/秒匀速右移跟拍、无停顿" |
| 生物力学动能匹配 | 重心分布与骨骼关节坐标精确锁定 | 禁止瞬间位移与"滑步" |
| 微环境连续 | 光入射角、色温分布、风力风向、空气介质密度切换瞬间绝对等同 | "光入射角 45°、色温 4800K、微风 2 级" |
| 姿态与空间连贯 | 镜头环绕到侧后方时肢体形态与前向情绪流完全吻合 | 视线始终跟随镜头方向 |

- 多轨迹组合设计：单一轨迹要写明空间路径、高度与速度指标；按叙事节奏组合多维轨迹——推镜加环绕、跟拍加低角仰起、拉镜加升降机位、平摇加焦点转移，并让动作枢轴与镜头轨迹变化节点精确对齐。

### 第四步：单镜视频生成（三重超锚定）

- 首镜只引用人物三视图与场景四格图。
- 从第 N 镜（N>1）起，除人物与场景图外，还必须同时绑定三重锚定：

| 锚定 | 内容 | 提取规则 |
| --- | --- | --- |
| 首帧像素锁 | 解析上一镜末帧提取为起始帧 | 排除缩帧、卡顿与静止尾帧，取物理动作的最终完整动态/峰值模糊帧 |
| 静态特征锁 | 最初生成的三视图与四格图锁定面容、服装材质与场景立体透视 | 防漂移 |
| 动态转场锁 | 上一镜成片作参考视频 | 继承镜头运动惯性、物体速度向量与最后一秒动态趋势 |

- 逐镜生成前把提取的尾帧展示给用户，指出时间点与关键衔接特征（骨骼重力状态、关节位置、镜头模糊方向、光线流动），确认后才注册绑定生成。

### 第五步：音频与合成

- 配乐 1 条全局轨；环境音分"持续背景氛围音"与"同步动作音效"两类，动态音效要标注声学空间坐标（距镜头距离、左右方位，如"走廊脚步声，距离 8 米渐近至 1.5 米，从左至右"）供下游做衰减处理；旁白层定义清晰音色画像。
- 层级意图：旁白最清晰主导，音效紧贴画面动作具空间物理质感，配乐保持低电平只做氛围渲染。
- 合成用起止帧精细对齐与无缝拼接，无多余硬切与黑帧；全局配乐与持续环境层开头结尾各加 1.5 秒线性淡入淡出，相邻切点的瞬态动作音效加 0.2-0.5 秒微淡入淡出交叉平滑。
- 合成后可选超分与补帧：提升到 1080p 或更高并强制 60 帧，让大幅运镜与动作切换达到影院级光流顺滑。

## 提示词模板

**直接续接分镜模板：**
```
上一镜末：{姿态/空间位置/视线方向/镜头速度向量}；
本镜：继续{运动}，{路径/高度/速度}，{动作枢轴与轨迹节点对齐}，
{微环境连续参数}，{情绪流}，一镜到底，无转场
```

**示例成句（走廊续接）：**
```
上一镜末：右脚前迈、身体前倾、视线朝右下、位于走廊中段、镜头以 1.2 米/秒右移跟拍；
本镜：继续匀速右移跟拍、无停顿，绕过立柱进入大厅，
动作枢轴（推门）与镜头轨迹节点精确对齐，
光入射角 45°、色温 4800K、微风 2 级，
人物情绪从警觉转为放松，一镜到底，无转场
```

**示例成句（赛博朋克风格长镜）：**
```
16:9，720p，赛博朋克风格；单镜穿越雨夜街道进入酒吧，
霓虹倒影随镜头角度拉伸变形，全息层与背景建筑异步速率，
湿面反射跟随镜头移动，推镜加环绕组合轨迹，
雨滴击打声由远及近（距离 6 米至 0.5 米，从左至右），
一镜到底，无转场
```

## 风格关键词与参数表

**核心关键词清单：** 一镜到底、物理直接续接、起止帧像素锁定、四维续接锚点、三重超锚定、多轨迹组合、微环境连续、声学空间坐标、禁人工转场花招。

**四维续接锚点表（每镜交接必核）：**

| 锚点 | 核对项 | 失败表现 |
| --- | --- | --- |
| 镜头动量 | 速度向量继承 | 切换瞬间停顿/变速 |

| 姿态空间 | 肢体形态与视线 | 姿态跳变 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 4-15 秒 | 总时长 ≤15 秒则 1 镜 |
| 画幅 | 16:9 | 全片统一 |
| 分辨率 | 720p 生成、1080p+60fps 可选输出 | 超分补帧 |
| 配乐/环境层 | 首尾 1.5 秒线性淡入淡出 | 全局轨 |

## 进阶技巧

- 动作与镜头同步：镜头环绕时主体重心随之偏移、视线跟随镜头方向；推镜逼近特写时明确微表情变化（由警觉困惑转为放松微笑、眼神闪烁或眼睑微垂）。
- 写实风格长镜要细化"物理镜头表达"：推拉与环绕中焦段与景深平滑过渡、动态景深、轻微色差、自然运动模糊；加体积光中的漂浮尘埃与镜头移动时影子的物理拉伸。
- 动画风格长镜做"多层视差"：前景遮挡物快速相对位移、中景人物与镜头平行、背景极慢角速度异步移动；极端运镜入口用手绘速度线，瞬动动作点用表现性拖影帧。
- 赛博朋克长镜强调湿面反射与全息视差：霓虹倒影随镜头角度拉伸变形，全息层与背景建筑异步速率、掠过后背时厚度压缩与逆透视畸变。
- 一致性控制：三重锚定缺一不可；尾帧提取选"最终完整动态/峰值模糊帧"，避开静止尾帧与黑场；微环境参数（光/色温/风）逐镜显式继承。
- 规避翻车：多空间穿越先画"空间路线图"（起点→途经→终点），每段续接只改一个变量，防止一次改多项导致脱轨。

## 常见问题

- 镜头接缝跳动：原因：三重超锚定缺失。解决步骤：补齐首帧像素锁＋静态特征锁＋动态转场锁后再生成；尾帧提取避开静止尾帧。
- 环境突变或光线闪烁：原因：切换瞬间微环境未锁定。解决步骤：补光入射角、色温、风力与尘埃密度的一致性描述，逐镜显式继承参数。
- 人物"滑步"或瞬移：原因：生物力学动能未匹配。解决步骤：锁定重心分布与关节坐标并让肌肉张力符合物理；禁止位移跳跃描述。
- 出现人工转场痕迹：原因：分镜里写了遮挡、甩镜或穿门。解决步骤：全部删除，只保留纯粹的物理直接续接；分镜用连续叙述。
- 速度不连贯：原因：镜头动量未继承。解决步骤：上一镜末速度向量写进下一镜开头（如"继续以 1.2 米/秒匀速右移跟拍、无停顿"）。
