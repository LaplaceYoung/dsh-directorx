# 电影级长镜头调度

## 技能定位

本技能以"AI 分镜导演＋预演艺术家＋运镜设计师"的角色主导流程：核心任务不是直接输出视频提示词，而是先设计"可拍性"——先定义人物、再定义空间、最后定义运镜，顺序不可颠倒——再分步生成视频。长镜头铁律：无跳切、无镜头重置、无瞬移、中途不换机位，一条镜头必须清晰经过每个在场人物至少一次。

本技能把一次生成拆成五个可独立验收的关卡：输入参数→人物与空场景→全景群像→路径标注→单镜生成。每关产出可单独检查的中间资产，任何一关失败只回退到最近一关，不推倒全局；同一关卡连续三次失败时暂停，请用户降低空间或路径复杂度后再继续。

## 适用场景

- 一个镜头横穿房间/街道、依次经过多人的群像长镜。
- 需要"一镜到底"电影感运镜的短片、广告或开场。
- 人物众多且空间关系复杂的场景单镜调度。

## 制作流程

### 第一步：收集输入参数

开拍前收集：人物数量及各自的参考图（哪些需要严格锁定身份）、场景类型与视觉风格、画幅（默认 16:9）、成片节奏（慢速滑行/中速穿行/贴身紧追）、每个角色是否需要特写停留。写入全局规格，规格文档作为后续所有步骤的唯一事实来源，任何提示词不得与规格冲突。

**输入参数表**

| 参数 | 默认值 | 取值范围 | 说明 |
|---|---|---|---|
| 人物数量 | 2-6 人 | 1-10 人 | 超过 6 人时路径长度与单镜时长冲突，建议拆成两个长镜 |
| 画幅 | 16:9 | 16:9 / 2.35:1 / 9:16 | 2.35:1 影院感最强但人物更小；9:16 适合竖屏平台 |
| 成片节奏 | 中速穿行 | 慢速滑行 / 中速穿行 / 贴身紧追 | 决定运镜副词与目标时长估算 |
| 单镜目标时长 | 10-15 秒 | 6-30 秒 | 超过 20 秒必须降低路径复杂度 |
| 特写停留角色 | 无 | 任一角色列表 | 路径须在该角色处设计 1-2 秒停留与轻推 |
| 是否配乐 | 是 | 是 / 否 | 影响第六步合成流程 |
| 参考图来源 | 用户上传 | 上传 / 生成 / 混合 | 无参考图时走第二步生成分支补齐 |

判定标准：全部参数填写完成，且画幅、节奏、人物数量三者兼容（9:16 竖幅慎用横向大穿行路径；2.35:1 宽幅慎用过度贴近的跟拍）。失败处理：人物参考图缺失时先在第二步生成分支补齐，禁止带空槽进入群像构图；节奏无偏好时默认中速穿行并在规格中注明。

### 第二步：人物图与空场景图

- 人物参考图：每个角色独立生成双格或多格参考图，含面部细节、独特体型与服装特征，用于锁定角色身份。双格构图建议"左半身肖像+右全身"，让后续生成能同时参照面部与体态。
- 空场景图：先生成不含任何人物的场景"外壳"，重点验证前景/中景/背景的纵深分层、家具之间的可通过间隙、机位高度（平视/微俯/低角）、自然光方向与氛围色调。核心目标是先验证空间逻辑与运镜路径可行，人物进场前把场景外壳锁死。完成后暂停请用户确认空间布局。

判定标准：透视正确（水平线稳定、垂直线不歪斜）；前景与中景之间有连续可见的地面通道（宽度不小于一个人物身位，能让运镜"穿过去"）；背景不遮挡中景人物；机位高度与后续路径起点一致；光照方向单一且与群像阶段统一。回退规则：按"调机位高度→重排家具间隙→替换场景类型"逐级重试，最多三次；仍失败则暂停请用户换场景参考或降低空间复杂度。人物参考图验收：五官、发型、服装颜色与版型可辨识；多张图之间外观一致。漂移时以图生图微调（只改姿态或服装一项），不整体重出。

### 第三步：全景群像构图

用全部人物参考图做严格身份参考、用空场景图做布局与透视参考，生成一张所有人同处同一物理空间的全景群像主镜：明确每个人的空间位置（沙发正中/扶手/地板/窗边）、姿态（坐/靠/蹲/立）、朝向与互动关系；明确机位角度且该角度必须自然衔接下一步红线起点；所有人入画、无关键面部遮挡。人物站位必须给运镜让路：前景/中景/背景之间必须留出可实际通行的路径。完成后暂停请用户确认构图。

判定标准：1) 全部人物在画面内且身份可辨识；2) 任一相邻人物之间留有空隙；3) 从画面底部到最远人物之间形成连续通道；4) 机位高度与空场景图一致；5) 路径要经过的角色侧对或背对路径来路，方便镜头"经过"。回退规则：人物缺失或身份漂移→保持空场景参考重生成群像；通道被堵→回第二步调整家具间隙；光照与空场景不符→回第二步统一光源方向。

### 第四步：运镜路径标注图

以全景群像为严格构图参考，在保证人物位置、空间透视与光照完全不变的前提下，叠加一条连续红色辅助路径与手绘箭头：红线起点必须是当前视角的真实起点，禁止凭空切入新视角开镜；路径只有唯一起点与唯一终点，禁止分叉、断裂或多条独立路径；每个方向变化点都必须标手绘箭头。路径按顺序经过各角色并标出停留关注点。完成后暂停请用户确认路径。

判定标准：红线起点可从画面内前景物高度倒推验证与机位一致；路径依次接触每个角色至少一次；方向变化点 3-8 个为宜；路径不与墙面、大型家具重叠（重叠处即穿帮风险点，需在提示词中明确"绕过"）。回退规则：起点错位→强制以当前视角重画红线；路径过绕→简化方向变化点，保持主体经过顺序不变；路径与障碍重叠→微调群像站位或障碍物位置后重画。

### 第五步：单镜视频生成

以全景群像作为起始首帧（锁定第 0 帧的人物样貌、站位与空间构图），以路径标注图作为运镜空间参考，生成一条从全景首帧出发、沿红线路径平滑穿行的长镜。视频中绝不能出现红线与箭头。优先稳妥路线，宁可路线平稳也不要花哨路线导致丢人或穿帮。

**单镜提示词模板**（按段落式逐字段填写，字段不可省略）

```
{视角类型}，从{路径起点}出发，沿{路线遵循}，依次经过{人物顺序与停留点}，整体{画面推进}；画面中{主体行为}，机位{运镜术语}；保持手持呼吸感，不出现跳切、镜头重置、瞬移或机位切换；最终画面不得出现红线、箭头或规划叠层。
```

占位符说明：

- {视角类型}：方案 A 写"单镜连续、手持第一人称、带轻微手持呼吸感"；方案 B 跟拍主体写"单镜连续、稳定跟拍、手持纪录片质感"。
- {路径起点}：与全景图机位一致的位置描述，如"门廊右侧低角处"。
- {路线遵循}：引用路径方向，如"沿红色路径先右后左绕行"。
- {人物顺序与停留点}：按经过顺序列人物与停留时长，如"先经过窗边的男士，再绕到沙发前的女士并停留两秒，最后靠近门口整理衣领的第三者"。
- {画面推进}：节奏副词——慢速滑行写"缓慢滑行、轻柔前漂"；中速写"稳步穿行"；贴身紧追写"快速手持追拍、贴近而紧迫"。
- {主体行为}：各人物在镜头经过时的动作（举杯、回头、起身、系扣），与群像阶段规划一致。
- {运镜术语}：推/拉/跟/弧/摇/俯仰，按方向变化点逐个书写，逗号分隔。

示例成句（中速穿行、三人群像）：

"单镜连续、手持第一人称、带轻微手持呼吸感，从玄关低角真实起点出发，沿红色路径先右后左绕行，依次经过窗边站立的男士、沙发上的女士并停留两秒、最后靠近门口整理衣领的第三者，整体稳步穿行；画面中男士举杯、女士回头微笑、第三者低头系扣，机位先横摇再弧线推进后轻推；保持手持呼吸感，不出现跳切、镜头重置、瞬移或机位切换；最终画面不得出现红线、箭头或规划叠层。"

失败按"重生成→调参→回退上游"三级处理：单镜问题先重生成；两次失败调参数（减方向变化点、补负约束句、调参考权重）；三次失败回退第四步简化路径。每镜生成后检查第 0 帧与末帧：末帧人物位置须与下一镜规划衔接处一致，偏差过大则调整路径终点描述。

**长镜段落结构表**（生成前用此表规划 10-15 秒长镜的时间分配，段数 3-5 段为宜）

| 段落 | 时间码 | 景别 | 运镜 | 内容要点 | 声音/节奏 |
|---|---|---|---|---|---|
| 开段 | 0-2 秒 | 全景/中全景 | 静态起幅→轻推 | 建立空间，交代全部人物在场 | 环境底噪，节奏舒缓 |
| 中段一 | 2-6 秒 | 中景 | 横摇→弧线 | 经过第一、二个人物，动作触发 | 对话或脚步细节声 |
| 中段二 | 6-10 秒 | 中景/近景 | 弧线→跟 | 经过核心人物并停留 1-2 秒 | 核心台词/动作顶点 |
| 收段 | 10-15 秒 | 中全景/全景 | 拉远→稳定收幅 | 离开人物群，末帧留出衔接空间 | 音乐渐强收束 |

段落划分依据方向变化点而非时间均分：每个方向变化点天然是一段，段内只保留一个主导运镜。

### 风格关键词与参数速查

**核心风格关键词清单**（写提示词时按需组合，同义词避免混用）

- 运镜质感：手持呼吸感、稳定跟拍、缓慢滑行、稳步穿行、贴身追拍、无缝连续、一镜到底。
- 空间层次：纵深分层、前景经过、通道让路、连续地面、透视正确。
- 人物调度：群像在场、依次经过、停留关注、互动关系、站位让路。
- 连续性：身份锁定、样貌一致、服装一致、光照不变。

**推荐参数表**

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 时长 | 10-15 秒 | 3-8 个方向变化点在此区间最稳 |
| 画幅 | 16:9 优先 | 横向穿行场景首选；2.35:1 需放大路径空间 |
| 分辨率 | 至少 1080p | 长镜细节多，低分辨率穿帮更明显 |
| 节奏 | 中速穿行 | 慢速滑行适合作开场，贴身紧追适合动作戏 |
| 机位高度 | 平视或微俯 | 低角会强化地面与通道，但易挡人物 |

**禁用项清单**（写入负约束句，防呆）

- 跳切、镜头重置、瞬移、机位切换、分屏、切黑、机械滑轨感、缩放代替推拉。
- 红线、箭头、路径叠层、标注文字。
- 人物瞬移、穿墙、穿家具、身份漂移、换装、新增光源、光照突变。

### 第六步：合成与导出

如需配乐则设计全片配乐轨，风格匹配场景氛围。合成后引导导出。用户上传了现成群像图可跳过构图与路径步骤，直接进入生成。导出前按"首帧一致、人物连贯、无规划痕迹、无跳切瞬移、画幅节奏达标、配乐匹配"六项复核，任一项不通过时按对应步骤的单镜重生成规则处理，不整体返工。

## 进阶技巧

### 技巧一：动作母题串联多人物

给每个角色分配一个"经过时的小动作"（回头、举杯、起身、系扣），提示词按经过顺序逐一写死。作用有二：一是给模型提供连续的"事件点"，降低中途空转概率；二是让观众注意力沿路径自然流动。操作步骤：1) 群像阶段就把每个角色的动作写进构图说明；2) 单镜提示词按经过顺序复述同一组动作；3) 某角色动作在成片中丢失时，只在该角色出场段补写动作重生成；4) 动作数量控制在 3 个以内，超过则合并或删减。

### 技巧二：路径复杂度与视频时长的配平

方向变化点每增加一个，模型失稳概率明显上升。操作步骤：1) 先用"起点→终点两点直线"版本验证人物与空间；2) 确认不穿帮后逐个增加方向变化点，每次只加一个并单独验证；3) 超过 8 个方向变化点或成片出现局部瞬移时，删除最外侧绕行段，优先保留贴近人物的弧线段；4) 时长超出目标时优先压缩停留时间而非删除人物，保持"全员出场"这一铁律。

### 技巧三：一致性控制的参考图分级

三张参考图的权重按"全景群像 > 空场景 > 单角色图"排列使用：首帧以群像为准、空间透视以空场景为准、身份细节以单角色图为准。同一张图在不同提示词中的描述必须逐字一致（服装、发型、颜色措辞不改写），否则模型会把"同一角色"渲染成"相似角色"。操作步骤：1) 每张参考图配一句固定描述写进规格文档，生成时原样复制；2) 漂移时先比对描述原文再动权重；3) 角色较多时做"角色名-固定描述"对照表，逐镜勾选引用。

## 常见问题

- 红线残留在成片里：原因：提示词结尾漏写负约束句"最终画面不得出现红线、箭头或规划叠层"。解决步骤：1) 检查单镜提示词是否包含完整负约束句；2) 缺失则补齐该句后整镜重生成；3) 已包含仍残留，则将路径标注图参考权重下调后重试。
- 镜头中途重置或瞬移：原因：视角类型与"无跳切、无镜头重置、无瞬移"负约束缺失，或路径方向变化点过密超出模型稳定范围。解决步骤：1) 确认视角类型与负约束句完整存在；2) 方向变化点超过 8 个则删除绕行段；3) 用简化路径重生成，仍失败则回第四步重画路径。
- 人物走位穿帮：原因：全景群像阶段没有留通行路径，人物站位堵住通道。解决步骤：1) 回第二步检查空场景的家具间隙；2) 调整间隙至不小于一个人物身位；3) 重新生成群像并确认通道连续后再进第四步。
- 机位与起点脱节：原因：红线起点与全景首帧视角不一致，模型只能凭空生成新机位。解决步骤：1) 以全景图实际视角为唯一起点重画红线；2) 确认起点描述与首帧前景物高度可相互印证；3) 重新生成并逐帧核对前 1-2 秒机位。
- 成片像机械滑轨而非手持：原因：提示词未写"手持呼吸感"，或运镜术语堆砌过多导致运动机械化。解决步骤：1) 确认视角类型含"手持、轻微呼吸感"表述；2) 减少运镜术语数量，保留主干（如"先弧线推进后轻推"）；3) 必要时用方案 B 稳定跟拍形态重生成。
