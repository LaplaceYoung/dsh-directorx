# 第一人称视角短片

## 技能定位

本技能把"镜头即主角之眼"作为不可违反的铁律贯穿全流程：主角永不出全脸，所有信息必须进入视野才成立，动作通过视线-声音-手部的完整主观移动链呈现。通过参考图职责系统、反抽卡门与逐镜质检，杜绝第三人称泄漏、换脸与空间穿帮，产出高度沉浸的第一人称叙事短片。工作流固定为六步：锁定全局规格 → 生成局部资产 → 网格总览与分镜 → 逐镜生成 → 逐镜质检 → 音频与组装，每一步都有可勾选的判定标准。

## 适用场景

- 第一人称视角的悬疑、冒险、情感短剧。
- 模拟主角亲历感的沉浸式内容（如"你醒来发现……"类叙事）。
- 需要严格主观视角、避免出戏的写实短片。
- 用户提供主角局部图（手、鞋、配饰）或场景照片的项目。

## 制作流程

### 第一步：锁定全局规格

- 写规格档案：片名、题材、16:9 画幅、片段时长 5-10 秒、导出 1080p/4K 与 24/30fps、语言。
- 约定片段间 0.5-1 秒黑场；默认无 BGM，对白后期配音；音乐音量不超过环境声的 60%。
- 画幅选竖屏（9:16）时同步锁定竖屏主观视野规则：视线落点保持在中央 1/3 竖带，手部动作不出安全区。

### 第二步：生成局部资产

- 按类别生成参考资产：角色（纪录片半身照质感）、主角局部（只拍手/鞋/袖，明确"不拍全脸"，带年龄质感）、场景（空间+光照+使用痕迹）、道具（纪录片特写+环境边缘）。
- 主角永不出全脸资产，只允许手、鞋、袖、胸前边缘、玻璃与黑屏手机反射等局部。
- 资产命名规范：每张资产登记类别+职责+污染风险三栏（如"手部动作参考｜负责手物接触｜可能引入袖口颜色漂移"），供逐镜声明继承与排除使用。

### 第三步：网格总览与分镜

- 生成网格总览图确认节奏（仅规划用，不锁脸）。
- 分镜表确认后才生成视频；每片段只承载一个主要剧情转折。
- 分镜表字段：片段号、时长、POV 载体（主角眼/玻璃反射/屏幕）、视觉信息（观众能看到什么）、触发事件（声音/动作）、视线轨迹（起点→转移→落点）、手部动作、空间锚点（本镜参照物）、声音证据、情绪基调。

### 第四步：逐镜生成

- 每镜提示词以"first-person POV from [主角]; camera is his/her eyes; no external shot"开头。
- 完整提示词模块：参考图输入（逐张声明只继承某职责、不继承某污染风险）→ 容器 → 首末帧契约 → 四锚点（身份/空间/状态/质量）→ 视觉 → 空间与环境力 → 动作阶段（First/Second/Final，每阶段含视线位置或移动、动作、可见物理反馈、环境反应或声音证据、继承末态）→ 运镜（起-触发-转-加速-落点）→ 声音证据 → 光与质感 → 一致性与质量 → 输出配置 → 文字字幕说明 → 禁止项 → 伪点质检。
- 反抽卡门 11 项检查：生成目标、仅验证、排除、主体唯一、首视焦点、参考职责单一、冲突术语、抽象风格词、模型最可能补偿、强制正向物理锚、污染词删除、严格 POV；结论为可生成或不可生成。

### 第五步：逐镜质检

- 每镜生成后立即质检，失败进入重做：POV 破整镜重跑不裁剪；空间不可能则重建环境参考；手物接触错重建手或道具参考；文字错走后期；情感过度撤音乐加停顿加真实噪音；参考污染减图分两遍跑。
- 全局硬锁：信息必须进入视野才成立；主观移动链完整（视线起点 → 声音/动作触发 → 视线转移 → 手部动作 → 视线落点）；声音可增强但不可替代关键视觉；AI 可读文字不生成（后期叠加或配音）；口型同步不要求。
- 质检判定表：POV 泄漏（出现第三视角/主角全脸/主角背影入画）= 整镜重跑；道具穿帮（手物穿插/物在手中瞬移）= 重建资产后重跑；空间矛盾（同镜内布局两次不一致）= 重建环境参考；情绪不足 = 先加声音与停顿；全部合格才进入组装。

### 第六步：音频与组装

- 每段定义环境空间声、动作声、允许对白、音乐规则与静默点；沉默可作最强情感点。
- 按分镜顺序组装导出，结尾落在视线落点或手部动作暂停处，禁止全身镜头（除非用户明示）。

### 每镜提示词模板

```
first-person POV from [主角]; camera is his/her eyes; no external shot.
[容器：本镜空间与时间]
[首末帧契约：起始视线落点→结束视线落点]
[身份锚：继承角色资产仅限手部/袖口/鞋，不继承面部]
[视觉：观众可见内容清单，逐项列出]
[空间锚：参照物及其位置，用于锁定本镜空间]
[动作阶段 First：视线起点+触发声音]
[动作阶段 Second：视线转移+手部动作+可见物理反馈]
[动作阶段 Final：视线落点+环境反应+继承末态]
[运镜：起(静止)→触发(微动)→转(跟随视线)→加速(动作同步)→落点(静止)]
[声音证据：环境声/动作声/对白，标注入场点]
[光与质感：延续全局光照，不加风格化滤镜]
[禁止项：no third-person shot, no full face, no cutaway, no text]
```

### 镜头语言对照表

| 叙事需求 | 视线语言（可用） | 导演语言（禁用） |
|---|---|---|
| 强调某个物件 | 视线落点停在该物件上，手伸入画框 | 特写推近 |
| 表现惊讶 | 视线快速转向声源，手部微抬 | 快速变焦 |
| 表现回忆 | 视线失焦，玻璃/水面反射淡入 | 闪回叠化 |
| 表现恐惧 | 视线缓慢扫视、喉结吞咽、脚步后退 | 环绕镜头 |
| 表现亲近 | 视线落在对方局部（手/肩），镜头微缓 | 过肩镜头 |

## 进阶技巧

- 镜头语言全部用视线语言：视线被声音牵引、视线跟随手、窗框拖出画面、凸面镜后视镜反射、玻璃反射模糊人影；禁止"推近、定格"等导演语言。
- 情感-视觉映射：紧张=冷暗强对比+窄斜构图+快而不稳；温暖=暖柔逆光+居中对称+慢而稳；悲伤=冷低饱和+留白+静慢；压迫=灰低饱和+上下打光+封闭下沉；平静=中性柔光+均衡慢静。
- 情绪不足时先加声音、停顿、手部犹豫与真实噪音，再考虑对话与音乐。
- 参考图职责系统：节奏锚/环境/角色入场/手部动作/道具细节/声音/质检各司其职，一图一职责并声明污染风险；首现镜必绑、后续持续绑同资产。
- 后期文字叠加用手写质感带瑕疵融入场景。
- 反射是主观视角的免费资产：镜子、玻璃、手机黑屏、汤匙背面都能让主角局部"合法入画"，且天然强化第一人称在场感；反射中的人影必须模糊或局部，禁止清晰全脸。
- 动作-反应成对书写：主角任何动作（开门、抓取、转身）后必须写一个可见结果（门缝透光变化、物体被拿起的重量感、转身后新视野），防止模型生成"动作悬空"。

## 常见问题

- 出现第三人称镜头：原因是模型把叙事镜头当默认输出，POV 约束不够强。解决步骤：① 检查提示词是否以 POV 声明句开头；② 确认禁止项含 no third-person shot；③ 整镜重跑，不裁剪修补（裁剪会留下缝合痕迹）。
- 换脸：原因是资产绑定缺失，模型自由生成面部。解决步骤：① 检查该镜是否绑定了主角局部资产（手/袖/鞋）；② 补充绑定并声明"只继承手部，禁止生成面部"；③ 重生成；④ 若反复出现，回第二步补主角局部资产。
- 环境声太干净显假：原因是生成音频缺乏真实环境纹理。解决步骤：① 后期叠加真实录音（脚步、空调、室外底噪）；② 音量压到与生成环境声同层；③ 保留 0.3-0.5 秒底噪进入与退出，避免突兀。
- 模型即兴加戏：原因是动作未被全量指定。解决步骤：① 每镜动作提示词全量指定（谁、做什么、以什么顺序）；② 动作阶段 First/Second/Final 逐段写满，不留自由发挥空间；③ 质检时比对成片与分镜动作清单。
- 情绪表达不足：原因是画面信息过满或节奏过快。解决步骤：① 先加声音（环境声细节）、停顿与手部犹豫；② 删除部分视觉信息制造留白；③ 最后才考虑加对白与音乐；④ 对白后保留 1 秒静默让情绪沉淀。
- 对嘴视频变速导致口型错位：原因是对口型镜头被变速。解决步骤：① 对口型镜头禁止变速，保持原始速度；② 需要节奏感时改在无口型镜头上做变速；③ 若已变速，重生成该镜而非后期修复。
