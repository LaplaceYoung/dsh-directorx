
name: 数字分身同框合成
description: >-
  适用于用户上传视频并要求换脸、换人、换背景或组合替换的场景。
  核心是镜头表精确拆解、运镜逐帧继承、色彩匹配与逐镜确认，输出与源视频节奏完全一致的成片。

## 技能定位

本技能解决"把视频里的人物/背景替换成用户指定形象，但保持原片运镜与节奏分毫不动"。三条铁律：运镜继承最高优先级（每帧都必须与原视频对齐，禁止新增任何运镜）、动态色彩匹配（替换区域自动贴合原片色调，不加预设滤镜）、逐镜确认（每个里程碑都暂停等待明确回复）。

当替换目标与原片人物同框出现时（同框合成），在三条铁律之上追加两条纪律：透视一致——替换人物的站位、大小、朝向与原位人物及场景透视严格吻合；光影统一——替换区域的光源方向、色温、阴影与原片一致。五条纪律共同保证"换了人，但画面逻辑没变"。

## 适用场景

- 用户上传视频+参考图，要求替换人物（换脸/换人）或替换背景。
- 需要把已有视频主角换成指定形象，用于二创、演示或内容替换。
- 同时换人物与背景的组合替换。
- 替换后人物与原片人物同框共演（对话、并肩、递物等）的镜头。

## 制作流程

1. 模式选择：引导用户选择替换模式（人物替换/换脸/背景替换/组合），并确认参考图已上传。
2. 原视频镜头表分析：逐镜输出分析表——镜头号、时间段（精确到 0.1 秒）、时长、运镜类型（固定/推/拉/横摇方向/俯仰/跟拍/手持晃动/俯冲/升起，复合运动逐项列出）、运镜强度与速度（慢<5°/s、中 5-15°/s、快>15°/s）、人物动作描述、背景描述、替换意图；并记录全片色彩基线（色温/亮度/对比度/饱和度）。所有字段可逐镜修改并重新呈现，直到用户确认整表无误。
3. 参考图分析：提取替换目标关键特征（面部/服装/背景），以表格呈现供确认；同时按质量分级评估——低分辨率（脸部像素<200×200 或长边<400px）、部分遮挡（>30%）、角度差（>45°侧脸）、异常曝光、背景杂乱。高风险必须处理：先引导用户补充素材，用户明确无法补充时才可申请自动补图；中风险提示可继续但需在后续逐镜卡中标注风险。
4. 分镜设计：每镜严格对应已确认的镜头段，时间段与运镜完全复用确认值；标注替换意图（人物/背景/组合）与对应元素标识；动作描述只复用原表，不得新增。同框镜头额外标注：替换人物与原片人物的相对站位、大小关系、遮挡层级。
5. 资产绑定：原视频分段登记并绑定为各镜参考视频；参考图登记绑定为角色/场景元素。
6. 逐镜替换生成：以原视频对应片段为参考视频（视频改写模式），叠加替换目标参考图；提示词按固定结构：替换对象描述→运镜继承声明（"保持与原视频完全一致的运镜：…不得新增任何运镜"）→动作保留声明→色彩匹配声明（"替换区域色彩亮度对比贴合全片基调，不加预设滤镜"）；固定负向约束：无新增运镜、无新布光、无风格滤镜、无字幕。同框镜头追加透视声明与光影声明（见提示词模板）。每镜生成后输出确认卡（时间段/替换类型/运镜继承判定/相似度与融合度与色彩匹配星级/已知问题/建议动作），星级≤3 必须注明原因并建议重试。
7. 最终拼接与质检：严格按原片时间线顺序拼接，不改切点节奏，时长误差≤0.1 秒；逐项质检——切点跳帧（拼接点前后 0.5 秒无跳帧/残影）、音画同步（偏差≤1 帧@30fps）、相邻镜色彩断层、运镜连续性、替换区域边缘（无锯齿/光晕/抠像残留）、时长匹配。全部通过才输出，否则定位问题并给出修复建议。

### 同框合成的双人站位与透视

| 检查项 | 判定标准 | 不通过处理 |
|---|---|---|
| 地平线与视平线 | 替换人物脚底与同框人物脚底在同一地平线 | 按视平线重算站位 |
| 人物大小 | 同景别时头部高度与同框人物一致 | 调整参考图比例后重出 |
| 朝向 | 对话关系成立：面对面或同向 | 翻转/调整朝向描述 |
| 纵深 | 前后站位符合近大远小的场景透视 | 参考场景纵深重排 |

生成时在提示词中写明与同框人物的相对位置："站在画面左侧、略靠后半个身位、与右侧人物面对面"。

### 遮挡与交互

- 遮挡层级：同框人物之间有前后遮挡时，替换人物必须落在正确的遮挡层级——被前景物体/人物遮挡的部位按原片形状保留，不强行完整显示。
- 交互动作：握手、递物、并肩行走等交互镜，动作由原片参考视频继承，提示词只声明"保持与原片一致的交互动作"，不新增动作细节。
- 视线连接：对话镜中替换人物视线必须指向同框人物面部方向，否则对话关系断裂。

### 光影统一参数

| 参数 | 做法 |
|---|---|
| 光源方向 | 从原片分析主光源方向并写入提示词（如"主光来自画面左侧"） |
| 色温 | 替换区域色温与原片基线一致（暖/冷） |
| 阴影 | 地面与墙面阴影方向一致，强度匹配 |
| 皮肤质感 | 与同框人物肤色明度、质感一致，避免"贴图感" |

### 合成检查清单

| 检查项 | 判定标准 | 不通过处理 |
|---|---|---|
| 切点跳帧 | 拼接点前后 0.5 秒无跳帧/残影 | 重出问题镜 |
| 音画同步 | 偏差≤1 帧@30fps | 对齐音频轨 |
| 透视 | 双人站位/大小/朝向成立 | 修正透视声明后重出 |
| 遮挡层级 | 前后遮挡关系正确 | 修正遮挡描述后重出 |
| 光影 | 色温/阴影方向统一 | 修正光影声明后重出 |
| 色彩 | 相邻镜无色彩断层 | 统一色彩基线声明 |

### 提示词模板

#### 同框合成提示词模板

```
替换对象描述：[替换人物特征与服装]
运镜继承声明：保持与原视频完全一致的[运镜]，不得新增任何运镜
动作保留声明：保持与原片一致的[交互动作/站位]不变
透视声明：[相对同框人物的站位、大小、朝向]
光影声明：主光来自[方向]，色温[暖/冷]，阴影方向与原片一致
色彩声明：替换区域色彩亮度对比贴合全片基调，不加预设滤镜
负向：无新增运镜, 无新布光, 无风格滤镜, 无字幕, 透视错乱, 光影不统一
```

占位符说明：
- [替换人物特征与服装]：逐字复用参考图分析表确认的特征。
- [运镜]：直接复制镜头表中的原始运镜描述，不简化不省略。
- [相对同框人物的站位、大小、朝向]：写明左右/前后身位、头部高度关系、视线方向。

示例成句：

```
替换对象描述：30 岁男性，深灰西装，短发，面容沉稳
运镜继承声明：保持与原视频完全一致的缓慢横摇，不得新增任何运镜
动作保留声明：保持与原片一致的握手动作与站位不变
透视声明：站在画面左侧、略靠前，与右侧人物正面相对，头部高度一致
光影声明：主光来自画面右侧窗户，色温暖调，地面阴影方向与原片一致
色彩声明：替换区域色彩亮度对比贴合全片基调，不加预设滤镜
负向：无新增运镜, 无新布光, 无风格滤镜, 无字幕, 透视错乱, 光影不统一
```

## 进阶技巧

- 运镜继承表述直接复用镜头表中的原始描述，不简化不省略；这是防止模型"自作主张"的最有效手段。
- 替换人物时优先提供正面近景+全身正面两张补图，能显著提升相似度稳定性；同框镜头再加一张"与目标人物同框"的参考构图图，透视关系一次锁定。
- 逐镜确认卡用星级自评（相似度/背景融合/色彩匹配），低分项直接触发重试，避免问题累积到成片；同框镜头额外自评透视与遮挡两项。
- 同框镜头先出单帧验证站位与光影，确认无误再生成整段，可避免整段返工。

## 常见问题

- **替换后人物忽大忽小或脸变形**：原因：参考图质量分级不足，或同框透视未声明。解决步骤：① 检查参考图质量分级，低分先补图再生成，勿带病作业；② 同框镜头补写透视声明（站位/大小/朝向）；③ 重出该镜并对比原片人物大小。
- **透视错乱**：原因：替换人物站位、大小、朝向未与原片人物对齐。解决步骤：① 按"地平线/头部高度/朝向/纵深"四项逐项核对；② 修正透视声明并重出；③ 与同框人物并帧对比确认关系成立。
- **光影不统一**：原因：替换区域光源方向、色温、阴影与原片不一致。解决步骤：① 从原片分析主光源方向并写入光影声明；② 确认色温与阴影方向声明逐字落实；③ 重出该镜，并帧对比肤色明度与阴影方向。
- **色彩跳变**：原因：提示词未写入原片色彩基线声明，或误加风格滤镜。解决步骤：① 确认每个提示词都写入了原片色彩基线声明；② 确认负向约束含"无风格滤镜"；③ 重出问题镜。
- **音画不同步**：原因：替换生成后音频轨未对齐。解决步骤：① 默认保留原视频音轨并精确对齐时间线；② 偏差≤1 帧@30fps 为通过标准；③ 除非用户明确要求换 BGM 或配音，否则不动音轨。
