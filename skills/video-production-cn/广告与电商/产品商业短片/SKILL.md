# 产品商业短片

## 技能定位

本技能以产品与包装摄影为核心构建商业广告：把镜头分成两类交叉剪辑——"环境主角镜"（产品出现在场景中，动态清晰地演绎产品与使用场景）与"氛围辅镜"（不必然出现设备的纯环境、纹理细节或生活方式镜头，用于暗示卖点），避免成片变成"桌上摆着包装"。商业广告靠更多镜头与概念间硬切获得能量，优先短镜头、每切必有明确视觉变化。

## 适用场景

- 运动相机、消费电子、食品饮料等产品卖点广告。
- 生活方式场景营销（水下、越野跑、跳伞、滑板、现场音乐）。
- 需要包装展示与 Logo 时长的商业成片。
- 用户已有产品图，需要"卖点展示+场景演绎"双轨结构的短片。

## 制作流程

### 第一步：规格与分镜

锁定标题、类型、画幅、时长、视觉风格、语言与模型偏好。规格表默认值：画幅 16:9（竖屏按投放改 9:16）、时长 15-60 秒、分辨率 720p 生成 1080p 输出。关键场景至少设计两个体现产品优势的应用场景（供后期合成交叉使用），每个场景独立元素。分镜优先 5-15 秒含内部剪辑的长镜，剪辑频率跟叙事节奏；每镜表达一个要点，景别变化按"全景建立→中景细节→特写情绪→高潮/Logo 收束"推进。镜头分类登记：

| 类型 | 定义 | 示例 | 占比建议 |
| --- | --- | --- | --- |
| 环境主角镜 | 产品出现在场景中，动态演绎卖点 | 运动相机固定在越野车头拍摄颠簸路面 | 55%-65% |
| 氛围辅镜 | 纯环境/纹理/生活方式，暗示卖点 | 浪花拍打礁石、车手汗珠特写 | 35%-45% |

### 第二步：元素与关键帧

- 物体元素从用户上传的产品图提取，描述必须与素材一致、不矛盾；用户已提供的资产直接绑定不重生成。
- 需要锁定首帧时可每镜生成一张关键帧：起始帧（动作前的预备姿态与意图、环境基准态、初始机位）、结束帧（动作完成后的收势、环境变化后状态、为下一镜就位的机位）或高光帧（视觉/情绪冲击最强的一瞬）。
- 关键帧描述模板：`[机位] + [主体预备/收势姿态] + [环境基准态] + [光线]`。

### 第三步：镜头视频生成

每镜引用该镜涉及的产品、场景与道具元素图。提示词先为每张参考图点名主体（面部参考用头像图、发型妆容服装用全身图），再按"镜头-主体-空间-音频"四层顺序补动态：镜头运动与切换、主体动作与表情、空间与背景运动、音频标记。多节拍可用"镜头1/镜头2"承接，禁止秒级精确时间计划。视频提示词结构示例：

```
镜头1：{运镜}，{主体动作}；镜头2：{运镜}，{主体动作}；
空间：{背景动态}；音频：{音效/音乐氛围标记}；
[参考图点名] 产品图提供包装细节，场景图提供环境
```

### 第四步：音频与合成

至少一条全局配乐，长片按段落拆配乐段；旁白在音频层定义音色、语气与精确文案。合成时严格注意强制包装镜头与 Logo 时长要求（如平台要求的包装特写秒数与 Logo 停留时长，写入规格，合成清单逐项核对）。按分镜顺序合成并引导导出。各阶段间暂停确认。

## 提示词模板

**产品演绎镜模板：**
```
[产品]在[场景]，[精确动词]地[演绎卖点动作]，[景别][运镜]，
[光线]，[主色调]，电影感氛围，[情绪词]，
no text, no watermark, no extra product
```

**氛围辅镜模板：**
```
纯[环境/纹理]镜头，[细节元素]，[光线与质感]，
[卖点暗示]，克制单一主色调，电影感氛围，
no product, no text, no watermark
```

**示例成句（环境主角镜）：**
```
运动相机固定在越野车前保险杠，镜头稳定记录颠簸砾石路面，
全景低角度跟拍，阳光直射+高光溢出，暖橙主色调，极限运动氛围，
引擎轰鸣与碎石碰撞音效，no text, no watermark
```

**示例成句（氛围辅镜）：**
```
纯环境镜头，浪花拍打礁石溅起水雾，逆光下晶莹剔透，
防水防溅卖点暗示，冷蓝克制主色调，电影感氛围，
no product, no text, no watermark
```

## 风格关键词与参数表

**核心关键词清单：** 电影感、克制单一主色调、负填充光线、荷兰角/俯仰角、推近/拉远揭示、甩镜/弧线、急甩（慎用）、渲染质感、氛围潜台词、微表情冻结。

**镜头语法交替表（避免同质化剪辑）：**

| 运动 | 用途 | 使用频率 |
| --- | --- | --- |
| 荷兰角/俯仰角 | 张力、非常规视角 | 每 4-6 镜 1 次 |
| 轻微旋转/横移 | 展示产品侧面 | 常用 |
| 推近（滑轨/变焦） | 逼近细节、情绪 | 常用 |
| 拉远揭示 | 环境关系、高潮 | 每段 1-2 次 |
| 甩镜/弧线 | 转场能量 | 每 8-10 镜 1 次 |
| 急甩 | 强调瞬间 | 慎用，全片 ≤2 次 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 成片时长 | 15-60 秒 | 默认 30 秒 |
| 单镜时长 | 5-15 秒（含内部剪辑） | 每镜表达一个要点 |
| 画幅 | 16:9 默认，9:16 可选 | 全片统一 |
| 主色调 | 单一主色约 90% 面积 | 禁霓虹撞色 |
| 分辨率 | 720p 生成，1080p 输出 | — |
| 剪辑频率 | 跟叙事节奏 | 每切必有视觉变化 |

**禁用项清单：** 桌上摆包装式静止镜头、同景别同机位连切、霓虹撞色、无视觉变化硬切、产品细节与素材矛盾、Logo 时长不足、文字水印。

## 进阶技巧

- 镜头语法交替制造高级感：荷兰角/俯仰角、轻微旋转或横移、推近（滑轨或变焦逼近主体）、拉远揭示、甩镜或弧线、急甩（慎用）——镜头间交替这些运动让剪辑有驱动力而非平淡；相邻两镜运动方向避免重复。
- 六条电影感核心规则：专业风格术语（引用作者导演与具体影片锚点）、构图与景别、强调负填充的光线、克制的单一主色调（约 90% 面积，禁霓虹撞色）、渲染质感、氛围与潜台词（冻结在戏剧瞬间的微表情）。
- 动作描述锚定具体身体部位并加程度副词（缓缓举起一只手、猛地甩头向左、用力蹬地）；多节拍按故事时间顺序列出主动作与次动作。
- 卖点即镜头：每个卖点配一种专属镜头语法（防水=水下慢镜、防抖=剧烈颠簸+稳定画面、续航=时间流逝空镜），卖点与语法一一映射，观众潜意识记住卖点。
- 一致性控制：产品元素描述与用户产品图逐项核对（材质、颜色、Logo 位置），写回结构化描述；同产品跨镜复用同一元素图。
- 规避翻车：产品特写镜先锁定"产品方向+包装完整+Logo 可读"，再写动态；防止模型把产品画歪或改写包装。

## 常见问题

- 成片像"桌上摆包装"：原因：主角镜占比过高、缺少氛围辅镜。解决步骤：补纯环境、纹理、生活方式镜头与主角镜交叉剪辑，按 6:4 比例重排。
- 镜头间无视觉变化：原因：每切都是同景别同机位。解决步骤：按"全景-中景-特写-高潮"节奏排布并交替镜头语法；相邻两镜至少有一个维度（景别/机位/运动）不同。
- 产品细节失真：原因：元素描述与产品图矛盾或没有锁定材质颜色。解决步骤：回写与素材一致的结构化描述（材质、颜色、Logo 位置逐项核对）；锁定后再生成。
- 包装与 Logo 时长不足：原因：合成时漏了强制包装镜头与 Logo 时长要求。解决步骤：回合成阶段补足；把强制时长写进规格与合成清单，逐项核对。
- 音画脱节：原因：音频标记缺失或未对齐。解决步骤：每镜提示词写明音频标记（音效/音乐氛围），合成时按触发点对齐。
