# 产品视觉电视广告

## 技能定位

本技能以"视觉逆向工程"为底层驱动制作品牌 TVC：先对上传的代言人图、场景调性图、产品图做高精度逆向拆解，产出可执行的生成逻辑文档，再依次推导品牌调性、品牌哲学、叙事方向、分镜表，最终逐段生成 15 秒广告片段。核心纪律是"确认前置"——分镜表未确认前严禁写规格、注册分镜、生成资产或生成视频；每张 15 秒分镜表以 3 秒视觉焦点与 7 秒高潮点的节奏逻辑编排。

## 适用场景

- 高端时尚、运动、汽车、3C 大牌调性 TVC。
- 有代言人与场景调性图的品牌广告片。
- 全球投放、产品发布、官网页面的品牌大片。
- 需要把参考影像"逆向拆解"为可执行生成逻辑的项目。

## 制作流程

### 前置条件（必做）

必须上传至少：代言人图＋场景调性参考图。可选：产品图、品牌视觉/色/质感/空间参考、既有广告参考。缺必需材料立即终止流程并提示补齐，不做任何推测产出。材料齐备后先输出一份"材料清点表"（材料名、用途、是否必需、缺失项），用户确认后进入第一阶段。

### 第一阶段：视觉逆向工程

对全部上传图做高精度逆向分析，输出 JSON 格式的"美学逆向规格文档"与"叙事潜力文档"：判定平面创意还是立体写实逻辑；拆解代言人外貌与姿态、产品结构材质与光影、场景空间分层与透视、光源方向与构图骨架，以及 3 秒视觉焦点与 7 秒高潮点。逆向文档字段模板：

| 对象 | 必拆字段 |
| --- | --- |
| 代言人 | 脸型、发型、体态、姿势、重心、视线、微表情术语 |
| 产品 | 结构比例、材质、表面状态、反光控制、Logo 位置 |
| 场景 | 空间分层、透视、主光源方向、构图骨架、色板占比 |
| 叙事潜力 | 3 秒焦点候选、7 秒高潮候选、动静节奏 |

只做分析，不生成任何叙事与素材。每个材质与结构判断标注"确证/推断"，推断项在后续生成时以保守参数处理。

### 第二阶段：品牌调性与哲学分析

基于逆向文档做品牌调性分析（品牌类型、高级感/时尚感/运动性能/汽车工程/3C 科技感来源、全球广告基调、目标受众情绪与视觉禁忌）与品牌哲学分析（品牌精神、主张关键词、代言人与品牌关系、产品与人物/场景关系、核心广告情绪）。同时确认规划参数：总时长、画幅、发布平台、品牌类型、是否允许品牌标识等。输出格式：调性结论一段 + 参数表一张，暂停确认。

### 第三阶段：叙事创意方向

提出 3 条一句话 TVC 叙事创意方向，每条含：标题、类型倾向、一句话故事、品牌哲学切入点、代言人情绪/动作、产品角色与 3 秒焦点/7 秒高潮点。类型覆盖高端情绪、时尚商业、运动性能、汽车品牌、3C 发布、短叙事、CG、实拍质感等。方向表逐行填写，暂停等用户选择、混合或修改。

### 第四阶段：前期故事脚本

按确认的方向输出前期故事脚本：标题、类型、总时长、画幅、视觉风格、品牌主张、核心叙事、各动作线、情绪节奏与段首尾转场策略。脚本只用于确认叙事方案，不得注册为分镜。判定标准：脚本必须能被一句话复述品牌主张，否则退回第三阶段。

### 第五阶段：全局分镜表（强制暂停）

每 15 秒输出一张独立分镜表：总时长严格 15 秒、含 5-12 个镜头，必须有 3 秒一个视觉焦点、7 秒一个视觉或情绪高潮。字段：

| 字段 | 内容要求 |
| --- | --- |
| 镜头序号/时间段 | 15 秒内精确到秒 |
| 镜头类型与角度 | 景别+角度术语 |
| 镜头运动 | 方向与速度 |
| 画面内容与表演 | 动作、微表情、关系 |
| 品牌/产品/代言人关系 | 谁在画面中承担什么功能 |
| 光影材质 | 光源、质感 |
| 音效/音乐/情绪曲线 | 时间点标注 |
| 转场逻辑/首尾衔接 | 承接上一表、预留下一表接口 |
| 商业表达功能 | 每镜承担的卖点/品牌任务 |

段首承接上一表的镜头内容与运镜方向；段尾为下一表预留运镜方向、动作动量或音乐节拍接口；必要时首尾重复小段动作或视觉符号保证分段连续性。分镜表必须完整输出并暂停等待确认，任何修改都完整重出再确认。

### 第六阶段至第八阶段：规格、注册与资产

分镜表确认后才写全局规格（标题、类型、画幅、总时长、分段时长、品牌调性、视觉风格、语言、分辨率、资产与段间转场策略）。默认横屏或竖屏按投放场景选择。每个 15 秒分镜表注册为一个完整分镜，禁止删减改写，只允许技术性编辑（拆分 ≤15 秒）。资产注册不以镜头为单位：只注册代言人全身三视图（以上传图为参考）、产品三视图、每场景一张资产图、跨表反复出现的道具/新造型/服饰/3C 界面等元素；禁止单镜资产、分镜资产图与关键帧图。所有图像生成严格用统一模型，生成后强制暂停等用户确认。

### 第九阶段至第十一阶段：提示词、生成与合成

每个 15 秒分镜对应一条视频提示词，把表内 5-12 个镜头整合进同一提示词，保留镜头顺序、3 秒焦点、7 秒高潮、动作链、转场逻辑、代言人动作、产品展示与首尾衔接策略；每条提示词显式写明本段如何承接上一段、如何衔接下一段。逐段生成 15 秒视频（引用已确认的代言人/产品三视图与场景图）。合成时按分镜顺序推上时间线；不额外生成独立配乐、旁白或音效，逐项检查动作方向、光影与段首尾的连续性。

## 提示词模板

**15 秒段提示词骨架：**
```
承接上一段：[上段结尾状态/运镜方向/音乐节拍]；
镜头1（0-3秒）：[景别][角度][运镜]，[画面内容]，[3 秒视觉焦点]；
镜头2（3-7秒）：…；镜头N（7-15秒）：[高潮内容]，[7 秒高潮点]；
代言人：[动作/微表情]，产品：[展示角度/Logo 时刻]；
转场逻辑：[镜头间衔接方式]；衔接下一段：[预留接口]；
[统一模型风格词]，[光影材质]
```

**示例成句（高端时尚段）：**
```
承接上一段：代言人自左向右走入画面；
镜头1（0-3秒）：全景侧跟，代言人穿过大理石柱廊，风衣下摆扬起，3 秒焦点为柱廊光影切割；
镜头2（3-7秒）：中景，代言人驻足侧头，目光落向镜头；产品腕表在袖口闪现；
镜头3（7-15秒）：特写推近腕表表盘，7 秒高潮为表盘光影扫过+代言人抬腕，
随后拉远收全景定格；转场：动作接动作（抬腕接拉远）；
衔接下一段：为下一段预留"腕表正面特写接续"；
统一模型风格词，高对比侧光，冷灰主色调
```

## 风格关键词与参数表

**核心关键词清单：** 高端调性、立体写实/平面创意（按逆向判定）、克制单一主色调、负填充光线、构图骨架、代言人微表情、产品高光控制、段首尾接口、3 秒焦点/7 秒高潮。

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 分段时长 | 严格 15 秒/表 | 5-12 镜/表 |
| 节奏 | 3 秒焦点、7 秒高潮 | 每表固定 |
| 画幅 | 横屏/竖屏按投放 | 生成前定死 |
| 分辨率 | 720p 生成、1080p 输出 | 统一模型 |
| 总时长 | 15 秒整数倍 | 按投放位决定 |
| 资产 | 仅四类 | 禁单镜资产 |

**禁用项清单：** 未确认分镜先写规格、未确认分镜先注册/生成、单镜资产与关键帧图、空洞美学词（高级感/奢华感不带结构）、流程跳步、段间断裂无接口。

## 进阶技巧

- 逆向文档是生成逻辑而非营销文案：禁止空洞美学词，每个元素写清位置、比例、材质、结构、表面状态与光照逻辑；不确定的材质给出专业判断并标注为推断。
- 汽车图要拆：车身比例、前脸、灯组、轮毂、腰线、内饰、漆面反射与速度暗示；3C 图要拆：屏幕比例、边框厚度、机身弧度、按键、接口、镜头模组与反射控制。
- 动态元素规则：人物必须描述姿势、重心、肩线、颈部转向、视线、手臂与手指姿态、腿支撑关系与微表情术语（眼轮匝肌收缩、上睑提拉、嘴角下垂等）。
- 段间接口是连续性命脉：每段末尾为下一段预留"运镜方向+动作动量+音乐节拍"三接口，合成前逐接口核对，缺一个即补写。
- 一致性控制：全部图像生成锁定统一模型；同场景跨段复用同一张场景资产图；代言人三视图每次必引用。
- 规避翻车：高光反射类产品（漆面、表盘）写清"反光控制"与"环境光映射"，防止过曝成白板。

## 常见问题

- 流程跳步：分镜表未确认就生成素材。原因：阶段性暂停点被跳过。解决步骤：回退补确认；每张表修改都重新完整输出再确认，确认记录留档。
- 资产过度注册：按镜头注册了单镜资产或关键帧。原因：把分镜表当资产清单。解决步骤：删掉只保留代言人/产品/场景/跨表重复元素四类；新需求资产走"跨表重复"判断。
- 段落断裂感：段首尾没预留运镜方向、音乐节拍与视觉符号接口。原因：分镜表末行未写接口。解决步骤：补写并显式声明承接关系，合成前逐接口核对。
- 逆向文档空泛：全是形容词。原因：未按字段模板拆解。解决步骤：重写成位置/比例/材质/结构/光照的可执行生成逻辑；不确定项标注"推断"。
- 段内节奏失效：3 秒焦点或 7 秒高潮缺位。原因：镜头排布未按节奏律。解决步骤：回分镜表重排镜头，把焦点/高潮锚到明确时间点。
