# 广告与电商（12 个子技能）

## 分类定位

本分类解决"把产品变成可投放的影像资产"：覆盖静态视觉（电商主图/详情页套装）到动态视频（产品广告、品牌 TVC、开箱测评、数字人口播带货）的完整链路，题材横跨数码工业、消费电子、珠宝配饰、服装时尚、食品饮料与潮流玩具。适合有明确商业目标的项目——无论是提升详情页转化、打造品牌调性，还是为信息流与社媒持续供给种草素材。

所有子技能共享同一条方法论主线——**以产品为真相中心**：开工前锁定产品基线或形象参数（轮廓比例、主色、材质、LOGO、结构分区、默认朝向，或面部、发型、服装、气质），全片以唯一权威源派生，杜绝形态、颜色与身份漂移。与此同时，多数子技能强调"确认前置"：分镜表、规格与卖点清单未经用户确认不得进入生成，宁可多一次确认，也不把偏差留到成片后返工。

核心方法可概括为一句话：先定基线与规格，再排分镜与节奏，逐镜生成并逐项审计一致性，最后按平台规格交付。本分类的技能产出均可直接商用，交付时须同步核对版权边界（如禁用艺术家名做 BGM 提示词）与平台合规要求。

## 通用制作流程

1. **需求确认与输入资产盘点**：确认品类、时长、画幅、投放平台与内容目标；收集产品图、卖点参数、代言人图、品牌标志等素材；用五问决策参数（品类/时长/画幅/测评风格/产品信息）框定边界；卖点只收录用户确认过的内容。
2. **基线与规格锁定**：提取产品基线六维或锁定形象参数（面部、发型、服装、气质、主色调），选定视觉风格分支（冷工业/赛博科技/极简纯白/暗金奢华、秀场/Lifestyle 等）；规格一经冻结只可引用不可改写，发现偏差回到该资产重新生成。
3. **创意方案与分镜规划**：按品类选择叙事模板（十二镜结构、15 秒分镜表、三幕结构、双镜单元、三幕开箱结构）；每镜写明景别、视觉焦点与高潮时间点；分镜未确认前不进入生成。
4. **风格与一致性锚定**：用风格字符串或关键词库逐字锚定所有提示词；光影四件套（主光方向色温、阴影硬度、高光位置、环境反射）每镜必写；连续镜头继承前段尾帧与参考图，保证轮廓、面料、动态全程一致。
5. **逐镜生成**：优先短镜头、每切必有明确视觉变化；每镜提示词写明音频标记（音效/音乐氛围/旁白），合成时按触发点对齐；禁止为节奏或情绪擅自加镜头，镜头数由叙事结构契约决定。
6. **音频合成与剪辑**：旁白口语化自然（约 4-5 字/秒）；BGM 只用风格、乐器、情绪描述，不出现任何艺术家或作品名；音画脱节时回到分镜的音频标记重新对齐，不做掩盖式修补。
7. **一致性审计与交付**：逐项对照基线与分镜审计（形态、颜色、LOGO、焦点不重叠、节奏锚点）；逐镜确认后按各平台规格（画幅、时长、字幕 Logo 规则）输出成片。

## 选型建议

- 要做电商静态主图与详情页成套视觉 → **电商产品视觉套装**
- 要做数码/工业产品功能可视化广告 → **工业产品演示视频**
- 要做珠宝、配饰、腕表广告 Vlog → **周边视觉珠宝广告十二镜**
- 要做奢侈品牌装饰艺术平面感广告 → **丝巾插画高定美学**
- 要做服装展示或穿搭动态化 → **高级时尚展示短片**
- 要做品牌大片级 TVC（有代言人）→ **产品视觉电视广告**
- 要做通用产品卖点加生活方式场景 → **产品商业短片**
- 要做开箱测评类内容 → **开箱初体验产品短片**
- 要做信息流口播带货 → **数字分身产品代言**
- 已有视频需要换人、换背景或同框合成 → **数字分身同框合成**
- 要做 Logo 具象化创意展示 → **创意品牌标志影像**
- 要做潮流玩具 IP 从概念到周边展示 → **玩具形象设计套件**

## 质量检查

1. 产品形态、颜色、LOGO 与注册基线对比无可见偏差，全套资产形态与基线一致。
2. 镜头节奏符合分镜表：3 秒视觉焦点、7 秒高潮点等锚点全部命中，镜头数不失控。
3. 卖点信息全部来自用户确认内容，无虚构功能、无未确认的价格与对比结论。
4. 视觉风格统一：光影四件套每镜必写，风格字符串逐字复用，无跨镜头漂移。
5. 音画同步：音频标记与触发点对齐，旁白节奏自然，BGM 与旁白互不干扰，无违禁引用。
6. 平台规格正确：画幅（9:16/16:9）、时长档位、字幕与 Logo 规则符合投放要求。
7. 逐镜确认无遗漏，任何漂移回到唯一基准资产重新派生，不靠剪辑掩盖偏差。
