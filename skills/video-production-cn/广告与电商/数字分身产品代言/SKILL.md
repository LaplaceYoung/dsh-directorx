# 数字分身产品代言

## 技能定位

本技能把数字人带货广告收敛为"极简但可信"的工业流程：一个数字分身、一个主场景、一个固定构图贯穿全片，用一段清晰的口播旁白驱动镜头分段与生成。它的方法论核心是"减法"——拒绝多机位、拒绝场景切换、拒绝为叙事节奏加镜头；全片只有一个可复用的关键帧作为身份与画面锚点，配合音频驱动的表演模型输出自然口播。视觉基调锁定"写实摄影+手机前置镜头感"：自然肤色、室内自然光、轻微手持稳定感，不做重美颜广告脸。

本技能把数字分身一致性落实为"参数锁定"：面部、发型、服装、气质四项在规格阶段一次定死，全片提示词逐字复用同一段形象描述，任何一镜漂移都回到唯一关键帧重新派生。

## 适用场景

- 电商信息流广告（默认 9:16 竖屏）：日用品、美妆、食品、数码产品口播带货。
- 品牌详情页视频与社媒种草素材：同一视觉资产多平台复用。
- 无真人出镜需求的商家：需要稳定、可复用的数字代言人形象。
- 用户已上传真人照片，需要"保留五官特征+电商可用"的数字分身。

## 制作流程

### 形象一致性参数

| 锁定项 | 参数 | 说明 |
|---|---|---|
| 面部 | 五官比例、肤色、眼型、眉形 | 写 3-5 个特征词，全片逐字复用 |
| 发型 | 长度、颜色、造型 | 如"黑色中长发、自然垂肩" |
| 服装 | 款式、颜色、材质 | 每镜引用同一套服装词汇 |
| 气质 | 亲和/专业/活力 | 决定表情与动作幅度基调 |

四项写入形象锁定模板，关键帧、逐镜视频、分镜表全部引用同一段文本。

**第一步：规格锁定。** 用文本编辑写入全局规格文档，默认参数：类型=数字分身产品代言；画幅 9:16；视觉风格=写实摄影、干净布光、手机前置摄像头拍摄质感；语言按角色受众>用户需求>用户输入语言的优先级确定；时长按口播文案量推算，单镜不超过 15 秒。

**第二步：分镜与关键元素设计。** 三类关键元素缺一不可：数字分身（角色）、产品资产、主场景。角色：无参考时用文生图按年龄、性别、着装、气质简报新建；有用户照片时用多模态图像模型做风格统一精修，保留可辨识五官与整体气质，输出单张干净的电商可用参考图。产品：优先请用户上传实物图（包装、单品、抠图、场景图均可）；没有则按品类简报生成演示用产品并明确告知可后期替换。场景：从角色+产品推导一个固定主场景（家、健身房、书店、办公室等），全片不换背景，卖点文案变化不改变场景。镜头数完全由口播分段决定：以句子完整为切分优先级，严禁按时间硬切——上一句说完再切下一句。全片一个构图、一个关键帧、同一资产ID：中近景或特写，人物主体占画面主导；避免全身，除非简报明确要求展示穿搭与产品全貌关系。分镜表必填字段：镜号、口播句段原文、该句对应的卖点、画面动作提示（持握/展示/指向）、镜头时长、音频层（旁白片段+音乐位置）。

### 口播动作库

口播表演不靠临场发挥，按卖点类型从动作库选用：

| 卖点类型 | 推荐动作 | 幅度 |
|---|---|---|
| 功效/成分 | 指向产品、轻拍包装 | 小幅 |
| 使用场景 | 模拟使用（涂抹/饮用/操作） | 中幅 |
| 优惠/价格 | 双手托举、靠近镜头 | 中幅 |
| 品牌背书 | 挺直上身、点头 | 小幅 |

动作与情绪分离：文案说功效时画面保持产品特写，动作只做辅助指向，不抢卖点；口播情绪与画面情绪不必同步。

### 产品展示运镜表

全片一个构图，产品展示在一镜内用动作与轻微运镜完成：

| 展示方式 | 镜头语言 | 适用 |
|---|---|---|
| 手持平举 | 中近景，产品与脸同层 | 默认，信息流通用 |
| 低角度仰拍 | 轻微仰角，产品略高于视线 | 增强产品权威感 |
| 俯拍桌面 | 产品平放俯拍 | 日常亲切感 |
| 佩戴展示 | 特写佩戴部位 | 美妆/饰品 |

全片只能选一种角度语言，禁止混用；镜头切换只发生在口播句子边界。

**第三步：独立音频设计。** 分镜中必须设计至少一条全局背景音乐轨；旁白层固定为独立音轨（类型标注"旁白"），写明音色身份、语气、逐字稿与放置指令。口播语言遵循规格文档设定。电平参考：旁白 -6dB 上下，BGM -18 至 -20dB，人声出现时音乐自动闪避。

**第四步：图像资产与关键帧生成。** 元素图用文生图（新建角色/演示产品），用户素材用图生图精修；分辨率 2K。每镜关键帧用图生图产出：角色+产品+场景的单张合成，布光、站位、持握方式全片一致，同一资产ID全片复用。关键帧要求：说话主体中近景/胸口以上，面部占比大且清晰，便于音频驱动模型对齐口型；产品必须清晰可读——手持或佩戴优先，与面部共享前景注意力，禁止过小、重度遮挡或杂乱背景淹没包装细节。

**第五步：视频生成。** 使用音频驱动视频模型，以关键帧+对应口播音频段为输入，1080p 分辨率。视频提示词的核心是描述"变化与动态"而非复述参考图的静态内容，遵循模板：运镜+说话者情绪+说话状态+具体肢体动作+（可选）背景事件。表演提示词用清晰的动作与节奏词（"平缓语速""亲切讲解"）而非抒情形容词；写明角色当前状态（正在说话/唱歌/含泪讲述）。生成时提示词加入 no music，避免与后期音乐打架。

**第六步：合成与导出。** 以旁白时间线为唯一时间基准，按分镜顺序拼接各镜视频；静音或衰减视频片段自带的多余音轨，防止旁白被叠音；不改播放速度、不做音频淡出处理。导出前引导用户确认。

### 绿幕/背景处理

- 全片一个主场景，不换背景；卖点文案变化不改变场景。
- 需要纯色背景时：优先选择与人物服装无冲突的绿色或中性灰；绿幕素材在合成时做边缘去杂色，避免绿色反光残留在肤色与发丝边缘。
- 背景虚化：浅景深虚化居家背景，产品与脸保持前景锐利。
- 判定标准：替换背景后人物边缘无绿边、无锯齿；不通过时调整去杂色强度并重出。

### 提示词模板

#### 形象锁定模板（全片复用段）

```
[年龄+性别]，[面部特征 3-5 词]，[发型词]，
[服装词]，[气质词]；写实摄影风格，自然肤色
```

示例成句：

```
28 岁年轻女性，圆脸杏眼、自然眉、小麦肤色，黑色中长发自然垂肩，
米白色针织开衫，亲和气质；写实摄影风格，自然肤色
```

#### 关键帧提示词模板（产品可见）

```
[风格串]，[景别]，[形象锁定段] [表情与视线]，
[持握/佩戴动作]，[产品名+关键特征]清晰可读，
[背景与光线]；[构图与镜头质感]
负向：无多余人物、模糊、重美颜滤镜
```

示例成句：

```
写实摄影风格，自然肤色，室内窗边漫射光；中近景，
28 岁年轻女性面带自然微笑直视镜头，右手举起产品瓶身
置于面部同层前景，瓶身标签清晰可读，柔和的手机前置镜头质感；
构图主体居中，浅景深虚化居家背景
负向：无多余人物、模糊、重美颜滤镜
```

#### 视频生成提示词模板（音频驱动）

```
镜头轻微推进，说话者[情绪]地[说话状态]（与音频同步），
[语速与节奏词]，[动作序列：先…再…]；
[背景光线状态]，动作幅度[适中/小幅]
负向：无音乐、无字幕、无多余人物
```

示例成句：

```
镜头轻微推进，说话者亲切热情地开口讲解（与音频同步），
平缓语速，自然的讲解手势：先指向产品瓶身，再双手托起
展示给镜头，眼神在镜头与产品之间自然切换；
背景光线柔和稳定，人物动作幅度适中
负向：无音乐、无字幕、无多余人物
```

**检查点：** ① 规格确认后暂停；② 分镜确认后暂停；③ 关键元素图确认后暂停；④ 关键帧确认后暂停；⑤ 旁白与音乐生成后暂停；⑥ 逐镜视频确认后暂停；⑦ 合成导出前暂停。每阶段展示成果邀请用户评审后再继续。

## 进阶技巧

- 镜头数就是卖点数：一条口播一个卖点对应一镜，卖点讲完即切；宁可镜头少而完整，不要为凑时长加无信息量的画面。
- 数字分身的一致性靠"单一锚点"：整片只用一张关键帧做参照，任何一镜漂移都回到这张图重新派生，而不是逐镜追改。
- 产品是"演员"不是道具：利用低角度仰拍增强产品权威感、俯拍增强日常亲切感，但全片只能选一种角度语言；布光用 45 度侧硬光+对侧柔补光，绝不平光。
- 口播情绪与画面情绪分离：文案说"性价比"时画面保持产品特写，文案说"使用场景"时切使用中景——画面永远服务卖点而非情绪。
- 后期 BGM 压到 -18 至 -20dB 左右作为氛围层，口播保持 -6dB 上下清晰可闻；人声出现时音乐自动闪避。

## 常见问题

- **旁白被视频自带声音叠音**：原因：视频片段自带音轨未处理，与旁白轨叠加。解决步骤：① 视频生成时提示词已加 no music；② 合成时静音所有视频段原音轨，只保留旁白主轨；③ 导出前试听确认无叠音。
- **口型与音频不同步**：原因：关键帧面部占比太小或产品遮挡脸部导致对齐失败。解决步骤：① 保证中近景大脸占比，面部占画面约 1/3 以上；② 产品与脸同层前景，不遮口型区域；③ 口型仍不同步则重出关键帧再驱动。
- **数字分身形象漂移**：原因：各镜提示词对形象描述不一致，或未引用唯一关键帧。解决步骤：① 全片逐字复用形象锁定模板，不换说法；② 任何一镜漂移回到唯一关键帧重新派生；③ 复核资产 ID 与命名，确认全片同一。
- **画面漂移或多机位幻觉**：原因：分镜里写"切中景/切特写/换角度"诱导模型多机位化。解决步骤：① 坚持一镜一构图；② 镜头切换只发生在口播句子边界；③ 删除分镜表中诱导多机位的描述。
- **产品不清晰**：原因：产品过小、背景杂乱、重度遮挡淹没包装细节。解决步骤：① 收紧构图或把手与产品拉近；② 让脸与产品都处于锐利前景；③ 关键帧阶段先确认产品可读再进入视频生成。
- **为叙事加镜头**：原因：为节奏、情绪或景别变化加镜头。解决步骤：这是违规操作——镜头数只由口播分段决定，是本流程的结构契约；发现即删，回到口播分段重新组织。
