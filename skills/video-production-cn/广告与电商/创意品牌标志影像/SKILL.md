# 创意品牌标志影像

## 技能定位

本技能把品牌标志从"平面图形"变成"真实世界里的物理存在"：以创意合成专家的视角，为每个 Logo 设计 6 个互不重复的具象化叙事场景，让 Logo 以纹身墨水、建筑形体、金属车标、玩偶形态、集装箱印刷等实体身份自然地活在画面里，而不是悬浮在表面上的贴纸。它的提示词哲学是"像跟朋友描述一张照片那样说话"——一条连贯的日常语句远比堆砌"超写实、电影级、体积光"这类术语有效。超写实的真实感来自具体的人物、物件与叙事逻辑，而非材质词汇的密度。

# 适用场景

- 品牌开屏动画、Logo 展示片、社媒品牌内容（默认 9:16 竖屏）。
- 产品发布预热、品牌升级官宣、活动视觉物料。
- 需要多场景、多角度、可拆条传播的 Logo 视觉资产包。
- 用户已有品牌标志图，需要自然融入真实生活场景的创意呈现。

# 制作流程

## 第一步：Logo 分析与全局规格

分析用户上传的 Logo，提取：核心形状/图形轮廓、主配色、文字内容与字体风格、整体视觉风格（极简/复古/科技等）。输出结构化描述，重点标注场景融合时必须精准保留的视觉特征（特定曲线、标志色、字形）。注意：颜色信息只用于保证 Logo 图形可识别地还原，不限制创意方向——创意从构图专家视角自由发散，不被品牌色绑架。

写规格文档锁定：画幅（默认 9:16；自定义画幅先核对图像模型与视频模型的画幅支持交集，两者仅 9:16 与 16:9 兼容，不兼容时提示并回退 9:16）、创意风格（超写实）、输出数量（6 张/6 条）。规格表字段：画幅、风格、数量、Logo 必保特征、场景题材禁区（品牌方指定）。

## 第二步：6 场景创意方案

为每个场景输出结构化字段：

- 创意概念：具体、有叙事感的真实世界场景——不是抽象概念，而是有具体物件、环境甚至人物动作的画面（如"纹身师在客人手臂上刺入 Logo""城市中心一座 Logo 形状的建筑""白色复古车头的金属 Logo 立标""抓娃娃机夹起 Logo 造型的玩偶抱枕""深蓝海面上漂浮的巨大集装箱印着 Logo、旁边站着海鸥"）。6 个场景方向必须明显不同（可跨越人文、动物、生物、建筑、产品等题材），禁止套路化模板。
- 超写实视觉描述：用简洁自然语言写画面上发生什么、有哪些具体物件——真实世界的叙事自带超写实，不需要堆砌材质与灯光术语。画面保持干净、有品位；即使是粗粝材质（沙地、水泥墙）也要呈现得精致高级，避免脏乱破败感。
- Logo 与场景融合：Logo 以自然存在的物理实体出现——是纹身墨水、是建筑结构、是车身徽章、是玩偶形状、是集装箱印刷；与场景的材质、光线、空间关系自然互动。不要写"无缝融合"类指令，关键是让 Logo 成为场景叙事的一部分而非外部图层。
- 视觉丰富度：通过具体物件构建纵深（纹身师的荧光绿手套、集装箱边的海鸥、建筑周围的树与车、娃娃机里的各色玩偶），比"前景/中景/背景分层"这类抽象指令有效。6 个场景在题材、氛围、色调上拉开差异，避免单调。
- Logo 尺度与构图：Logo 是核心主体，必须醒目不能太小；6 张中大小可灵活变化（有的占画面约 1/3 或更多，有的较小但清晰可辨）。Logo 尽量正面朝前，避免极端倾斜或翻转以保证品牌识别；6 张的差异来自题材、场景、色调与尺度，而不是歪斜角度。创意元素服务于 Logo，不能喧宾夺主。
- 视频运动逻辑：运动来自场景自身的物理逻辑（纹身针刺入皮肤、海鸥转头、爪子下落），禁止与内容相悖的强行运动。
- 环境音设计：按画面中的真实物理动作设计环境音（碰撞、摩擦、自然音），营造沉浸真实感。
- 推荐时长：3-5 秒——细微运动用 3 秒，需要过程感的用 4-5 秒。

Logo 边缘处理：边缘不必完美平滑，允许随材质与物理环境产生不规则变化（墨水晕染、沙粒塌陷、表面磨损、曲面自然包裹），整体形状与配色仍可识别为原 Logo 即可。全部场景统一使用规格锁定的画幅。

检查点：创意方案完成后暂停展示，用户确认或修改后才生成图像。6 场景差异自查表：题材（人文/动物/生物/建筑/产品至少跨 3 类）、氛围（冷/暖/动/静拉开）、色调（每场景主色不同）、尺度（大/中/小各至少 1 张）。

## 第三步：批量生成图像

以用户 Logo 为参考图执行图生图（图像生成模型，2K）。提示词写成一条连贯的自然语言句子，像描述照片给朋友听："画面里有什么、发生什么、Logo 在哪里以什么形态出现"。结尾补视角与构图（如"特写镜头""高角度俯拍""居中构图"）。不要写成要点列表或堆术语；禁止"超写实电影级构图、戏剧性体积光、浅景深、无缝融合"这类抽象指令式写法。

好提示词共性：一句定清具体场景；Logo 作为物理物件融入（墨水/建筑/车标/玩偶/印刷）无需写"如何融合"；场景有真实物件与细节使其可信；以视角构图收尾。指定从参考图提取 Logo 的形状、轮廓与配色以保证可识别，但创意不被原色限制。图像要写实、精致、高质量，避免卡通化、扁平化、插画感；6 张在题材、场景、色调上差异明显。

## 第四步：批量生成视频

以对应场景图为参考执行图生视频（视频生成模型，720p，3-5 秒整数）。动态描述基于图像内容的物理逻辑——主体应如何自然运动，而不是添加画面中不存在的夸张运动；保持与超写实基调一致的轻微自然运动。每条视频提示词必须包含自然环境音效描述（按画面物理动作写碰撞/摩擦/环境声），使模型自动生成与内容同步的真实音效；音效必须来源于画面可见动作，不为不存在的东西配音。整条提示词（含参考图标记）不超过 2000 字符。

检查点：图像批量生成后暂停展示确认，通过后再进入视频生成。

## 第五步：合成

按创意节奏排布 6 条片段：视觉强度渐进递进或强弱对比交替。转场以干净的硬切或极短溶解为主，避免过多特效干扰超写实质感。用户需要完整呈现时可加简单开场/收尾标记（可选）。

# 提示词模板

**图像生成模板（一句话式）：**
```
{场景一句话：谁/在哪/发生什么}，{Logo 以什么物理形态出现在哪里}，
{2-3 个具体物件细节}，{视角/构图收尾}，
从参考图提取 Logo 形状轮廓与配色，写实精致高质量
```

**视频生成模板：**
```
{场景一句话}，{基于物理逻辑的自然运动描述}，
{环境音效：碰撞/摩擦/环境声}，3-5 秒，720p，超写实
```

# 风格关键词与参数表

**核心关键词清单：** 超写实、叙事感场景、物理实体融入（纹身/建筑/车标/玩偶/印刷）、具体物件纵深、自然运动逻辑、环境音同步、干净有品位、精致高级。

**6 场景布局表：**

| 维度 | 要求 |
| --- | --- |
| 题材 | 人文/动物/生物/建筑/产品至少跨 3 类 |
| 氛围 | 冷/暖/动/静拉开 |
| 色调 | 每场景主色不同 |
| Logo 尺度 | 大/中/小各至少 1 张 |
| 时长 | 细微运动 3 秒、过程感 4-5 秒 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 画幅 | 9:16 默认，16:9 兼容 | 生成前核对交集 |
| 图像 | 2K | 图生图 |
| 视频 | 720p、3-5 秒整数 | 图生视频 |
| 提示词长度 | ≤2000 字符（视频） | 含参考图标记 |
| Logo 占比 | 约 1/3 或更大，可小但清晰 | 正面朝前 |

**禁用项清单：** "无缝融合"类抽象指令、术语堆砌（超写实/体积光/浅景深堆叠）、卡通化/扁平化/插画感、极端倾斜翻转、画面外物体配音、强行夸张运动、脏乱破败感、画幅混用。

# 进阶技巧

- 角度心理学：低角度让 Logo 显得更大、更有权威、更令人向往（英雄镜头）；俯拍显得更日常、更易接近。机位角度是塑造观众感受的最直接工具，选择应反映品牌想让观众感受到什么。
- 品牌帧思维：6 张图每一帧都是可复用的战略资产——一张图可同时用于 campaign、详情页与广告；先设计帧再开机，拍摄日只执行确认过的帧。
- 批量角度测试：一次生成 8-12 个角度变体由数据选优，而不是凭感觉定 3-4 个；多数品牌 3-4 个角度即可，突出品牌可用 8-12 个——多出的角度是"丰富 vs 目录朗读"的区别。
- 文案式收尾：如需完整呈现，用一条简短标语画面收尾，与 Logo 主色呼应，形成记忆点。
- 竖屏原生构图：9:16 不是"横屏裁一版"，而是单独设计构图，Logo 与叙事元素按竖屏视觉重心排布。
- 一致性控制：6 场景共用同一 Logo 参考图与同一组必保特征（曲线/标志色/字形）；边缘随材质变化但整体可识别，生成后逐张核对识别度。
- 规避翻车：Logo 极简图形（如圆形/字母）容易在物理化时"消失"，用"保留轮廓完整"明确指令；细字 Logo 不用远场景，改特写。

# 常见问题

- Logo 像贴纸悬浮：原因：把 Logo 写成了"叠加在表面上的图层"。解决步骤：让 Logo 作为场景叙事的一部分自然存在（纹身/建筑/车标/玩偶/印刷）；提示词写清材质物理状态（墨水晕染、沙粒塌陷、表面磨损）。
- 术语堆砌反而差：原因：提示词堆"超写实、体积光、无缝融合"等抽象词。解决步骤：改为一条讲清场景的日常语句；检查提示词是否含 3 个以上抽象术语并删除。
- 6 场景同质化：原因：复用同一种创意套路。解决步骤：核对题材/氛围/色调是否拉开差异，按 6 场景布局表逐项自查，重写重复场景。
- 运动与内容物理逻辑不符：原因：添加了画面中不存在的动作。解决步骤：运动必须源自场景自身物理（爪落、针刺、海浪），删除强行运动描述。
- 音效无中生有：原因：为画面外物体配音。解决步骤：音效必须对应画面可见物理动作，不为不存在的东西配音；逐条核对音效来源。
- 画幅不一致：原因：图像与视频模型画幅支持未核对。解决步骤：全部场景统一规格锁定画幅，生成前核对图像与视频模型支持交集，不兼容回退 9:16。
- Logo 过度倾斜/翻转：原因：用角度制造差异。解决步骤：保持正面朝向以保证品牌识别，差异靠题材、场景、色调与尺度制造。
