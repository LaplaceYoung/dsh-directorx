# 人文纪录短片

## 技能定位

本技能以观察式纪录片精神制作短片：镜头"不设计故事、只偶然看见生活"。核心是抓住决定性瞬间——手工作坊、背影、点烟喝茶发呆等无目的小动作，用长镜头加自然光加保留瑕疵的真实感呈现。题材限定真实的人与平凡生活，地域聚焦亚洲、非洲、中东、南美、东欧等区域。

## 适用场景

- 人物与生活纪实类短片（6-12 秒长镜头为主）。
- 传统手工艺、市井生活、乡村日常的记录。
- 需要人文温度、拒绝商业广告感的品牌或公益内容。
- 用户提供实拍素材或场景照片的风格化制作。

## 制作流程

### 第一步：锁定规格

写规格档案：标题、主题地域、画幅（16:9 或 2.35:1 变形宽银幕）、目标时长、视觉风格、输出语言。规格默认值：画幅 16:9、单镜 6-12 秒、成片 30-60 秒、低饱和自然色。主题地域决定场景素材库方向，写入规格供全流程引用。

### 第二步：分镜设计

生成关键元素、镜头表与音频层；完成后扫描上下文已有素材（用户提供或先前生成）并逐一绑定到分镜槽位，避免重复生成。镜头表逐镜登记：主体与微动作、环境与空气感、光线条件、镜头语言与景别、色彩系统、精神关键词、时长。

### 第三步：生成元素与起始帧

- 起始帧公式：主体与微动作 + 环境与空气感 + 光线条件 + 镜头语言与景别 + 色彩系统与胶片质感 + 精神关键词。核心是抓决定性瞬间，丢弃一切运镜与节奏词汇。
- 微动作库：背影、吸烟的手、望着窗外、停顿的空白时刻。
- 空气感必选其一：尘埃、晨雾、湿气、热浪、风拂衣。
- 光线只允许自然光：晨光、黄昏、阴天漫射、窗边侧光；禁人工补光感。
- 元素描述模板：`{主体}在{环境}，{微动作}，{空气感}，{自然光}，{景别}，{低饱和自然色胶片质感}，{精神关键词}`。

### 第四步：逐镜生成

- 视频公式：极度克制的运镜 + 主体连续微动作 + 环境与光线的细微流逝 + 色彩系统 + 纪录片节奏 + 精神关键词。
- 每镜只描述一种运镜，按优先级：固定机位（强烈推荐）> 轻微手持（仅呼吸感）> 极慢推或极慢摇；禁止旋转、快速变焦、无人机、花哨运镜、跳切。
- 单镜 6-12 秒，严禁短于 5 秒。
- 允许轻微失焦、曝光波动、人物短暂停顿作为真实感加分。
- 失败处理：生成失败只在同模型内重试，不自动切换其他工具，停下来告知用户；连续两镜失败检查运镜是否越界或动作是否过度设计。

### 第五步：音频与组装

- 环境声（市集/风/雨/街道）为主；BGM 音量低于视频音频层并淡入淡出、不喧宾夺主。
- 不强行音画同步，让声画自然流淌；不用对白驱动叙事。
- 镜头间用 0.5-1 秒黑场或声音延续制造呼吸空间；禁抖音式快剪、音乐卡点与特效转场。
- 组装自查：全片是否以"人"进入而非景观；每镜是否只有一种运镜；光线是否全为自然光；瑕疵是否保留。

## 提示词模板

**起始帧模板：**
```
{主体}，{微动作}，{环境}，{空气感：尘埃/晨雾/湿气/热浪/风拂衣}，
{自然光：晨光/黄昏/阴天漫射/窗边侧光}，{景别}，
低饱和、柔和高光、有细节阴影、真实肤色，胶片质感自然色，
{精神关键词：专注/疲惫/松弛/孤独}
```

**视频镜模板：**
```
{固定机位/轻微手持/极慢推/极慢摇}，{主体连续微动作}，
{环境与光线的细微流逝}，低饱和自然色胶片质感，
纪录片节奏，{精神关键词}，
no artificial light, no fast cuts, no camera tricks
```

**示例成句（手工作坊）：**
```
固定机位，老匠人低头打磨木器，木屑缓缓飘落，尘埃在窗边侧光中浮动，
中景，低饱和柔和高光、真实肤色，胶片质感自然色，
专注与疲惫并存，no artificial light, no fast cuts
```

**示例成句（市井背影）：**
```
轻微手持，老人背影穿行早市，湿气弥漫，晨光斜照，
全景，低饱和自然色，胶片质感，
松弛的日常，no artificial light, no camera tricks
```

## 风格关键词与参数表

**核心关键词清单：** 观察式纪录片、决定性瞬间、固定机位、自然光、低饱和、柔和高光、有细节阴影、真实肤色、胶片质感、空气感（尘埃/晨雾/湿气/热浪/风拂衣）、保留瑕疵。

**微动作库与景别映射：**

| 微动作 | 推荐景别 | 情绪指向 |
| --- | --- | --- |
| 背影 | 全景/中景 | 留白、孤独 |
| 吸烟的手 | 特写 | 沉思、疲惫 |
| 望着窗外 | 中景 | 出神、期待 |
| 停顿的空白时刻 | 中景/近景 | 松弛、日常 |

**推荐参数：**

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 单镜时长 | 6-12 秒 | 严禁短于 5 秒 |
| 成片时长 | 30-60 秒 | 按题材 |
| 画幅 | 16:9 或 2.35:1 | 变形宽银幕更"电影" |
| 运镜 | 每镜一种：固定>轻微手持>极慢推/摇 | 固定机位强烈推荐 |
| 光线 | 仅自然光 | 禁人工补光感 |
| 色彩 | 低饱和、柔和、真实肤色 | 胶片质感自然色 |
| 转场 | 0.5-1 秒黑场或声音延续 | 禁快剪卡点特效 |

**禁用项清单：** 城市景观与宏大风景做主角、旋转/快速变焦/无人机/花哨运镜、跳切、人工补光感、高饱和、音乐卡点、特效转场、对白驱动叙事。

## 进阶技巧

- 地域场景素材库：亚洲=早市摊/老茶馆/传统市集/渔村/老铁路旁；非洲=日落尘土归家/热闹市集/雨季日常/传统手工艺；南美=街头音乐/老街/海边日常/泥地球场/夜市烟火；中东=阳光透射的市集/专注手工艺/虔诚祈祷/尘沙环境日常。主题地域选定后只从对应库取景，防止跨地域穿帮。
- 背影叙事比正面更高级、留白更多：全片可安排 30%-50% 镜头为背影或侧影，正面只留给"决定性瞬间"。
- 色彩系统直出：低饱和、柔和高光、有细节阴影、真实肤色，参考胶卷质感的自然色；色板在首镜定死后全片锁定，禁中途换风格词。
- 观感对标"长期驻点摄影师偶然拍到的自然状态"，追求全球观众共情，避免刻板区域风格。
- 长镜头优先，不为"有趣"而缩短镜头：剪不下去的镜头用"声音延续"衔接（上一镜环境声拖入下一镜），保留完整呼吸。
- 规避翻车：人物脸部特写过多会滑向"剧情片"，控制特写占比 ≤20%；多人同框场景容易变形，优先单人微动作。

## 常见问题

- 拍成城市宣传片：原因：以景观/建筑开场或主体化。解决步骤：必须从"人"进入，严禁城市景观与宏大风景做主角；首镜即人物或生活细节，景观只作背景出现。
- AI 味过重：原因：画面过于干净完美。解决步骤：保留瑕疵（轻微失焦、曝光波动、停顿）是真实感的加分项；删除"完美妆容、锐利、干净"类词汇。
- 运镜过度：原因：每镜多运镜或选了花哨运动。解决步骤：每镜只一种运镜，固定机位优先；出现旋转/变焦立即回退重生成。
- 光线太假：原因：提示词混入人工光词。解决步骤：只允许自然光，禁人工补光感；统一追加 no artificial light 负向词。
- 剪辑太快：原因：镜头过短或快剪。解决步骤：镜头间用黑场或声音延续制造呼吸，长镜头优先；单镜不足 5 秒的镜头删除或合并。
- 生成失败：原因：内容超出模型稳定范围。解决步骤：只在同模型内重试，不自动切换其他工具，停下来告知用户；调整微动作幅度与运镜后重试。
