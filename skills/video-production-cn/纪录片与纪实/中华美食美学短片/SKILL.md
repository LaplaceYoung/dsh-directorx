# 中华美食美学短片

## 技能定位

本技能以人文纪录美食片的审美体系为纲：暖调厚重有机的色调纪律、明暗 6:3:1 的光比控制、以食材物理属性为核心的视觉基因分析、以及"微距钩子+慢镜高潮"的十五秒节奏结构。其独特之处在于把"烟火气"拆成可执行的规则：蒸汽与油花的光学逻辑、食材状态的物理变化链、禁止暴力的镜头语法（禁破裂/禁炸裂/禁切碎类词汇，除非是温柔的切片动作），以及"以动作接动作、以遮挡接场景"的无缝转场纪律。最终产出一部画面上治愈、声音上沉浸、节奏上连贯的美食短片。

## 适用场景

- 食材溯源类：从产地到餐桌的完整旅程（田间收获、运输、加工、烹饪）。
- 烹饪技法类：以刀工、火候、锅气为叙事核心的厨房特写短片。
- 人文叙事类：以食物为纽带的人物故事与地域记忆。
- 竖屏美食短视频与横屏纪录片风格短片均可，默认 16:9 或 9:16。
- 需要旁白配音（深沉慢速磁性男声）+ 物理音效（滋啦、剁刀、咕嘟）分层设计的项目。

## 制作流程

### 第一步：食物视觉基因分析
调用多模态解析工具对食材做"逆向工程"：分析成熟度、含油率、组织纤维、水分张力等物理属性；评估蒸汽、雾气、油花飞溅、明火、火星的动态轨迹与光线折射逻辑；建立明暗 6:3:1 的光比纪律（主光六成、辅光三成、点缀一成）。若用户上传食物参考图，则登记为资产作为后续生成的视觉锚点。输出两类重构描述：

| 输出类型 | 内容 | 示例 |
| --- | --- | --- |
| 食材重构描述 | 肉质/果蔬/液体的表面质感参数 | "五花肉肥瘦相间、油光湿润、纹理细腻" |
| 技法重构描述 | 微距、慢镜的拍摄规格 | "微距 2-3cm 工作距离、120fps 慢镜" |

物理属性检查表：蒸汽轨迹（上升角度、密度、遇冷凝结）、油花飞溅（飞溅半径、颗粒大小、慢镜下的球体形态）、明火（火焰颜色分层：蓝焰-橙焰-红焰）、火星（飞散方向与亮度衰减）。

### 第二步：创意挖掘与方案定稿
给出三个单句剧情方向供用户选择：食材溯源式（一片土地的物产如何走上餐桌）、烹饪精研式（一道菜从备料到出锅的细节流）、人文叙事式（食物连接的人物与记忆）。选定后进入分镜设计。判定标准：三类方向的分镜节奏不同——溯源式多外景大全景、精研式多厨房特写、人文式多人物中景，选定后不得混用主节奏。

### 第三步：分镜设计（十五秒节奏律）
每十五秒为一个分镜单元，含 5-12 个内部镜头：前 3 秒必须给出视觉焦点（切面微距、调料入锅瞬间、蒸汽划过镜头前的折射），后 7 秒给出叙事高潮（丰收/盛宴全景、食物在慢镜中的物理形变如爆汁蒸腾、人物尝食的微表情）。分镜表按以下字段逐镜登记：

| 字段 | 要求 |
| --- | --- |
| 镜头号/时间点 | 单元内 0-15 秒定位 |
| 景别与机位 | 特写/中景/全景 + 机位方向 |
| 运镜 | 微距推进/升降/横移/固定 |
| 食材动态与物理反馈 | 状态变化、飞溅、蒸汽、折射 |
| 转场指令 | 动作接动作 或 蒸汽/火光遮挡 |
| 视听节奏点 | 音效与视觉顶点同步位置 |

分镜表按 1000 字左右撰写并强制暂停等待用户确认。转场铁律：禁止黑场、禁止叠化，必须用动作接动作（搅拌勺的旋转接盘子的晃动）或物理遮挡（蒸汽升起遮蔽镜头切下一场）。词汇禁令：禁止破裂、崩裂、炸裂、切碎、爆裂、碎片等暴力词汇，除非是自然的食材加工且动作须轻柔流畅。

### 第四步：素材生成与二次确认
按已确认分镜生成 2K 食材、厨具与环境图像：照明要有层次、暗部细节丰富、高光要有湿润质感；要求极致食欲感。同时生成旁白音色参考。生成完成后强制暂停，向用户展示食材/场景图与声纹，确认满意后才进入视频生成。

### 第五步：提示词编写（通用公式）
采用结构化公式：镜头号与机位 + 运镜术语 + 食材动态细节与物理反馈 + 烟火气与环境交互 + 视听节奏点。中英混写：中文描述画面，英文写物理参数。烹饪美学参数：逆光打蒸汽、肉质用次表面散射、色温偏暖；质感强调高光泽油脂、酥脆细节、有机微观纹理。转场指令明确标注"以蒸汽遮挡/动作匹配从镜头 A 无缝过渡到镜头 B"。负向约束：塑料感、人造光、文字、logo。

### 第六步：视频生成与合成
以十五秒分镜为连续任务逐镜生成，镜头间运动必须连贯，禁止生硬卡顿；十五秒内食材状态变化必须符合物理规律（如蔬菜由生转熟的变色过程）。合成阶段：打开视频轨原声，把画面内的物理音效精确对齐视觉动作（滋啦声对齐入锅瞬间）；整片统一做暖调人文色调校准。检查 5-12 个微镜头在十五秒内的逻辑连贯性与音画对齐度。

### 第七步：质量复核
按三层清单验收：

| 层面 | 检查项 |
| --- | --- |
| 画面层 | 暖调厚重有机、高光湿润、暗部有细节、无塑料感人造光 |
| 节奏层 | 每 15 秒前 3 秒有视觉钩子、后 7 秒有高潮、镜头间以动作匹配或遮挡衔接、无黑场叠化 |
| 声音层 | 旁白深沉缓慢有磁性、物理音效与动作帧对齐、环境音保留呼吸感 |

不通过则定位到具体镜头与参数修正后重生成，禁止整片推倒重来。

**三类镜头的模板与示例：**

| 镜头类型 | 模板 | 示例成句 |
| --- | --- | --- |
| 微距钩子镜 | 特写，微距[推进/固定]，[食材]+[切面/纹理细节]，[液体/水珠动态]，逆光[蒸汽/光晕]，湿润光泽 | 特写，微距缓慢推进，青笋横切面，纤维纹理清晰，水珠沿切面滑落，逆光下蒸汽在镜头前滑过，折射出暖色光晕，画面湿润有光泽 |
| 高潮慢镜镜 | [景别][升降/固定]，[食材入锅瞬间]，[油花/飞溅定格成慢镜]，[食材物理形变]，[音效与视觉同步]，[蒸汽遮挡转场] | 全景缓慢升降，热油入锅瞬间，油花向四周飞溅定格成慢镜，食材在油中翻滚上浮，表面泛起金黄脆壳，滋啦声与视觉顶点同步，随后镜头以蒸汽遮挡转场至下一场景 |
| 状态链镜 | 中景，[食材]在[介质]中由[初始态]逐渐[变化]，[微观动态]，[收汁/挂勺细节]，全程物理规律无跳变 | 中景，豆腐在汤汁中由白嫩逐渐浸染酱色，边缘微微颤动，气泡从底部升起又破裂，汤汁收浓挂在勺沿，全程状态变化符合物理规律，无跳变 |

**负向词块：** 无塑料感、无人工光源感、无文字、无 logo、无暴力碎裂效果。

**占位符速查：** 食材=笋/豆腐/五花肉/面糊；物理反馈=起泡/飞溅/蒸汽/挂汁；转场=蒸汽遮挡/动作匹配；节奏点=滋啦声与视觉顶点同步。

## 进阶技巧

- 用"食材状态链"驱动叙事：一个十五秒单元内只允许一种明确的物理变化（凝固、沸腾、焦化、软化），变化本身就是剧情；状态链写进提示词（"由白嫩逐渐浸染酱色"），模型按物理规律推进。
- 蒸汽与火光是最廉价的转场道具：让蒸汽、油烟或火星在镜头前形成全遮挡帧，下一镜从同类遮挡中揭开，实现无痕空间跳转；全遮挡帧需要 0.3-0.5 秒满屏，太薄会穿帮。
- 慢镜只用在物理形变顶点（爆汁、蒸腾、汤汁滴落），与全景丰收镜头形成"特写-宏观"的两极呼吸节奏；慢镜减速 2-3 倍封顶。
- 旁白与画面节奏互为表里：旁白停顿处留给环境音（锅气、蝉鸣、雨声），避免解说填满每一秒；旁白字数按 15 秒单元 40-55 字控制。
- 一致性控制：同食材跨镜复用同一张食材元素图；油花、蒸汽方向与光源方向在单元内保持一致，防止物理逻辑错乱。
- 规避翻车：需要"切片"表现时用"薄刃轻压、缓慢划过"的温柔措辞，避开禁用暴力词；手部入镜动作写清部位与轨迹。
- 迭代策略：先出 15 秒单单元样片验证色板、光比与旁白声线，再批量扩片；样片阶段调参数成本最低。

## 常见问题

- 画面发"塑料感"或色彩失真：原因：高光过曝或饱和度失控。解决步骤：回到 6:3:1 光比与暖调校准，负向词加塑料质感；降低高光权重、恢复暗部细节后重生成该镜。
- 转场生硬：原因：直接切镜或使用叠化。解决步骤：改为动作匹配或蒸汽遮挡后再切；在分镜表转场栏明确标注转场类型，逐镜核对。
- 食材状态跳变：原因：提示词未写明十五秒内的物理变化链。解决步骤：补上"从生到熟、由浅至深"的状态演进描述；同一单元只保留一种物理变化。
- 音画脱节：原因：物理音效未对齐动作帧。解决步骤：逐帧对齐滋啦/剁刀/咕嘟声与视觉事件；以动作触发帧为基准，音效头对齐（±2 帧）。
- 十五秒内容过满或过空：原因：镜头数失控或钩子/高潮缺位。解决步骤：回到 3 秒钩子 + 7 秒高潮的节奏律，砍掉与主题无关的冗余镜头；镜头数控制在 5-12 个。
