# 纪录片与纪实（8 个子技能）

## 分类定位

本分类解决"把真实世界拍成有质感的纪实短片"：题材横跨人物生活、旅行、手工艺、日常 Vlog、植物科普与美食，风格从观察式纪录到治愈系拼贴、从电影级旅行到博物学科学图谱。适合有人文温度、真实质感和传播意图的项目，无论是品牌人文内容、创作者系列 Vlog，还是科普与非遗宣传。

所有子技能共享同一条方法论主线——**以真实感为底线、以视觉锚定防漂移**：题材限定真实的人与生活，用长镜头、自然光、保留瑕疵替代编排与美化，明确拒绝城市宣传片逻辑与 AI 味；同时用风格字符串、参考图或锚图把画风、角色与色调在跨镜头间锁死，应对"大量重复场景下的形象与氛围漂移"这一核心矛盾。

核心方法可概括为一句话：先立事实与视觉锚（文献、档案、锚图、三视图资产），再排叙事结构（三幕、节点、单元节奏），逐镜继承参考生成，最后以旁白与声音设计完成沉浸感交付。

| 手绘风旅行记录 | 旅行照片加手绘角色，做治愈系轻叙事 Vlog | 真实照片叠加 2D 卡通贴纸角色的拼贴旅行短片，六节点叙事 |

## 通用制作流程

1. **选题与素材确认**：明确题材（人物、旅行、工艺、日常、植物、美食）、风格方向与时长；收集真实照片、参考素材或角色形象；判断走纪实拍摄管线还是电影感创作管线，二者互不混用。
2. **事实与视觉锚建立**：梳理事实来源（工艺文献、植物档案、食材溯源、旅行素材），制作视觉锚定资产——标准三视图、18 世纪博物学分析图、锚图或角色双视参考图；禁止用不完整参考图直接生成视频，锚定资产须先行验收。
3. **叙事结构规划**：按题材套用结构模板（三幕 18 节点、起承转合、三段式、六节点叙事、15 秒自动切单元），每段写明情绪弧线与镜头数边界；钩子与高潮锚定到明确时间点。
4. **风格与一致性锁定**：选定画风（手绘贴纸、古版画质感、治愈系、电影感、博物学），用风格字符串逐字锚定所有提示词；锁定矿物颜料色板或暖调配色与明暗光比，跨镜头只引用元素编号不重写属性。
5. **分镜与逐镜生成**：以 2x3 六格分镜矩阵或节奏单元驱动生成，整段自动切镜不拆分；连续场景提取前段尾帧作参考；运动轻缓、转场简单，保留手绘贴纸的静态质感或纪录片的松弛节奏。
6. **旁白与声音设计**：按格绑定纪录片式旁白（高信息密度、深沉音色或口语化）；组间用 J-cut/L-cut 声音桥衔接，切点前引入下组拟音；物理音效（纸笔摩擦、蒸汽油花）与动作对齐，BGM 避让旁白。
7. **一致性验收与交付**：对照锚点审计画风、角色、色调与节奏，按质检分级（可用/返修）处理；补齐封面三规格与各平台分发文案，按平台规则输出成片。

## 选型建议

- 要做真实人物与平凡生活的观察式记录 → **人文纪录短片**
- 要做目的地旅行电影感成片加分发套餐 → **电影级旅行记录**
- 要做手绘贴纸风格的治愈旅行 Vlog → **手绘风旅行记录**
- 要做非遗与传统工艺纪录或宣传片 → **传统手工艺纪录短片**
- 要做晨间咖啡、独居日常等系列化治愈 Vlog → **温馨日常记录短片**
- 要做植物科普向纪录短视频 → **植物生长纪录短片**
- 要做书法、绘画等创作过程展示 → **匠心工艺创作过程短片**
- 要做美食题材的纪实美学短片 → **中华美食美学短片**

## 质量检查

1. 真实感纪律：观察而非编排，保留瑕疵与自然光，无城市宣传片逻辑与 AI 味。
2. 视觉锚一致：角色、画风、色调跨镜头无漂移，全部派生自唯一权威源；画风确定后全系列只使用该风格关键词行。
3. 结构完整：三幕/节点/单元节奏齐备，钩子与高潮到位，镜头数控制在约定范围内（如 5-12 个）。
4. 旁白与画面绑定：逐格台词与画面同步，信息密度与音色符合纪录片调性；对白镜头按规则处理字幕。
5. 声音设计：组间接声音桥过渡，物理音效与动作对齐，BGM 与旁白避让达标，音画无脱节。
6. 转场与运动克制：动作接动作、遮挡接场景，运动轻微不破坏风格质感，慢镜不加速不插帧。
7. 交付完整：封面三规格齐备，各平台文案按节奏差异化，画幅与时长符合目标平台，内容无违禁词汇。
