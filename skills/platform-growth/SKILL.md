# Platform Growth & Analytics

The four metrics are the audience's feedback voice, not a report card: CTR (thumbnail+title), retention (curve), traffic sources, audience-growth videos (new viewers, last 90 days).

## Decision rules
- Never decide on one metric; use 7/30-day trends; rule out algorithmic randomness first; combine dimensions (attractiveness, resonance, conversion, traffic health).
- Low CTR → A/B thumbnail/title; browse context = curiosity hooks, search context = answer-style titles. CTR is a percentage — a hit's CTR drops as impressions scale (3% of a million > 10% of a thousand).
- CTR high + retention drops = thumbnail overpromised → make the thumbnail match the content.
- Retention curve spike = replay segment = strongest resonance → clone it. First-30s losses are critical — fix slow opens, muddled explanations, harsh jump cuts.
- Traffic: heavy external traffic drags average retention — check browse retention separately; low subscription-feed numbers = loyal-audience signal; low suggested traffic = missing continuity (is there a "what's next"?).
- High completion + poor conversion → the content is fine — fix product choice, pitch, CTA, landing; don't blame the video.

## Hit teardown (4 steps)
1. Scope: your hit or a same-tier competitor's (new accounts must study same-scale competitors); grade vs account historical averages.
2. Structure: 3-s hook type (question/suspense/benefit/conflict); shot-by-shot reconstruction (scale/picture/line/duration); commerce standard = problem → show product → solve pain → order CTA; extract the highest-engagement fragment for reuse.
3. Comments: high-frequency keywords (praise/price/usage questions), sentiment, purchase intent; new user questions = next video topics.
4. Conversion: source mix; funnel exposure→cart click→product view→purchase; verify content-product claim match.

## Series and topic library
- Audience-growth videos → 2-3 no-brainer follow-ups; fixed column name + fixed opening format; goal = convert one-hit viewers into subscribers; consistency > frequency; review first 24-72h data and adjust title/thumbnail.
- Topic library: three columns — problem (pain/search term), hook (opening grab), value (viewer gain). Prioritize pain×search, differentiation, controllable production cost.

## Close the loop
- Every retrospective extracts a verified structure into an SOP with documented failure conditions (evidence-backed, reusable, invalidation recorded) — this is the whole point of the review.
- Growth loop: topic (data/comments/search) → script (hook + structure template) → produce → publish → retrospective (4 metrics + 4-step teardown) → SOP → next topic.
