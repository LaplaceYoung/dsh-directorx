# DirectorX skills

Skills in this directory are loaded recursively from `SKILL.md` files.

- `directorx-series-craft/` locks a show's cast, look, and shot rules as a series pack, and revises one shot without re-entering the film.
- `directorx-blocking-craft/` turns roster + start + event sequence into a one-take world-state lock before craft.
- `minimax-h3-prompt-copilot/` absorbs the official H3 handbook (spec, three-part formula, table cases) and the T2VA/I2VA/FL2VA/L2VA/Ref2VA fields, executed with DirectorX tools.
- `trailer-craft/` is the theatrical trailer / 片花 contract: hook → world → raise → title, hard cuts only.
- `continuous-video/` is the native continuity and transition contract for multi-shot video.
- `*-prompt-copilot/` are prompt-quality skills for DirectorX generation. They provide creative guidance only; current provider capabilities and execution remain governed by the local generation tools.
