# H3 使用手册（DirectorX 内化）

来源：官方《MiniMax H3 模型 - 使用手册》全文 + 成片抽帧对照。不搬运体验入口、积分或第三方画布。执行仍走 DirectorX 闸。

## 模型规格（交 generate 时按这个夹）

| 项 | 官方值 |
| --- | --- |
| 时长 | 4–15 秒 |
| 画幅 | 文生 / 全参考：21:9、16:9、4:3、1:1、3:4、9:16；首尾帧：跟图 |
| 分辨率 | **1440p 官方推荐**（16:9 短边 1440 → 2560×1440）。768p 可事后升 |
| 帧率 | 24 |
| 声音 | 每条都有，原生立体声 |
| 首尾帧 | 0 / 1 / 2 张；边长 256–5760；宽高比 5:2～2:5 |
| 全参考 | 图 ≤9；视频 ≤3 段、单段 2–15s、合计 ≤15s；音频 ≤3 且必须配图或视频；混输 ≤12 |
| 成稿 | ≤7000 字符 |
| 格式 | 图 JPG/PNG/WEBP/HEIC；视频 H.264/H.265；音频 WAV/MP3 |

有首/尾帧时不要再传 `role:reference`。全参考和首尾帧是两条入口，不要混。

## 成稿公式（手册第四章）

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

交模型时再收成官方三字段：`integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`。有首尾帧先写对齐句。详见 `base-modes.md`、`ref-mode.md`。

### 参考素材说明

按上传顺序编号：`@图片1` `@视频2` `@音频3`。每份只锁一个职责：

| 用途 | 写什么 |
| --- | --- |
| 人物 | 锁脸/体貌/服装轮廓 |
| 物体 / 产品 | 锁外形与颜色，不许改成假银色 |
| 场景 / 氛围 | 锁空间和光 |
| 首帧 / 尾帧 | 明确说是开头还是结尾 |
| 风格 / 构图 / 分镜 | 只借维度，不抄原图 logo |
| 动作 / 运镜 | 锁轨迹，换主体时写清替换 |
| 音色 / 音频复用 | 复刻时把台词/歌词原文写上 |
| 视频编辑 | 对源片做哪几处增删改 |

没上传就整段跳过。禁止「参考这些图」而不说每张干什么。

### 核心创意

一句话锁：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。默认会切镜。要一镜到底就全文不要 `[Shot N]`。环绕不要写「环绕」，写 `truck left + pan right` 或反过来。

### 画面过程

按 shot 写「想要」：景别、内容、运镜、动作、台词、音效。台词长短必须配得上这个 shot 的秒数。跨镜台词写明从哪镜接到哪镜。画内文字、按钮、招牌必须给出原文。

「不想要」单独写。不要 BGM 就写 `非叙事性音乐：N/A` 或 `non_diegetic_music: N/A`。少写比喻，写看得见的东西。

## 三类入口

| 入口 | 提示词要点 | 抽帧看到的 |
| --- | --- | --- |
| 全参考 | 每份素材写职责 | 源运动在，只改点名的层 |
| 图生（1 张） | 写清首帧还是尾帧 | 从图往前或往后演 |
| 图生（首+尾） | **H3 不会自动加切镜**，只补两帧之间 | 单镜插值 |
| 纯文生 | 外观+空间+动作+风格都写细；大全景+中景+特写分层 | 15s 片多，1440p |

## 手册表格里反复出现的写法

抽过 18 条官方成片（均为 1440p；竖屏电商 1440×2560；时长 6.5–15s）：

- **预告/大片**：图1 风格，图2 人物。先超广角建立，标题原文双引号，硬切。成片「THE STARS WERE LISTENING」与提示词逐字相同。
- **时尚 campaign**：氛围图 / 人物图 / 产品图 / ending logo 分开锁。故事极简，产品嵌进动作。成片从车灯特写进。
- **片头包装**：色块、剪影、具名转场（黑胶圆遮罩、竖切）。成片开场就是圆盘遮罩。
- **MG / 字体**：只允许点名的字。成片「颜色错位」稳住；品牌英文若只靠文字描述会塌成 `TEXT`。字易乱码时把字做成图，写「按图片理解，不要当文字处理」。
- **AR / 世界编辑**：源视频是唯一镜头基础，禁止重生成场景。点名叠加物。成片保留斑马线/灯杆透视，UI 小字仍会糊。
- **短剧**：画幅、正反打、不要字幕写进不想要。成片竹林雪夜特写对得上。
- **电商**：产品图锁外形，模特图锁人。竖屏白棚近景。
- **游戏 UI**：角色图 + UI 风格图。面板原文写进提示词。成片 `RIGHT ARM EQUIPMENT` / `CHRONOS CLAW` 可读，重复项仍会糊。
- **工业**：改背景时写透视、阴影方向、焦点与源片 100% 一致。成片百叶窗+文件柜+红方块还在。
- **风格化**：黏土/赛璐璐/3D 仙侠先锁体块再写一条动作弧。
- **动作迁移**：视频锁动作，图锁替换后的身份。成片厨房递盘对得上。
- **编辑**：一条提示词里并列多条替换。成片同时出现绿书、红沙发、无墨镜、车未燃烧、左侧树。
- **换主体**：猫换狗只改点名对象，机位和拥抱还在。
- **台词改写**：旧台词和新台词都用引号写出，并说略调表演。
- **音色**：写要说的原文 +「音色参考音频1」。

## 容易踩的坑

| 病 | 改 |
| --- | --- |
| 一段话不分段 | 按三段公式拆 |
| 传了图不说用途 | `@图片1 是人物参考` |
| 既要配乐又写不要 BGM | 删一个 |
| 一镜到底却写了很多 Shot | 删 Shot 结构 |
| 要脸一致却不传人 | 上传人物参考并标注 |
| 纯文生写太短 | 外观+场景+动作+风格 |
| 3 秒镜头塞长对白 | 台词对齐镜长 |
| 首尾帧还塞参考图 | 官方拒，身份写进静帧 |

## 其它模型可借的部分

编号参考并声明职责、看得见的时间线、画内文字原文、不想要单独写、台词对齐镜长、首尾帧只插值不加切。字段名仍用该模型自己的，不要把 `integrated_multimodal_description` 塞给不会吃的接口。
