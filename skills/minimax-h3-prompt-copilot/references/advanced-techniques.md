# 运镜与声画（官方词表）

完整模式结构见 `base-modes.md` / `ref-mode.md`。这里只放交稿时要逐字用的词。

运镜必须落在该镜句子里，不要在段尾堆标签。

| 维度 | 写法 |
| --- | --- |
| 变焦 | Zoom In / Zoom Out |
| 推拉 | Push In / Pull Out |
| 摇 | Pan Left / Pan Right |
| 移 | Truck Left / Truck Right |
| 俯仰 | Tilt Up / Tilt Down |
| 升降 | Pedestal Up / Pedestal Down |
| 弧 | Arc Shot |
| 跟 | Tracking Shot |
| 固定 | Static Shot |
| 抖 | Shake Slightly / Shake Strongly |
| 主观 | POV |
| 滚 | Roll Clockwise / Roll Counterclockwise |
| 幅度 | with small amplitude / with large amplitude |
| 速度 | at slow speed / at fast speed |

说话：`(S1)` + `<d>[Language] exact words</d>`。画外音固定句 `says in an off-screen voiceover`，并写唇形闭合。

跨切对白用 `<scenetrans>`。片尾截断用 `<cutoff>`。
