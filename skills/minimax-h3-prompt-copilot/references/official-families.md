# 官方 H3 片种方法（DirectorX 版）

MiniMax 随 H3 发布了八个片种技能。原版绑另一套画布工具，不能原样搬进 DSH。这里只吸收**方法**：先锁资产和节拍，再写成官方 H3 字段，用 DirectorX 工具交片。

分叉用 `directorx_ask`。生成仍过 craft / ready。商标、真人、官方 UI 没有授权素材就停，不要编。

## 极简产品广告

短电商/发布片。默认 10s，H3 一条成片，不要宫格锚当镜头。

1. 问清主变体、画幅、5/10/15s、白科技/暗轮廓/品牌色场/生活场景、画内英文文案。
2. 先出三张独立锚图（主视角、材质或结构、收束构图），不要四宫格——模型会把格子拍进成片。
3. 节拍表：一拍一动作。10s 通常中段一句文案 + 收束一句。单行 3–5 个英文词。
4. 成稿走 T2VA 或 I2VA。产品本体颜色不许改成假银色。
5. 不要：口播带货、复杂屏幕演示、用原产品图直接喂视频（只用锚图）。

## 品牌宣传短片

15–30s。先品牌事实表和出处，再选故事脊，再拍。

- AI/SaaS：意图 → 能力 → 结果 → 证据 → 标
- 实物：揭示 → 使用 → 特写 → 场景 → 结果 → 标
- 服务：情境 → 过程 → 证据 → 承诺 → 标

没有官方 logo/色/产品图就不要发明。H3 片长不够就多镜硬切再 `directorx_canvas_pack`。声称必须能对上用户材料。

## 歌词 MV

字是画面层，不是字幕条。超过 15s 就拆 2–5s 短镜，对齐同一条主音频。

- 角色卡 / 场景卡 / 字体包装卡分开，不要串味。
- 硬切，不要淡。切点落在气口或鼓点，不要切在元音中间。
- 可见字必须和唱的那句逐字相同。
- 续镜用上一镜尾帧当下一镜首帧。最后 `pack` cut。

## 三维动画短片

先锁角色体块和场景体积，再写一条可观察的动作弧。风格写 `3D CG`。物理接触要写清起势和落地。不要一镜塞三场高潮。

## 纸艺定格解说

学习目标 + 一个视觉隐喻。角色、层叠布景、道具分开出锚。动作按定格节拍写（一拍一置换），声景写纸张、剪刀、粘贴。风格 `claymation` 或纸材质描述，不要写成实。

## 拼贴解说

图形块、剪报边、色块层是主体。信息一拍一块。不要假照片人脸。适合概念科普，不适合产品保真。

## 手绘实拍

手、纸、墨的物理声进 `overall_soundscape`。镜头多固定或微推。画中世界和拍摄桌子的空间关系要写清。不要把纸面画成无接缝 CG。

## 双人游戏开场

两套角色锚、一条共同轴。先建立空间再交锋或合作。UI 文字用双引号原样。超过 15s 拆镜硬切。不要抄现成游戏 IP。

## 动态图形 / 字体

负空间、一条连续运动核、点名文字原文。除点名的字以外禁止其它可读字。字易糊就出字图当参考。

## AR / 世界编辑

源视频是唯一镜头基础。禁止重生成场景。只叠加点名的虚拟物，透视和手部跟源片。

## 源片编辑

一条提示词并列多条替换（物、人、光、背景、台词）。每条写旧→新。机位和未点名的层保持 100%。

## 共用纪律

- 片种方法管叙事和资产；H3 字段管成稿。先读本页对应段，再读 `base-modes.md` 或 `ref-mode.md`。
- 一条 H3 成片 ≤15s。更长就分镜 + pack，不要把 30s 塞进一句提示词。
- 官方 Hub 工作流里的专用生成工具不要调用。DirectorX 只用 `directorx_*`。
