# Script Writing

剧本管戏，分镜管拍——这一层只产出故事、场次、动作与台词，不写镜号、不写运镜、不写生成提示词。

## 结构铁律
- Premise 一句话可验证：「如果（激励事件），一个（有缺陷的主角）必须（外部目标），否则（代价）」。写不出冲突和方向 = 还没有故事。
- 每场戏 = 目标 + 冲突 + 转折：结尾时人物的处境或认知必须发生变化；没有转折的场不属于这个故事。晚进场，早离场。
- 升级不平台：每个障碍比上一个更重；冲突复利；没有铺垫的高潮是假高潮。
- 主角同时有 Want（驱动情节的具体目标）和 Need（ tied to 缺陷的潜意识缺失，驱动主题）。有 Want 无 Need = 有情节没意义。
- 弧光先设计后写场：从第一场到最后一场，主角内心变了什么？「他赢了/输了」不是弧光。
- 主题靠选择和可见的代价呈现，永远不让角色说出主题。
- 契诃夫之枪：出现的物件/名字/承诺必须有用，否则删掉。悬念（观众比角色知道得多）优于惊吓。
- 开场画面与结尾画面互成镜像，一帧之内看得见变化。

## 时长预算（写之前先算）
- 有目标时长就把它折成节拍预算再动笔：**台词 ≈ 4.5 字/秒，动作节拍 ≈ 2.5 秒/拍**；3 分钟 ≈ 45-55 拍。
- 节拍按戏剧权重分配到场；写完逐场核对：写超先砍动作节拍，写欠补冲突不补寒暄。
- 容差 ±15%：时长是估算不是秒表，但超出容差就是结构问题，不是误差。
- 格式越短节拍密度越高：短剧开场 3 拍内必须见冲突或异常，没有铺垫的余地。

## 钩子与悬念（短剧生死线）
- 开场钩子：第一拍就是钩子的一部分——具体的承诺、可见的异常、马上到来的冲突。
- 结尾悬念：每个叙事单元的最后一拍必须落在悬念上——一句没说完的话、一个没解释的动作、一声来历不明的响。
- 下一单元的开场必须接住上一单元的悬念——接住不等于立刻解开。
- 爽点/爆点要有戏扛：大纲或计划里承诺的爆点，文本里必须有连续节拍在兑现它；爆点是演出来的，不是说说。

## 台词纪律
- 单句台词 ≤ 35 字，一口气说得完；长句拆成两句，中间插一拍动作或对方反应。
- 谁的话像谁：词汇、句长、口头禅、回避的话题构成声音；盖住名字认不出是谁 = 声音失败。两个角色的台词可以互换 = 声音失败。
- 每句台词至少干一件事：推进情节 / 揭示人物 / 制造张力。一件都不干的删。
- 台词短，动作密：两三句对白就要有一次动作或反应插入；连续四句对白无画面动作就闷了。
- 潜台词优先：外部战术目标与内部情感目标分开；行为可以与台词矛盾（嘴上让座，身子没动）；信息藏进动作，台词只说三分。
- 台词是结构化数据不是散文：每句独立带说话人与语气，动作是独立节拍——这是下游 TTS、时长计算、对账的地基。

## 常见病
| 病 | 症状 | 治法 |
| --- | --- | --- |
| 广播剧 | 整场只有台词 | 每两三句插一拍画面动作 |
| 注水 | 寒暄、让茶、问路占篇幅 | 删。每拍要么推进要么翻转 |
| 演讲癖 | 一人连说四句 | 拆给对手或用动作打断 |
| 全知病 | 台词把信息说尽 | 藏进动作与潜台词 |
| 断头戏 | 结尾平收 | 最后一拍换成悬念 |
| 散文病 | 动作混着引号对白 | 台词归台词、动作归动作 |

## 边界
- 不写镜号、运镜、景别、生成提示词——那是分镜层（storyboard-craft）的活。
- 小说改编走 novel-characters / novel-outline / novel-art / novel-script 全套（有确定性质量门）；本 skill 覆盖一般脚本任务的写法要求。
