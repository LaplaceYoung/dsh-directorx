# 模块填写指南

本文件详细说明每个模块的作用、填写要点和常见陷阱。

模块按功能分组。标记含义：
- `[L1]` = L1精简版包含
- `[L2]` = L2标准版包含
- `[L3]` = L3详尽版包含
- `(L1+)` = L1及以上都包含，但详尽度递增

## 扩充指南

如果发现 AI 有新的弱点需要专门约束，按以下格式追加新模块：
1. 标题用 `## N. 模块名 [适用等级]`
2. 说明"解决什么AI弱点"
3. 给出填写要点
4. 给出"好的 vs 坏的"示例对比

# 一、信息层

## 1. 基础信息 [L2 L3]

**作用**：显式声明所有元参数，让 AI 一开始就建立正确的创作框架。

**填写要点**：
- 时长精确到秒（影响分镜密度：每镜头 1-3 秒为佳）
- 类型用斜杠分隔多个关键词（帮助 AI 定位风格交叉点）
- 字幕/Logo 明确写"无"，比不写更有效（消除默认行为）

**好的示例**：
> 片段时长：15秒。画面比例：16:9。类型：经典格斗游戏回忆向 / 香港九龙红霓虹旧街 / 顶级AAA游戏CG预告片质感。对白：无。字幕：无。

**坏的示例**（太模糊）：
> 一个15秒的格斗视频。

## 2. 整体风格 / 总控要求 (L1+)

**作用**：建立画面质感和创作方向。L1 叫"整体风格"，L3 升级为带行为规则的"总控要求"。

**L1 填法**（一段话）：画面质感 + 色调 + 镜头语言 + 氛围概括。

**L3 填法**（增加行为规则）：
- 在风格声明后，加一段"总控行为规则"：列出必须做和禁止做的核心行为
- 再加一段"动作骨架概要"：用箭头串起核心动作链 `A → B → C → D`

**好的 L3 总控示例**：
> 整体为顶级AAA游戏CG预告片质感...草薙京动作必须短促、狠、爆发强、重心低、前压明显，不做现代MMA，不做拳击花连打。每个动作结束时身体已进入下一动作准备状态，不能重新站稳再攻击。

# 二、角色与场景层

## 3. 角色资产描述 [L2 L3]

**作用**：锁定角色外观一致性。L3 额外加 `{{Mixed N}}` 标记用于多参考图系统。

**填写要点**：
- **逐件描述服装**：颜色 + 款式 + 位置细节（如"胸前黑色口袋条"而非仅"黑夹克"）
- **声明动作气质**：用关键词而非长句（"压迫、短促、爆发、落地重"）
- **L3 必加"特别注意"**：写出该角色最容易出现的问题

**好的示例**：
> 草薙京 {{Mixed 1}}：白色短款高立领夹克，黑色拉链和镶边，胸前黑色口袋条，袖口和下摆黑色装饰边；黑色高领紧身内搭，胸前银灰几何线条；深蓝黑直筒微喇牛仔裤；腰侧金属链条；黑色半指皮革手套；黑色厚底皮靴。动作气质：压迫、短促、爆发。

**坏的示例**：
> 一个穿黑衣服的格斗家。

## 4. 场景资产描述 [L2 L3]

**作用**：锁定环境一致性。

**填写要点**：
- 先写宏观（地形、建筑群），再写微观（积水、纹理、反光）
- 声明"纵深结构"：街道/楼梯/远山的延伸方向（这是空间方向的锚点）

## 5. 空间方向总原则 [L3]

**作用**：解决 AI 跨镜头跳轴、人物左右互换的顽疾。

**填写要点**：
- 锁定攻击方/被攻击方的相对位置
- 指定一个"纵深锚点"（固定的背景参照物，如"中央楼梯始终在街道深处"）
- 明确声明"不能左右互换、不能方向反转"
- 如果有反打镜头，说明"反打是同一运动的反向观察，不是新动作"

**好的示例**：
> 草薙京始终是攻击发起方，克里斯始终在草薙京攻击前方。中央纵深楼梯和最亮红色霓虹招牌始终作为街道深处方向锚点。不能左右互换、不能方向反转。

# 三、视觉控制层

## 6. 色卡与调色 [L2 L3]

**作用**：防止配色混乱、特效无层次。

**填写要点**：
- 主色 + 辅助色 + 禁止色都要声明
- 特效（火焰/光芒等）要分层描述颜色：核心层 → 主体层 → 边缘层

**好的示例**（火焰分层）：
> 火焰颜色分层：金白高温核心、明亮太阳橙、饱和橘红主体、深红边缘、局部暗红烟尘、透明高热扰动、金色火星。

## 7. 光影系统 [L3]

**作用**：写实场景中防止光源混乱、过曝、死白。

**填写要点**：
- 按层级声明：环境光 → 动态主光 → 轮廓光/补光
- 特殊状态（蓄力/爆发）的光影变化要单独说明
- 声明高光保护规则："火焰中心不能死白，五官和服装纹理必须保留"

## 8. 摄影机与镜头语言 (L1+)

**作用**：控制运镜风格与构图。

**填写要点**：
- L1：一句运镜风格 + 稳定/抖动规则
- L2：运镜允许项 / 禁止项
- L3：虚拟摄影机参数（画幅/快门/色彩空间）+ 每个镜头标注焦段

**L3 焦段参考**（扩充版）：
| 焦段 | 典型景别 | 推荐机位 | 推荐运镜 | 适用场景 |
|---|---|---|---|---|
| 16-24mm | 超广角环境 | 高/低机位 | 环绕/快速推进 | 环境交代、压迫感、追逐 |
| 24-28mm | 全景/中景 | 贴地/主观 | 跟随/手持 | 贴地跟随、主观视角、动作戏压迫 |
| 35-50mm | 中景 | 肩高 | 动态跟拍 | 肩高动态跟拍、双人对话、格斗中景 |
| 50-75mm | 中近景/半身 | 平视 | 缓慢推移 | 半身、情绪、肖像 |
| 75-85mm | 特写 | 平视/微仰 | 固定/微动 | 特写、慢动作、贴脸冲击 |
| 85-135mm | 长焦特写 | 远距离 | 压缩感固定 | 压缩感、远观、分离主体与背景 |

焦段选择原则：动作戏多用 24-50mm 表现压迫感；慢动作特写用 75-85mm；环境交代用 16-24mm。

**画幅/比例 → 构图与运镜提示**（按比例调整写法，比例本身在平台UI选，不是提示词维度）：

| 画幅 | 构图重心 | 运镜偏好 | 写法提示 |
|---|---|---|---|
| **16:9 横屏** | 横向调度、双人并排、环境展开 | 横移/横扫/双人同框 | 强调水平线、左右调度、环境纵深 |
| **4:3 / 3:2**（经典/产品片） | 居中为主 + 克制横向（介于横屏与方形之间）；对单个立式主体（瓶/人）天然友好，纵向呼吸足 | 推/拉/小角度环绕，**回避大幅横扫** | 强调居中构图、主体端庄、纵向呼吸；横向运镜要克制 |
| **9:16 竖屏**（短视频/手机） | 纵向引导线、肖像框、单人主体 | 俯拍/仰拍/纵向推拉/上下扫视 | 强调垂直构图、单人居中、上下层次；少用双人并排 |
| **1:1 方形** | 居中对称、几何感 | 固定/微旋/居中推拉 | 强调对称、中心构图、平面设计感 |
| **2.35:1 / 2.39:1 超宽**（电影感） | 极端横向、留白、人物渺小感 | 缓慢横移/长镜头/环境主导 | 强调电影感、横向留白、人物在宽幅中的位置 |

关键纪律：**不同画幅要重新设计构图，不能直接裁切**。竖屏≠横屏裁切（要纵向引导线、肖像框）；4:3≠横屏缩窄（要居中为主、克制横运镜）。如果用户指定画幅，主动按上表调整构图与运镜描述。

# 四、动作与物理层（L3 核心）

## 9. 动作逻辑 [L3]

**作用**：确保动作因果链正确，防止 AI 生成"打一拳—停顿—收回—再打一拳"的割裂节奏。

**填写要点**：
- 用箭头串起完整动作链
- 每个动作说明"为什么这样"（因果关系）
- 大量使用"不是X，而是Y"句式纠正 AI 误解

**"不是X，而是Y"句式范例库**：
- "右拳打空后不是主动收拳，而是顺着出拳惯性继续走完轨迹"
- "飞踢不是为了命中，而是为了高速压近距离"
- "后拉不是逃跑，而是打空后的余势回带与蓄力前的拉位动作"
- "液态化不是融化、黏液、腐烂，而是丝带状的上行流体光带"

## 10. 真实身体力学 [L3]

**作用**：防止动作无重量、断裂、瞬移。

**填写要点**：描述发力链时从下到上：脚（蹬地/踩实）→ 膝（微屈/吸收）→ 腰胯（拧转）→ 肩（前送）→ 臀（挥出）→ 手（爆发）。

## 11. 衣物发丝惯性 [L3]

**作用**：让衣物随运动自然摆动，增加真实感。

**填写要点**：按运动状态列举（冲刺时/旋转时/后拉时/静止时）衣物各部位的延迟与回落。

## 12. 动态环境与真实物理 [L3]

**作用**：让环境对动作产生响应，增强沉浸感。

**填写要点**：
- 动作 → 环境响应（落地→水花；火焰→积水蒸发；冲击波→薄雾推开）
- 分层描述：近景/中景/远景的不同响应程度

## 13. 接触阴影与重量感 [L3]

**作用**：防止人物"飘"在画面上。

**填写要点**：脚下必须有接触阴影、反光、水花；落地时鞋底压开积水，膝盖吸收冲击。

## 14. 曝光滚降与画面精细度 [L3]

**作用**：防止特效区域过曝、细节丢失。

**填写要点**：分近/中/远三层声明必须保留的细节。

# 五、节奏与连续性层

## 15. 动作节奏与变速控制 [L2 L3]

**作用**：控制整体节奏，防止拖沓或过快。

**填写要点**：用时间轴标注每个阶段的节奏（高速连攻 / 慢动作 / 蓄力停顿 / 爆发）。

## 16. 运动中位置连续性 [L3]

**作用**：保证位置变化连续，不跳变。

**填写要点**：用箭头串起完整的位置变化链。

## 17. 连续性与动作完整性 [L2 L3]

**作用**：保证镜头间所有要素连续。

**填写要点**：列出必须保持连续的参数 + 禁止的断裂类型。

## 18. 克里斯动态反应补强 / 对手反应 [L3]

**作用**：防止配角/对手站桩、僵住。

**填写要点**：逐动作描述对手的微反应（头部偏转、肩膀后撤、脚步滑移）。

## 19. 高燃打斗补强 [L3]

**作用**：强化攻击的压迫感和环境反馈。

**填写要点**：每次攻击"几乎命中"（擦面/贴脸/撞肩颈）+ 环境反馈（发丝带起/水花/蒸汽/热雾）。

# 六、稳定性层

## 20. 时间稳定与资产锁定 [L2 L3]

**作用**：对抗 AI 逐帧漂移。

**填写要点**：逐项列出不可变化的细节（发型、服装颜色、道具尺寸、五官比例）。

## 21. 抗AI闪烁 [L3]

**作用**：防止元素逐帧闪烁、忽隐忽现。

**填写要点**：列出不能闪烁的元素（五官、镶边、线条、腰链、招牌文字、电缆）。

# 七、约束层

## 22. 严格禁止 [L1 L2 L3]

**作用**：负面约束是控制 AI 不偏离风格的最有效手段。

**填写要点**：
- **按类别分组**（风格/动作/镜头/特效/文字/一致性/物理），不要散乱罗列
- **L1 用一句话**，L2/L3 用分类列表
- **针对 AI 已知弱点定向约束**（"禁止站桩""禁止跳轴""禁止闪烁"直击缺陷）
- **禁止项越多越好**（L3 的禁止列表占总篇幅 20-30% 是正常的）

**好的分类示例**：
```
禁止横版游戏视角、固定侧视全景、实机游戏感；
禁止现代MMA动作、拳击花连打、武术套路、杂技翻腾；
禁止方向穿帮、人物左右互换、无逻辑跨轴；
禁止火焰漩涡、魔法阵、喷火柱、激光束；
禁止字幕、文字、水印、logo、背景音乐。
```

# 八、输出层

## 23. 文字与标识规则 [L2 L3]

**作用**：控制画面中是否出现文字。

**填写要点**：
- 无文字时：明确写"禁止字幕、文字、水印、logo"（比不写更有效）
- 有标题时：精确拼写 + 字体风格 + 位置 + 停留帧数
- 标题必须声明"不要乱码、不要错误字母、不要额外文字"

# 模块选择速查表

根据场景快速决定用哪些模块。本表只列基础模块；**音频设计、转场机制、错峰时序、段间衔接、特效行为、变身链条、`{{Mixed N}}` 标记、"不是X而是Y"对照库**等高级模块见 `advanced-modules.md`（按场景按需读取）。

| 场景特征 | 必选模块（基础） |
|---|---|
| 任何视频 | 基础信息、整体风格、分镜、**音频设计**（见 advanced-modules.md #24）、负面约束 |
| 有角色 | 角色资产描述 |
| 有场景 | 场景资产描述 |
| 多角色写实动作 | + 空间方向、动作逻辑、身体力学、对手反应 |
| 有特效（火/光） | + 色卡调色、光影系统、曝光滚降（+ 特效行为规则见 advanced-modules.md #28） |
| 多镜头连续 | + 连续性、资产锁定、抗闪烁 |
| 高速运动 | + 衣物发丝惯性、接触阴影 |
| 有转场设计 | + 转场机制（见 advanced-modules.md #25，写入分镜每个镜头末尾） |
| 有标题文字 | + 文字与标识规则（精确拼写） |

**命中以下场景时，额外读取 `advanced-modules.md` 对应章节**：

- 风格化MG/转场设计 → #25 转场机制、#26 错峰时序控制
- 多段视频（超单次生成时长）→ #27 段间衔接锚点
- 火焰/能量/魔法特效 → #28 特效行为规则
- 变身/觉醒/形态切换 → #29 角色状态转换
- 多角色写实CG → #30 `{{Mixed N}}` 标记系统
- 需纠正AI常见错误 → #31 "不是X而是Y"对照库
