# 风格预设库

每个预设包含：核心色调、视觉权重、必须做、禁止做。

选定风格后，将对应预设的内容注入到提示词的"整体风格/总控要求"和"严格禁止"模块中。

## 扩充指南

想新增风格预设时，按以下格式追加：
1. 标题用 `## <编号>. <风格名>`
2. 一句话定义该风格
3. 列出：核心色调 / 视觉权重 / 必须做 / 禁止做
4. 给出该风格最典型的应用案例（一行描述即可）

## 1. 写实实拍胶片质感

**定义**：真人实拍电影质感，胶片颗粒，变形宽银幕镜头。

- **核心色调**：电影级调色，通常去饱和 + 对比度提升；根据场景定（雨后黄昏偏冷蓝暖橙，霓虹夜偏深蓝洋红）
- **视觉权重**：环境氛围 50% + 人物表演 40% + 镜头语言 10%
- **必须做**：
  - 声明具体摄影机/镜头（如变形宽银幕镜头、65mm）
  - 声明胶片质感（颗粒、ISO、卤化银感）
  - 声明景深特征（浅景深、焦外虚化）
  - 声明调色风格（电影级滚降、ACES）
- **禁止做**：
  - 不要动画/卡通渲染
  - 不要过度CG感
  - 不要3D角色
  - 不要体积光过曝
  - 不要塑料质感皮肤

**典型应用**：电影预告片、MV、广告大片

## 2. 纯二维日系赛璐璐 + Editorial MG

**定义**：极简硬边赛璐璐人物 + 高级杂志排版动态图形合成。

- **核心色调**：冷蓝视觉风格（深海蓝、钴蓝、青蓝、黑色、纯白）；红色为**受限强调色**——仅用于酒液/危险信号/单帧攻击闪烁/标题中极少量强调
- **视觉权重**：Editorial杂志排版 60% + 二维赛璐璐人物 30% + 游戏UI与抽象符号 10%
- **必须做**：
  - 大面积负空间、不对称版式、局部超大特写、极细线条、精确对齐
  - **设计一条贯穿全片的核心视觉母题变形链**（母题自选：几何形/物件/符号皆可，需在镜头间反复自然变形。示例之一：刀刃→圆环→月相→蝴蝶→瞳孔）
  - 错峰时序（多元素分 2-3 层级、间隔 2-3 帧依次出现，具体数值视节奏而定）
  - 任何时刻只保留一个主要视觉锚点，辅助动态图形不超过三组，并声明锚点优先级链（如 轮廓>眼睛>道具）
  - 人物/建筑/房间/怪物/道具全部**平面化、剪影化、硬边化、图形化**
- **禁止做**（按七大类，对齐参考提示词）：
  - **写实化类**：不要写实人物、真人质感、三维角色、写实光影、体积光、真实材质、金属真实反射、写实景深、焦外虚化、真实镜头眩光、摄影机晃动、第一人称写实镜头
  - **空间类**：不要立体3D城市、三维空间穿越、隧道效果、三维建筑旋转、真实环绕镜头、电影级真实透视
  - **动作类**：不要普通赛璐璐战斗番、复杂连续打斗、流畅写实格斗、大量人物对战、血腥效果、写实怪物
  - **转场类**：不要普通淡入淡出、柔和溶解转场、连续闪白、随机闪白、无叙事作用的高频闪烁
  - **特效类**：不要过度运动模糊、廉价故障艺术、大量随机乱码、完整英文单词（除非落版标题）、无意义粒子堆叠、所有元素同时高速运动
  - **排版类**：不要廉价科技界面、拥挤排版、随机字体堆叠、常规信息流模板、电商广告感
  - **环境类**：不要大面积霓虹灯、紫粉霓虹配色、赛博朋克写实街景、雨夜写实城市、复杂车辆与人群
  - **一致性类**：不要额外手指、肢体融合、刀具弯曲、刀具尺寸漂移、人物面部漂移、透视畸形、风格漂移、突然写实化

**典型应用**：游戏宣传PV、高级MG动画、时尚动态海报

## 3. 顶级AAA游戏CG预告片质感

**定义**：高精度写实角色、PBR材质、电影级光影、物理真实。

- **核心色调**：根据场景定（九龙霓虹偏鲜红主导 + 冷蓝青灰暗部；写实战斗偏自然色 + 橘金火焰）
- **视觉权重**：角色表演与动作 50% + 环境氛围 30% + 特效 20%
- **必须做**：
  - 角色资产逐件锁定（用 `{{Mixed N}}` 标记，标记系统详见 advanced-modules.md #30）
  - 声明PBR材质（参考下方 PBR 材质词库）
  - 声明电影级光影（ACES调色、体积光、环境遮蔽）
  - 声明真实身体力学（逐关节发力链）
  - 声明接触阴影与重量感
  - 终极必杀/觉醒/神性特效时，从下方"终极特效质感词库"取正面词、排除负面词
- **禁止做**：
  - 不要横版游戏视角、固定侧视全景、实机游戏感
  - 不要卡通渲染、低多边形
  - 不要廉价粒子特效、爆闪白屏
  - 不要现代MMA动作（如果是经典格斗角色）
  - 不要人物穿身、距离跳变、攻击轴线丢失
  - 终极特效不要柔和圣光感（详见下方词库）

**典型应用**：游戏CG预告、格斗游戏大招演出、角色登场动画

### 附：终极特效质感词库（适用于必杀/觉醒/神性特效）

涉及终极特效时，**必须**从正面词库取 3-5 个、从负面词库明确排除：

| ✅ 正面质感词（取） | ❌ 负面质感词（排除） |
|---|---|
| 凌厉、锋利、切割感 | 柔和、温润 |
| 硬边轮廓、锐利光束 | 圣洁、治愈、圣光感 |
| 切割感光刃、强烈方向性 | 柔雾、均匀泛光、扩散 |
| 高对比明暗分离 | 明确发光点、光球 |
| 攻击性、压迫感、危险感 | 能量核心、圆盘光源、灯泡感 |
|  | 舞台灯效、廉价闪烁 |

**关键纪律**：观众**看不到**明确发光点/光球/光源核心，**只能**看到从角色轮廓后方迸发的逆光边缘。

### 附：PBR 材质词库（按类别）

- **皮肤**：真实皮肤纹理、毛孔、肌肉高光、湿润反光、次表面散射
- **布料**：真实褶皱、垂坠、编织纹理、磨损、油污
- **金属**：拉丝、氧化、锈迹、真实反射、各向异性高光
- **液体**：流动、涟漪、折射、焦散、粘稠度
- **能量体/神纹**：贴合肌肉走向、自发光纹路、放射结构、能量流动

## 4. 赛博朋克写实街景

**定义**：霓虹浸染的潮湿未来都市，写实质感。

- **核心色调**：深蓝 + 洋红 + 青色霓虹 + 湿地反射；暖色仅用于招牌/窗户
- **视觉权重**：环境氛围 50% + 人物 30% + 霓虹细节 20%
- **必须做**：
  - 声明潮湿表面反射（水坑、雨痕、油污）
  - 声明霓虹光源分层（近景招牌/中景楼群/远景全息）
  - 声明空气感（雾、蒸汽、雨、体积光）
- **禁止做**：
  - 不要紫粉霓虹过饱和（保持克制）
  - 不要干净整洁的未来感（要旧、脏、生活痕迹）
  - 不要塑料质感
  - 不要无雾的清晰远景

**典型应用**：科幻短片、赛博朋克游戏、未来都市氛围

## 5. 水彩/手绘插画风格

**定义**：传统媒介质感，笔触可见，色彩柔和晕染。

- **核心色调**：柔和自然色，有限调色板（3-5色为主），留白
- **视觉权重**：笔触与肌理 50% + 主体 40% + 留白 10%
- **必须做**：
  - 声明具体媒介（水彩/水粉/墨水/彩铅）
  - 声明笔触特征（湿画法晕染/干笔飞白/线条粗细变化）
  - 声明纸张质感（冷压/热压、棉浆/木浆）
- **禁止做**：
  - 不要数字绘画的平滑渐变
  - 不要锐利硬边（除非是针管笔线条部分）
  - 不要照片级写实
  - 不要均匀饱和的颜色

**典型应用**：绘本动画、艺术短片、诗意氛围

## 6. 黏土/定格动画风格

**定义**：实体材质感，手工痕迹，微缩世界。

- **核心色调**：柔和饱和的童话色，哑光质感
- **视觉权重**：材质肌理 50% + 角色表演 40% + 微缩布景 10%
- **必须做**：
  - 声明黏土类型（油性黏土/纸黏土/聚合物）
  - 声明指纹和工具痕迹可见
  - 声明微缩景深（移轴镜头感）
  - 帧率声明（12fps 定格感）
- **禁止做**：
  - 不要平滑CG表面
  - 不要完美对称
  - 不要数字绘制的光影
  - 不要写实比例（要微缩布景感）

**典型应用**：儿童内容、创意广告、艺术项目

## 7. 产品广告片 / Editorial Tech

**定义**：高端产品摄影质感，影棚环境，材质细节驱动，双色调戏剧光。参考案例4（透明鼠标产品片）。

- **核心色调**：单色暗调主导（pitch-black / 深灰），双色调强调光（如 vibrant blue + warm neon orange）；色温对比是高级感来源
- **视觉权重**：产品材质细节 50% + 光影互动 35% + 环境/反光 15%
- **必须做**：
  - **参考图锚定**：用 `<Picture N>` 或 `{{Mixed N}}` 锁定产品来源，声明 `in its original scene`
  - **环境恒定声明**：用 `The environment is constant throughout` 一句话锁定环境，避免漂移（这是产品片最关键的防崩坏技巧）
  - **材质母题（Material motif）**：声明一个贯穿全片的材质特征（如 `glowing internal metallic micro-components and glossy acrylic refractions`），所有镜头围绕它表现
  - **双色调光影作为身份**：声明两种对比色作为主光，贯穿全片（duotone rim lighting）
  - **每个镜头明确运镜动词**：push-in / glides along / rotating in a slow orbit / sweep across
  - **光影与材质互动**：每个镜头声明光如何照射材质（refracting through / sweeping across / flaring along edges）
  - **音频分层 + 收束**：环境低频 + 触感拟音（机械点击）+ 切镜音效（glassy whoosh）+ 收束设计（resolves to near-silence）
- **禁止做**：
  - 不要环境漂移（背景必须全程恒定）
  - 不要产品形态变形（锁定参考图）
  - 不要廉价电商广告感（要 Editorial 杂志级）
  - 不要过曝高光（保留材质层次）
  - 不要杂乱环境（保持 studio void 的纯净）
  - 不要普通日光（要戏剧性双色调）

**典型应用**：科技产品广告、概念产品片、材质展示动画、品牌主视觉

## 8. 中国传统老字号 / 国潮奢华（Chinese Heritage Luxury）

**定义**：中国传统老字号品牌的喜庆厚重质感，中国红亮面 + 奢华金浮雕，影棚级荣誉背书氛围。参考案例：晋善晋美·1915 酒瓶产品片。

- **核心色调**：
  - 主色 = 中国红亮面釉质 + 奢华金（香槟金/古铜金）
  - 辅助色 = 暖白/米金背景、金色粒子光晕、暗红绸缎
  - **禁止色** = 冷蓝、紫粉、纯黑死黑、廉价电商饱和红
- **视觉权重**：产品材质细节 45% + 金色光影互动与浮雕纹理 35% + 喜庆氛围（红绸/粒子/展台）20%
- **必须做**：
  - 声明"材质母题"并贯穿全片不可变（如"扁方红亮面瓶身 + 金盖 + 金椭圆铭牌"三要素）
  - 双色调光影作为身份：暖金主光 + 中国红环境反射光（duotone warm-gold + China-red）
  - 每镜头明确运镜动词（push-in / orbit / glide）
  - 光影与材质互动（金光扫过浮雕铭牌 / 红釉高光流动 / 金粒子环绕瓶身）
  - 环境恒定声明（防漂移）
  - "老字号荣誉"氛围用金色浮雕纹理 + 暖光高反射 + 金色光晕（非廉价特效）
- **禁止做**：
  - 不要现代极简电商广告感（要老字号厚重质感）
  - 不要冷色调 / 赛博 / 科技感
  - 不要瓶身形态变形（锁定参考图）
  - 不要廉价粒子、廉价烟花（要金色光晕质感）
  - 不要过曝死白（保留金浮雕层次）
  - 不要完整佛像/人像抢戏（文化元素建议作浅浮雕纹理而非完整场景）

**典型应用**：中国传统酒类/茶类/老字号品牌主视觉、节庆礼盒广告、百年品牌荣誉片、国潮奢华产品片。

**配套音频色调词库**（平台原生音频时选用）：
- 典雅厚重：古筝、编钟、古琴、箫
- 喜庆克制：中国鼓、磬、木鱼（慎用唢呐，易跑偏廉价节庆）
- 收束：金磬余韵、归于近寂静

## 9. 自定义风格

当用户的风格不在以上预设中时，按下方模板现场编写。**编写流程见 SKILL.md 第二步**：先在回复里写出预设全文 → 问用户是否永久保存 → 用户同意后写入本节。

**自定义预设模板**（填写后可永久保存）：

```
## N. <风格名>

**定义**：<一句话定义>

- **核心色调**：<主色 + 辅助色 + 禁止色>
- **视觉权重**：<层A X% + 层B Y% + 层C Z%>
- **必须做**：
  - <该风格的关键特征1>
  - <该风格的关键特征2>
  - <该风格的关键特征3>
- **禁止做**：
  - <容易跑偏的点1>
  - <容易跑偏的点2>
  - <容易跑偏的点3>

**典型应用**：<场景描述>
```

编写自定义预设后，询问用户："这个风格预设是否要永久保存到库中供下次使用？"
