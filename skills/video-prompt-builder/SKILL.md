# AI 视频生成提示词构建器

一个根据用户需求，匹配并填充最合适的视频生成提示词模板的 skill。

支持三个复杂度等级（对应不同的控制粒度），覆盖从快速创意探索到逐帧精确控制的全场景。

## 工作流程

当用户触发本 skill 时，按以下步骤进行。整个流程是**引导问答式**的——通过逐项确认关键参数，匹配最合适的模板。

### 快速通道（适用于 L1 / 描述已清晰的需求）

如果用户一句话已含足够信息（如"5秒写实动作片预告，英文，单主角"或"透明鼠标的产品广告片"），可直接推断全部参数并跳到第三步组装，仅在输出时标注"我按 L1+写实+英文 推断，如需调整告诉我"。只有信息缺失时才回到下面的逐项问答。

### 第一步：收集核心参数

向用户确认以下 9 个关键参数（可用 `AskUserQuestion` 工具批量询问，也可逐项自由对话）：

| 参数 | 作用 | 常见选项 | 询问方式 |
|---|---|---|---|
| **复杂度等级** | 决定使用哪套模板骨架 | L1 精简版 / L2 标准版 / L3 详尽版 | 总问 |
| **输入模态** | 决定文生/图生/v2v范式，影响留白程度（见 advanced-modules.md #32） | 纯文生 / 单图参考 / 多图融合 / 参考视频重绘(v2v) | 总问 |
| **视觉风格** | 决定风格预设和约束方向 | 写实实拍 / 二维动画 / AAA游戏CG / 产品广告 / 其他 | 总问 |
| **时长** | 决定分镜密度与是否分段（主流平台单次上限5-16秒，详见 advanced-modules.md #27 平台表） | 5秒内 / 5-15秒 / 15秒以上（需分段，按平台上限拆） | 总问 |
| **角色/主体数量** | 决定是否需要一致性锁定模块 | 0-1个 / 2-3个 / 4个以上 | 总问 |
| **音频策略** | 决定音频模块是功能性还是冗余（详见 advanced-modules.md #33） | 无声视频 / 平台原生音频 / 后期自配只要画面 | 总问 |
| **段数/在作品中的位置** | 决定是否需要段间衔接锚点 | 单段 / 多段（第N段，共M段） | **条件问**：先按"时长+平台"自动推导单/多段，仅推导为多段时才追问 N |
| **目标AI平台**（可选） | 影响语言、格式、负面字段（见平台格式规则） | Kling / Sora / Vidu / Runway / Pika / 通用 | 可选，多可推断 |
| **输出语言** | 最终提示词语言 | 中文 / 英文 / 双语 | 可推断 |

> **认知负荷说明**：虽然维度从 8 升到 9，但"每次必问"仍约 6 个——"段数"条件化（自动推导）抵消了"音频策略"的新增；"平台"和"语言"多数可推断。

**关于复杂度等级的推荐**——如果用户不确定，按以下规则推荐：

- **L1 精简版**（~300字，3-5个镜头）：适合快速创意探索、概念测试、风格不明确时的试错、产品广告短片。模板有 6 个核心模块。
- **L2 标准版**（~1500-2500字，6-8个镜头）：适合风格化动画、MG动画、有明确叙事的预告片。模板有 12 个模块。
- **L3 详尽版**（~5000字+，8-15个镜头）：适合多角色格斗、物理交互复杂、需要极高连续性的写实CG。模板有 23 个模块。

更详细的等级对比见 `references/levels.md`。

### 第二步：选择风格预设

根据用户选择的视觉风格，从 `references/style-presets.md` 中读取对应的预设（当前内置 8 个：写实胶片/二维赛璐璐+MG/AAA游戏CG/赛博朋克/水彩/黏土/产品广告/中式老字号）。预设包含：

- 该风格的核心色调规则
- 推荐的视觉权重比例
- 风格特有的"必须做"和"禁止做"清单

**如果风格不在预设库中，按以下三步走自定义流程**（不要跳步）：
1. **现场编写**：按 `style-presets.md` 末尾的自定义预设模板，在**回复里**写出预设全文（定义/核心色调/视觉权重/必须做/禁止做/典型应用）。编写时即可直接用于组装提示词，**无需等落盘**。
2. **询问用户**：写完后问"这个风格预设是否要永久保存到库中供下次使用？"
3. **落盘（仅当用户同意）**：用户同意后，用 Edit 工具把预设写入 `style-presets.md` 的"自定义风格"区域，编号顺延（如 #10、#11）。用户不同意则只保留在本次对话，不写入文件。

### 第三步：组装提示词

读取 `references/modules.md`（基础模块）了解填写指南，然后按所选等级的模板骨架组装提示词：

1. 从 `references/levels.md` 读取对应等级的骨架（中文或英文骨架视输出语言而定）
2. 填入用户确认的参数（时长、风格、角色等）
3. 套用风格预设的约束清单（L1 从"必须做"里挑 2-3 项最关键的，不要全塞）
4. 根据角色数量决定是否展开"角色资产描述"模块
5. 根据是否有动作戏决定是否展开"动作逻辑""真实身体力学"模块
6. **按场景命中条件，额外读取 `references/advanced-modules.md` 的对应章节**（音频设计/转场机制/错峰时序/段间衔接/特效行为/变身链条/`{{Mixed N}}`/"不是X而是Y"对照库）
7. **按输入模态分支**：
   - **图生视频（单图/多图-图生型）**：读取 #32，按其"模板差异表"对骨架做图生转换（L1 改"整体风格/场景概述/分镜"三处；L2/L3 按差异表逐模块转换），应用留白原则，并在 Shot 1 加首帧锚定 `opens exactly on image N`
   - **参考视频重绘(v2v)**：读取 #32 末尾的 v2v 范式，**强制降级到 L1 风格描述**（运动交给源视频，提示词只写风格覆盖层）
8. **按音频策略处理音频模块**（详见 #33）：
   - **无声视频**：音频模块不写内容，只在基础信息声明"对白/字幕/水印/音乐：无"（消除 AI 默认行为）
   - **平台原生音频**：正常写完整音频设计（#24），强调踩点/拟音/分层
   - **后期自配**：音频模块写"仅画面，音频后期制作"或不写音频，重心全放画面

**模块选择原则**：宁可少选，不可堆砌。提示词A（精简）之所以有效，正是因为它不堆砌模块。一个错误的倾向是把所有模块都塞进每个提示词——这会让 AI 信息过载。根据等级严格裁剪模块数量。

### 第四步：输出与交付

输出格式：

1. 先用简短摘要说明"已选择 X 等级 + Y 风格，共 N 个模块、约 N 字"，让用户快速了解产出
2. 然后输出完整提示词（用代码块包裹，方便复制）
3. 最后提供"可调整项"清单——告诉用户哪些地方最值得根据实际效果微调

如果用户要求双语，先输出主语言版本，再输出翻译版本。

### 第五步：迭代优化

提示词交付后，主动询问：

> "如果你把这段提示词喂给 [目标AI] 后效果不理想，告诉我哪里出了问题（比如'角色脸漂移''动作断裂''风格不统一'），我可以针对性调整对应的模块。"

这是 skill-creator 推荐的核心循环：**草稿 → 测试 → 反馈 → 迭代**。

## 关于扩充

本 skill 的设计目标是**可持续扩充**。用户积累更多案例后，可以在以下位置添加：

- **新的风格预设** → `references/style-presets.md`
- **新的真实案例** → `references/examples.md`
- **新的基础模块** → `references/modules.md`
- **新的高级模块**（音频/转场/特效/变身等，发现 AI 新弱点时） → `references/advanced-modules.md`
- **新的等级**（如果有特殊场景） → `references/levels.md`

每个 references 文件的开头或末尾都有"扩充指南"说明格式规范。

## 重要设计原则

这些原则来自对 4 个真实高质量视频提示词的逆向分析，是本 skill 的理论基础。每条标注适用等级——**L1 只需遵循标了 `[全等级]` 的原则**，其余按等级启用，避免 L1 膨胀：

1. **模块化分块** `[全等级]` — 每个关注点独立成块，避免信息混杂导致 AI"顾此失彼"
2. **单一视觉锚点** `[全等级]` — 每帧只允许一个主要焦点，防止画面崩塌
3. **音频与画面双轨道** `[全等级]` — 音乐驱动型视频中，音频踩点与画面同等重要（见 advanced-modules.md #24）
4. **错峰时序** `[L2+]` — 多元素出现时分层级、分帧间隔，禁止所有元素同时运动（见 #26）
5. **图形匹配转场** `[L2+]` — 前镜头的某个元素自然变形为后镜头的主体结构（见 #25）
6. **资产锁定 + 抗闪烁** `[L2+]` — 逐项列出不可变化的细节，对抗 AI 逐帧漂移
7. **空间方向锁定** `[L3]` — 防止跨镜头跳轴/人物左右互换（多镜头写实必要）
8. **逐关节发力链** `[L3]` — 描述动作时从脚→膝→腰→肩→臂→手（写实动作必要）
9. **特效行为独立约束** `[L3]` — 火焰/能量的触发、蔓延、分层、释放各有规则（见 #28）
10. **状态转换链条** `[L3]` — 变身/觉醒必须完整分步，禁止跳切（见 #29）
11. **"不是X，而是Y"纠正句式** `[L2+]` — 针对 AI 已知错误主动纠正（对照库见 #31）
12. **负面约束分类** `[全等级]` — 按类别组织禁止清单（风格/动作/镜头/特效/文字/一致性/物理）
13. **复杂度与约束量成正比** `[全等级]` — 角色越多、动作越复杂、镜头越多，需要的约束模块越多

详细的模块清单和填写指南见 `references/modules.md` 和 `references/advanced-modules.md`。
