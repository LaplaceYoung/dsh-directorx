# 一致性与控制清单

## 先立锚点，后写镜头

跨镜头一致性的关键是先建立可复用锚点，再进入逐镜生成：

- 角色锚点：年龄感、脸型、发型、服装、配饰、体态、声音方向；
- 场景锚点：空间结构、主光源方向、色调、天气、标志性物件；
- 道具锚点：材质、颜色、磨损、尺寸关系。

这些锚点一旦确定，后续镜头只引用锚点，不重新描述全部细节。

## 参考素材逐份声明用途

多张参考图或多段参考视频同时存在时，逐份说明：

- 哪张图定义角色身份；
- 哪张图定义服装或场景；
- 哪段视频只提供运动参考；
- 哪些素材明确不进入最终画面。

避免写“参考这些图片生成……”，因为模型无法判断每张图的职责。

## 首尾帧是运动路径，不是两张贴图

图生视频时：

- 首帧定义运动的起点状态；
- 尾帧定义运动结束后应达到的状态；
- 提示词正文只描述从首帧到末帧之间要发生的变化，不重复图中已有内容。

## 参数与提示词分离

画幅、时长、分辨率、模型档位、声音开关属于请求参数，不应混进提示词正文。
提示词只负责创作内容，参数由设置界面或 API 字段承载。

## 逐镜交接

系列镜头之间，把上一镜结束时的位置、姿态、道具状态写入下一镜的开头约束，
避免相邻镜头出现“瞬移”或身份漂移。

## 生成后检查

- 角色五官、服装、身高是否一致；
- 左右手、手指、文字、图案是否出现明显错误；
- 运动是否符合物理限制；
- 首尾帧与计划是否匹配；
- 声音事件是否落在对应画面上。
