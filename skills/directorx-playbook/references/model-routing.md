# 模型能力路由

## 先判断任务类型

1. 只回答图片内容 → 视觉模型；
2. 从文字或参考图生成单张图 → 图像模型；
3. 从文字、首尾帧或参考图生成视频 → 视频模型；
4. 生成旁白、对白或简单音效 → 音频模型；
5. 需要先查影视知识再决定参数 → 先调用知识库工具。

## 按协议选择配置方式

- 端点是标准聊天补全协议时，视觉能力选择聊天协议；
- 端点是图像生成协议时，图像能力选择图像协议；
- 视频任务如果支持提交任务并轮询状态，选择对应的异步协议；
- 端点没有正式协议时，先用模拟模式跑通流程，再接真实服务。

## 能力开关规则

- 未启用的能力不注册工具，模型也不应尝试调用；
- 修改配置后工具集合热更新，无需重启；
- 一个能力失败不影响其他能力继续工作。

## 降级顺序

生成失败时按以下顺序处理：

1. 检查 Base URL、API Key、模型名是否匹配；
2. 检查参数是否在模型支持范围内；
3. 简化提示词，只保留一个核心变化；
4. 切换模拟模式确认链路；
5. 报告明确错误，而不是无脑重试。
