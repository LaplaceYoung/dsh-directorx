# 一句话生成广告配方

核心原则：**agent 负责理解、创意、分镜、提示词与合成；所有图像/视频/音频生成一律占位排队（mossland_prepare_generation），由用户在 WebUI 执行**。绝不直接调用 image_generate / video_generate 花钱。

工具：`bash`（pandoc 读产品介绍）+ `view_image`（看产品图）+ `ask`（澄清与拍板）+ `knowledge_search` / `knowledge_read` / `skill_read`（研究广告方法论）+ `mossland_prepare_generation`(占位排队) + `video_edit` / `bash ffmpeg`（用户执行完生成后的合成）。

## 阶段序列

1. **读**（不生成）—
   - `bash` 用 `pandoc -t plain` 读产品介绍文档；`view_image` 逐张看产品图/品牌素材；
   - 在回复里给出**产品理解**：是什么、核心卖点（排序）、外观/质感/品牌色、适用人群，以及从材料里能推断和不能推断的事。

2. **问**（需求澄清，不生成）— 用 `ask` 一次性问清关键缺口（给默认选项方便用户快答）：
   - 目标受众与投放平台（决定画幅/时长/节奏，如抖音 9:16 15-30s）；
   - 风格基调（高级感/活力/剧情反转/实测种草…）；
   - 必须出现与必须回避的元素、是否有品牌口播/标语、交付截止时间倾向。

3. **研**（不生成）— 基于知识库说明"好广告长什么样"：
   - `knowledge_search` + `knowledge_read` 读 105-commercial-pipeline、11-genre-commercial 相关文章；`skill_read` 读 short-video / motion-design；
   - 在回复里用 3-5 条**浓缩成对本片的判断**（不是照抄理论）：如 3 秒钩子怎么兑现、卖点如何视觉化、单一 CTA 等。

4. **案**（创意方向，不生成）— 给出 **3 个有差异的创意方向**：
   - 每个方向：一句话概念 + 叙事结构（钩子→展开→CTA）+ 视觉风格 + 为什么适合这个产品与受众；
   - `ask` 让用户拍板选一个（或混搭/改）。

5. **本**（脚本+分镜，不生成）— 选定方向后：
   - 写完整脚本（含口播文案/字幕文案）；
   - 按 skill 要求出**逐镜分镜表**：镜号 / 时长 / 画面内容 / 运镜 / 音频（BGM/音效/口播）/ 字幕；
   - 每镜附**完整生成提示词**与参数（画幅、时长、首帧/参考图引用），以占位清单列出，`ask` 请用户审定分镜后再排队。

6. **队**（占位排队，用户执行）— 分镜确认后：
   - 每个生成任务用 `mossland_prepare_generation` 排队：video（各镜头）、image（需要首帧锁定的关键帧/产品特写）、audio（BGM/口播 TTS）；
   - 提示词必须即拿即用：产品外观锚点（从产品图提取的措辞）、风格锚、镜头语言全部写全；
   - 明确告诉用户：这些任务在 WebUI 生成面板里，由用户逐个执行；执行完回来继续。

7. **收**（合成，不花生成预算）— 用户执行完队列后：
   - 用 `video_edit` / `ffmpeg` 按分镜顺序拼接，贴 BGM、口播、字幕，校准响度与画幅；
   - 成片落 `generated/final/ad_<产品名>.mp4`；如个别镜头用户没跑或不满意，指出缺哪几镜并可修订其提示词重新排队。

## 门禁
- 全程零直接生成：image_generate / video_generate 在本配方下一律不用，全部走 mossland_prepare_generation。
- 阶段 2 的澄清不可跳过（用户明确说"你自己定"时才可用默认值并说明选择理由）。
- 阶段 4 未经用户拍板不得进入脚本；阶段 6 未经用户审定分镜不得排队。
- 排队项的提示词必须自包含（用户执行时看不到上下文）：产品描述、风格、画幅、时长、参考素材路径全部写入 prompt 或 parameters。
