# 拉片 + 主体替换（通用）

适用：用户给出源片（或源片名称）并要求换成另一个主体。不是某个品牌的专用流程。

1. 析 — 这是复刻，不是新拍。列出源片与替换主体。
2. 研 — 拉片要记下的字段；主体替换纪律（锁摄影、换身份）。
3. 拉片 — 有源文件则逐镜拆；没有则按该类型发布片骨架占位，并标明待对帧。
4. 问 — 源片版本、替换范围、占位批次。
5. 位 — 1:1 占位，提示词写入替换主体，规格写推荐模型。禁止源商标。

用 brief → knowledge/skill → 拉片表 → propose 占位走完即可，不要为某一个源片写死分支。
