# 拉片 + 主体替换（通用）

适用：用户给出源片（或源片名称）并要求换成另一个主体。不是某个品牌的专用流程。

1. 析 — 这是复刻，不是新拍。列出源片与替换主体。
2. 研 — 拉片字段与主体替换纪律（锁摄影、换身份、禁源商标）。
3. 拉片 — 有源文件则 `directorx_video_analyze` / 抽帧逐镜拆。没有则按该类型发布片骨架占位并标「待对帧」；公开评论/分镜只作结构参考。
4. 问 — 源片版本、替换范围（人 / 产品 / endcard）、占位批次。
5. 位 — 1:1 `directorx_propose`（提示词写入替换主体，规格写推荐模型），`directorx_canvas_shotlist` 签字。禁止源商标。

每镜拉片表：镜号 / 时长 / 景别 / 运镜 / 剪点 / 源主体动作 / 替换主体身份 / 产品语义 / 连续性。

用 brief → knowledge → 拉片表 → propose → shotlist 走完即可，不要为某一个源片写死分支，也不必走 orchestrate。
