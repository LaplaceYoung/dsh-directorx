# 预告片配方（25-45s）

预告片不是短片缩写。观众只拿到承诺，拿不到结局。

制作方式：**单元化制作** + 画布硬切组装。

## 阶段序列
1. **路** — `directorx_skill_route`，读 `trailer-craft` 与返回的文章 id。
2. **研** — 预告片语法：钩子开场、世界一眼、冲突升级、片名砸下。日漫热血先锁原创角色锚，专名不进生成。
3. **问** — 时长（默认 35s）、画幅、片名卡、风格分期（复古赛璐璐 / 剧场版数字光）。
4. **案** — 片花节拍表 + 16:9 角色设定表 + 每镜一张冲击帧。每镜 4–6 秒，一个动作弧。
5. **稿/位** — 每镜 `prompt_plan` → `prompt_craft` → `generate_ready` → `propose` / `canvas_shotlist` 签字。
6. **切** — 成片后 `directorx_canvas_pack` `transition=cut`。`directorx_canvas_sheet` 出接触表给评审。禁止 fade。
7. **交** — 质检冲击帧是否可读，再 `directorx_skill_capture`。

## 门禁
- 第一镜必须是钩子，不能是演职员表或日常建立。
- 不要在预告片里兑现高潮结局。
- 动态画面禁止叠化。片名卡可以是最后一刀硬切。
- 有人名必须先出 16:9 设定表再拍。
