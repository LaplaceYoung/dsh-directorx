# 《祝福》半小时剧案例

用户原话：「改编鲁迅的小说祝福为半小时ai电视剧」

**必须**调用 `directorx_case_run`。骨架拍板（抽核 / 近原 / 重写）未经确认不得扩写分集。

## 流程
1. 析 — 体量 1800s，题材礼教吃人
2. 研 — 1924《彷徨》情节核 + 时长预算
3. 问 — 改编幅度、单集/两集、占位批次
4. 角色 — 祥林嫂少/暮、鲁四老爷
5. 位 — 设定图 + 六段关键戏剧镜占位

不直拍狼吃阿毛；不出现鲁迅肖像；不抄既有影视造型。
